Was ist llms.txt? Die Datei, die KI Ihre Website erklärt

llms.txt ist eine einfache Textdatei im Stammverzeichnis Ihrer Domain (ihreseite.de/llms.txt), die Ihre Website der KI in klarer, maschinenfreundlicher Sprache beschreibt und auf Ihre wichtigsten Seiten verweist. Stellen Sie sie sich als „README für KI“ vor.

Wozu es sie gibt

robots.txt sagt Crawlern, worauf sie zugreifen dürfen; eine Sitemap listet URLs auf. Keine von beiden sagt einer KI, worum es auf Ihrer Website geht oder was sie zitieren soll. llms.txt schließt diese Lücke – eine knappe, kuratierte Zusammenfassung, die KI schnell lesen kann.

Was hineingehört

  1. Eine kurze Beschreibung Ihres Unternehmens oder Ihrer Website
  2. Die wichtigsten Fakten: was Sie tun, wo, Öffnungszeiten, Kontakt
  3. Links zu Ihren wichtigsten Seiten, jeweils mit einer einzeiligen Beschreibung
  4. Optional die Inhalte, auf die sich KI am meisten stützen soll

Garantiert sie eine Zitierung?

Nein. Sie ist ein Signal unter mehreren – strukturierte Daten, Crawler-Zugang, Einheitlichkeit. Aber sie macht Sie zu einer einfacheren, klareren Quelle. Was ist AEO?

So fügen Sie sie unter WordPress hinzu

Sie können sie von Hand anlegen, doch sie veraltet, wenn sich Ihre Website ändert. Ein Plugin kann sie automatisch erzeugen und aktuell halten. AEO für WordPress

Häufige Fragen

Ist llms.txt ein offizieller Standard?

Eine entstehende Konvention, die zunehmend anerkannt wird. Sie kostet nichts und kann nur helfen.

Wo genau liegt die Datei?

Im Stammverzeichnis Ihrer Domain: https://ihreseite.de/llms.txt

Ist das dasselbe wie robots.txt oder sitemap.xml?

Nein. Diese regeln den Zugriff und listen URLs. llms.txt beschreibt und kuratiert Ihre Website für KI.

Hat Ihre Website eine llms.txt – und braucht sie eine?

Ohne Registrierung.
