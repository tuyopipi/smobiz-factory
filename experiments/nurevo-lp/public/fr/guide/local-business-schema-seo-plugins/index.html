Ajoutez un schema d'entreprise locale à Yoast SEO, Rank Math ou AIOSEO, gratuitement

Gardez votre plugin SEO. Nurevo AEO, un plugin WordPress gratuit, ajoute les informations dont l'IA a besoin pour décrire une entreprise locale (adresse, téléphone, horaires, type d'activité, services et FAQ) aux données structurées que Yoast SEO, Rank Math ou All in One SEO publient déjà, sans les dupliquer.

Dernière vérification : octobre 2026. Les offres des plugins SEO évoluent ; consultez les pages officielles de chaque plugin pour leurs fonctions actuelles.

Ce que publient les versions gratuites de Yoast SEO, Rank Math et AIOSEO

Quand une IA répond à une question comme « quel dentiste près de chez moi est ouvert le samedi », elle a besoin de faits lisibles sans deviner : quel type d'activité, où, quel numéro appeler, quels horaires. Sur WordPress, ces faits viennent généralement du JSON-LD de votre plugin SEO.

Les versions gratuites publient votre site comme une Organization avec un nom, une URL et un logo. La plupart des informations locales se trouvent dans des extensions ou offres de SEO local payantes. En octobre 2026 :

Ce n'est pas une critique de ces plugins : ils s'occupent du référencement, et Nurevo AEO est conçu pour fonctionner à côté d'eux, pas à leur place.

Comment Nurevo AEO complète les manques sans dupliquer le schema

Nurevo AEO n'imprime pas un second jeu de données structurées à côté de celui de votre plugin SEO. Il se branche sur le filtre que chaque plugin utilise pour construire son graphe JSON-LD (wpseo_schema_graph pour Yoast SEO, rank_math/schema/validated_data pour Rank Math, aioseo_schema_output pour AIOSEO) et n'ajoute que ce qui manque :

  1. L'adresse, le téléphone, les horaires, la description et l'e-mail rejoignent le nœud existant de votre entreprise, sous le même @id.
  2. Une valeur déjà définie par votre plugin SEO n'est jamais écrasée. Si vous avez rempli les réglages Local SEO de Rank Math, ces valeurs restent.
  3. Les services que vous saisissez sont ajoutés et liés à votre entreprise.
  4. Les questions de FAQ que vous saisissez sont ajoutées à la FAQPage uniquement sur la page qui affiche le bloc Nurevo FAQ ou le shortcode [nurevo_faq], en ignorant celles qui ont déjà une réponse.
  5. WebSite, WebPage, Article et le fil d'Ariane restent exactement tels que votre plugin SEO les publie.

La page garde un seul graphe qui décrit une seule entreprise, sans doublon. Avec toute autre configuration (SEOPress, The SEO Framework, le schema du thème ou aucun plugin SEO), Nurevo AEO imprime son propre graphe et place les informations de l'entreprise sous l'@id d'entreprise existant, si bien que les deux décrivent une seule entreprise.

Mise en place en cinq étapes

  1. Installez Nurevo AEO depuis WordPress.org (Extensions > Ajouter, recherchez « Nurevo AEO ») et activez-le. Laissez votre plugin SEO actif.
  2. L'assistant de configuration s'ouvre une fois. Choisissez le type de site (commerce local, boutique en ligne ou B2B), confirmez le nom, l'adresse, le téléphone, les horaires et la description, puis choisissez ce qui est publié pour l'IA.
  3. Vérifiez les informations que le plugin a reprises de vos réglages existants. Il ne remplit que les champs vides, donc rien de ce que vous avez saisi n'est remplacé, et l'assistant vous relit les horaires tels qu'ils seront publiés.
  4. Saisissez vos services et vos questions dans Nurevo AEO > Settings, et placez le bloc Nurevo FAQ (ou [nurevo_faq]) sur la page où la FAQ doit apparaître.
  5. Ouvrez Nurevo AEO > AEO Score, lisez ce que le diagnostic envoie, cochez la case de consentement et cliquez sur Run diagnosis. Appliquez ensuite les corrections en un clic proposées par la liste.

Pour voir ce que l'IA lit de l'extérieur, lancez le test gratuit de lisibilité par l'IA avec l'URL de votre page d'accueil.

Ce qui est gratuit

Tout ce qui est décrit ici fonctionne avec l'offre gratuite, sans clé de licence ni période d'essai :

  1. Le score AEO : de 0 à 100, avec des alertes de type feu tricolore et une liste de points à corriger.
  2. Des corrections en un clic pour les données structurées de base, le llms.txt et l'accès des robots d'IA.
  3. Un JSON-LD schema.org rendu côté serveur, lu même par les robots qui n'exécutent pas JavaScript.
  4. Un llms.txt à l'adresse /llms.txt, généré dans le plugin à partir de votre contenu WordPress.
  5. Des règles robots.txt pour les robots que la recherche par IA utilise pour lire et citer les pages.
  6. Des types de site pour les commerces locaux, les boutiques en ligne et les entreprises B2B.

Les offres payantes ajoutent un jeu de règles toujours à jour (Standard) et la mesure de visibilité dans l'IA en bêta (Pro). Rien sur cette page n'en a besoin.

Ce que les données structurées peuvent et ne peuvent pas faire

Les données structurées aident l'IA à lire correctement vos informations : les bons horaires, le bon numéro, le bon type d'activité. Elles ne décident pas de ce que dit une IA. Aucun outil ne peut garantir qu'une IA vous mentionnera, et Nurevo ne le promet pas.

Questions fréquentes

Nurevo AEO duplique-t-il le schema de mon plugin SEO ?

Non. Avec Yoast SEO, Rank Math ou All in One SEO, il ajoute seulement les informations manquantes au graphe que votre plugin SEO publie déjà, sous le même @id d'entreprise, et n'écrase jamais une valeur définie par le plugin. La page garde un seul graphe qui décrit une seule entreprise.

Dois-je supprimer Yoast SEO, Rank Math ou AIOSEO ?

Non. Gardez votre plugin SEO pour le référencement. Nurevo AEO ajoute par-dessus les informations dont l'IA a besoin.

Nurevo AEO est-il gratuit ?

Oui. Les informations de l'entreprise, les services, la FAQ, le score AEO, les corrections en un clic, le JSON-LD, le llms.txt et les règles pour les robots d'IA sont dans l'offre gratuite. Les offres payantes ajoutent seulement un jeu de règles toujours à jour et la mesure de visibilité dans l'IA (bêta).
