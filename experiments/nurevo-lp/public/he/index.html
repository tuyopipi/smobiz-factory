הציבו בעצמכם את JSON-LD, ‏llms.txt ושורות robots.txt

העתיקו את ה-JSON-LD שלוח הבקרה יוצר אל ה-<head> של ה-HTML, הציבו את llms.txt בשורש האתר והוסיפו את השורות ל-robots.txt. מכיוון שהם סטטיים, גם סורקי AI שלא מריצים JavaScript יכולים לקרוא אותם. העתיקו שוב אחרי שינוי פרטי העסק.

אופציונלי: תג מדידה

tag.js (ישירות או דרך GTM)

מודד ביקורים שמגיעים מ-AI ועוזר לדפדפנים ולסוכני AI שמריצים JavaScript. הוא מוטמע באמצעות JavaScript (גם דרך GTM), ולכן סורקים שלא מריצים JavaScript לא רואים אותו. הוא לא מחליף את התוסף או את העותק הסטטי.
