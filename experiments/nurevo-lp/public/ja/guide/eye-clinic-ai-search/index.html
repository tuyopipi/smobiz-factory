眼科のAI検索対策：保険・選定療養・自費を書き分け、白内障・コンタクト・近視の情報をAIに正しく読ませる手順

眼科のAI検索対策でいちばん大切なのは、「その検査・治療は保険か、選定療養か、自費か。自分で払う分はいくらか」を、治療ごとのページに文字で書くことです。眼科は1つの医院の中で、保険の白内障手術、選定療養の多焦点眼内レンズ、自費の屈折矯正手術やオルソケラトロジーが並ぶため、AIが取り違えやすい分野です。そのうえで、コンタクトレンズの「処方（医院）」と「販売（販売店）」を分けて書き、医療広告のルールを守ったまま、同じ事実を構造化データ・llms.txt・Googleビジネスプロフィールにそろえます。

作成日：2026年11月17日（JST）。多焦点眼内レンズの選定療養（病院のお知らせ）、低濃度アトロピン点眼薬の承認（薬事日報）と医療機関の説明資料、コンタクトレンズについての消費者庁・政府広報・厚生労働省の資料、schema.orgの型（schema-dts 2.1.0の型定義）は同日に確認しました。厚生労働省の医療広告Q&Aの項目は2026年11月16日に確認した範囲です。

AIの回答は日や聞き方によって変わります。この記事の対策は、AIが医院の事実を正しく読める状態をつくるものです。AIの回答に必ず表示される・順位が上がることを保証するものではありません。この記事は法的・医学的な助言ではありません。個別の表現や費用の扱いは、管轄の保健所・地方厚生局などで確認してください。

眼科で、患者さんがAIに聞くこと

眼科の質問は、症状の相談だけでなく「お金」と「手続き」が入るのが特徴です。患者さん本人だけでなく、高齢の親の白内障や子どもの近視を調べる家族もAIに聞きます。よく出る質問の型は次の6つです。

質問の型例AIが答えに使う情報
地域×症状「◯◯駅の近くで、土曜に目の充血を診てもらえる眼科」診療時間（曜日ごと）、予約なしで受診できるか、対象年齢
コンタクト「コンタクトの処方箋だけもらえる眼科」「初めてのコンタクトは何が必要？」処方の流れ、所要時間、持ち物、医院と販売店の関係
白内障「多焦点眼内レンズの費用は保険でいくら？」単焦点・多焦点の違い、選定療養の追加費用（片眼・税込）、届出の有無
子どもの近視「子どもの近視の進行を抑える治療はある？費用は？」治療の種類、対象年齢、保険と自費の分け方、通院の頻度
屈折矯正「ICLとレーシックの違いと料金」自費であること、費用、主なリスク・副作用、適応検査
検査と予約「眼底検査の後は運転できる？」「手術の相談は予約制？」検査の所要時間、当日の注意、予約の方法と電話の受付時間

どの型も、AIが使えるのは条件が文字で書いてあるページです。料金表が画像だけ、「費用はご相談ください」だけ、保険か自費かが書かれていない、というページは出典になりにくくなります。

上位の記事で抜けていたこと

「眼科 AI検索対策」「クリニック LLMO」「ophthalmology AEO」などで上位に出る記事を、日本語5本・英語6本読みました。日本語で眼科に絞った記事はなく、クリニック全般・歯科・眼鏡店向けの記事が中心でした。英語の眼科向け記事は、多くが支援会社の紹介ページで、「レビュー50件以上・星4.5以上がAIに好まれる」「約40%の改善」のような数字を、根拠を示さずに、または別の研究の数字をそのまま当てはめて挙げていました。

どの記事にもなかったのは、次の4点です。この記事はここを中心に書きます。

  1. 保険・選定療養・自費の3つを、治療ごとにどう書き分けるか（多焦点眼内レンズ、子どもの近視治療を含む）。
  2. コンタクトレンズの処方（医院）と販売（販売店）を、サイトと構造化データでどう分けるか。
  3. 眼科を表すschema.orgの型（Ophthalmology）と、眼鏡店の型（Optician）の使い分け。
  4. WordPressでの具体的な設定と、AIに出ているかの確かめ方。

保険・選定療養・自費の3つを書き分ける

眼科でAIがいちばん間違えやすいのは費用です。「白内障手術は保険がきく」と「多焦点眼内レンズは追加の費用がかかる」が同じページに混ざって書かれていると、AIは「多焦点も保険でできる」「白内障手術は30万円かかる」のような、どちらも不正確な答えを作りかねません。治療ごとに、次の3つのどれにあたるかを1行目近くに書きます。

治療・サービス書いておくこと誤解されやすい書き方
白内障手術（単焦点眼内レンズ）保険診療であること、入院か日帰りか、術前検査と通院の回数多焦点の費用と同じ表に並べる
多焦点眼内レンズを使う白内障手術選定療養であること、保険の診療費とは別に払うレンズの追加費用（レンズごと・片眼・税込）、医院が届出をしていること「自費で約◯万円」と全額自費のように書く
子どもの近視の進行を抑える治療治療の名前、対象年齢、検査と薬代のどちらが保険・自費か、1か月あたりの費用、通院の頻度、近視が止まる・視力が戻るものではないこと「近視が治る」「視力回復」
オルソケラトロジー・屈折矯正手術（ICLなど）自由診療で行うならその旨、費用（片眼・両眼、検査代・再診代を含むか）、主なリスク・副作用、適応検査「料金はカウンセリングで」だけ
コンタクトレンズの検査・処方処方の流れ、所要時間、持ち物、レンズ代はどこに払うか医院と販売店の料金を区別せずに書く

多焦点眼内レンズを使う白内障手術は、2020年（令和2年）4月から選定療養の対象になりました。選定療養は、患者さんが選んで受ける追加の医療で、その分の費用は全額自己負担になり、通常の診療費とは別に払います。ある市立病院のお知らせでは、レンズごとの追加費用（税込・片眼）が234,300円〜272,800円と示され、地方厚生局に届け出ていることも書かれています。藤沢市民病院：多焦点眼内レンズのお知らせ（PDF）。費用は医院やレンズで変わるため、自院の金額をレンズごとに書いてください。

子どもの近視では、近視の進行を抑える初めての薬として、参天製薬の「リジュセアミニ点眼液」が2024年12月27日付で承認されました。薬事日報（2025年1月9日）。ある医療機関の説明資料では、対象は5〜15歳、診察・検査は保険診療で、点眼薬は自費（30日分5,000円・税込）、オルソケラトロジーと併用する場合はすべて自費とされています。医療機関の説明資料（PDF）。これは1つの医療機関の扱いです。自院でどう扱うかを、その通りに書いてください。

自費の手術・治療ページ：費用と主なリスクを同じページに

日本の医療広告のルールでは、患者さんが自ら調べて見るウェブサイトなら、一定の条件を満たすことで、通常は広告できない内容も詳しく説明できます（「限定解除」）。厚生労働省のQ&Aでは、自由診療の場合の条件として、通常必要とされる治療の内容・費用と、主なリスク・副作用を書くこと（一般的な短所を1〜2個並べるだけでは足りない、Q6-12）、相談に答える問い合わせ先を書くこと（予約専用の番号や自動応答だけでは満たさない、Q6-10）、見やすく書くこと（Q6-11）が示されています。承認された機器・薬を使う自費の治療では、自由診療であることと標準的な費用を書くようにも示されています。厚生労働省：医療広告等ガイドラインに関するQ&A（PDF）

これはAIが「費用」「リスク」「何回通う？」を聞かれたときに使える情報と同じです。屈折矯正手術・多焦点眼内レンズ・近視治療のページは、次の順番にすると読みやすくなります。

  1. 治療の名前と、保険・選定療養・自費のどれか。
  2. どんな方に向くか、受けられない方・適応検査の内容（見え方を約束する書き方はしない）。
  3. 流れ：適応検査、手術・治療の日、術後の通院の回数と時期。
  4. 費用：片眼か両眼か、税込か税別か、検査代・薬代・再診代を含むか、保険の部分と自己負担の部分。
  5. 主なリスク・副作用と、術後の生活の注意（運転・洗顔・仕事など、医院の案内として）。
  6. 相談に答える問い合わせ先（受付時間つき）と、術後に困ったときの連絡先。
  7. ページの最終更新日。レンズの種類や費用を変えたら、日付も変える。

コンタクトレンズ：処方は医院、販売は販売店と分けて書く

コンタクトレンズは、視力補正を目的としないカラーコンタクトも含めて高度管理医療機器です。消費者庁は、購入する前にまず眼科医を受診して処方してもらい、定期検診の頻度を決めてもらうよう呼びかけています（2021年9月10日）。消費者庁：コンタクトレンズによる眼障害について。政府広報オンラインによると、国民生活センターの「医師からの事故情報受付窓口」には2014年8月〜2022年12月に104件の事故情報が寄せられ、購入先はインターネット通販が半数以上でした。政府広報オンライン。

販売店の側でも、厚生労働省の通知（2012年7月18日）で、販売時に医療機関への受診状況を確かめ、受診していない人には受診を勧め、受診した医療機関の名前を記録することとされています。厚生労働省：コンタクトレンズの販売時における取扱いについて。患者さんがAIに「コンタクトはどこで作れる？」と聞いたとき、医院が「検査と処方をするところ」だと分かる書き方が役に立ちます。

  1. コンタクトのページに、初めての方と継続の方それぞれの流れ・所要時間・持ち物（使っているレンズの箱など、医院の案内として）を書く。
  2. 医院の中や隣に販売店がある場合、医院と販売店が同じ事業者か別の事業者かを書く。別なら、営業時間・電話番号・料金も分けて書く。
  3. 「処方箋だけ」に応じるか、他の店で買う人にどう案内するかを、医院の方針としてFAQに書く。
  4. 定期検査の目安は、医院の方針として書く（期間の数字を一般論として断定しない）。

口コミ・術後の見え方：一般的な「AI対策」の助言とぶつかるところ

AI検索対策の記事では「口コミを増やす」「実績を見せる」がよく勧められます。眼科の手術や近視治療では、ここに注意が必要です。

よくある助言医療機関での扱い（厚生労働省のQ&A）代わりにできること
患者さんの声をサイトに載せる治療の内容や効果についての体験談は掲載できない（Q1-18、Q2-9）流れ・費用・リスク・通院回数など、事実の説明を詳しくする
「術後に裸眼で見えるように」と効果を見せる治療効果の表現には制限がある。術前・術後の写真も治療効果の表現として扱われる（Q2-8、Q3-14）何が書けるかは事例解説書と保健所で確認する
「地域No.1」「痛くない」「日帰りで安心」虚偽・誇大・比較優良の表示は禁止されている例として扱われる手術時間や通院回数など、数字や事実で書ける範囲だけを書く
口コミをFAQや構造化データのレビューに入れる上と同じ。医院が依頼・編集した口コミも対象になりうるFAQは「保険はききますか」「何日後に運転できますか」など事実の質問にする

事例は事例解説書（PDF）にもまとまっています。医院が依頼していない第三者の口コミをAIが読むかどうかは医院が決められないので、自院のサイトでは事実を正確に書くことに集中するのが確実です。

構造化データ：Ophthalmologyの型と、併設の眼鏡店の型

schema.orgには、眼科と眼鏡店をそれぞれ表す型があります（2026年11月17日にschema-dts 2.1.0の型定義で確認）。

型・プロパティ意味眼科での使い方
Ophthalmology目と視覚にかかわる病気の診断・治療（内科的・外科的な治療を含む）。MedicalBusinessの一種で、LocalBusinessの一種眼科の医院・クリニックの型に。住所・電話番号・営業時間をそのまま持てる
Optometric視力を測り、矯正用のレンズを処方する分野米国の検眼（オプトメトリスト）を想定した型。日本の眼科医院にはOphthalmologyが合う
Optician眼鏡などを販売する店医院とは別の事業者の眼鏡・コンタクト販売店に。医院の型には使わない
medicalSpecialty診療の分野。値にOphthalmologyがある本文に書いている分野だけを入れる
Service と offers提供するサービスと、その料金自費の治療や選定療養のレンズ代を1つずつ登録し、本文と同じ料金を入れる

Googleは、AIによる概要などのために特別な構造化データは不要で、構造化データはページに見えている内容と一致させるよう案内しています。Google：AI features and your website。料金を構造化データにだけ書く、本文と違う料金を入れる、医院と販売店を1つの事業者として出す、ということは避けてください。

WordPressの眼科サイトでの設定手順

  1. WordPress.orgからNurevo AEO（無料）をインストールして有効化します。Yoast SEO・Rank Math・All in One SEO・Slim SEOはそのまま使えます。0.9.1からはSEO SIMPLE PACKやVK All in One Expansion Unitとも、構造化データを重複させずに併用できます。
  2. 初回の設定ウィザードで「クリニック・歯科」を選びます（型はMedicalBusinessになります）。そのあと設定画面の「業種（schema.org型）」欄を Ophthalmology に変えます。この欄にはschema.orgの型名をそのまま入れられます。
  3. 医院名・住所・電話番号・説明を確認します。空欄の項目だけが既存の設定から補われ、入力済みの値は上書きされません。
  4. 営業時間は「月〜金 9:00-12:00 14:00-18:00 / 土 9:00-13:00」のように曜日と時刻だけを書きます。手術日・コンタクトの受付終了時刻・検査の予約枠などの条件は、本文の表に書きます。
  5. 設定画面のサービスに、自費の治療や選定療養のレンズ代を1つずつ登録します（例：「多焦点眼内レンズ（◯◯）追加費用・片眼」）。名前・説明・料金・通貨を入れると、料金つきのサービス（Service と Offer）として出力されます。料金は本文と同じ値にし、本文を変えたら同時に直します。
  6. 白内障・コンタクト・近視治療の各ページの編集画面のサイドバーで、そのページだけのFAQ（「多焦点は保険がききますか」「処方箋だけもらえますか」「何歳から始められますか」）を入れます。体験談や見え方を約束する答えは入れません。終わったキャンペーンや古い料金のページは「このページをllms.txtに載せない」にします。
  7. AEOスコアの画面で診断を実行し、不足をワンクリック修正で直します。外からどう見えるかは無料のAI可読性チェックで確かめます。

診療分野（medicalSpecialty）を足したいとき

Nurevo AEOは medicalSpecialty を自動では出しません。出したい場合は、テーマの functions.php か小さなプラグインで、事業の構造化データを変えるフィルター（webmcp_canary_business_node）を使います。

add_filter('webmcp_canary_business_node', function ($org, $settings) {
    // 本文に書いている診療分野だけを足す
    $org['medicalSpecialty'] = array('Ophthalmology');
    return $org;
}, 10, 2);

AIに出ているかを確かめる

整えたあとは、患者さんや家族が聞きそうな質問を「地域×症状×曜日」「地域×白内障×多焦点の費用」「子どもの近視×治療×費用」「地域×コンタクト×処方」の組み合わせで5〜10個つくり、ChatGPTやPerplexityに投げます。医院が名前やURLで出るか、保険・選定療養・自費の区別と金額が正しく書かれているかを記録します。費用を間違えて答えられていたら、料金表と治療ページの書き方、古い料金のページやPDFが残っていないかを見直します。AIの回答は回ごとに変わるので、同じ質問を期間をあけて何度か確かめます。測り方はAIでの登場率の測り方にまとめています。

Nurevo AEOでは、Free・Standardプランでも月に1回、業種と地域から作った3つの質問（医院名は含めません）をPerplexityに投げ、回答に医院の名前やサイトが出たかを記録します。Proプラン（月14,800円〜）では、ベータ版のAI登場率の計測で、AIの回答に医院が出る割合を競合との比較・推移とあわせて見られます（現在の計測対象はPerplexity）。どちらも回答のサンプルを見るもので、すべての回答を観測するものではありません。

よくある質問

眼科のAI検索対策は、何から始めればいいですか？

治療・検査のページごとに、保険・選定療養・自費のどれかを書くことからです。次に多焦点眼内レンズや自費の治療のページに費用・主なリスク・問い合わせ先を書き、名前・住所・電話番号・診療時間を構造化データ・Googleビジネスプロフィールとそろえます。

多焦点眼内レンズの費用は、どう書けばいいですか？

選定療養であること、保険の診療費とは別に払う追加費用であることを書き、レンズごとの金額を片眼・税込などの条件つきで表にします。2020年4月から多焦点眼内レンズを使う白内障手術は選定療養の対象で、追加分は全額自己負担です。

コンタクトレンズの販売店が併設されています。構造化データはどうしますか？

医院と販売店が別の事業者なら、医院はOphthalmology、販売店はOpticianなど別の型・別の情報として扱い、1つにまとめないでください。サイトの本文でも、営業時間・電話番号・料金を分けて書きます。

構造化データの型は何を使えばいいですか？

schema.orgのOphthalmologyが眼科を表す型で、MedicalBusinessとLocalBusinessの一種です。Optometricは米国の検眼を想定した型、Opticianは眼鏡などの販売店の型です。型より、値が本文と一致していることが大切です。

手術の症例数や術後の視力を載せると、AIに選ばれやすくなりますか？

AIへの効果は確かめられていません。日本の医療広告のルールでは、治療効果の表現や術前術後の写真に制限があります。載せる場合の条件は、医療広告ガイドラインと事例解説書、管轄の保健所で確認してください。

対策すればChatGPTに眼科が必ず出ますか？

いいえ。AIの回答は変動し、どのツールや対策でも表示や順位は保証できません。できるのは、AIが医院の事実を正しく読める状態をつくり、出ているかを継続して確かめることです。
