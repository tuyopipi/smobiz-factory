スペインのWeb制作会社の自社サイト248件に見るAI検索への対応（2026年11月）

スペインのWeb制作会社の自社サイト248件のトップページ・robots.txt・llms.txt を調べたところ、llms.txt があったのは31.9%（79件）で、到達100件以上の17か国の中でシンガポール・インド・ブラジルに次ぐ4位でした（米国23.1%、英国21.5%、日本13.4%）。AI検索に関わる6項目をすべて満たしたのは27.4%で17か国中3位でしたが、1つも当てはまらないサイトも25.8%あり、6項目の平均（3.67）は10位でした。WordPress のサイト167件は0項目が1件もなく5項目以上が80.2%だったのに対し、WordPress 以外の81件は79.0%が0項目と、はっきり二つに分かれていました。

公開：2026年11月27日。データ：2026年11月12日集計。調査・執筆：Nurevo AEO（Bestie.合同会社）。Nurevo はAI検索対策（AEO）のツールと WordPress プラグインを提供しており、この分野に利害があります。国別レポートの9本目です（これまでに米国・英国・オーストラリア・インド・カナダ・フランス・シンガポール・ブラジル）。英語版とスペイン語版もあります。

要点

  1. スペインのWeb制作会社の自社サイト248件のうち、llms.txt があったのは31.9%（79件）で、到達100件以上の17か国で4位でした。米国（23.1%、p=0.002）・英国（21.5%、p<0.001）・イタリア（20.0%、p=0.022）より高く、フランス（26.4%、p=0.14）・ブラジル（34.1%）とは統計的な差が見られませんでした。日本（13.4%）の2.4倍です。
  2. AI検索に関わる6項目をすべて満たしたのは27.4%（68件）で、17か国中シンガポール・インドに次ぐ3位でした。一方で6項目に1つも当てはまらないサイトが25.8%（64件）あり、6項目の平均は3.67（10位）、JSON-LD は69.0%（12位）でした。
  3. 分かれ目は WordPress かどうかでした。WordPress のサイト167件は llms.txt 42.5%・JSON-LD 97.0%・6項目の平均5.11 で、0項目のサイトはありませんでした。WordPress 以外の81件は JSON-LD 11.1%・平均0.72 で、64件（79.0%）が0項目でした。WordPress のサイトどうしで比べると、スペインの llms.txt（42.5%）は米国（30.1%）・フランス（27.5%）・スペイン以外の海外（33.0%）より高い値でした（p<0.001・p<0.001・p=0.009）。

調査概要

  1. 対象：Web制作会社の自社サイト。当社の収集リストで国がスペインとなっている制作会社サイト485件のうち、トップページに到達できた248件です。一般企業のサイト全体ではありません。比較には同じ調査のスペイン語圏の中南米4か国（メキシコ116件・コロンビア81件・アルゼンチン76件・チリ50件、計323件）・フランス（405件）・イタリア（110件）・ポルトガル（46件）・英国（942件）・米国（4,472件）・日本（2,486件）・スペイン以外の海外（13,104件）を使いました。
  2. 取得したもの：各サイトのトップページ、/robots.txt、/llms.txt、/llms-full.txt を1回ずつ（User-Agent：NurevoSurvey/1.0）。2026年11月上旬〜12日に取得し、11月12日に集計しました。
  3. 判定方法：llms.txt は、ステータス200で中身がHTMLではなく20文字を超えるテキストを「あり」としました。JSON-LD はトップページにあるかどうか、「壊れている」は JSON として読み込めないブロックが1つ以上あるもの。Organization系は @type に Organization・LocalBusiness・Corporation・ProfessionalService を含むもの。WordPress はHTMLに wp-content・wp-includes・WordPress の generator があるものです。
  4. AIボットのブロック：robots.txt で、各ボットに当てはまるグループの規則がトップページ（/）を Disallow にするか（最長一致）で判定しました。分母は robots.txt があるサイトです。「AIボットをブロック」は GPTBot・ClaudeBot・PerplexityBot・Google-Extended・CCBot・OAI-SearchBot のどれかをブロックしているもの。「AIボットに言及」は Googlebot・Bingbot 以外の11種のAIボットのどれかを User-agent で名指ししているものです。
  5. 「6項目」は、(1) llms.txt がある、(2) JSON-LD がある、(3) Organization または LocalBusiness の型がある、(4) robots.txt があり GPTBot・ClaudeBot・PerplexityBot・OAI-SearchBot のどれもブロックしていない、(5) meta description がある、(6) canonical がある、のうち当てはまる数（0〜6）です。この調査のための単純な目安で、AIの回答に載るかどうかを示すものではありません。
  6. HTTP 202：スペインでトップページがステータス202を返したのは14件（到達件数の5.6%）で、すべて WordPress 以外のサイトでした。米国（15.0%）・英国（14.9%）より少ない割合です。202のページはほとんどの項目が「なし」になるため、ステータス200のサイトだけで比べた値も本文に書きました。
  7. 統計：スペインと他の地域の差はカイ二乗検定で、件数が小さいAIボットのブロックはフィッシャーの正確検定で確かめました。30件未満の区分は載せていません（ポルトガルのAIボットのブロック率は robots.txt があるサイトが27件のため「—」）。地域（州・都市）は収集リストの248件中198件で空欄だったため、地域別の分析はしていません。

結果：スペインと中南米・フランス・イタリア・ポルトガル・英国・米国・日本の比較

スペインは llms.txt（31.9%）・FAQPage（12.5%）・6項目すべて（27.4%）で、米国・英国より高い値でした（llms.txt は対米国 p=0.002・対英国 p<0.001、FAQPage は対米国 p<0.001・対英国 p=0.026、6項目すべては対米国 p=0.001・対英国 p<0.001）。JSON-LD（69.0%）は米国（69.0%）・英国（68.8%）と同じ水準でした。スペイン以外の海外と比べると、llms.txt（p=0.048）と6項目すべて（p=0.031）は高く、meta description・canonical・robots.txt はやや低い値でした（p=0.044・0.029・0.010）。

隣のフランスとは形が違いました。フランスは JSON-LD（90.1%）・meta description（90.4%）・canonical（93.6%）・robots.txt（93.3%）が20ポイント前後高く（いずれも p<0.001）、0項目のサイトは3.7%だけでした。一方で llms.txt（26.4%、p=0.14）と6項目すべて（24.0%、p=0.32）にはスペインとの統計的な差が見られませんでした。イタリアに対しては、スペインは llms.txt（p=0.022）・6項目すべて（p=0.039）・JSON-LD（p<0.001）で高い値でした。

スペイン語圏の中南米4か国と比べると、スペインは JSON-LD（69.0%・54.8%、p<0.001）・6項目すべて（27.4%・18.3%、p=0.009）が高く、llms.txt は31.9%と24.5%でした（p=0.050）。ステータス200のサイトだけ（スペイン234件）で比べると、llms.txt は33.8%で米国（27.2%、p=0.028）・英国（25.3%、p=0.011）より高く、スペイン以外の海外（29.6%、p=0.16）とは差がはっきりしませんでした。6項目すべては29.1%で、米国（22.3%、p=0.016）より高い値でした。

WordPress かどうかで二つに分かれる

スペインの制作会社サイトの67.3%（167件）が WordPress でした。WordPress のサイトは JSON-LD 97.0%・6項目の平均5.11 で、0項目のサイトはなく、96.4%が4項目以上、80.2%が5項目以上でした。WordPress 以外の81件は JSON-LD 11.1%・平均0.72 で、64件（79.0%）が0項目でした。0項目の64件は、ステータス202を返した14件と、ステータス200で返ったものの構造化データ・meta description・canonical・robots.txt・llms.txt のどれも見つからなかった50件です。JavaScript で後から中身を出すサイトや、ホスティング側で robots.txt を出さないサイトは、この調査では「なし」になります。

WordPress のサイトどうしで比べると、スペインは llms.txt 42.5%・6項目すべて37.7% で、米国（30.1%・25.2%）・フランス（27.5%・25.9%）・スペイン以外の海外（33.0%・27.9%）より高い値でした（llms.txt p<0.001・p<0.001・p=0.009）。中南米4か国（38.3%、p=0.44）・イタリア（36.8%、p=0.45）とは差が見られませんでした。WordPress 以外のサイトで項目が少ない傾向は、米国・イタリア・中南米4か国でも同じでした。

ブロックの中身（事実）

  1. GPTBot をブロックしていた9件のうち7件は、OAI-SearchBot をブロックしていませんでした。残りの2件は、Googlebot・Bingbot 以外の11種のAIボットをすべてブロックしていました。
  2. 11種のAIボットのどれかをブロックしていた11件のうち5件は、GPTBot・ClaudeBot・anthropic-ai・Google-Extended・CCBot・Bytespider・Applebot-Extended の7つをまとめてブロックする同じ組み合わせでした。11種すべてが2件、残りの4件は Bytespider だけ・GPTBot と CCBot など、それぞれ別の組み合わせでした。
  3. Googlebot・Bingbot をブロックしていたサイトはありませんでした。
  4. robots.txt でAIボットの名前を挙げていたのは25件（robots.txt があるサイトの14.0%）で、そのうち16件はどのAIボットもトップページをブロックしていませんでした。
  5. AIボットをブロックしていた10件のうち6件には llms.txt もありました。
  6. robots.txt に Sitemap の行があったのは、robots.txt があるサイトの87.6%でした。

llms.txt の中身と、5項目のサイトに欠けていたもの

  1. llms.txt があった79件の行数の中央値は60行でした。llms-full.txt があったのは9件（3.6%）です。
  2. 6項目のうち5項目を満たしたサイトは73件で、そのうち66件（90.4%）は欠けていた1項目が llms.txt でした。

限界

  1. 対象はWeb制作会社の自社サイトで、一般企業のサイト全体ではありません。国は当社の収集リストの記載によるもので、スペインの制作会社全体を代表する標本ではありません。到達248件は17か国の中では小さく、地域ごとの分析は行っていません。ボット別の件数などは小さい数です。
  2. トップページだけを見ています。robots.txt はトップページ（/）に対する判定で、一部のディレクトリだけのブロックや、ファイアウォール・CDN によるブロックは数えていません。llms.txt は有無だけを見て、中身の質は見ていません。
  3. 各サイト1回の取得で、到達できなかったサイト（237件）は除いています。HTTP 202 を返した14件は、実際のトップページとは違うページを見ている可能性があります。JavaScript で後から出す中身や構造化データは数えていないため、WordPress 以外のサイトの値は低めに出ている可能性があります。
  4. SEOプラグインはHTMLの文字列による判定で、痕跡を消している場合や複数入っている場合は正しく分けられません。
  5. 今回の数字は2026年11月12日の集計です。週ごとに取り直すため、次の集計では値が変わることがあります。

読み方（意見）

ここからは当社の解釈です。スペインの制作会社サイトは、llms.txt と「6項目すべて」で17か国の上位に入りました。WordPress のサイトだけを見ると、llms.txt の割合は米国やフランスより高い値です。一方、WordPress 以外のサイトの多くはこの調査の方法では項目を確認できず、平均を下げています。これが実際に項目がないのか、JavaScript での表示など調査の方法で見えていないだけなのかは、この調査では区別できません。AIボットのブロックは少数で、ほとんどが学習用のボットに限られていました。どのボットをブロックするかは各サイトの判断です。これらの項目がそろっていても、AIの回答に載ることが保証されるわけではありません。
