WordPressのSEOプラグイン別に見たAI検索対応：Web制作会社サイト12,376件を調査（2026年11月）

日本と海外のWeb制作会社の自社サイトのうち、WordPress で作られている12,376件のトップページを調べたところ、日本でいちばん多く検出されたSEOプラグインは All in One SEO（35.2%）、海外は Yoast SEO（53.1%）でした。日本では、SEOプラグインが検出されたサイトの19.3〜22.5%に llms.txt があった一方、検出されなかったサイトでは7.7%でした。

公開：2026年11月14日。データ：2026年11月12日集計。調査・執筆：Nurevo AEO（Bestie.合同会社）。Nurevo はAI検索対策（AEO）のツールと WordPress プラグインを提供しており、この分野に利害があります。

要点

  1. 日本の WordPress 制作会社サイト2,295件で検出されたSEOプラグインは、All in One SEO 35.2%（807件）、Yoast SEO 14.4%（331件）、Rank Math 1.7%（40件）。48.6%（1,115件）ではどれも検出されませんでした。海外10,081件では Yoast SEO 53.1%、Rank Math 22.2%、All in One SEO 6.1%です。
  2. llms.txt がある割合は、日本では SEOプラグイン検出ありの3区分で19.3〜22.5%、検出なしで7.7%。海外では All in One SEO 51.1%、Rank Math 40.8%、Yoast SEO 30.8%、検出なし24.2%でした。
  3. robots.txt でAIボットをトップページから締め出しているサイトは、どのプラグインの区分でも少数でした（日本0.0〜1.1%、海外3.8〜9.2%）。海外では WordPress 以外のサイトの方が高く15.9%でした。

調査概要

  1. 対象：Web制作会社の自社サイト。日本3,352件（制作会社であることを確認できたもの）と海外20,335件、計23,687件。一般企業のサイト全体ではありません。
  2. 到達：トップページを取得できたのは15,838件（日本2,486件、海外13,352件）。このうち WordPress と判定した12,376件（日本2,295件、海外10,081件）がこのレポートの主な対象です。
  3. 取得したもの：各サイトのトップページ、/robots.txt、/llms.txt、/llms-full.txt を1回ずつ（User-Agent：NurevoSurvey/1.0）。2026年11月上旬〜12日に取得し、11月12日に集計しました。
  4. 判定方法：WordPress は、トップページのHTMLに wp-content/・wp-includes/、または generator の WordPress 表記があるもの。SEOプラグインは、同じHTMLに yoast、rank-math（rankmath）、all in one seo（aioseo）、seopress、slim seo の文字列があるかをこの順に調べ、最初に見つかったものとしました。llms.txt は、ステータス200で中身がHTMLではなく20文字を超えるテキストを「あり」としました。AIボットのブロックは、robots.txt で GPTBot・ClaudeBot・PerplexityBot・Google-Extended・CCBot・OAI-SearchBot のいずれかについて、トップページ（/）が Disallow になるか（最長一致）で判定し、分母は robots.txt があるサイトです。
  5. 国は当社の収集リストでの所在国です。30件未満の区分は載せていません（国別のシェアは WordPress サイトが100件以上ある国だけ）。

結果：SEOプラグインのシェア

日本と海外で順位が入れ替わります。日本では All in One SEO が Yoast SEO の約2.4倍（807件と331件）で、Rank Math は1.7%でした。海外では Yoast SEO が半数を超え、Rank Math が2割強で続きます。日本では WordPress サイトの約半数でどのプラグインも検出されませんでした（理由は「限界」を参照）。

プラグイン別：トップページの項目

SEOプラグインが検出された区分では、JSON-LD・OGP・canonical が9割以上でそろっていました。差が出たのは llms.txt と、パンくず（BreadcrumbList）です。BreadcrumbList は Rank Math・SEOPress の区分でトップページにはほとんど見られませんでした。これは各プラグインがトップページに何を出力するかの既定の違いとみられ、下層ページでの扱いはこの調査では見ていません。

「6項目」は、(1) llms.txt がある、(2) JSON-LD がある、(3) Organization または LocalBusiness の型がある、(4) robots.txt があり GPTBot・ClaudeBot・PerplexityBot・OAI-SearchBot のどれもブロックしていない、(5) meta description がある、(6) canonical がある、のうち当てはまる数です。この調査のための単純な数で、Nurevo の0〜100点のスコアとは別物です。

  4. 国内の WordPress 制作会社サイトの48.6%では、主要5つのSEOプラグインのいずれもトップページから検出されなかった（Nurevo AEO 調査、2026年11月）。

限界

  1. プラグインはトップページのHTMLに残る文字列で判定しています。プラグイン名を出さない設定・キャッシュや最適化による除去があると「検出なし」になり、複数の名前が残るサイトは先に調べた方（Yoast SEO → Rank Math → All in One SEO → SEOPress → Slim SEO）に数えています。
  2. 調べたのは5つのプラグインだけです。日本で使われている SEO SIMPLE PACK などの他のプラグインや、テーマに組み込まれたSEO機能は判定しておらず、「検出なし」に含まれます。日本で「検出なし」が多い理由の一部はこれと考えられます。
  3. トップページだけを見ています。robots.txt はトップページ（/）に対する判定で、一部のディレクトリだけのブロックや、ファイアウォール・CDN によるブロックは数えていません。
  4. 対象はWeb制作会社の自社サイトで、一般企業のサイト全体ではありません。プラグインと各項目の関係は同時に見られたというだけで、プラグインが原因であることを示すものではありません（SEOに詳しい会社ほどプラグインを入れ、ほかの対策もしている、ということもありえます）。
  5. 各サイト1回の取得で、到達できなかったサイトは除いています。llms.txt は有無だけを見て、中身の質は見ていません。

当社の見方（意見）

ここからは事実ではなく当社の意見です。どのSEOプラグインの区分でも、構造化データ・canonical・OGP といった基本の項目は高い割合でそろっていました。プラグインごとの差は、llms.txt のような新しい項目と、トップページに出す構造化データの中身に表れています。SEOプラグインを入れていない WordPress サイトや WordPress 以外のサイトでは、基本の項目から抜けていることが多いため、まずそこを確かめるのがよいと考えます。どれを整えてもAIの回答に出ることが保証されるわけではありません（別の調査では、サイト側の項目と登場の間に関係は見られませんでした）。

自社やお客様のサイトを確かめる

無料チェックで、llms.txt・構造化データ・AIクローラーの許可状況を1分ほどで確認できます。WordPress なら Nurevo WebMCP プラグインで llms.txt を出し、Yoast SEO・Rank Math・All in One SEO が出す構造化データに、足りない会社の事実を重複させずに加えられます。お客様のサイトにまとめて入れたい制作会社の方はパートナー制度をご覧ください。

よくある質問

日本の制作会社でいちばん使われているSEOプラグインは？

この調査では All in One SEO で、国内の WordPress 制作会社サイト2,295件中807件（35.2%）でした。Yoast SEO は331件（14.4%）、Rank Math は40件（1.7%）です（2026年11月）。

海外ではどうですか？

海外のWeb制作会社の WordPress サイト10,081件では、Yoast SEO 53.1%、Rank Math 22.2%、All in One SEO 6.1%、SEOPress 0.8%でした。WordPress サイトが100件以上ある13か国のすべてで Yoast SEO が最多です。

SEOプラグインを入れると llms.txt やAI対応が良くなりますか？

この調査は同時に見られた傾向を示すだけで、因果は示していません。日本では検出ありの区分で llms.txt が19.3〜22.5%、検出なしで7.7%でしたが、AIの回答に出ることを保証するものでもありません。
