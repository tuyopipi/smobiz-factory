AI検索への対応度（6項目）の分布：Web制作会社サイト15,838件を調査（2026年11月）

日本と海外のWeb制作会社の自社サイト15,838件のトップページを、AI検索に関係する6項目（llms.txt・JSON-LD・会社の型・robots.txt・meta description・canonical）で数えました。日本の2,486件は平均4.05点で、52.2%が5点以上でしたが、6項目すべてそろったのは10.4%でした。5点のサイトの94.9%は、欠けている1項目が llms.txt でした。

公開：2026年11月15日。データ：2026年11月12日集計。調査・執筆：Nurevo AEO（Bestie.合同会社）。Nurevo はAI検索対策（AEO）のツールと WordPress プラグインを提供しており、この分野に利害があります。

要点

  1. 国内Web制作会社サイト2,486件の6項目の平均は4.05点（中央値5点）。5点以上は52.2%（1,297件）、6項目すべては10.4%（258件）でした。海外13,352件は平均3.83点、5点以上58.2%、6項目すべて21.8%です。
  2. 日本で5点だった1,039件のうち986件（94.9%）は、欠けていた1項目が llms.txt でした。llms.txt 以外の5項目がそろっているサイトは日本全体の50.0%（1,244件）です。
  3. WordPress かどうかで差が大きく、日本の WordPress サイトは平均4.21点、WordPress 以外（191件）は2.14点でした。海外でも WordPress は4.87点、WordPress 以外は0.61点です（海外の WordPress 以外にはHTTP 202の応答が多く、その分を除くと1.09点）。

調査概要

  1. 対象：Web制作会社の自社サイト。日本3,352件（制作会社であることを確認できたもの）と海外20,335件、計23,687件。一般企業のサイト全体ではありません。
  2. 到達：トップページを取得できたのは15,838件（日本2,486件、海外13,352件）。これがこのレポートの分母です。
  3. 取得したもの：各サイトのトップページ、/robots.txt、/llms.txt、/llms-full.txt を1回ずつ（User-Agent：NurevoSurvey/1.0）。2026年11月上旬〜12日に取得し、11月12日に集計しました。
  4. 6項目：(1) llms.txt がある（ステータス200、HTMLではない、20文字超）、(2) トップページに JSON-LD がある、(3) 読み取れた JSON-LD に Organization または LocalBusiness を含む型がある、(4) robots.txt があり、GPTBot・ClaudeBot・PerplexityBot・OAI-SearchBot のどれもトップページ（/）を Disallow されていない（最長一致）、(5) 10文字以上の meta description がある、(6) canonical がある。当てはまる数を0〜6点としました。この調査のための単純な数で、Nurevo の0〜100点のスコアとは別物です。
  5. (4) は robots.txt が無いサイトを0点にしています。robots.txt が無ければクロールは原則として止められませんが、この数え方では「置いて、止めていないことを確かめられる」ことを1点としています。
  6. HTTP 202：海外の1,477件（海外到達の11.1%）はトップページがステータス202で返り、うち1,435件が0点でした。自動アクセスへの確認画面などで本来のページが取れていない可能性があるため、202を除いた値も併記しています。日本では202はありませんでした。
  7. 国は当社の収集リストでの所在国です。30件未満の区分は載せていません（国別は到達100件以上の国だけ）。

結果：点数の分布

日本も海外も5点がいちばん多い山です。日本は2〜4点にも4割強（41.4%）が分かれる一方、0点は1.6%でした。海外は6点が日本の約2倍（21.8%と10.4%）ですが、0点も19.6%あり、二つの山に分かれています。海外の0点の多くはHTTP 202の応答でした（調査概要を参照）。

限界

  1. 6項目はこの調査のための単純な数で、項目の重みは同じにしています。どの項目がAIの回答にどれだけ効くかは示していません。
  2. トップページだけを見ています。下層ページの構造化データや canonical は見ていません。robots.txt はトップページ（/）に対する判定で、一部のディレクトリだけのブロックや、ファイアウォール・CDN によるブロックは数えていません。
  3. robots.txt が無いサイトは (4) を0点にしています。数え方を変えると、特に robots.txt を置かないことが多い WordPress 以外のサイトの点数は上がります。
  4. 各サイト1回の取得です。HTTP 202 など、本来のページが取れていない可能性がある応答も到達に含めています（202を除いた値を併記）。
  5. llms.txt は有無だけで、中身の質は見ていません。型は JSON-LD のみで、microdata は数えていません。
  6. 対象はWeb制作会社の自社サイトで、一般企業のサイト全体ではありません。国は当社の収集リストによるもので、各国の制作会社を無作為に抽出したものではありません。

当社の見方（意見）

ここからは事実ではなく当社の意見です。国内の制作会社サイトは、meta description・canonical・robots.txt といった基本はおおむねそろっており、差が出ているのは llms.txt と会社の型（Organization・LocalBusiness）でした。この2つはどちらも追加の作業で足せるものなので、点数を上げたい場合はまずそこから確かめるのがよいと考えます。ただし、どの項目を整えてもAIの回答に出ることが保証されるわけではありません（別の調査では、サイト側の項目と登場の間に関係は見られませんでした）。

よくある質問

6項目とは何ですか？

llms.txt がある、JSON-LD がある、Organization または LocalBusiness の型がある、robots.txt があり GPTBot・ClaudeBot・PerplexityBot・OAI-SearchBot を止めていない、meta description がある、canonical がある、の6つです。当てはまる数を0〜6点としました。Nurevo の0〜100点のスコアとは別物です。

日本の制作会社サイトの平均は何点ですか？

2,486件の平均は4.05点（中央値5点）でした。5点以上が52.2%、6点が10.4%です（2026年11月）。

いちばん欠けている項目は？

llms.txt です。日本の達成率は13.4%で、5点のサイト1,039件のうち94.9%は欠けている1項目が llms.txt でした。

6点ならAIの回答に出ますか？

保証はありません。この6項目はAIにサイトを読み取ってもらうための基本的な準備を数えたもので、回答に出るかどうかは質問や他の情報源にも左右されます。
