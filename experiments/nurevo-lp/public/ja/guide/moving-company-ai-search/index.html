引越し業者のAI検索対策：見積もり・料金の条件・キャンセル料・対応エリアをAIに正しく読ませる手順

引越し業者のAI検索対策の中心は、AIに聞かれる「見積もりは無料か、家に来てもらう必要があるか」「単身・家族でいくらぐらいか、何で金額が変わるか」「キャンセルや日にちの変更はいつまで無料か」「物が壊れたらどうなるか」「うちの地域に来てくれるか」に、ページ本文で条件まで書いて答えることです。キャンセル料や見積もりのルールは国土交通省の標準引越運送約款に沿って書き、会社は schema.org の MovingCompany、対応エリアは areaServed、無料見積もりは Service として、本文と同じ値を構造化データにします。

作成日：2026年11月19日（JST）。国土交通省・運輸局・兵庫県の資料、引越安心マークの報道、上位の記事はこの日に読みました。schema.org の型は同じ日に schema-dts 2.1.0 で確認しました。Google と国税庁のページは2026年11月1日に確認した内容です。

AIの回答は日や聞き方によって変わります。この記事の対策は、AIが引越し業者の事実を正しく読める状態をつくるもので、AIの回答に必ず表示される・順位が上がることを保証するものではありません。約款の細かい扱いは、国土交通省の最新の約款と管轄の運輸局で確かめてください。

引越しを考える人はAIに何を聞くか

引越しの相談は、場所・時期・荷物の量・お金・不安がからみます。「3月末に◯◯市から◯◯市へ、2人暮らしの引越し。いくらぐらいで、どこに頼めばいい？」「見積もりは家に来てもらわないとだめ？」「前日にキャンセルしたらいくら取られる？」「冷蔵庫が壊れたら補償される？」「エアコンの取り外しもやってくれる業者は？」といった質問です。

AIがこれに答えるには、業者のサイトに、対応する地域、見積もりの方法と費用、料金が何で決まるか、キャンセル・延期の料金、補償の申し出の方法、頼める作業（梱包、家具の組み立て、エアコンなど）が文字で書かれている必要があります。料金が「お見積もりします」だけ、対応エリアが地図の画像だけ、キャンセル料が約款のPDFの中だけ、という状態だと、AIは一括見積もりサイトや比較記事の一般論で答えることになります。

Googleは、AIによる概要やAIモードに出るための追加の要件や特別な構造化データはなく、構造化データを見える文章と一致させる、ビジネスプロフィールを最新にする、といった通常の基本が大切だとしています。Google：AI features and your website。引越し業者の対策も、裏技ではなく、事実をそろえて書くことが本体です。

見積もりとキャンセル料は、約款どおりに本文に書く

国土交通省の標準引越運送約款は、2018年6月1日施行の改正で、キャンセル・延期の料金の上限を、引越し当日は運賃と料金の50%以内、前日は30%以内、前々日は20%以内にしました（それまでは当日20%、前日10%）。1台のトラックで複数の家の荷物を運ぶ「積合せ」の引越しにも約款が使われるようになりました。国土交通省：標準引越運送約款等の改正について・中国運輸局

兵庫県の消費者向けの資料（2019年2月）は、改正後の約款のポイントとして、見積料や内金・手付金は見積もりのときに請求しないこと、見積書に書いた荷物の受け取り日の3日前までに業者が内容の変更を確かめること、荷物の破損や紛失は引越しの日から3か月以内に申し出ることを挙げています。消費者には、電話やネットだけの見積もりは避けて下見に来てもらうこと、解約・延期の料金を前もって確かめることをすすめています。兵庫県：引越しのトラブル（PDF）

AIは「前日キャンセルはいくら？」と聞かれると、約款の一般的なルールで答えることがあります。自社の扱いが約款どおりなら、そのことと料金の区分を料金のページとFAQに文字で書き、約款より利用者に有利な扱い（例：前々日までは無料）にしているなら、それをはっきり書きます。約款のPDFを置くだけでは、AIも人も読みにくいままです。

上限は2018年6月1日施行の標準引越運送約款による（国土交通省のページで2026年11月19日確認）。自社の約款を使っている場合や、その後の改正があった場合は、自社で使っている約款の値を書いてください。
引越しの日から見てキャンセル・延期の料金の上限（約款）ページでの書き方の例
当日運賃と料金の50%以内「当日のキャンセル・延期：運賃と料金の50%以内」
前日運賃と料金の30%以内「前日：30%以内」
前々日運賃と料金の20%以内「前々日：20%以内」
それより前上の区分に当たらない自社の扱い（例：「3日前までの連絡は無料」）をそのまま書く

料金は税込で書きます。国税庁は、消費者に前もって価格を示す場合は消費税を含めた総額を表示するよう案内しています。国税庁：タックスアンサー No.6902

料金は「条件つきの例」で書く

引越しの料金は荷物の量・距離・時期・建物の条件で変わるので、一律の価格は書けません。だからといって「お見積もりします」だけでは、AIは「業者によって違います」としか答えられません。条件を全部書いた見積もりの例を2〜3通り、作成した月と一緒に載せると、AIも人も「この条件ならこのくらい」と読めます。

  1. 例ごとに書く条件：人数と間取り、荷物の量（家具・家電の主なもの、段ボールの数）、移動の距離（市内・県内・県外など）、時期（月・平日か土日か・時間帯）、建物（階数、エレベーターの有無、トラックを停める場所からの距離）、作業員とトラックの数、含まれる作業（梱包材、養生、家具の組み立てなど）。
  2. 金額は税込で、見積もりを作った年月を添えます。古い例は更新するか消します。
  3. 繁忙期の扱いは、なぜ高くなるのか（作業員とトラックの数に限りがあるなど自社の事情）と、早めの予約や日程の調整でどう変わるかを書きます。業界全体の需要の数字は、出典を確かめられるものだけを使います。
  4. 追加料金がかかる場合（当日の荷物の増加、吊り上げ作業、長い距離の手運びなど）と、その決め方を書きます。兵庫県の資料は、見積もりの金額を業者の都合で増やすことはできないと案内しています。

対応エリア・補償・信頼の手がかり

対応エリアは、地図の画像だけでなく、都道府県と市区町村の名前を文字で書きます。長距離や県外の引越しを受けるか、受けるなら別の扱いがあるかも書きます。複数の営業所があるなら、営業所ごとのページに住所・電話・対応エリアを書き分けます。複数店舗・支店のAI検索対策

補償は、破損や紛失の申し出の期限（約款では引越しの日から3か月以内）、申し出の窓口、事前に伝えてほしい物、自社が入っている保険があればその範囲を書きます。保険の金額などを書くときは、契約の内容と同じにします。

信頼の手がかりとして、引越安心マークがあります。全日本トラック協会が2014年度に作った引越事業者優良認定制度で、安全で安心な引越しのサービスを提供すると認めた業者に与えられます。国土交通省：引越事業者優良認定制度。認定には、引越しを行う営業所が安全性優良事業所（Gマーク）かそれと同じ水準であること、約款を守ること、苦情に対応する体制があることなどが求められます。九州運輸局。2025年12月の報道では、2025年度に41社が認定され（有効期間は2026年1月1日〜2028年12月31日）、マークを持つ業者は348社・1,673事業所でした。LOGISTICS TODAY（2025年12月22日）

認定を受けているなら、マークの画像だけでなく「引越安心マーク（全日本トラック協会の引越事業者優良認定）取得、有効期間◯年◯月まで」と文字で会社概要に書きます。受けていないのに似た表現を使うことはしません。口コミは、Googleビジネスプロフィールなど第三者の場所で集め、サイトに自分で載せた口コミで評価を水増ししないようにします。

構造化データ：MovingCompany と areaServed

schema.org には引越し業者のための型 MovingCompany があり、住宅・建設関係の業種（HomeAndConstructionBusiness）の一つとして LocalBusiness の下にあります。対応エリアは areaServed で、都道府県や市区町村を AdministrativeArea として並べられます。無料の訪問見積もりは Service と Offer（0円）で表せます。

Nurevo AEOで業種を MovingCompany にし、訪問見積もりをサービスに入れ、対応エリアを下のフィルターで足すと、次のような形になります（値は例です）。

構造化データの値は、ページ本文と同じにします。Offer に入る金額は1つだけなので、引越しのプランの料金は本文の「条件つきの例」の表に書き、構造化データには無料の見積もりのように金額が決まっているものだけを入れるのが安全です。

WordPressの引越し業者サイトでの設定手順

  1. WordPress.orgからNurevo AEO（無料）をインストールして有効化します。Yoast SEO・Rank Math・All in One SEO・Slim SEOはそのまま使えます。0.9.1からはSEO SIMPLE PACKやVK All in One Expansion Unitとも、構造化データを重複させずに併用できます。
  2. 初回の設定ウィザードで「その他」を選び、設定画面の「業種（schema.org型）」に MovingCompany と入力します。「専門サービス」は ProfessionalService になるため選びません。
  3. 会社名・住所・電話番号・受付時間・説明を確認します。説明には、対応エリア、単身・家族・オフィスなど受ける引越しの種類、見積もりの方法を短く書きます。
  4. サービスに、訪問見積もり（0円・所要時間）、オンライン見積もり、主なプラン、エアコンなどの付帯作業を1つずつ登録します（最大20件）。名前・時間（分）・税込の料金と通貨（JPY）・カテゴリ・予約ページのURL・説明を入れると、Service・Offer・予約の操作（ReserveAction）として出力され、llms.txtにも1行ずつ載ります。料金が条件で変わるプランは、金額を入れずに説明に条件を書きます。
  5. 対応エリアは、開発者向けの webmcp_canary_business_node フィルターで areaServed を足します（下のコード。子テーマの functions.php かコードスニペットのプラグインに）。SEOプラグインを使っている場合は、そのプラグインの会社のノードにまとめられ、プラグイン側にすでにある値が優先されます。
  6. よく聞かれる質問（見積もりの費用と方法、キャンセル・延期の料金、補償の申し出、当日の追加料金、支払い方法、対応エリア外の扱い）をFAQに入れ、Nurevo FAQブロック（または[nurevo_faq]ショートコード）を置きます。料金ページだけの質問は、ブロックエディタのNurevo AEOパネルでそのページ専用のFAQにできます。
  7. /llms.txt を開き、料金・見積もり・対応エリア・補償・会社概要のページが載っているか確かめます。終わったキャンペーンのページは、Nurevo AEOパネルでllms.txtに載せない設定にできます。AEOスコアの画面で診断を実行し、不足をワンクリック修正で直します。
// 対応エリアを業者のノードに足す（値は「対応エリア」ページの本文と同じにする）
add_filter('webmcp_canary_business_node', function (array $node, array $settings) {
    $node['areaServed'] = array(
        array('@type' => 'AdministrativeArea', 'name' => '◯◯県'),
        array('@type' => 'AdministrativeArea', 'name' => '◯◯県◯◯市'),
    );
    return $node;
}, 10, 2);

WordPress以外のサイトでも、確かめる項目は同じです。登録不要の無料チェックにURLを入れると、構造化データ・llms.txt・AIクローラの許可の状態を確かめられます。SEOプラグインとの併用の詳細はYoast・Rank Math・AIOSEOに店舗情報を追加する方法をご覧ください。

一括見積もりサイト・比較サイトとのそろえ方

AIは、業者のサイトだけでなく、一括見積もりサイトや比較記事、Googleビジネスプロフィールも読みます。会社名・住所・電話・対応エリア・営業時間が場所ごとに違うと、どれが正しいかAIが判断できません。掲載しているサイトを一覧にして、年に1〜2回、自社サイトの値に合わせて直します。

料金やキャンペーンは掲載先ごとに違うことがあるので、自社サイトには「料金は見積書の金額が基準」「掲載サイトのキャンペーンは各サイトの条件による」と書いておくと、AIが古い割引の値をそのまま答える場面を減らせます。

  1. 見積もりの方法（訪問・オンライン・電話）ごとに、費用がかからないこと、所要時間、見積書を渡すことが書かれている。

AIに出ているかを確かめる

整えたあとは、引越しを考える人が聞きそうな質問を、地域・時期・人数・不安（キャンセル料、補償、見積もり）の組み合わせで5〜10個つくり、ChatGPTやPerplexityに投げて、自社が名前やURLで出るか、料金やキャンセル料の説明が正しいか、引用元が自社サイトか一括見積もりサイトかを記録します。AIの回答は回ごとに変わるので、同じ質問を期間をあけて何度か確かめ、料金のページを直した月の前後で分けて記録します。AIでの登場率の測り方

Nurevo AEOでは、Free・Standardプランでも月に1回、業種と地域から作った3つの質問（会社名は含めません）をPerplexityに投げ、回答に会社の名前やサイトが出たかを記録します。Proプラン（月14,800円〜）では、ベータ版のAI登場率の計測で、AIの回答に会社が出る割合を競合との比較・推移とあわせて見られます（現在の計測対象はPerplexity）。どちらも回答のサンプルを見るもので、すべての回答を観測するものではありません。

よくある質問

引越し業者のAI検索対策は、何から始めればいいですか？

料金のページに条件を書いた見積もりの例を載せること、キャンセル・延期の料金と補償の申し出の期限を文字で書くこと、対応エリアを市区町村の名前で書くことからです。そのうえで業種を MovingCompany にした構造化データと、Googleビジネスプロフィール・掲載サイトの値をそろえます。

料金を載せると、他社に比べられて不利になりませんか？

一律の価格ではなく、条件つきの例として載せれば、実際の見積もりと違うという誤解は減らせます。料金が書かれていないと、AIは一括見積もりサイトや一般論の金額で答えることがあります。例には条件と作成年月を必ず添えてください。

キャンセル料はどう書けばいいですか？

国土交通省の標準引越運送約款（2018年6月1日施行）では、上限は当日が運賃と料金の50%以内、前日が30%以内、前々日が20%以内です。自社で使っている約款の値と、無料になる時期を、料金のページとFAQに文字で書きます。

見積もりは訪問しないといけませんか？

決まりではありませんが、兵庫県の消費者向けの資料は、電話やネットだけの見積もりを避けて下見に来てもらうようすすめています。訪問・オンライン・電話のそれぞれで何が分かり、見積書がどう渡されるかを書くと、AIも違いを説明しやすくなります。

構造化データの型は何を使えばいいですか？

schema.org の MovingCompany です。対応エリアは areaServed、無料の見積もりは Service と Offer（0円）で表せます。値はページ本文と同じにしてください。

Nurevo AEOは無料で使えますか？

はい。会社の連絡先・受付時間・サービス・FAQの構造化データ、llms.txt、AIクローラ設定、AEOスコアは無料プランで使えます。有料プランは常に最新のルールセット（Standard、月3,000円）と、ベータ版のAI登場率の計測（Pro、月14,800円〜）を追加するものです。Nurevo AEO（WordPress.org）

対策すればChatGPTに会社が必ず出ますか？

いいえ。AIの回答は変動し、どのツールや対策でも表示や順位は保証できません。できるのは、AIが会社の事実を正しく読める状態をつくり、出ているかを継続して確かめることです。
