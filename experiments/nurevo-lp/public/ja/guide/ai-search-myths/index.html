AI検索対策（AEO・LLMO・GEO）のよくある誤解12個：公式情報と調査で確かめた「本当のところ」と、お客様への説明のしかた

AI検索対策の誤解の多くは、「AI専用の特別な施策がある」「何かを置けばAIに出る」「AIにも順位がある」の3つの思い込みから生まれています。Googleは生成AI機能のための最適化もSEOであり、AI専用のファイルやマークアップは要らないと説明しています。実際にできるのは、AIが読む事実をサイトと掲載情報でそろえ、AIのクローラを止めず、決めた質問で見え方を繰り返し確かめることです。

作成日：2026年11月13日。Google・OpenAI・Perplexityの説明は、当サイトの各ガイドを作成した際（2026年10月31日〜11月12日）に公式ページで確認したもので、本文の各所に確認先のリンクを付けています。仕様は変わることがあるため、お客様に説明する前に最新の公式ページもご確認ください。

この記事は、制作会社・SEO会社・MEO会社の担当者が、お客様から「〜って本当？」と聞かれたときにそのまま使えるよう、誤解ごとに「実際」「根拠の強さ」「自分で確かめる方法」「お客様への一言」をまとめたものです。事業者の方がご自身で判断するときにも使えます。なお、AIの回答は質問のたびに変わり、どんな対策でも、AIに必ず表示されることや順位を保証することはできません。

早見表：12の誤解と、根拠の強さ

「根拠の強さ」は、次の3段階で示しています。公式＝Google・OpenAIなど、その仕組みを運営する会社が自社のページで説明していること。当社調査＝Nurevoが自分で測った結果（条件つき）。説明なし＝公式の説明が見当たらず、誰も確かなことを言えないこと。お客様への説明では、この区別をそのまま伝えるのがいちばん誠実です。

誤解1・2：「AI検索対策はSEOと別物」「もうSEOはいらない」

Googleは、生成AI機能のための最適化について、AI機能はGoogle検索の中心となる仕組みの上に作られており、引き続きSEOであると説明しています（Google：生成AI機能向けの最適化、2026年7月10日更新）。同じページでは、AIによる概要やAIモードに表示されるには、ページがインデックスされ、スニペット付きで表示できる状態であることが前提だとしています。つまり「SEOはもういらない」は逆で、SEOの土台がないとGoogleのAI機能には出られません。

一方で、「SEOと全く同じなので何もしなくてよい」というのも言い過ぎです。AIは質問に直接答えるため、営業時間・料金・対応エリア・サービス内容のような事実が、サイトのどこかにはっきり書かれ、掲載情報と食い違っていないことの重みが増します。また、ChatGPTやPerplexityはGoogleとは別のクローラでページを読むので、それらを止めていないかの確認が加わります。AEO・GEO・LLMOという呼び方の違いはAEO・SEO・GEOの違いにまとめています。

お客様への一言：「AI検索対策の土台はSEOと同じです。そのうえで、AIが答えに使う事実をサイトに正しく書き、ChatGPTやPerplexityのクローラが読めるかを確かめる作業を足します。」

誤解3：「llms.txtを置けばAIに出る」

llms.txtは、サイトの要点と主なページをAI向けにまとめるために提案された形式です（llmstxt.org）。Googleは、生成AI機能のために新しいAI用のテキストファイルを作る必要はなく、Google検索はllms.txtを使わないと明記しています（Google：生成AI機能向けの最適化）。ChatGPTやPerplexityについては、llms.txtを読んで回答に使うと説明する公式のページを、この記事の作成時点で確認できていません。

当社が日本の地域事業者62件をPerplexityで測った調査でも、llms.txtを含むサイト側の対策のスコアと、名前が挙がる・引用される割合との間に関係は見られませんでした（詳しくは誤解5）。なお、国内のWeb制作会社のサイト2,357件を当社が2026年11月に調べたところ、llms.txtがあったのは321件（13.6%）でした（調査レポート）。

では置く意味がないかというと、「害はなく、手間も小さい補助」という位置づけが正確です。サイトの要点が1か所にまとまっていると、AIのエージェントや、将来この形式を使うサービスが読みやすくなる可能性があります。ただし効果は約束できません。書き方はllms.txtの書き方をご覧ください。

お客様への一言：「llms.txtは置いておいて損のない補助のファイルですが、これだけでAIに出るものではありません。Googleは使わないと明言しています。」

誤解4・5：「AI専用の構造化データがある」「スコアを満点にすればAIに出る」

Googleは、生成AI機能のために特別なschema.orgのマークアップは必要ないとしています（Google：生成AI機能向けの最適化）。構造化データについては、ページに表示されている内容と一致させることを求めています（Google：AI機能とウェブサイト）。「AI専用のマークアップを入れます」という提案は、根拠のない商品になりやすいので注意してください。役に立つのは、会社や店の名前・住所・電話・営業時間・業種などの通常の構造化データを、表示内容と同じ値で、重複なく出すことです。

では、構造化データやllms.txtを整えてスコアを上げれば、AIに出やすくなるのでしょうか。当社は2026年10月24日に、日本の地域事業者62件について、サイトの中の対策（構造化データ・llms.txt・クローラの許可など）を測る当社のスコアと、おすすめを尋ねる質問にPerplexityがその事業者の名前を挙げる・サイトを引用する割合を比べました。結果は、関係が見られないというものでした（Spearmanのρ＝0.03、95%信頼区間 −0.23〜0.28）。62件で確実に見つけられるのは強めの関係だけなので、弱い関係があることまでは否定できません（調査の詳細）。

当社のスコアは「AIがサイトを読める状態か」を確かめるためのもので、AIに選ばれるかどうかの予測ではありません。自社製品の数字ですが、お客様に誤解を与えないよう、ここではそのままお伝えします。

お客様への一言：「構造化データは、AIや検索エンジンに事実を正しく伝えるための基本の整備です。点数を上げること自体が目的ではなく、整えたうえで実際のAIの回答を測って確かめます。」

誤解6：「AIのクローラはまとめてブロックしておけば安全」

AIのクローラには、AIの学習のためにページを集めるものと、AI検索の回答を作るためにページを読むものがあります。OpenAIは、検索用のOAI-SearchBotと、学習用のGPTBotを別のクローラとして公開しており、OAI-SearchBotを拒否したサイトはChatGPTの検索回答に表示されないとしています（OpenAI：クローラの概要）。PerplexityもPerplexityBotとPerplexity-Userを公開しています（Perplexity：クローラ）。

つまり「AIのボットは全部止める」と書くと、学習を止めるつもりで、AI検索に出る道も閉じてしまうことがあります。逆に、学習用のGPTBotを止めても、検索用のOAI-SearchBotを許可していれば、OpenAIの説明ではChatGPTの検索回答の対象からは外れません。学習を許可するかどうかは、AI検索とは別の、お客様自身が決めることです。

当社の調査では、robots.txtがある国内のWeb制作会社のサイト2,158件のうち、少なくとも1つのAIボットにトップページを拒否していたのは28件（1.3%）で、検索用のOAI-SearchBotやClaude-SearchBotを拒否していたサイトはありませんでした（調査レポート）。止めているのは主に学習用のクローラです。

お客様への一言：「AIの学習に使われるのを止めることと、AI検索に出ることは別々に選べます。検索用のクローラは許可し、学習用はご希望に合わせて決めましょう。」

誤解7・8：「AIで1位を保証できる」「1回聞いて出なければ失敗」

Googleは、SEO会社の選び方を説明するページで、Google検索で1位を保証できる人はいないと書いています（Google：SEOの専門家が必要ですか？）。第三者のツールやアドバイスについても、AIでの改善をうたう主張は慎重に見るよう勧めています（Google：第三者のSEOツールとアドバイス）。AIの回答は、同じ質問でも日や回、ログインの有無や地域によって変わり、検索結果のような決まった順位もありません。

同じ理由で、お客様が試しにChatGPTで1回聞いて「出てこなかった」としても、それだけで対策の成否は判断できません。当社が計測で使っている方法は、店名を含まない質問を決めておき、同じ質問を同じ条件で何回か聞いて、名前が出た割合とサイトが引用された割合を分けて記録するものです。月ごとの推移で見れば、偶然の上下と変化を区別しやすくなります（AIでの登場率の測り方）。

お客様への一言：「AIの回答は毎回変わるので、1回の結果では判断しません。決めた質問を同じ条件で繰り返し聞き、割合の推移でご報告します。」

誤解9：「ツールを使えばAIの内部の評価がわかる」

Googleは、第三者のツールはGoogleの内部のランキングやAIの仕組みにアクセスできないと説明しています（Google：生成AI機能向けの最適化）。AI検索の計測ツールがしているのは、決めた質問をAIに送り、返ってきた回答に名前や出典が含まれるかを数えることです。これは役に立つサンプルですが、「AIからの評価点」ではありません。

ツールを選ぶときは、どのAIで測るか、質問をいくつ・何回聞くか、質問に店名を含めるか、失敗した回をどう扱うかが書かれているかを確かめてください。各社の違いはAEOツールの比較にまとめています。

お客様への一言：「ツールでわかるのは、決めた質問への実際の回答のサンプルです。AIの中の評価は誰にも見えません。」

誤解10：「直せばすぐ変わる」「AI会社に頼めば直してもらえる」

AIや検索エンジンが直したページをいつ読み直し、いつ回答に反映するかについて、決まった期間を示す公式の説明は見当たりません。また、会社や店の依頼でAIの回答そのものを書き換えてもらう窓口も、各社の公式ページでは確認できませんでした。GoogleのAIによる概要には、回答に対して問題を報告する機能がありますが、確実に直す手段ではありません（Google検索ヘルプ：AIによる概要）。

効果の中心は、AIが読む元の情報（自社サイト、Googleビジネスプロフィール、掲載先のサイト）を正しくそろえることです。直した日付を記録し、1〜2週間など間隔を決めて同じ質問で測り直してください。

お客様への一言：「AIの回答を直接直す方法はありません。AIが読む元の情報を直し、日付を記録して、同じ質問で変化を確かめます。」

誤解11・12：「Search ConsoleでAIのクリックがわかる」「店はサイトだけでよい」

Search Consoleの生成AIパフォーマンスレポートでは、AIによる概要とAIモードでサイトへのリンクが表示された回数を確認できます。わかるのは表示回数で、AI機能からのクリック数や順位はこのレポートでは確認できません（Search Consoleヘルプ：生成AIパフォーマンスレポート）。ChatGPTやPerplexityでの見え方はSearch Consoleの対象外なので、決めた質問での計測や、アクセス解析の参照元とあわせて見ます（Search ConsoleでAIの表示を見る方法）。

店舗や地域の会社では、Googleはビジネスプロフィールの情報を最新に保つよう勧めています（Google：AI機能とウェブサイト）。サイトの営業時間とビジネスプロフィールの営業時間が違うと、AIがどちらを答えるかはわかりません。サイト・構造化データ・ビジネスプロフィール・主な掲載先で、同じ事実を同じ書き方でそろえることが、地域の事業者にとっていちばん効果の見込める作業です（店舗の構造化データの足し方）。

お客様への一言：「Search Consoleでは、GoogleのAI機能での表示回数だけがわかります。店の情報は、サイトとビジネスプロフィールで同じにそろえるのが先です。」

自分で確かめる手順（WordPressの場合）

誤解を解くときは、説明よりも「お客様のサイトで一緒に確かめる」ほうが伝わります。次の順で、30分ほどで確認できます。

  1. ブラウザで「サイトのURL/robots.txt」を開き、OAI-SearchBot・PerplexityBotなど検索用のクローラが Disallow されていないかを見る（誤解6）。WordPressでは、SEOプラグインやセキュリティ系プラグインがrobots.txtを書き換えていることがあるので、設定画面もあわせて確認する。
  2. リッチリザルトテストにトップページと会社概要のURLを入れ、会社・店の構造化データが出ているか、営業時間や住所が表示内容と同じかを見る（誤解4）。SEOプラグインとテーマの両方が出していて重複していないかも確認する。
  3. 「サイトのURL/llms.txt」を開き、あるか、中身が今のサービスや料金と合っているかを見る。ない場合は作ってもよいが、効果は約束しない（誤解3）。
  4. Googleビジネスプロフィールの営業時間・電話・住所と、サイトの表記を見比べ、違いがあれば正しい方にそろえる（誤解12）。
  5. お客様と一緒に、店名を含まない質問を3〜5個決め、ChatGPT・Perplexity・GoogleのAIモードで聞き、日時と条件、名前が出たか、サイトが引用されたかを表に記録する（誤解7・8）。
  6. Search Consoleの権限があれば、生成AIパフォーマンスレポートで表示回数を確認し、「検索の生成 AI」の設定で意図せずサイトが除外されていないかを見る（誤解11）。

お客様に渡す「1枚の説明資料」の作り方

上の内容は、A4で1枚にまとめるとお客様との認識合わせに使えます。おすすめの構成は次のとおりです。誤解の否定ばかりにせず、「できること」を同じだけ書くのがこつです。

  1. AI検索対策とは何か（1〜2文）：SEOを土台に、AIが答えに使う事実を正しく伝え、見え方を確かめること。
  2. できること：クローラの許可の確認、構造化データ・サイト・ビジネスプロフィールの事実をそろえる、llms.txtなどの補助の整備、決めた質問での定期的な計測と報告。
  3. できないこと：AIに必ず出ること・順位の保証、AIの回答を直接直すこと、AIの内部の評価を知ること、反映までの期間を約束すること。
  4. よくある誤解（3〜5個）：早見表から、そのお客様が気にしているものを選ぶ。それぞれに公式ページのリンクを付ける。
  5. 確かめ方：どの質問を、どのAIで、何回、どの頻度で測り、何を報告するか。

月額サービスとして続けるときの作業範囲と報告のしかたは制作会社がAI検索対策を月額サービスにする方法にまとめています。お客様にNurevoをご紹介いただく制作会社・個人の方向けには、紹介パートナーの制度があります（パートナープログラム）。

Nurevo AEOでできること

Nurevo AEO（WordPressプラグイン、無料）は、AIがサイトを読める状態かを診断し、足りない構造化データ・llms.txt・AI検索用クローラの許可をサーバー側で出力します。自動で読み取るのは空欄だけで、入力済みの値は上書きしません。学習用のクローラ（GPTBot・Google-Extendedなど）は初期設定ではサイトのrobots.txtのとおりで、管理画面から許可か拒否かを選べます。これを止めても、AI検索やスコアには影響しません。SEO SIMPLE PACKやVK All in One Expansion Unitとも構造化データが重複しないように併用できます（0.9.1以降）。WordPress.orgで無料で入れてみる

料金はFree 0円、Standard 月3,000円、Pro 月14,800円〜です。接続したFree・Standardのサイトでは、店名を含まない3つの質問を月1回Perplexityに聞く無料のAIチェックが使えます。決めた質問を同じ条件で測り続ける計測はPro（ベータ）で、現在はPerplexityで測っています。上で書いたとおり、どのプランでもAIに出ることは保証しません。

よくある質問

LLMOやGEOは、意味のない言葉なのですか？

呼び方の問題で、目指すことはほぼ同じです。AIの回答で正しく取り上げられることを目的に、AIが読む情報を整えることを指します。言葉の違いより、どの作業をして、どう確かめるかを決めることが大切です。

llms.txtは置かないほうがよいのですか？

置いて問題はありません。ただし、Google検索は使わないと明言しており、他のAIで効果を示す公式の説明も確認できていないため、効果は約束せずに補助として扱うのが正確です。

GPTBotを止めると、ChatGPTに出なくなりますか？

OpenAIは、検索用のOAI-SearchBotと学習用のGPTBotを別のクローラとしています。ChatGPTの検索回答に表示されなくなるのは、OAI-SearchBotを拒否した場合だと説明しています。止める前にrobots.txtでどちらを指定しているかを確かめてください。

お客様に「AIで1位にしてほしい」と言われたら？

AIの回答には決まった順位がなく、同じ質問でも回答が変わること、Google自身が1位の保証はできないと書いていることを伝えます。そのうえで、決めた質問で名前が出る割合を測り、推移を報告する形を提案するのが誠実です。

誤解かどうか、自分で確かめる方法はありますか？

あります。robots.txt・構造化データ・llms.txt・ビジネスプロフィールはそれぞれ直接開いて確認でき、AIでの見え方は店名を含まない質問を同じ条件で繰り返し聞くことで確かめられます。手順はこの記事の「自分で確かめる手順」をご覧ください。
