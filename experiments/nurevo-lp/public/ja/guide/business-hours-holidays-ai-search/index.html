営業時間・定休日・祝日・臨時休業をAIに正しく読ませる書き方：年末年始の前にやること

AIに営業時間を正しく答えてもらうには、ふだんの営業時間・定休日・祝日の扱いをHTMLの文字で1か所にまとめて書き、年末年始や臨時休業は「何月何日から何月何日まで、休み（または何時から何時）」と日付つきで、サイト・Googleビジネスプロフィール・構造化データの3か所を同じ日に直します。休みが7日以上続くときや、いつまで休むか決まっていないときは、Googleビジネスプロフィールでは特別営業時間ではなく「臨時休業」を使います。期間が過ぎたお知らせは消すか「終了しました」と書き換え、古い日付を残しません。

作成日：2026年11月20日（JST）。料金の書き方は料金ページをAIに正しく読ませる書き方で扱いました。この記事は、店舗・クリニック・教室・事務所など、人が訪れる場所を持つすべての事業者に向けて、「営業しているか」「何時までか」をAIに正しく伝える方法に絞ります。年末年始の休みを決める前に読める形で書きます。

AIの回答は日・聞き方・使うサービスによって変わります。この記事の手順は、AIが営業時間を読み違えにくい状態を作り、正しく確かめるためのもので、回答に出ることや正しく答えられることを保証するものではありません。

サイトに書く：営業時間のブロックに入れる6つのこと

AIは「◯◯は日曜に開いている？」「今から行ける？」と聞かれると、ページの営業時間の部分を抜き出して答えます。曜日ごとの時間と例外が離れた場所にあると、例外を落として答えやすくなります。店舗情報のページ（アクセスや会社概要のページ）に、次の6つを1か所にまとめて書きます。

書くこと書く例抜けると起きること
曜日ごとの時間月・水〜金 10:00〜19:00／土・日 9:00〜18:00平日の時間を土日にも当てはめられる
定休日火曜定休休みの日に「営業中」と答えられる
祝日の扱い祝日は営業（火曜が祝日の場合も営業し、翌日休み）祝日に開いているかを推測で答えられる
受付終了・ラストオーダー最終受付 18:00閉店時刻の直前に行ってよいと伝わる
昼休み・時間帯の分け方13:00〜14:00 は休み昼休みの時間に「営業中」と答えられる
深夜をまたぐ時間金・土 18:00〜翌2:00「2時に開く」と読まれる

悪い例：「営業時間 10時〜（不定休）」。良い例：「営業時間：月・水〜金 10:00〜19:00、土・日 9:00〜18:00（最終受付は閉店の1時間前）。定休日：火曜。祝日は営業します（火曜が祝日の場合も営業し、翌水曜が休み）。臨時休業はこのページの『お知らせ』に日付つきで書きます。」

「不定休」の店は、決まり方を書きます。「月2回、前の月の25日までにこのページでお知らせします」のように、どこを見れば分かるかを書くと、AIも「公式サイトで確認を」と案内しやすくなります。営業時間を画像で見せている場合も、同じ内容を文字で書き添えます。

年末年始・お盆・臨時休業のお知らせの書き方

期間のある休みは、日付と曜日と「休み」か「時間の変更」かを、1行ずつ書きます。「年末年始はお休みをいただきます」だけでは、AIはいつからいつまでかを答えられません。

  1. 書く場所：店舗情報のページの営業時間のすぐ近くと、お知らせの記事の両方。トップページだけのバナー画像にしない
  2. 書き方：「2026年12月30日（水）〜2027年1月3日（日）は休業します。1月4日（月）から通常どおり営業します。12月29日（火）は17:00で閉店します。」
  3. 年を省かない：「12/30〜1/3」だけだと、翌年になってから去年のお知らせとして読まれても区別できない
  4. 期間が過ぎたら：その日のうちにお知らせを消すか、冒頭に「この休業は終了しました」と書く。営業時間のブロックの横に出した一言も消す
  5. 臨時休業（急な休み）：理由は短くてよいので、日付と再開日を書く。再開日が決まっていなければ「再開日はこのページでお知らせします」と書く
  6. 長い休業や移転：休業の期間、移転先、問い合わせ先を書く。移転で住所が変わるときは、古い住所のページを残さない

お知らせの記事は、年ごとに新しく作るより、同じURLの「年末年始の営業のお知らせ」を毎年書き換えるほうが、古い年のページが残りません。新しく作る場合は、前の年の記事に「この記事は2025年のものです」と書いてリンクします。

Googleビジネスプロフィール：特別営業時間と臨時休業の使い分け

GoogleのAIによる概要やAIモードがGoogleビジネスプロフィールをどう使うかは公開されていません。ただ、Googleマップと検索の店の情報には直接出るので、サイトと同じ日に直します。Googleのヘルプでは、次のように使い分けます（特別営業時間・閉業・臨時休業、2026-11-20に確認）。

状況使う設定ヘルプにある注意
祝日・年末年始・イベントで時間が変わる、または休む（6日まで続けて）特別営業時間通常の営業時間と同じでも、祝日の営業時間を確認しておくようすすめている
7日以上続けて休む、季節で休む、再開が未定臨時休業広い検索では、営業中の店のあとに表示されることがある
深夜をまたぐ特別営業時間2日に分けて入れる（19:00〜24:00 と翌日 0:00〜）翌日の通常の時間は使われなくなるので、翌日分も入れ直す
再開したとき「決まった営業時間で営業している」に戻す臨時休業の表示が消える

ちょうど7日の休みは、ヘルプのページによって書き方が少し違います（特別営業時間のページは「7日以上は臨時休業」、閉業のページは「7日を超える場合は臨時休業」）。7日ちょうどになるときは、どちらでも済むように、特別営業時間を入れたうえでサイトに日付つきのお知らせを出しておくのが無難です。

特別営業時間の手順：business.google.com で「プロフィールを編集」→「営業時間」→「特別営業時間」の編集。提案された日付を確認するか、日付を追加し、休みなら「休業」にチェック、営業するなら時間を入れて保存します。特別営業時間は、プロフィールが「決まった営業時間で営業している」になっていないと表示されません。Googleが使う祝日の一覧には、その日に「営業時間が通常と異なる可能性がある」と表示される日が国ごとに載っています（Google で使用する祝日のリスト）。

店舗が複数ある場合、Googleビジネスプロフィールには特別営業時間を他の店舗にコピーする機能が加わったと報じられています。コピーは上書きで、古い特別営業時間も一緒に写る、という注意も紹介されています（Search Engine Roundtable（2025-01-28））。店舗ごとの設定の考え方は多店舗のAI検索対策へ。

構造化データ：定休日・深夜・年末年始の書き方

構造化データは、本文に書いた営業時間を機械が読みやすい形でも示すものです。本文の代わりにはならず、本文と一致させます。Googleのローカルビジネスの構造化データのドキュメント（日本語版、2026-09-12更新）では、openingHoursSpecification は推奨のプロパティで、次の書き方が例として載っています。

<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "HairSalon",
  "@id": "https://example.jp/#business",
  "name": "ヘアサロン例",
  "openingHoursSpecification": [
    {
      "@type": "OpeningHoursSpecification",
      "dayOfWeek": ["Monday", "Wednesday", "Thursday", "Friday"],
      "opens": "10:00",
      "closes": "19:00"
    },
    {
      "@type": "OpeningHoursSpecification",
      "dayOfWeek": ["Saturday", "Sunday"],
      "opens": "09:00",
      "closes": "18:00"
    },
    {
      "@type": "OpeningHoursSpecification",
      "opens": "00:00",
      "closes": "00:00",
      "validFrom": "2026-12-30",
      "validThrough": "2027-01-03"
    }
  ]
}
</script>
<!-- 火曜は書かない＝定休日。3つ目は年末年始の休業（Googleの例と同じ書き方）。
     本文のお知らせと同じ日付にし、1月4日を過ぎたら消す -->
書きたいこと書き方（Googleのドキュメントの例）
ふだんの営業時間dayOfWeek に曜日、opens と closes に時刻（10:00 など）。曜日ごとに時間が違えば、まとまりごとに分ける
定休日その曜日を書かない。または、その曜日の opens と closes を両方 00:00 にする
24時間営業opens を 00:00、closes を 23:59
深夜をまたぐ営業1つにまとめて書く（土曜 opens 18:00・closes 03:00 で、土曜18時から日曜3時まで）
年末年始などの休業validFrom と validThrough に日付、opens と closes を 00:00

schema.org には、ふだんの営業時間を上書きする specialOpeningHoursSpecification というプロパティもあります（schema.org）。ただ、Googleのドキュメントには載っておらず、Googleが例に使っているのは上の validFrom・validThrough の書き方です。また schema.org の説明では「opens が書いてあれば営業、なければ休み」となっていて、「00:00〜00:00で休み」というGoogleの書き方と表現が違います（OpeningHoursSpecification）。迷ったら、Googleの例の書き方にそろえます。

曜日の値には PublicHolidays（祝日）もありますが、どの国の祝日かは定義されておらず、Googleのドキュメントの例にもありません。祝日の時間が違う場合は、祝日ごとに日付で書くか、本文の文章で書きます。書いたら リッチリザルトテスト や Schema Markup Validator で文法を確かめます。ChatGPTやPerplexityが営業時間の構造化データを使うと明記した公式の資料は、調べた範囲では見つかりませんでした。

WordPressでの手順（Nurevo AIOの場合）

Nurevo AIO（無料、旧表示名 Nurevo AEO）では、設定画面の「営業時間」に入れた文字が、店の構造化データと llms.txt の「Hours」の行に出ます。次の順で進めます。

  1. 先に店舗情報のページの本文を、この記事の6つのことで整える（構造化データより本文が先）
  2. 「営業時間」の欄には、毎週決まっている時間と定休日だけを書く（例：「月・水〜金 10:00-19:00 / 土・日 9:00-18:00 火曜定休」）。よくある日本語・英語の書き方なら、曜日ごとの openingHoursSpecification として出る
  3. 祝日・「第2火曜」・ラストオーダーなどを欄に書くと、読み違えを避けるため曜日ごとの形には直さず、入れた文字のまま（openingHours の文字列として）出る。推測で時間を作ることはない。例外は本文に書き、欄は毎週の形にしておくと、曜日ごとの形で出る
  4. 「24:00まで」は 23:59 として、「18:00-02:00」は深夜をまたぐ時間として出る。「9-5」のように午前・午後がはっきりしない書き方は曜日ごとの形にせず、入れた文字のまま出る（「9:00-17:00」と24時間制で書く）
  5. 年末年始の休業を構造化データにも出したい場合は、開発者向けの webmcp_canary_business_node フィルターで、Googleの例と同じ形の1行を足せる（下のコード）。期間が過ぎたら消す
  6. SEOプラグインやテーマが店の名前・住所・電話・営業時間まで出している場合、Nurevoは店の情報を重ねて出さないので、フィルターは効かない。そのときは、そのプラグインやテーマの営業時間の設定で直す。Yoast SEO・Rank Math・All in One SEO・Slim SEO と一緒でも二重にならず、0.9.1からは SEO SIMPLE PACK・VK All in One Expansion Unit とも併用できる
  7. ネットショップやBtoBとして設定したサイトでは、営業時間は構造化データにも llms.txt にも出ない（訪れる場所がないため）
add_filter('webmcp_canary_business_node', function ($org, $settings) {
    // 年末年始の休業。本文のお知らせと同じ日付にし、期間が過ぎたら消す
    if (!empty($org['openingHoursSpecification']) && is_array($org['openingHoursSpecification'])) {
        $org['openingHoursSpecification'][] = array(
            '@type'        => 'OpeningHoursSpecification',
            'opens'        => '00:00',
            'closes'       => '00:00',
            'validFrom'    => '2026-12-30',
            'validThrough' => '2027-01-03',
        );
    }
    return $org;
}, 10, 2);

子テーマの functions.php や、コードを追加するプラグインに書きます。書いたら、ページのソースかリッチリザルトテストで、店の情報に休業の1行が入っていることを確かめます。llms.txt の「Hours」の行は「営業時間」の欄の文字がそのまま出るので、年末年始の一言を欄に足した場合は、期間が過ぎたら欄からも消します。

お客様のサイトを保守している制作会社は、年末年始・お盆・ゴールデンウィークの前に「休みの日程を聞く→サイト・プロフィール・構造化データを直す→期間後に戻す」を保守の作業に入れておくと、直し忘れを防げます。月額で支援する制作会社向けにパートナー制度があります。

年末年始の前のスケジュール

いつやること
休みの日程が決まったらすぐサイトの営業時間のブロックとお知らせに日付つきで書く。Googleビジネスプロフィールの特別営業時間を入れる
同じ日予約サイト・ポータル・SNSのプロフィールの営業時間を直す。構造化データに休業の1行を足す場合はここで
休みの数日前同じ質問をAIに聞き、休みの日について何と答えるかを記録する（下の確かめ方）
休みの最終日の翌日お知らせを消すか「終了しました」に。構造化データの休業の1行と、営業時間の欄に足した一言を消す
その1〜2週間後同じ質問でもう一度確かめ、古い休みの情報を答えていないかを見る

各AIが新しい営業時間を反映するまでの日数は公開されていません。休みの直前に直しても間に合うとは限らないので、日程が決まった時点で直すのが確実です。

確かめ方：営業時間の質問を決めて記録する

営業時間が正しく伝わっているかは、同じ質問を同じAIに、日を変えて何回か聞いて記録します。1回の答えだけで判断しないでください。

質問の例見ること
「（店名）は何時まで？」曜日ごとの時間と受付終了が合っているか
「（店名）は祝日に開いている？」祝日の扱いを推測ではなく、書いたとおりに答えるか
「（店名）の年末年始の営業は？」今年の日付で答えるか。去年のお知らせを答えていないか
「（地域）で日曜の夜に開いている（業種）は？」社名なしの質問で、時間の条件に合う店として出るか

記録するのは、日付・AIのサービス名・質問・答え・出典のURLです。出典が古いPDF、ポータル、去年のお知らせなら、そこを直します。Nurevoの無料プランとStandardでは、月に1回、業種と地域から作った社名なしの質問3つをNurevoのサービスがPerplexityに聞き、名前が出たか・サイトが引用されたかを表示します。Pro（月14,800円〜、ベータ）は最大20問をPerplexityで計測します（ChatGPTは設定され次第）。営業時間の質問は手で記録してください。詳しくはAIでの登場率の測り方へ。

  3. 「不定休」の場合は、決まり方とお知らせを出す場所が書いてある
  4. 年末年始・臨時休業のお知らせに、年・日付・曜日・再開日が書いてある
  5. 期間が過ぎたお知らせ・古い営業時間のPDFやチラシが残っていない
  6. Googleビジネスプロフィールの通常の営業時間・特別営業時間がサイトと同じ
  7. 7日以上の休み・再開未定の休みは「臨時休業」にしている。再開したら戻した
  8. 構造化データの営業時間が本文と同じ。休業の1行は期間後に消す予定を決めた
  9. 予約サイト・ポータル・SNSの営業時間もサイトと同じ
  10. AIへの質問を決め、休みの前と後に記録した

よくある質問

Googleビジネスプロフィールを直せば、ChatGPTやPerplexityの答えも直りますか？

そうとは限りません。ChatGPTやPerplexityがGoogleビジネスプロフィールをどう使うかは公開されていません。サイト・ポータル・SNSも同じ日に直し、出典として表示されたページを確かめてください。

定休日は構造化データにどう書きますか？

その曜日を書かないか、その曜日の opens と closes を両方 00:00 にします。Googleのドキュメントはどちらの例も載せています。本文にも「火曜定休」と書きます。

祝日だけ時間が違います。構造化データで書けますか？

曜日の値に PublicHolidays はありますが、どの国の祝日かは定義されておらず、Googleの例にもありません。祝日ごとに validFrom・validThrough で日付を書くか、本文に文章で書くのが確実です。Googleビジネスプロフィールでは祝日ごとに特別営業時間を入れます。

臨時休業にすると検索で不利になりますか？

Googleのヘルプには、広い検索では臨時休業の店が営業中の店のあとに表示されることがある、と書かれています。休みが6日までなら特別営業時間を使い、再開したらすぐ「決まった営業時間で営業している」に戻します。

AIが去年の年末年始の休みを答えます。

表示された出典のURLを確かめ、去年のお知らせなら消すか「終了しました」と書き換えます。お知らせに年を書いていなかった場合は、年を書き足します。反映までの日数は公開されていないので、数日〜数週間後に同じ質問で確かめます。

営業時間を画像で見せています。問題ですか？

画像を読めるかどうかはAIのサービスごとに違い、公開されていません。デザインのために画像を残す場合も、同じ内容をHTMLの文字で書き添えてください。

Nurevoの「営業時間」の欄に祝日のことも書いていいですか？

書けますが、その場合は読み違えを避けるため、入れた文字のまま出て曜日ごとの形にはなりません。欄には毎週決まった時間と定休日だけを書き、祝日や臨時休業は本文に書くと、曜日ごとの形で出ます。

AIが読める状態か、無料で確かめる

無料の診断は登録不要で、URLを入れるだけでAIのクローラーの許可・構造化データ・llms.txt を確認できます。WordPressなら無料のプラグインで、営業時間・住所・電話を構造化データと llms.txt に出せます。SEOプラグインの出力とは重複しません。
