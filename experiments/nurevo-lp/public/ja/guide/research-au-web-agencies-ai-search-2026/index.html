オーストラリアのWeb制作会社の自社サイト1,719件に見るAI検索への対応（2026年11月）

オーストラリアのWeb制作会社の自社サイト1,719件のトップページ・robots.txt・llms.txt を調べたところ、llms.txt があったのは24.3%（418件）で、日本の13.4%より高く、米国（23.1%）・英国（21.5%）・ニュージーランド（25.4%）とは統計的な差が見られませんでした。AI検索に関わる6項目をすべて満たすサイトは20.8%で、日本のちょうど2倍です。robots.txt でAIボットをブロックしていたのは4.7%で、GPTBot をブロックしていた56件のうち55件は ChatGPT の検索用ボット（OAI-SearchBot）をブロックしていませんでした。

公開：2026年11月19日。データ：2026年11月12日集計。調査・執筆：Nurevo AEO（Bestie.合同会社）。Nurevo はAI検索対策（AEO）のツールと WordPress プラグインを提供しており、この分野に利害があります。国別レポートの3本目です（これまでに米国・英国）。

要点

  1. オーストラリアのWeb制作会社の自社サイト1,719件のうち、llms.txt があったのは24.3%（418件）。日本（13.4%）より高く（p<0.001）、米国（23.1%、p=0.32）・英国（21.5%、p=0.12）・ニュージーランド（25.4%、p=0.68）とは差が見られませんでした。トップページが HTTP 202 を返した250件を除くと28.4%です。
  2. AI検索に関わる6項目をすべて満たすサイトは20.8%（357件）で、日本（10.4%）の2.0倍でした。FAQPage の構造化データは10.3%で、米国（6.2%）・日本（3.9%）より高い値です（どちらも p<0.001）。
  3. robots.txt があるサイト1,336件のうち、AIボットをブロックしていたのは4.7%（63件、日本1.3%）。GPTBot をブロックしていた56件のうち55件は OAI-SearchBot を許可していました。検索用・質問時の取得に使われる4つのボットのどれかをブロックしていたのは5件（0.4%）でした。

調査概要

  1. 対象：Web制作会社の自社サイト。当社の収集リストで国がオーストラリアとなっている制作会社サイト2,289件のうち、トップページに到達できた1,719件です。一般企業のサイト全体ではありません。比較には同じ調査の米国（4,472件）・英国（942件）・ニュージーランド（417件）・日本（2,486件）・オーストラリア以外の海外（11,633件）を使いました。
  2. 取得したもの：各サイトのトップページ、/robots.txt、/llms.txt、/llms-full.txt を1回ずつ（User-Agent：NurevoSurvey/1.0）。2026年11月上旬〜12日に取得し、11月12日に集計しました。
  3. 判定方法：llms.txt は、ステータス200で中身がHTMLではなく20文字を超えるテキストを「あり」としました。JSON-LD はトップページにあるかどうか、「壊れている」は JSON として読み込めないブロックが1つ以上あるもの。Organization系は @type に Organization・LocalBusiness・Corporation・ProfessionalService を含むもの。WordPress はトップページのHTMLに wp-content/・wp-includes/、または generator の WordPress 表記があるもの。SEOプラグインはトップページのHTMLの文字列で判定しました。
  4. AIボットのブロック：robots.txt で、各ボットに当てはまるグループの規則がトップページ（/）を Disallow にするか（最長一致）で判定しました。分母は robots.txt があるサイトです。「AIボットをブロック」は GPTBot・ClaudeBot・PerplexityBot・Google-Extended・CCBot・OAI-SearchBot のどれかをブロックしているものです。
  5. 「6項目」は、(1) llms.txt がある、(2) JSON-LD がある、(3) Organization または LocalBusiness の型がある、(4) robots.txt があり GPTBot・ClaudeBot・PerplexityBot・OAI-SearchBot のどれもブロックしていない、(5) meta description がある、(6) canonical がある、のうち当てはまる数（0〜6）です。この調査のための単純な数で、Nurevo の0〜100点のスコアとは別物です。
  6. HTTP 202：オーストラリアでは250件のトップページがステータス202を返しました（日本は0件）。これらのページには JSON-LD も WordPress の痕跡もなく、ボット確認などの別のページが返った可能性があります。そのため、202を除いた値も並べています。
  7. 統計：オーストラリアと他の地域の差はカイ二乗検定で確かめました。30件未満の区分は載せていません。

結果：オーストラリアと米国・英国・日本の比較

オーストラリアの値は、ほとんどの項目で米国・英国より1〜3ポイント程度高く、なかでも FAQPage（10.3%）は米国（6.2%）との差がはっきりしていました。llms.txt・「6項目すべて」・AIボットのブロックは、米国・英国・ニュージーランドとの間に統計的な差は見られません。日本と比べると、llms.txt・FAQPage・「6項目すべて」が高く、meta description・canonical・robots.txt は低めです。低めの項目は、202を返した250件（ほぼすべての項目が「なし」になる）の影響を受けており、202を除くと meta description 82.2%、canonical 88.8%、robots.txt 90.2% です。オーストラリア以外の海外全体（11,633件）と比べると、llms.txt は少し低めでした（24.3%と26.7%、p=0.04）。

ボット別のブロック率

オーストラリアで robots.txt があるサイト1,336件について、ボットごとにトップページをブロックしている割合です。学習用とされるボット（CCBot・GPTBot・Bytespider・ClaudeBot・Google-Extended・Applebot-Extended・anthropic-ai）は3.4〜4.3%で、米国・英国とほぼ同じ、日本の3〜4倍でした。検索用やユーザーの質問に答えるときに使われるボットは、ChatGPT-User 4件、PerplexityBot 2件、OAI-SearchBot・Claude-SearchBot 各1件です。Googlebot をブロックしていたサイトが1件、Bingbot は0件でした。

ブロックの中身（事実）

  1. GPTBot をブロックしていた56件のうち55件（98.2%）は、OAI-SearchBot をブロックしていませんでした。米国は128件中119件（93.0%）、英国は28件中28件です。
  2. 上の11種のAIボットのどれかをブロックしていた65件のうち42件（64.6%）は、GPTBot・ClaudeBot・anthropic-ai・Google-Extended・CCBot・Bytespider・Applebot-Extended の7つをまとめてブロックする同じ組み合わせでした（米国58.5%・英国77.1%）。次に多いのは CCBot と Bytespider の2つだけ（6件）です。
  3. OAI-SearchBot・ChatGPT-User・Claude-SearchBot・PerplexityBot のどれかをブロックしていたのは5件（robots.txt があるサイトの0.4%）でした。
  4. robots.txt でAIボットの名前を挙げていながら、どれもトップページをブロックしていないサイトが79件ありました（robots.txt があるサイトの5.9%）。
  5. AIボットをブロックしていた65件のうち14件（21.5%）には llms.txt もありました。

限界

  1. 対象はWeb制作会社の自社サイトで、一般企業のサイト全体ではありません。国は当社の収集リストの記載によるもので、オーストラリアの制作会社全体を代表する標本ではありません。ボット別の件数などは小さい数です。
  2. トップページだけを見ています。robots.txt はトップページ（/）に対する判定で、一部のディレクトリだけのブロックや、ファイアウォール・CDN によるブロックは数えていません。llms.txt は有無だけを見て、中身の質は見ていません。

当社の見方（意見）

ここからは事実ではなく当社の意見です。オーストラリアの制作会社サイトは、米国・英国とほぼ同じ水準で、FAQPage や所在地・連絡先の型がやや多いのが特徴でした。日本との差は llms.txt と「全部そろっているか」に表れています。AIボットのブロックは少数で、ブロックしているサイトもほとんどが学習用のボットに限っていました。どのボットを止めるかは各社の判断ですが、AI検索に出たい場合は、検索用のボットまで止めていないかを確かめる価値があります。どれを整えてもAIの回答に出ることが保証されるわけではありません（別の調査では、サイト側の項目と登場の間に関係は見られませんでした）。

オーストラリアの制作会社は日本よりAI検索への対応が進んでいますか？

llms.txt（オーストラリア24.3%・日本13.4%）と「6項目すべて」（20.8%・10.4%）はオーストラリアが高く、JSON-LD は71.3%と69.4%で差は見られませんでした。meta description や canonical は日本のほうが高めです（2026年11月、Web制作会社の自社サイト）。
