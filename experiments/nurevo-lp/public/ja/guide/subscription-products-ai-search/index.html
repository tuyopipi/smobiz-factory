定期便・サブスク商品のAI検索対策：解約条件・回数・総額をAIに正しく読ませる手順

定期便についてAIに聞く人が知りたいのは「1回いくらで、何回続けると総額いくらか」「いつまでに、どうやって解約できるか」です。答えの材料になるのは、商品ページの本文に文字で書いた1枚の条件の表です。初回価格と2回目以降の価格、回数の約束、総額、スキップと解約の締め切り、解約の方法を同じ表に並べ、注文の最終確認画面・よくある質問・llms.txt と同じ値にそろえると、AIが「初回だけの価格」や「条件の抜けた『いつでも解約可能』」を答えにしにくくなります。

作成日：2026年11月28日（日本時間）。消費者庁と埼玉県の公開ページ、schema.org、Google と WooCommerce の公式の説明を同じ日に読んで確認しました。

対象は、食品・化粧品・日用品などを定期便やサブスクリプションで売っているネットショップの方と、その制作・運用の担当者です。ショップ全体の情報（送料・返品・在庫）はネットショップのAI検索対策、色やサイズの書き方は商品のサイズ・色・仕様をAIに正しく読ませる手順にあります。ここでは「定期で届く契約の条件」だけを扱います。

この記事は法律の助言ではありません。表示が法律に合っているかは、消費者庁の資料や専門家に確認してください。AIの答えは聞くたびに変わることがあり、ここに書いたことでAIに出ることを約束するものではありません。

上位の記事に書かれていなかったこと

「定期通販 AIO対策」「ECサイト LLMO」「subscription ecommerce AI search」などで上位に出る日本語6本・英語5本を、2026年11月28日に読みました。定期購入の条件と解約方法を画像ではなく文字で書くべきだという指摘（MarTechLab）や、「解約は簡単か」「一時停止できるか」といった質問を見張るべきだという指摘（Ranktracker、Texta）は役に立つものでした。一方で、次のことはどの記事にもありませんでした。

  1. 定期便の条件を、どの項目・どの順番でページに書けばよいかの具体的な形
  2. 特定商取引法の最終確認画面の項目と、AIが読むページの項目をそろえる考え方
  3. 定期便の価格を構造化データでどこまで書けるか（Google が何を案内していないか）
  4. WordPress（WooCommerce Subscriptions）の画面での手順
  5. 定期便の条件について、AIの答えが正しいかを確かめる質問の例

以下では、この5つを順に埋めます。

定期便についてAIに聞かれる質問と、答えに必要な事実

生成AIの答えを買う前の参考にする人は増えています。株式会社ギャプライズの2025年の調査（800人）では、44.0%が購入前に生成AIを使っていました（MarTechLab）。定期便は「買ったあとに続く契約」なので、聞かれるのは商品のよさより条件です。よくある質問と、答えに必要な事実を並べました。

よく聞かれること答えに必要な事実書いてないとどうなりやすいか
1回いくら？初回価格と2回目以降の価格、税込か、送料込みか初回の安い価格だけが答えに出る
何回で解約できる？回数の約束（最低回数）の有無と回数「いつでも解約可能」とだけ答えられる
全部でいくらかかる？回数の約束がある場合の総額、ない場合の例利用者が自分で計算することになる
休める？間隔は変えられる？スキップ・休止・間隔の変更の方法と締め切り「できるかどうか分からない」と答えられる
どうやって解約する？解約の方法（画面・電話・メール）、受付時間、締め切り、解約料他のサイトの口コミが答えの材料になる
他の定期便と比べてどう？上のすべてが、比べられる形で並んでいること比べる材料が少ない店は候補に挙げにくい

どの質問も、ページに文字で書かれていれば答えの材料になります。画像のバナーやポップアップの中だけにある条件は、AIの検索の仕組みによっては読まれません。

1枚の「定期便の条件」の表にまとめる

条件はページのあちこちに散らさず、1か所に、1行1項目で並べます。AIは見出しと短い行の組み合わせを読み取りやすく、人にとっても比べやすくなります。架空のコーヒー豆の定期便で書いた例です。

【定期便の条件】国産ブレンド珈琲豆 定期便（200g）
- 1回の内容：珈琲豆 200g × 1袋
- お届けの間隔：4週間ごと（2・4・6週間から選べます）
- 価格：初回 1,980円、2回目以降 2,480円（税込・送料込み）
- 回数の約束：なし（初回のあと、いつでも解約できます）
- 総額の例：3回受け取った場合 6,940円
- お支払い：お届けごとにクレジットカードで決済（発送日に決済）
- スキップ・休止・間隔の変更：マイページから、次回発送日の5日前まで
- 解約の方法：マイページの「定期便の解約」ボタン、または電話 03-0000-0000（平日10〜17時）
- 解約の締め切り：次回発送日の5日前まで（それ以降は次の1回が届きます）
- 解約料：なし
- 返品：未開封で到着から8日以内（初回のみ送料当店負担）
最終更新：2026年11月28日

書くときのポイントは4つです。1つ目は、初回価格と2回目以降の価格を同じ行に書くことです。2つ目は、回数の約束がないなら「なし」と書くことです。書いていないと、AIは「ない」とは判断できません。3つ目は、締め切りを「次回発送日の5日前」のように日付の数え方で書くことです。4つ目は、最終更新日を入れることです。価格や締め切りを変えたら、日付も変えます。

同じ表を、商品ページ、定期便の案内ページ、注文の最終確認画面、よくある質問の答えで使い回します。言い回しが違っても、数字と締め切りは同じにします。

特定商取引法の最終確認画面と同じ値にそろえる

2022年6月1日に施行された改正特定商取引法（第12条の6）で、ネットショップの注文の最終確認画面に、契約の大事な条件を表示することが決まりました（消費者庁）。埼玉県の消費生活支援センターの説明では、表示する項目は次の6つです（埼玉県）。

最終確認画面の項目定期便で書くこと上の条件の表の行
分量1回の内容、回数、期間1回の内容・回数の約束
価格各回の代金と、今後支払う代金の総額価格・総額の例
支払の時期と方法いつ、何で決済するかお支払い
引渡しの時期いつ届くか、間隔お届けの間隔
申込みの期限期限がある場合はその期限（期限があれば足す）
申込みの撤回・解除解約の方法、締め切り、解約料解約の方法・締め切り・解約料

同じページでは、大きな「お試し」「初回無料」の近くに小さく定期購入と書く表示や、条件を隠した「いつでも解約可能」が、誤解を招く表示の例として挙げられています。こうした表示で誤解して申し込んだ人は申込みを取り消せる（第15条の4）とされ、行政処分や罰則の対象にもなります（埼玉県）。消費者庁のガイドライン「通信販売の申込み段階における表示についてのガイドライン」も公開されています（消費者庁）。

AI検索のためにも、この6項目は役に立ちます。最終確認画面に出す値をそのまま商品ページの条件の表にも書いておくと、AIが読むページと、お客様が申し込む画面の内容が一致します。逆に、商品ページには「初回1,980円」だけ、条件は最終確認画面にだけ、という作りだと、AIが読めるのは初回価格だけになりがちです。最終確認画面はログインやカートの中にあり、AIの検索のクローラーは通常そこまで入りません。

構造化データで書けること・書けないこと

Google の商品の構造化データ（merchant listing）の説明には、定期便の周期や回数を書く項目はありません。UnitPriceSpecification（単位あたりの価格）は、単位価格、元の価格（取り消し線の価格）、会員価格の書き方として案内されています（Google）。

schema.org の語彙では、UnitPriceSpecification に referenceQuantity（何あたりの価格か）や billingDuration（「定期の契約や支払いプランの期間」を表すのに使える）が定義されています（UnitPriceSpecification、billingDuration）。書くなら次のような形ですが、Google の検索の表示に使われるとは案内されていないため、優先度は本文の表より下です。

<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "Offer",
  "url": "https://shop.example.jp/product/coffee-subscription/",
  "price": "2480",
  "priceCurrency": "JPY",
  "availability": "https://schema.org/InStock",
  "priceSpecification": {
    "@type": "UnitPriceSpecification",
    "price": "2480",
    "priceCurrency": "JPY",
    "valueAddedTaxIncluded": true,
    "referenceQuantity": { "@type": "QuantitativeValue", "value": 4, "unitCode": "WEE" }
  }
}
</script>
※ 価格・URLは書き方の例です。WooCommerce がすでに出している Product の
  offers を、プラグインやフィルターで書き換える形にし、Product を2つ作らないでください。
  Google はこの書き方を定期便の表示に使うとは案内していません。

WooCommerce はすでに商品の Product と Offer を出しているので、別の Product を足すと同じ商品が2つあることになります。足すなら WooCommerce の Offer を書き換える形にし、できないなら構造化データは触らず、本文の表とよくある質問を整えるほうが確実です。

WordPress（WooCommerce Subscriptions）での手順

WooCommerce Subscriptions の公式の説明（2026年11月25日更新）では、定期便の商品に設定する項目は、定期の価格、支払いの間隔（日・週・月・年ごと、1〜6の間隔）、更新を止めるまでの期間、初回登録料、無料のお試し期間です。初回登録料は定期の価格に足され、たとえば月75ドルに登録料200ドルなら、最初の会計は275ドルになるとされています（WooCommerce）。

  1. 1. 商品の編集画面で、定期の価格・間隔・期間・登録料・お試し期間を設定し、保存後にプレビューで、お客様に見える価格の表示を確認する
  2. 2. 商品説明に「定期便の条件」の表を文字で貼る。プレビューで見えた価格の表示と、表の数字が同じかを確かめる
  3. 3. 解約の方法・スキップの方法を書いた案内ページを1つ作り、商品説明からリンクする
  4. 4. 注文の最終確認画面に、条件の表と同じ6項目が出ているかを、実際にテスト注文の直前まで進めて確かめる
  5. 5. よくある質問（何回で解約できるか、いつまでに解約すればよいか、休めるか）を、Nurevo AEO の設定に入れ、Nurevo FAQ ブロックを案内ページに置く。そのページにだけ FAQPage の構造化データが出る
  6. 6. Nurevo AEO のサイトの種類を「ネットショップ」にし、返品ポリシーと配送のページのURLを入れる。llms.txt の商品の一覧には商品ごとに価格が1つ載るので、その価格がどの回の価格かが分かるよう、商品名か案内ページで補う
  7. 7. SEO SIMPLE PACK などのSEOプラグインと併用していても、Nurevo AEO 0.9.1 以降は構造化データを重ねて出さない。他の構造化データのプラグインを足す場合は、Product が2つにならないかを確かめる

llms.txt の商品の行には、名前・URL・価格・通貨・在庫・SKU・カテゴリーが載り、周期や回数の約束は載りません。条件を llms.txt にも載せたい場合は、案内ページのURLを主なページとして載せるか、開発者向けのフィルター（webmcp_canary_llms_txt_lines）で行を足します。

海外のお客様にも売る場合

米国では、ネットでの定期契約に ROSCA という法律があり、決済情報を受け取る前に大事な条件をはっきり示すこと、同意を得ること、簡単に止められる方法を用意することが求められています。連邦取引委員会（FTC）の「クリックで解約」の規則は2025年7月に裁判所で取り消され、2026年3月に規則づくりがやり直されています（Gibson Dunn）。州ごとの自動更新の法律も約30州にあるとされます（Jones Day）。

英国では、DMCC法の定期契約の規則が2027年1月に施行される見込みと伝えられています（2026年10月22日時点、DWF）。どちらの国でも、条件の表を英語で用意しておくことが、法律への対応とAIの答えの両方の土台になります。

AIの答えを確かめる質問の例

条件の表を載せたら、ChatGPT・Perplexity・Google の AI による概要で、次のように聞いてみます。ページの更新から反映まで時間がかかることがあるので、数週間おきに同じ質問を繰り返し、答えと日付を記録します。

  1. 「（店名）の（商品名）の定期便は、何回続けないと解約できませんか？」
  2. 「（商品名）の定期便を3回受け取ると、総額いくらですか？」
  3. 「（店名）の定期便の解約は、いつまでに、どうやって申し込めばよいですか？」
  4. 「（商品のジャンル）の定期便で、回数の約束がないものを教えて」

答えが表と違うときは、AIが出典にしたページを確かめます。古いキャンペーンのページ、比較サイト、口コミが出典になっていることがよくあります。自社の古いページなら更新するか、最新の案内ページへのリンクを足します。Nurevo AEO の Pro プランでは、こうした質問でのAIでの登場を Perplexity で計測しています（ChatGPT は設定され次第）。

チェックリスト

  1. 条件の表が、画像ではなく文字で商品ページにある
  2. 初回価格と2回目以降の価格が同じ行にある
  3. 回数の約束が「なし」または「◯回」とはっきり書いてある
  4. 総額（または受け取り回数ごとの例）が書いてある
  5. スキップ・休止・解約の締め切りが、次回発送日からの日数で書いてある
  6. 解約の方法と受付時間、解約料が書いてある
  7. 最終確認画面の6項目と、表の数字が一致している
  8. よくある質問の答えと、表の数字が一致している
  9. 古いキャンペーンのページが、今と違う条件のまま残っていない
  10. 表に最終更新日があり、条件を変えたら更新している

よくある質問

定期便の条件は、商品ページと別のページのどちらに書けばいいですか？

商品ページに条件の表を置き、解約やスキップの手順は別の案内ページにまとめてリンクするのがおすすめです。どちらのページでも数字と締め切りは同じにします。

「初回無料」「初回980円」と大きく書いてもいいですか？

書くことはできますが、すぐ近くに2回目以降の価格と回数の約束を同じ大きさで書いてください。埼玉県の説明では、大きなお試しの表示の近くに小さく定期購入と書く表示が、誤解を招く例として挙げられています。

回数の縛りがあると、AIに不利になりますか？

回数の約束があること自体で不利になるかは分かりません。ただ、書いていないと、AIが「いつでも解約可能」と答えたり、口コミの不満が答えの材料になったりしやすくなります。回数と総額をはっきり書くほうが安全です。

構造化データだけで条件を伝えられますか？

伝えられません。Google の商品の構造化データには定期便の周期や回数の項目がなく、本文の文字の表が一番大事です。構造化データは補助として考えてください。

WooCommerce Subscriptions の設定を変えたら、何を直せばいいですか？

商品説明の条件の表、案内ページ、よくある質問、最終確認画面の表示の4つを同じ日に直し、表の最終更新日を変えます。llms.txt の価格は WooCommerce の価格から作られます。

Nurevo AEO は定期便の条件を自動で出力しますか？

いいえ。Nurevo AEO はショップの情報（OnlineStore）、返品ポリシー、llms.txt の商品の一覧（商品ごとに価格1つ）を出し、AIの検索のクローラーを許可します。周期や回数の約束は、本文の表とよくある質問で書いてください。

まず、AIからショップがどう読めているかを確かめる

無料の診断で、構造化データ・llms.txt・AIのクローラーの許可の状態が登録なしで分かります。WordPress なら Nurevo AEO を無料で入れて、ショップの情報と商品の一覧をAI向けに出せます。
