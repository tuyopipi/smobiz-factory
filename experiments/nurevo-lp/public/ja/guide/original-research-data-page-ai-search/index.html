独自調査・データのページの作り方：AI検索と記者に引用される「原本」を自社サイトに置く手順

独自調査やデータをAI検索に引用してもらうには、プレスリリースだけでなく、自社サイトに「原本」のページを置き、数字と一緒に対象・件数・期間・方法・限界を書くことが基本です。数字や引用を足した文章はAIの回答に使われやすいという研究がある一方、出典として選ばれる仕組みは公表されておらず、引用を約束できる方法はありません。小さな会社でも、自社の受注や問い合わせの集計、価格の推移、測定・比較の結果なら、ほかにないデータを作れます。

作成日：2026年11月25日（日本時間）。研究と調査の数字は、論文（arXiv）・Search Engine Land の記事・Googleの公式ドキュメント・消費者庁の発表と報道を同日に読んで確認しました。

AIの回答は日々変わり、どのページを出典にするかはAIの会社ごとに決めていて、詳しい基準は公表されていません。この記事は、調査を正しく、確かめられる形で公開するための手順です。

数字や一次情報は、AIの回答に使われやすいのか：3つの研究

「独自データはAIに引用されやすい」という話はよく見かけますが、根拠になっている研究は条件つきです。主な3つを並べます。

研究条件わかったこと
GEO（プリンストン大学ほか、KDD 2024）1万件の質問。Google上位5件をもとに gpt-3.5-turbo が答える実験用の仕組み（Perplexity でも検証）統計を足すと見える量の指標が19.3→25.2、引用を足すと27.2、出典を書くと24.6。キーワードの詰め込みは17.7に下がった。最大で約40%の改善（Perplexity では最大37%）
Kevin Indig（Search Engine Land）Gauge のデータで、7業種・316の質問で引用された301ページ・1,075件の引用一次調査は8ページ（2.7%）だが引用の8.4%（90件）を集め、1ページあたり11.3件（ほかは3.4件）。ただし90件中75件はクラウドのデータ基盤の性能比較という1つの分野に集中
Sprinklr の研究者（SIGIR 2026）6つのAIモデル、2つの文書をくらべる実験を25万2,000回引用の順番を最も左右したのは、質問との関連性と並び順。明記された価格と新しい日付も効いた。見た目の書式だけの変更はほとんど効かなかった

出典：GEO の論文、Kevin Indig の記事、What Gets Cited。GEO は実験用の仕組みでの結果で、今のChatGPTやGoogleのAIモードでの数字ではありません。Indig の記事は質問の選び方を説明しておらず、記事に日付の記載もありません。

3つから言えるのは、①数字・引用・出典を本文に書くと回答に使われやすい傾向がある、②一次調査が強いのは「比較の基準になる数字」を求める質問がある分野、③見た目を整えるより、質問に合った中身と新しい日付が大事、というところまでです。

Googleも、役に立つコンテンツの自己評価の質問として「独自の情報・報道・調査・分析を提供しているか」を挙げています（Google 検索セントラル）。

国内の担当者は一次情報をどう見ているか

国内でも一次情報への注目は高まっています。PRIZMA の調査（2026年7月、426人）では、AIによる概要の対策で効果を実感した施策として「一次情報」が43.5%（外部への配信52.8%に次ぐ）でした（ASCII.jp）。別の調査（2026年8月、1,003人）では、実施している施策の1位が「一次情報」の46.9%でした（TRUE MARKETING）。

どちらもAI対策のサービスを売る会社の調査で、効果は回答者の自己申告です。「一次情報を出せば引用される」ことを示すデータではありません。

小さな会社でも作れる独自データ5種類

大きなアンケートを外注しなくても、ほかの会社が持っていないデータは手元にあります。

種類例注意
自社の実績の集計見積もり依頼の内訳、問い合わせの多い月、修理の故障箇所の割合個人が特定されないように集計し、少ない件数のグループは出さない
価格・相場の記録毎月の仕入れ値、地域の家賃の募集価格を1年記録どこの何を、いつ記録したかを書く
測定・比較（ベンチマーク）道具や機器を同じ条件で試した結果、サイトの表示速度の比較条件と手順を書き、他社製品を扱うなら公平に
お客様へのアンケート利用後アンケートの満足度、選んだ理由対象が「利用した人」だけだと明記。No.1表示に使うなら後の「日本の決まり」の章を必ず確認
公開データの集計官公庁の統計を地域・業種で集計し直す元のデータの出典と取得日を書き、加工したことを明記

Indig の分析で引用が集中したのは「性能を比べた結果」でした。自社の業種で「比べたいけれど数字がない」質問（例：〇〇の修理は何日かかる？）を探すと、テーマが決まりやすくなります。

調査ページに書く10の項目

プレスリリースは配信サービスに載りますが、数字の原本は自社サイトに置きます。リリースからは必ずこのページにリンクします。

項目書き方理由
タイトル何を・どこで・いつ・何件（例：〇〇市の見積もり依頼412件の集計、2026年10月）質問と合うかを一目で判断できる
要点1文に1つの数字。分母・時期・出典名を同じ文に入れるその1文だけを引用されても意味が通る
調査概要対象・抽出の方法・期間・方法・件数（n）数字の重みを読者とAIが判断できる
設問・定義質問文そのもの、「あり」とみなした条件数字の意味がぶれない
結果の表表は画像ではなく文字の表。分母を書くAIも読者も読み取れる
限界調べていないこと、偏りのありそうなところ過大な引用を防ぐ
意見「ここからは当社の意見です」と分ける事実と解釈を混ぜない
引用・転載のルール出典の書き方と、そのまま使える1文引用する人の手間を減らす
データファイルCSVなど。列の説明を付ける裏付けを確かめられる
日付と更新履歴公開日・集計日・直した内容新しい日付は引用に効くという研究がある

Nurevo の調査ページもこの形で作っています。たとえば国内Web制作会社サイトの調査は、対象2,756件・トップページに到達できた2,357件・2026年11月5日集計と調査概要に書き、限界・引用のルール・当社の意見を別の見出しに分けました。会社名は出さず、30件未満のグループの数字も出していません。

日本の決まり：調査をNo.1表示や広告に使うとき

調査の結果を「満足度No.1」のように広告で使うと、景品表示法の対象になります。消費者庁は2024年9月26日に「No.1表示に関する実態調査報告書」を公表しました（消費者庁）。報道によると、広告368件・消費者1,000人へのWebアンケート・広告主15社への聞き取りをもとにしており、比べた相手の会社を知っていた広告主は15社中1社でした（ECのミカタ）。

長官の会見では、利用したかどうかを確かめずに満足度を聞いた調査が問題の例として挙げられ、調査会社に頼んだ場合でも責任は広告主にあること、根拠を消費者が確かめられるようにすることが求められました（会見要旨）。2008年の公正取引委員会の報告書の考え方（客観的な調査にもとづくこと、結果を正確に引用すること）も引き続き使われます。

日本マーケティング・リサーチ協会は2022年1月18日に、結果ありきの「No.1調査」への抗議状を出しました。報道では、設計を明かさない、回答者の偏り、上回った時点で調査を止める、部門を細かく分けて1位を作る、といった手口が挙げられています（J-CAST）。

  1. 調査ページには、No.1表示に使うかどうかにかかわらず、対象・比べた相手・期間・方法・件数を書く
  2. 利用者に聞いたのか、利用していない人の印象を聞いたのかを明記する
  3. 広告やリリースに数字を使うときは、調査ページへのリンク（またはQRコード）を付ける
  4. お金を払って記事や順位を載せた場合は広告と明示する（2023年10月からのステルスマーケティング規制）

この記事は法律の助言ではありません。広告に使う前に、必要に応じて専門家に確認してください。

構造化データ：Dataset を使うか

Google は、データセットを Dataset Search で見つけやすくするための構造化データ Dataset を説明しています。「データのある表やCSVファイル」もデータセットの例に入っています。必須は name と description（50〜5,000文字）で、creator・license・temporalCoverage・spatialCoverage・variableMeasured・distribution（ダウンロードのURLと形式）などが推奨です（Google 検索セントラル）。

これは Dataset Search 向けのもので、AIの回答に使われると公表しているAIの会社はありません。ページに文字で調査概要と表を書くことが先で、Dataset はCSVを公開するときの追加と考えてください。ページに見えていない内容を構造化データだけに書くのは避けます。

WordPressでの手順

  1. 固定ページで調査ページを作り、URLを /research-2026/ のような短い英字にします。要点・調査概要・結果・限界・意見・引用のルール・データ・更新履歴を見出しで分けます。
  2. 結果はテーブルブロックで文字の表にします。グラフを画像で入れる場合も、同じ数字の表を下に置きます。
  3. CSVをメディアライブラリ（または自社サーバー）に置き、ページからリンクします。列の名前と意味を本文に書きます。フォームの入力やメールアドレスの登録をしないとデータが見られない形にすると、AIのクローラーも記者も中身を読めません。
  4. プレスリリース・ブログ記事・会社概要から調査ページにリンクします。リリースの書き方はプレスリリースをAI検索向けに整えるにあります。
  5. Nurevo AEO（無料のWordPressプラグイン）では、フィルター webmcp_canary_schema_graph の extra に足したノードは、SEOプラグインと併用していても外されません（下の例）。構造化データを出さない設定にしたページでは呼ばれません。0.9.1 からは SEO SIMPLE PACK・VK All in One Expansion Unit と一緒に使っても構造化データは重複しません。
  6. Nurevo AEO の llms.txt は最近更新した公開済みのページと投稿を30件まで並べます。調査ページを長く更新しないと外れることがあるため、残したい場合はフィルター webmcp_canary_llms_txt_lines で行を足します（2つ目の例）。
  7. 入れたら、ページのソース（application/ld+json）と /llms.txt で、本文と同じ内容が出ているかを確かめます。WordPress.orgで入手
// 調査ページ（スラッグ research-2026）にだけ Dataset を足す
add_filter('webmcp_canary_schema_graph', function (array $bundle) {
    if (!is_page('research-2026')) {
        return $bundle;
    }
    $bundle['extra'][] = array(
        '@type'            => 'Dataset',
        'name'             => '（地域）の引っ越し見積もり 依頼内容の集計 2026年10月',
        'description'      => '当社に2026年10月に届いた見積もり依頼412件を、間取り・移動距離・希望日で集計したデータ。対象・期間・集計方法と限界は本文に記載。',
        'creator'          => array('@id' => $bundle['org_id']),
        'license'          => 'https://creativecommons.org/licenses/by/4.0/',
        'temporalCoverage' => '2026-10-01/2026-10-31',
        'distribution'     => array(array(
            '@type'          => 'DataDownload',
            'encodingFormat' => 'text/csv',
            'contentUrl'     => 'https://example.co.jp/wp-content/uploads/2026/11/research-2026.csv',
        )),
    );
    return $bundle;
});

llms.txt に調査ページを残す

上の Dataset とは別に、調査ページへの入り口を llms.txt に固定する例です。

// 調査ページを、更新日にかかわらず llms.txt に載せる
add_filter('webmcp_canary_llms_txt_lines', function (array $lines) {
    $lines[] = '## 調査・データ';
    $lines[] = '';
    $lines[] = '- [引っ越し見積もり依頼の集計 2026年10月](https://example.co.jp/research-2026/): 412件の集計、方法・限界・CSVあり';
    $lines[] = '';
    return $lines;
});

確かめ方

  1. 調査が答える質問（例：「（地域）の引っ越しはいつが安い？」）を ChatGPT・Perplexity・GoogleのAIモードに聞き、答えと出典のURLを日付付きで記録します。
  2. 出典に調査ページ・リリース・それを取り上げた記事のどれが出るか、数字が正しく引用されているかを見ます。数字が違っていたら、要点の1文をより明確に書き直します。
  3. Googleアナリティクス4で、調査ページへのAIのサービスからの流入と、CSVのダウンロード数を見ます。被リンクや言及は Search Console のリンクのレポートや社名の検索で見ます。
  4. AIの回答は日によって変わるため、同じ質問を毎月同じ日に聞きます。決めた質問のセットで記録する方法はAIでの登場率の測り方にあります。
  5. Nurevo AEO の無料のAIチェックは、接続したサイトに月1回、業種と地域から作った3つの質問を Perplexity に聞きます。継続して測る Pro（月14,800円〜）も現在は Perplexity で測っています（ChatGPTは設定され次第）。

公開前のチェックリスト

  1. タイトルに、何を・どこで・いつ・何件かを入れた
  2. 要点の各文に、分母・時期・出典名を入れた
  3. 対象・抽出の方法・期間・方法・件数・設問を書いた
  4. 結果を画像だけでなく文字の表でも載せた
  5. 調べていないこと（限界）を書いた
  6. 事実と当社の意見を見出しで分けた
  7. 個人や取引先が特定されないように集計し、少ない件数は出していない
  8. No.1表示や広告に使う場合、利用者に聞いたか・比べた相手を明記した
  9. CSVと列の説明を、登録なしで見られるようにした
  10. 引用のルールと、そのまま使える1文を書いた

毎年続けると強くなる

同じ方法で毎年（または毎月）集計すると、「前年からどう変わったか」という、ほかにない数字ができます。URLは年ごとに分け（/research-2026/、/research-2027/）、前年のページは消さずに残し、互いにリンクします。方法を変えたときは、比べられない点を限界に書きます。

よくある質問

独自調査のページを作れば、AIに引用されますか？

必ずとは言えません。数字や出典を書いた文章は回答に使われやすいという研究はありますが、出典の選び方は公表されていません。対象・件数・方法・限界をそろえ、確かめられる形にすることが前提です。

回答者は何人いれば調査として出せますか？

決まった基準はありません。件数そのものより、件数と対象を正直に書くことが大切です。少ない件数を細かく分けた数字は出さず、限界に書きます。

プレスリリースだけ出せば十分ですか？

数字の原本は自社サイトに置くことをおすすめします。リリースの配信ページは変更や削除ができないことがあり、方法やデータを全部は載せられません。リリースから調査ページにリンクします。

調査結果をダウンロードするのにメール登録を必須にしてもいいですか？

営業上の理由で登録を求めることはできますが、AIのクローラーや記者は登録の先を読めません。少なくとも要点・調査概要・主な表はページに文字で公開してください。

「満足度No.1」と書くための調査をしてもいいですか？

景品表示法の対象になります。消費者庁は、利用したか確かめずに満足度を聞いた調査を問題の例に挙げ、責任は広告主にあるとしています。比べた相手・対象・方法を明記し、必要に応じて専門家に確認してください。

AIでデータを分析・文章化してもいいですか？

使えますが、数字は元のデータで確かめ、AIをどう使ったかを調査概要に書くと読者が判断できます。Googleも、自動化やAIをどう使ったかの説明を勧めています。

Dataset の構造化データは必須ですか？

必須ではありません。Google の Dataset Search 向けのもので、AIが使うと公表している会社はありません。CSVを公開するなら、本文と同じ内容で足すとよいでしょう。

まず、AIがあなたのサイトを読めるか確認

登録不要の無料チェックで、構造化データ、llms.txt、AI検索のクローラーの許可の状態がわかります。WordPressなら、Nurevo AEOで不足分を無料で整えられます。
