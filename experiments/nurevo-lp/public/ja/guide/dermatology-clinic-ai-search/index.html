皮膚科・美容皮膚科のAI検索対策：保険診療と自費診療を分け、料金とリスクをAIに正しく読ませる手順

皮膚科・美容皮膚科のAI検索対策でいちばん効くのは、「その治療は保険がきくのか、自費ならいくらで、どんなリスクがあるのか」を、施術ごとのページに文字で書くことです。AIは「◯◯駅の近くでニキビを保険で診てもらえる皮膚科」「シミ取りレーザーの料金とダウンタイム」のような条件つきの質問に答えるとき、条件が読み取れるページを使います。そのうえで、医療広告のルール（体験談・治療前後の写真の制限、自費診療の料金とリスクの表示）を守り、同じ事実を構造化データ・llms.txt・Googleビジネスプロフィールにそろえます。

作成日：2026年11月16日（JST）。厚生労働省の「医療広告等ガイドラインに関するQ&A」、美容医療の検討会の報告書、国民生活センターの相談件数、schema.orgの型（schema-dts 2.1.0の型定義）は同日に確認しました。

AIの回答は日や聞き方によって変わります。この記事の対策は、AIがクリニックの事実を正しく読める状態をつくるものです。AIの回答に必ず表示される・順位が上がることを保証するものではありません。この記事は法的な助言ではありません。個別の表現は、管轄の保健所などで確認してください。

皮膚科・美容皮膚科で、患者さんがAIに聞くこと

皮膚科の質問は、大きく2つに分かれます。1つは一般皮膚科の質問で、「子どものアトピーを診てもらえる皮膚科」「土曜に開いている皮膚科」「水虫は保険で治療できる？」のように、症状・対象・時間・保険の有無が入ります。もう1つは美容皮膚科の質問で、「シミ取りレーザーの料金の相場」「医療脱毛は何回で終わる？」「ダウンタイムが短いニキビ跡の治療」のように、料金・回数・ダウンタイム・リスクが入ります。

どちらも、AIが答えに使えるのは「条件が文字で書いてあるページ」です。料金表が画像だけ、保険か自費かが書かれていない、「カウンセリングでご案内します」だけで料金の目安がない、というページは、条件つきの質問の出典になりにくくなります。

美容医療は相談の多い分野でもあります。国民生活センターに寄せられた美容医療の相談は、2023年が6,281件、2024年が10,744件、2025年が7,944件でした（PIO-NETの件数、2026年5月31日現在、2026年7月31日更新）。国民生活センター：美容医療。患者さんは料金やリスクを事前に確かめたいと考えており、AIにもそれを聞きます。正確な料金とリスクを書いておくことは、AI対策である前に、患者さんへの説明そのものです。

上位の記事で抜けていたこと

「クリニック AI検索対策」「美容クリニック LLMO」などで上位に出る記事を日本語・英語で読むと、多くは「診療科・住所・診療時間を正しく」「構造化データを入れる」「口コミを増やす」で終わっていました。英語の記事の中には、出典のない「レビュー50件以上」のような目安を挙げるものもあります。

皮膚科・美容皮膚科で特に大切な次の4点は、ほとんど扱われていませんでした。この記事ではこれを中心に書きます。

  1. 保険診療と自費診療を、ページ上でどう書き分けるか。
  2. 自費の施術で、料金と主なリスク・副作用をどこにどう書くか（医療広告のルールとの関係）。
  3. 「口コミを増やす」「症例写真を載せる」という一般的な助言が、日本の医療広告のルールとぶつかる点。
  4. WordPressでの具体的な設定（型・サービスと料金・ページ専用のFAQ）と、出ているかの確かめ方。

保険診療と自費診療を分けて書く

AIに誤解されやすいのは、同じ「ニキビ治療」「シミ治療」でも、保険でできるものと自費のものが混ざっている場合です。施術や症状のページで、保険か自費かを1行目近くに書いてください。厚生労働省のQ&Aでも、承認された機器や薬を使う自費の治療（例：インプラント、ホワイトニング）について、自由診療であることと標準的な費用を書くよう示されています。厚生労働省：医療広告等ガイドラインに関するQ&A（PDF）

表は、皮膚科・美容皮膚科で聞かれやすい質問と、上位の記事に足りなかった点をもとにしています。
ページ書いておくことAIに誤解されやすい書き方
症状のページ（ニキビ・アトピー・湿疹・水虫・いぼなど）保険で行う診療の範囲、自費の選択肢があればその名前と自費である旨、受診の目安保険と自費の治療を区別せずに並べる
施術のページ（レーザー・ピーリング・注入・脱毛など）自費であること、1回あたり・コースの料金（税込か税別か）、回数の目安、主なリスク・副作用、ダウンタイム「料金はカウンセリングで」だけ
料金表のページ保険と自費を分けた表、更新日、初診料・再診料・薬代の扱い画像だけの料金表、キャンペーン価格だけ
診療案内（トップ・アクセス）一般皮膚科と美容皮膚科の診療時間・予約方法が違うならそれぞれ、対象年齢美容の予約時間を一般の診療時間として書く

一般皮膚科と美容皮膚科で受付時間や予約の仕方が違う場合は、AIが混同しないよう、診療時間の表を分けて書きます。予約制か、予約なしで受診できるかも、それぞれに書きます。

自費の施術ページ：料金と主なリスク・副作用を同じページに

日本の医療広告のルールでは、患者さんが自ら調べて見るウェブサイトであれば、一定の条件を満たすことで、通常は広告できない内容も詳しく説明できます（「限定解除」）。厚生労働省のQ&Aでは、自由診療の場合の条件として、通常必要とされる治療の内容・費用と、主なリスク・副作用に関する事項を書くことが挙げられ、一般的な短所を1〜2個並べるだけでは足りないとされています（Q6-12）。また、問い合わせ先が書かれていることも条件の1つで、予約専用の番号や自動応答だけの番号では満たさないとされています（Q6-10）。条件の項目は見やすく書く必要があり、極端に小さい文字や背景と同じ色の文字は認められません（Q6-11）。厚生労働省：Q&A（PDF）

これはAI検索対策とも同じ方向です。AIが「料金」「ダウンタイム」「リスク」を聞かれたときに使えるのは、それが本文に書いてあるページです。施術ページの型は、次の順番にすると読みやすくなります。

  1. 施術の名前と、自費診療であること。
  2. どんな悩みに対して行うか（効果を約束する書き方はしない）。
  3. 施術の流れ、1回の時間、通常必要な回数の目安と間隔。
  4. 料金（1回・コース、税込か税別か、麻酔・薬・再診など別にかかるもの）。
  5. 主なリスク・副作用と、ダウンタイムの目安。
  6. 受けられない方・注意が必要な方。
  7. 問い合わせ先（相談に答える窓口の電話番号や受付時間）と、施術後に困ったときの連絡先。
  8. ページの最終更新日。

承認されていない医薬品・機器を使う施術や、承認された薬を承認外の目的で使う施術には、追加の説明が必要です。Q&Aでは、承認外の使い方も未承認医薬品と同じ扱いになるとされています（Q2-14）。書くべき項目は医療広告ガイドライン本体で確かめてください。

美容医療については、厚生労働省の検討会の報告書（2024年11月22日）が、医療広告のネットパトロールの強化や、施術後のトラブルの相談窓口を設けて患者さんに伝えることなどを求めています。厚生労働省：美容医療の適切な実施に関する検討会 報告書（PDF）。施術後の連絡先をページに書いておくことは、この流れにも合っています。

口コミ・症例写真：一般的な「AI対策」の助言とぶつかるところ

AI検索対策の記事では「口コミを増やす」「症例写真で実績を見せる」がよく勧められます。医療機関では、ここに注意が必要です。

よくある助言医療機関での扱い（厚生労働省のQ&A）代わりにできること
患者さんの声をサイトに載せる治療の内容や効果についての体験談は掲載できない（Q1-18、Q2-9）施術の流れ・料金・リスクなど、事実の説明を詳しくする
口コミをFAQや構造化データのレビューに入れる同上。クリニックが費用を出したり、依頼・編集したりした口コミも対象になりうるFAQは「保険はきくか」「何回かかるか」など、事実の質問と答えにする
ビフォーアフター写真で効果を見せる術前だけ・術後だけの写真も、治療効果の表現として広告できない（Q2-8、Q3-14）写真を使う場合の条件は、ガイドラインと事例解説書で確認する
「地域No.1」「痛くない」「必ずきれいに」虚偽・誇大・比較優良の表示は禁止されている例として扱われる数字や事実で書ける範囲だけを書く

一方で、クリニックが費用を出したり依頼したりしていない、患者さん個人のSNSや第三者の口コミサイトの投稿は、広告にあたらないとされています（Q2-11）。AIがそれを読むかどうかはクリニックが決められないので、自院のサイトでは事実を正確に書くことに集中するのが確実です。事例は事例解説書（PDF）にもまとまっています。

schema.orgには、皮膚科を表す型があります（2026年11月16日にschema-dts 2.1.0の型定義で確認）。

WordPressの皮膚科サイトでの設定手順

  1. WordPress.orgからNurevo AEO（無料）をインストールして有効化します。Yoast SEO・Rank Math・All in One SEO・Slim SEOはそのまま使えます。0.9.1からはSEO SIMPLE PACKやVK All in One Expansion Unitとも、構造化データを重複させずに併用できます。
  2. 初回の設定ウィザードで「クリニック・歯科」を選びます（型はMedicalBusinessになります）。そのあと設定画面の「業種（schema.org型）」欄を Dermatology に変えます。この欄にはschema.orgの型名をそのまま入れられます。
  3. クリニック名・住所・電話番号・説明を確認します。空欄の項目だけが既存の設定から補われ、入力済みの値は上書きされません。
  4. 営業時間は「月〜金 9:00-12:00 15:00-18:00 / 土 9:00-13:00」のように曜日と時刻だけを書きます。一般と美容で時間が違う場合や、祝日・最終受付などの条件は、本文の表に書きます。
  5. 設定画面のサービスに、自費の施術を1つずつ登録します。名前・説明・所要時間・料金・通貨を入れると、料金つきのサービス（Service と Offer）として出力されます。料金は本文と同じ値にし、本文を変えたら同時に直します。
  6. 各施術ページの編集画面のサイドバーで、そのページだけのFAQ（「保険はききますか」「何回くらい必要ですか」「ダウンタイムはどのくらいですか」）を入れます。体験談や効果を約束する答えは入れません。キャンペーンページなど載せたくないページは「このページをllms.txtに載せない」にします。
  7. AEOスコアの画面で診断を実行し、不足をワンクリック修正で直します。外からどう見えるかは無料のAI可読性チェックで確かめます。

診療分野（medicalSpecialty）を足したいとき

Nurevo AEOは medicalSpecialty を自動では出しません。出したい場合は、テーマの functions.php か小さなプラグインで、事業の構造化データを変えるフィルター（webmcp_canary_business_node）を使います。本文に書いている分野だけにしてください。

add_filter('webmcp_canary_business_node', function ($org, $settings) {
    // 本文に書いている診療分野だけを足す（例：一般皮膚科と美容皮膚科）
    $org['medicalSpecialty'] = array('Dermatology', 'PlasticSurgery');
    return $org;
}, 10, 2);

AIに出ているかを確かめる

整えたあとは、患者さんが聞きそうな質問を「地域×症状×保険」「地域×施術×料金」「施術×ダウンタイム」の組み合わせで5〜10個つくり、ChatGPTやPerplexityに投げます。クリニックが名前やURLで出るか、保険か自費か・料金・リスクが正しく書かれているかを記録します。料金を間違えて答えられていたら、料金表と施術ページの書き方、古いキャンペーンページが残っていないかを見直します。AIの回答は回ごとに変わるので、同じ質問を期間をあけて何度か確かめます。測り方はAIでの登場率の測り方にまとめています。

米国の医療経営団体MGMAに掲載された分析（2026年5月、AI検索サービス会社の創業者による寄稿）では、独立系の診療所200件のうち、ChatGPTで名前が挙がったところはありませんでした。MGMA。国や条件は違いますが、実際に質問して確かめることが出発点です。

Nurevo AEOでは、Free・Standardプランでも月に1回、業種と地域から作った3つの質問（クリニック名は含めません）をPerplexityに投げ、回答にクリニックの名前やサイトが出たかを記録します。Proプラン（月14,800円〜）では、ベータ版のAI登場率の計測で、AIの回答にクリニックが出る割合を競合との比較・推移とあわせて見られます（現在の計測対象はPerplexity）。どちらも回答のサンプルを見るもので、すべての回答を観測するものではありません。

よくある質問

皮膚科のAI検索対策は、何から始めればいいですか？

症状と施術のページごとに、保険診療か自費診療かを書くことからです。次に自費の施術ページに料金・回数の目安・主なリスクと副作用・ダウンタイムを書き、名前・住所・電話番号・診療時間を構造化データ・Googleビジネスプロフィールとそろえます。

美容皮膚科の料金は、サイトに載せたほうがいいですか？

はい。AIは料金を聞かれたとき、料金が本文に書いてあるページを使います。厚生労働省のQ&Aでも、自費診療を詳しく説明するウェブサイトでは、通常必要な治療の内容・費用と主なリスク・副作用を書くことが条件の1つとされています。

構造化データの型は何を使えばいいですか？

schema.orgのDermatologyが皮膚科を表す型で、MedicalBusinessとLocalBusinessの一種です。美容皮膚科も行う場合は、medicalSpecialtyにDermatologyとPlasticSurgeryを入れる方法があります。型より、値が本文と一致していることが大切です。

症例写真（ビフォーアフター）を載せると、AIに選ばれやすくなりますか？

AIへの効果は確かめられていません。日本の医療広告のルールでは、治療前後の写真は治療効果の表現として扱われ、制限があります。載せる場合の条件は、医療広告ガイドラインと事例解説書、管轄の保健所で確認してください。

口コミサイトの評価が低いと、AIに出なくなりますか？

AIがどの情報をどれだけ使うかは公表されておらず、断定はできません。クリニックが依頼していない第三者の口コミは広告にあたりませんが、クリニックが費用を出したり依頼したりした口コミを自院のサイトに載せることはできません。自院のサイトでは事実を正確に書くことに集中してください。

Nurevo AEOは無料で使えますか？

はい。業種・住所・診療時間・サービスと料金・FAQの構造化データ、llms.txt、AIクローラ設定、AEOスコアは無料プランで使えます。有料プランは常に最新のルールセット（Standard、月3,000円）と、ベータ版のAI登場率の計測（Pro、月14,800円〜）を追加するものです。Nurevo AEO（WordPress.org）

対策すればChatGPTにクリニックが必ず出ますか？

いいえ。AIの回答は変動し、どのツールや対策でも表示や順位は保証できません。できるのは、AIがクリニックの事実を正しく読める状態をつくり、出ているかを継続して確かめることです。
