GeminiアプリとClaudeに自社サイトが出典として出る仕組みと、出ているかの確かめ方

Geminiアプリは、Googleがクロールしたページを回答の根拠（グラウンディング）に使うことがあり、それを許すかどうかは robots.txt の「Google-Extended」で決まります。Claudeは、検索用のClaude-SearchBotと、質問に応じてページを読むClaude-Userでサイトを読み、学習用のClaudeBotとは別に止めたり通したりできます。サイト側でできるのは、①この4つの名前を目的どおりに設定し、②答えと事実を本文の文字で書き、③社名を入れない質問で出典に出ているかを記録することです。どのページを出典に選ぶかの基準は、GoogleもAnthropicも公開していません。

作成日：2026年11月19日（JST）。GoogleのAIによる概要・AIモードはAIによる概要に出典として出る条件、PerplexityはPerplexityに引用される仕組み、ChatGPTはChatGPTに載る方法で扱いました。この記事は、残る2つ、GeminiアプリとClaudeに絞って、公式の資料で確かめられることと、サイト側の手順を書きます。

AIの回答は日・聞き方・プランによって変わります。この記事の手順は、GeminiとClaudeがサイトを読める状態にし、出典に出ているかを正しく記録するためのもので、回答に出ることや順位を保証するものではありません。

まず分ける：Geminiアプリ・Google検索のAI機能・Claude

上位の記事には「GeminiとAIによる概要は基本的に同じ」と書くものがありますが、サイト側の設定ではこの2つは別物です。Google検索のAIによる概要・AIモードは検索の一部で、Googlebotがページを読めて検索結果に出せれば対象になります。一方、Geminiアプリ（gemini.google.com やスマートフォンのGemini）でGoogleがクロールしたページを回答の根拠に使ってよいかは、Google-Extended という別の名前で管理されています。

Google-Extended の説明はGoogleのクローラー一覧（2026-10-30更新）、ClaudeのクローラーはAnthropicのヘルプ（日本語版）にあります。

「Gemini 自社 表示される 方法」「Claude 引用される」「how to get cited by Claude」などで上位の日本語4本・英語6本を読みました。「答えを先に書く」「会社情報をそろえる」は共通していますが、GeminiアプリとAIによる概要を分けた記事はほぼなく、Claudeの3つのクローラーをAnthropicの資料に沿って説明した記事も、WordPressでの手順を書いた記事もありませんでした。

「Google-Extended を止めてもAI検索には影響しない」Google検索（AIによる概要を含む）には影響しない。Geminiアプリのグラウンディングには影響する目的に合わせて選ぶ

Claudeのシェア・引用率・反映までの日数多くは書いた会社自身の集計で、方法が十分に書かれていない使わない

目的別の robots.txt：検索には出たい・学習は止めたい

いちばん多い希望は「AIの検索や回答には出たいが、学習には使われたくない」です。Claudeについては名前が分かれているので、Claude-SearchBot と Claude-User を通し、ClaudeBot だけを止められます。個別のグループを作るときは、サイト全体の決まり（例：/wp-admin/ を読ませない）もそのグループの中に書き直します。クローラーは自分の名前のグループがあると、そのグループだけを見るためです。

# 例：Claude の検索と回答には読ませ、学習用の ClaudeBot だけ止める
User-agent: Claude-SearchBot
Allow: /
Disallow: /wp-admin/

User-agent: Claude-User
Allow: /
Disallow: /wp-admin/

User-agent: ClaudeBot
Disallow: /

# Google-Extended は書かない（＝止めない）。
# Disallow にすると、Gemini の学習だけでなく
# Gemini アプリのグラウンディングにも使われなくなる（Googleの説明）。

Geminiは事情が違います。Google-Extended は学習とGeminiアプリのグラウンディングをまとめて管理するため、「学習だけ止めて、Geminiアプリの出典には出る」という設定は、Googleの説明の範囲ではできません。Geminiアプリに出典として出たいなら、Google-Extended は止めない、が答えです。なお、Googleは2027年の初めに、学習の可否を伝える共通の仕組み（AIPREF、「user-agent: __usage_ai-training」）に対応する予定としています。

Anthropicも2026年10月30日から、学習を望まないことを伝える機械可読の信号（IETFの aipref の草案）を認識し始めた、としています。ただし robots.txt で ClaudeBot を名指ししていれば、そちらが優先されます。設定が食い違わないよう、どちらか一方で意図をはっきり書いてください。

出典に選ばれやすくするために、ページ側でできること

読める状態にしても、質問への答えがページになければ出典にはなりません。GeminiもClaudeも基準は公開していないため、次はAI全般に共通する手入れです。詳しくはAIに引用される記事の書き方とllms.txtの書き方にまとめています。

  1. 質問に対する答えを、見出しのすぐ下の1〜2文で書く（料金・営業時間・対応エリア・対象など）
  2. 数字には日付を付け、他社の数字には出典を付ける
  3. 社名・住所・電話番号を、自社サイトとGoogleビジネスプロフィールなど外部の掲載でそろえる
  4. 画像やPDFの中だけにある事実を、本文の文字でも書く
  5. 構造化データは本文と同じ内容にする（本文にないことを書かない）

WordPressでの手順（Nurevo AEO の場合）

Nurevo AEO（無料のWordPressプラグイン）は、WordPressの仮想 robots.txt に、AI検索で使われるクローラー（ChatGPTの OAI-SearchBot・ChatGPT-User、Claudeの Claude-SearchBot・Claude-User、Perplexityの PerplexityBot・Perplexity-User）を許可する行を足します。サイトの既存の決まり（/wp-admin/ など）は、これらのグループにも書き写されます。

学習用のクローラー（GPTBot・ClaudeBot・Google-Extended・Applebot-Extended・CCBot）は、初期設定ではサイトの robots.txt に任せ、ワンクリックで許可・ブロックを選べます。ここで「ブロック」を選ぶと Google-Extended も止まります。Googleの説明では、その場合Geminiアプリのグラウンディングにも使われなくなるので、Geminiアプリに出典として出たいサイトは、学習用をまとめてブロックする前に考えてください。ClaudeBot だけを止めたい場合は、上の例のように自分で robots.txt に書きます。

  1. 管理画面の Nurevo AIO → 設定で「AI検索のクローラー（ChatGPT検索・Claude・Perplexity）を仮想robots.txtで許可する」が有効か確かめる
  2. 学習用クローラーの選択肢を、Geminiアプリへの影響を踏まえて選ぶ
  3. サーバーに robots.txt の実ファイルがあると仮想 robots.txt より優先されるので、実ファイルがないか確かめる
  4. SEOプラグインやセキュリティプラグイン、レンタルサーバーのWAF・海外アクセス制限がクローラーを止めていないか確かめる
  5. 下のコマンドで、robots.txt の中身とアクセスの応答を確かめる
# 1) robots.txt の中身（Claude の3つと Google-Extended の行）
curl -s https://example.jp/robots.txt | grep -i -E -A3 "claude|google-extended"

# 2) Claude-SearchBot を名乗ったアクセスが 200 で返るか（403・503・確認画面は要注意）
curl -s -o /dev/null -w "%{http_code}\n" -A "Claude-SearchBot" https://example.jp/

# 3) アクセスログで実際に来ているか（ログの場所はサーバーによって違う）
grep -E "ClaudeBot|Claude-SearchBot|Claude-User" access.log | tail -20
# Google-Extended は専用のユーザーエージェントがないので、ログには出ない

ログに来たアクセスが本当にAnthropicのものかは、公開されているIPの一覧と照らし合わせます。Google-Extended はログに出ないので、robots.txt の中身で確かめるしかありません。

出典に出ているかの確かめ方

Geminiアプリでは、出典があると回答の下や本文中に「ソース」ボタンが出ます。ただしGoogleは「すべての回答に関連リンクやソースが付くわけではない」としています（Geminiアプリのヘルプ）。ボタンがなければ、その回答ではリンクを示していないということです。Googleは、Geminiが不正確な内容を事実のように示すことがあるとも書いています（回答についてのヘルプ）。

Claudeは、ウェブ検索を使った回答には出典が付きます（Claudeのヘルプ、API でもウェブ検索では出典が常に有効）。新しい画面ではウェブ検索の切り替えがなく、必要なときにClaudeが検索します。検索しなかった回答には出典が付かないので、「出典がない＝読まれていない」とは限りません。

記録すること理由
社名を入れない質問（例：「◯◯市で土曜に診てくれる歯科は？」）を5〜20個決める社名で聞くと出るのは当たり前で、比べられない
日付・アプリ（Gemini／Claude）・プラン・ログイン状態・モデル条件が変わると回答も変わる
回答に社名が出たか、出典に自社のURLがあったか名前が出ることと、出典に選ばれることは別
同じ質問を2〜3回聞く1回の結果は偶然のことがある
設定を変えた日変える前と後を比べるため

よくある質問

Google-Extended を止めると、Google検索やAIによる概要から消えますか？

Googleは、Google-Extended はGoogle検索への掲載にも順位にも影響しないとしています。影響するのはGeminiモデルの学習と、GeminiアプリやVertex AIでのグラウンディングです。

Geminiの学習だけを止めて、Geminiアプリの出典には出られますか？

Googleの説明では、Google-Extended は学習とグラウンディングをまとめて管理しているため、その2つを分ける設定はありません。Googleは2027年の初めに共通の学習拒否の信号（AIPREF）に対応する予定としていますが、その後の扱いは公開を待つ必要があります。

ClaudeBot を止めると、Claudeの回答に出なくなりますか？

Anthropicの説明では、ClaudeBot は学習用で、検索と回答は Claude-SearchBot と Claude-User です。この2つを止めていなければ、ClaudeBot を止めても検索や回答のための読み込みは続きます。

Claudeはどの検索エンジンの結果を使っていますか？

Anthropicのヘルプには、画像検索はBingとありますが、ウェブ検索の提供元は書かれていません。2025年3月にBrave Searchが委託先の一覧に加わったと報じられましたが、仕組みとして公表されたものではありません。

アクセスログに Google-Extended が出てきません。設定が効いていないのですか？

Google-Extended には専用のユーザーエージェントがなく、既存のGoogleのクローラーで読むため、ログには出ません。効いているかは robots.txt の中身で確かめます。

robots.txt を変えたら、すぐにGeminiやClaudeの回答に反映されますか？

反映までの時間は、どちらも公開していません。設定を変えた日を記録し、数日あけて同じ条件で確かめてください。出典に出るかは、設定とは別にAIが決めます。

GeminiやClaudeが自社について間違ったことを言います。どうすればいいですか？

出典が示されていればそこをたどり、自社サイトの古い記述を直し、外部の掲載には更新を依頼します。AIの回答を直接書き換える方法はなく、直るまでの期間も決まっていません。

AIが自社サイトを読めるか確かめる

無料チェックは登録不要です。URLを入れると、AIクローラーの許可、構造化データ、llms.txtの状態が分かります。WordPressなら無料のプラグインで、Claude-SearchBot と Claude-User を許可する設定と、学習用クローラーの選択、事業の事実の構造化データをまとめて整えられます。
