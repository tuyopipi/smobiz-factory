Search ConsoleでAIによる概要・AIモードの表示を見る方法：生成AIレポートの読み方と注意点

GoogleのAIによる概要（AI Overviews）とAIモードにあなたのサイトがどれだけ表示されたかは、Search Consoleの「生成AIパフォーマンスレポート（検索）」で見られます。2026年8月31日から全世界のサイトに提供されています。わかるのは表示回数で、ページ・国・デバイス・日付ごとに分けられます。クリックはこのレポートには出ないため、通常の検索パフォーマンスと並べて読みます。

作成日：2026年11月10日。Googleの仕様は、同日にSearch Consoleヘルプと検索セントラルの公式ページで確認したものです。画面や仕様は変わることがあるため、最新のヘルプもあわせてご確認ください。

このレポートで見えるのはGoogleの検索の中のAI機能だけです。ChatGPTやPerplexityでの見え方は、別の方法で確かめる必要があります（後の章）。また、どんな対策をしても、AIの回答に必ず表示される・順位が保証されるということはありません。AIの回答は日々変わります。

生成AIパフォーマンスレポートでわかること・わからないこと

Googleは2026年6月3日にこのレポートを発表し（検索セントラル ブログ）、最初は一部のサイトから提供を始めました。ヘルプによると、2026年8月31日時点で全世界のすべてのサイトに提供されています（Search Console ヘルプ：生成 AI パフォーマンス レポート（検索））。要点は次のとおりです。

表示回数のほかに、クリック数・掲載順位・検索キーワードをこのレポートで見られるとは、ヘルプには書かれていません。
項目内容（2026年11月10日時点のヘルプによる）
対象Google検索のAIによる概要とAIモード。Search Labsの試験機能のデータは含まれません
指標表示回数（AI機能の中で、あなたのサイトへのリンクが利用者に表示された回数）
分け方ページ、国、デバイス（パソコン・タブレット・モバイル）、日付
検索タイプ「ウェブ：テキストベース」と「ウェブ：マルチモーダル」（Googleレンズ、かこって検索、画像のアップロードなど）
時刻日付は太平洋時間。直近のデータは暫定値で、グラフでは点線で示されます
書き出しグラフと表をダウンロード可能。画面で「~」や「-」と表示された値は、ファイルでは0になります
通常のレポートとの関係通常の検索パフォーマンスの「ウェブ」のデータに含まれる分を、AI機能に絞って見せるもの
DiscoverDiscoverの生成AI機能は、別の「生成 AI パフォーマンス レポート（Discover）」で見ます

わからないことも押さえておきます。どんな検索語でAIに表示されたか、AIの回答の中で何番目に出たか、AIの回答からのクリック数は、このレポートでは見られません。GoogleのAI機能からのクリックや表示は、通常の検索パフォーマンスの「ウェブ」の数字に含めて集計されます（Google：AI機能とウェブサイト）。Discoverのレポートはこちらのヘルプにあります。

レポートの開き方と、表示されないときの確認

  1. Search Consoleで対象のプロパティを選び、生成AIパフォーマンスレポート（検索）を開きます。直接開くURLは https://search.google.com/search-console/performance/search-analytics/ai です（ログインが必要です）。
  2. 期間を「過去3か月」などに広げ、グラフで表示回数の推移を見ます。直近の点線部分は暫定値なので、月の比較からは外します。
  3. 表の「ページ」タブで、AI機能に表示されたページを確認します。リダイレクト後の最終URLで集計されます。
  4. 「国」「デバイス」タブで、どの地域・端末で表示されているかを見ます。店舗や地域の事業なら、国内の比率を確認します。
  5. 検索タイプのフィルタで「ウェブ：マルチモーダル」に切り替え、画像を使った検索での表示があるかも見ておきます（商品や料理、建物などの写真が多いサイト向け）。

レポートが出てこない、または数字が空のときは、まず2つを確認します。1つは、AI機能での表示回数がまだ少ない場合で、ヘルプはこれがよくある理由だとしています。もう1つは、後で説明する「検索の生成 AI」設定でサイトが除外されている場合です（ヘルプ）。

なお、2026年8月13日〜17日はGoogle側の記録の不具合で表示回数が少なく出ていましたが、データは後に復元されたと公表されています（Search Console のデータ異常）。過去の数字に不自然な落ち込みがあるときは、まずこのページを見ます。

数え方の注意：グラフと表の合計が合わない理由

このレポートは、場所によって数え方が違います。知らずに比べると、数字が合わずに混乱します。

Search Console ヘルプ（生成 AI パフォーマンス レポート（検索））の説明をもとに作成。
見ている場所数え方例：同じAIの回答に、自社の2ページのリンクが出た
グラフの合計プロパティ（サイト）単位1回
表の「ページ」ページ単位ページAに1回、ページBに1回（合計2回）
表の「国」「デバイス」「日付」プロパティ単位1回
グラフ（URLで絞り込んだとき）URL単位絞り込んだページの1回

このため、ページ表の合計はグラフの合計より大きくなることがあります。報告書に書くときは「サイト全体の表示回数（グラフ）」と「ページごとの表示回数（表）」を分けて書き、足し合わせないようにします。表は通常のレポートと同じく1,000行までの制限があります。

通常の検索パフォーマンスと並べて読む

生成AIレポートは表示回数しかないため、単独では「表示が増えて良かった」以上のことが言えません。通常の検索パフォーマンス（検索タイプ：ウェブ）のページ別のクリック数・表示回数と、同じ期間・同じページで並べると、読み取れることが増えます。

原因は数字からは断定できません。あくまで仮説を立てて確かめるための目安です。
AI機能の表示回数通常レポートのクリック数考えられること・次にやること
増えた増えた・変わらないAI機能でも通常の結果でも見つけられている。そのページの事実（料金・営業時間など）が最新かを定期的に確認
増えた減ったAIの回答で用が足りて、クリックが減っている可能性。ページの中に、AIの要約だけでは伝わらない情報（予約、見積もり、写真、事例）があるかを見直す
少ない・ない多い通常の検索では強いが、AI機能のリンクにはあまり出ていない。質問に直接答える文章や、ページの見える内容と一致した構造化データがあるかを確認
少ない・ない少ないまずは通常のSEOの基本（インデックス、スニペット表示の可否、内容の充実）から

Googleは、AI機能に表示されるための追加の要件や特別な最適化はなく、ページがインデックスされ、スニペット付きで表示できる状態であることが条件だとしています（Google：AI機能とウェブサイト）。表示が少ないページは、まず通常の検索での状態を確認するのが近道です。

毎月の確認チェックリスト

  1. 期間を前月1か月（太平洋時間の日付）に固定し、グラフの表示回数を記録する。暫定値の日は含めない
  2. ページ表の上位10ページと、前月からの増減を記録する
  3. 同じ10ページについて、通常の検索パフォーマンス（ウェブ）のクリック数と表示回数を並べて記録する
  4. 国・デバイスの比率に大きな変化がないかを見る
  5. データ異常のページで、その月に記録の不具合が公表されていないかを確認する
  6. 「検索の生成 AI」設定が意図どおり（通常は「含める」または親から継承）かを確認する
  7. ChatGPT・Perplexityなど、Google以外のAIでの見え方を別の方法で記録する（後の章）

記録表の列は「月／AI機能の表示回数（サイト）／上位ページ／そのページのウェブのクリック数・表示回数／メモ（サイトの変更・不具合）」の5つで十分です。サイトの変更（ページの追加、構造化データの修正、テーマ変更）をメモに書いておくと、後で増減の理由を考えやすくなります。

「検索の生成 AI」設定：除外すると何が起きるか

レポートと同時に、AI機能へのサイトの表示を止める設定も用意されました。Search Consoleの［設定］＞［検索の生成 AI］にあり、2026年8月31日時点で全世界のサイトに提供されています（Search Console ヘルプ：検索の生成 AI 設定）。

Search Console ヘルプ（検索の生成 AI 設定）と、Google検索セントラル（AI機能とウェブサイト）をもとに作成。
選択肢・方法起きること
含める（既定）AIによる概要・AIモード・Discoverの生成AI機能に、サイトのリンクと内容が使われる
除外これらのAI機能にリンクと内容が出なくなり、回答を作る材料にも使われない。AI機能からの表示やアクセスもなくなる
親から継承ドメインプロパティなど上位のプロパティの設定に従う（上位がある場合の既定）
Google-Extended（robots.txt）AIの学習への利用を制限するためのもの。「検索の生成 AI」設定は学習には影響しない
noindexGoogle検索そのものから外す
nosnippet・data-nosnippet・max-snippet検索結果やAI機能での抜粋（プレビュー）に使われる範囲を制限する

Googleは、この設定は検索のほかの部分の順位や掲載の判断には使わないとしています。除外は設定から1〜2日で反映され、キャッシュなどの都合でもっとかかる場合があります。

多くの事業者にとって、AI機能はお客様に見つけてもらう入口の1つです。除外するのは、会員向けの情報や、要約されると誤解を招く内容が中心のサイトなど、はっきりした理由がある場合に限るのが無難です。一部の文章だけ要約に使われたくないなら、サイト全体の除外ではなく data-nosnippet を使う方法もあります。

WordPressでの手順

  1. プロパティはドメインプロパティで登録する：DNSのTXTレコードで所有権を確認します。上位のドメインプロパティの「検索の生成 AI」設定は下位のURLプレフィックスのプロパティに引き継がれるため、www付き・なし、http・httpsをまとめて管理できます。
  2. インデックスを止めていないか確認する：WordPressの［設定］＞［表示設定］の「検索エンジンでの表示」にチェックが入っていると、検索エンジンにインデックスしないよう求めます。移転や公開直後に外し忘れがないかを見ます。
  3. robots.txtでGooglebotを止めていないか確認する：ブラウザで /robots.txt を開き、Googlebot や全体（User-agent: *）に Disallow: / がないかを見ます。
  4. 要約に使われたくない一部分には data-nosnippet：ブロックエディタでその段落を「HTMLとして編集」にし、囲む要素に data-nosnippet 属性を付けます。ページ全体を止めたいときは、使っているSEOプラグインのページごとの設定（noindex など）を使います。
  5. 構造化データとページの見える内容をそろえる：営業時間・料金・住所などは、ページの文章と構造化データで同じ値にします。食い違いはAIの回答の誤りの原因になります。

Nurevo AEO（WordPressプラグイン、無料）は、構造化データ・llms.txt・AI検索のクローラ向けのrobots.txtをサーバー側で出力します。AIの学習用のクローラ（Google-Extendedなど）は、初期設定ではサイトのrobots.txtのとおりにしておき、許可か拒否かを管理画面から選べます。これはrobots.txtの仕組みで、Search Consoleの「検索の生成 AI」設定とは別のものです。WordPress.orgで入手

Search Consoleでわからないこと：ChatGPT・Perplexityの見え方

Search Consoleが扱うのはGoogleだけです。ChatGPTやPerplexityの回答にあなたの会社や店が出ているかは、次の方法で補います。

方法わかること
アクセス解析の参照元AIの回答からサイトに来た訪問。OpenAIは、ChatGPTの検索結果からのリンクに utm_source=chatgpt.com を付けるとしています（OpenAI：パブリッシャー向けFAQ）
決めた質問を定期的に聞く店名を含まない質問で、名前が出たか・サイトが引用されたかの割合。AIでの登場率の測り方
計測ツール質問のセットを自動で聞き、言及・引用・競合・推移を記録。AEOツールの比較

Nurevo AEOでは、接続したFree・Standardのサイトに、業種と地域から作った店名を含まない3つの質問を月1回Perplexityに聞く無料のAIチェックがあります。決めた質問のセットを継続して測るPro（月14,800円〜、ベータ）も、現在はPerplexityで測っています。Search ConsoleのGoogleの数字と、こうしたGoogle以外のAIの記録を、同じ月の表に並べておくと全体像がつかめます。

よくある質問

生成AIパフォーマンスレポートはどこにありますか？

Search Console ヘルプにある直接のURL（search.google.com/search-console/performance/search-analytics/ai）から開けます。2026年8月31日時点で全世界のサイトに提供されています。表示されない場合は、AI機能での表示回数が少ないか、「検索の生成 AI」設定で除外されている可能性があります。

AIによる概要からのクリック数は見られますか？

生成AIパフォーマンスレポートで見られるのは表示回数です。GoogleのAI機能からのクリックや表示は、通常の検索パフォーマンスの「ウェブ」の数字に含まれますが、AI機能の分だけを切り分けたクリック数は見られません。ページ別に、AI機能の表示回数と通常のクリック数を並べて読むのが現実的です。

グラフの合計と、ページ表の合計が違うのはなぜですか？

グラフはサイト単位、ページ表はページ単位で数えるためです。同じAIの回答に自社の2ページが出た場合、グラフでは1回、ページ表では各ページに1回ずつ数えられます。報告書では2つを足し合わせないようにします。

「検索の生成 AI」設定で除外すると、通常の検索順位は下がりますか？

Googleは、この設定は検索のほかの部分の順位や掲載の判断には使わないとしています。ただし、除外するとAIによる概要・AIモード・Discoverの生成AI機能からの表示とアクセスはなくなります。AIの学習への利用を制限したい場合は、この設定ではなくGoogle-Extendedを使います。

ChatGPTやPerplexityでの表示もSearch Consoleでわかりますか？

いいえ。Search ConsoleはGoogleのデータだけです。ChatGPTやPerplexityは、アクセス解析の参照元、決めた質問を定期的に聞く方法、計測ツールなどで別に確認します。

表示回数を増やすために特別な設定はありますか？

Googleは、AI機能に表示されるための追加の要件や特別な最適化はないとしています。インデックスされていてスニペット付きで表示できること、内容が質問に直接答えていること、構造化データがページの見える内容と一致していることなど、通常の基本を整えるのが近道です。表示が保証される方法はありません。

まず、AIがあなたのサイトを読めるか確認

登録不要の無料チェックで、構造化データやllms.txt、AI検索のクローラの許可など、AIが読む情報の状態がわかります。WordPressなら、Nurevo AEOで不足分を無料で整えられます。
