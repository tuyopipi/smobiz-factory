Bing Places for Businessの登録と、Copilot・Bingでの店舗情報のそろえ方：Googleからの取り込み、同期の向き、重複の直し方

Bing Places for Businessは、BingとBingマップに出る店舗情報を無料で管理するMicrosoftのサービスです。Googleビジネスプロフィール（GBP）を使っているなら、取り込むのがいちばん早く、同期を有効にすると「GBPがBingを上書きする」ため、直すのはGBPとサイトの2か所です。MicrosoftはCopilotとの連携を深めると言っていますが、今のCopilotの回答がBing Placesをどう使っているかは公表していません。だからこそ、Bing Places・GBP・サイトの店名・住所・電話番号・営業時間を同じにしておくことが、いちばん確かな準備です。

作成日：2026年11月24日（日本時間）。Bing Placesの仕様は、同日にMicrosoftの公式ブログと、Microsoftのフォーラム（Microsoft Q&A）での担当者の回答で確認しました。Bing Placesの画面とヘルプはこの日の取得で読めなかったため、画面の名前や手順は変わっている可能性があります。登録するときは画面の表示に従ってください。

どんな登録をしても、CopilotやほかのAIの回答に必ず店が出る・順位が上がるということはありません。AIの回答は日々変わります。この記事は、AIに店の事実を正しく伝えるための準備をまとめたものです。

Bing Placesとは：2025年10月の作り直しで何が変わったか

Microsoftは2025年10月3日に、Bing Places for Businessを作り直したと発表しました（Bing Search Blog）。Bingの検索結果とBingマップに出る店舗情報を、無料で作成・管理するサービスです。

Bing Search Blog（2025-10-03）と Search Engine Journal（同日）をもとに作成。
変わったこと内容
場所（URL）bingplaces.com から bing.com/forbusiness へ。既存の掲載は新しいアカウントへ自動で移り、以前のログイン情報で入ると転送される
Googleからの取り込み速く確実になり、店名・営業時間・連絡先などを保ったまま取り込める
おすすめ機能（Recommendation Tool）写真・ウェブサイトのリンク・営業時間・SNSのリンクの追加を提案する。飲食店にはメニューやネット注文のリンクも
複数店舗まとめて編集する機能と、掲載の状態をすぐ確かめられる表示
今後BingマップとCopilotとの連携を深めることに投資を続ける（予定として書かれている）

Bingは2026年2月にAIでの引用を見るAI Performanceを公開したときも、店舗ならBing Placesを整えるよう勧めています（Bing Webmaster Blog）。見方はBing Webmaster ToolsのAI Performanceの見方にまとめています。

CopilotはBing Placesを使っているのか：わかっていること・いないこと

「CopilotはBing Placesの情報で店を答える」と書く記事は多いのですが、今回読んだMicrosoftの資料には、その仕組みを説明したものはありませんでした。わかっていることと、わかっていないことを分けておきます。

項目状態根拠
Bing Placesの情報がBingの検索結果とBingマップに出るMicrosoftが説明しているBing Search Blog
Copilotとの連携を深める予定として発表されているBing Search Blog
店舗はBing Placesを整えるよう勧めるAI Performanceの発表の中でMicrosoftが勧めているBing Webmaster Blog
今のCopilotの回答がBing Placesのどの項目を使うか公表されていない—
Bing PlacesがWindowsの検索やEdgeにも出る一部の制作会社の記事の主張。Microsoftの資料では確認できなかった—

使われ方がわからない以上、特定の項目に賭けるより、店の基本の事実をどこで見ても同じにしておくのが現実的です。Copilotは回答の出典にウェブのページも使うため、サイトの側の情報も同じくらい大切です。

登録の手順：既存の掲載を探す → 取り込む → 確認する

  1. bing.com/forbusinessにMicrosoftアカウントでログインします。
  2. 先に、自分の店がすでに載っていないか探します。Bingは公開されている情報から掲載を自動で作ることがあり、新しく作ると重複の原因になります。
  3. GBPを使っているなら「Googleから取り込む（Import from Google）」を選び、GBPのアカウントでログインして店を選びます。Microsoftのフォーラムの担当者は、取り込みは「最大2日かかることがある」と答えています（Microsoft Q&A、2025-11）。
  4. 取り込んだら、業種（カテゴリ）を必ず確かめます。2023年のサポート担当者の回答では、カテゴリは取り込まれず手で設定するとされていました（Microsoft Q&A）。2025年の作り直しで変わった可能性があるため、画面で確認します。
  5. GBPを使っていないなら、店名・住所・電話番号・業種・営業時間・ウェブサイトを手で入れ、表示される方法で所有者の確認をします。確認の方法（電話・メール・郵送のはがきなど）は、国や店の情報によって出るものが違います。
  6. おすすめ機能が出す提案（写真・営業時間・SNSのリンクなど）を埋め、サイトと同じ表記になっているかを最後に見直します。

日本の住所での登録の可否や、日本で選べる確認の方法は、今回読めた資料では確かめられませんでした。フランスでは「確認がはがきだけで、届かない」という相談があり、Microsoftの担当者は、Googleからの取り込みを試し、だめならサポートに連絡するよう答えています。手で公開できるのはサポートだけだそうです（Microsoft Q&A、問い合わせ先）。

写真は最大100枚、カテゴリは最大10個などの上限は、Whitespark のガイド（2025-10-30更新）がBingのヘルプをもとに書いています（Whitespark、二次情報）。

GBPと同期するときの注意：上書きの向きを決めておく

2023年のBing Placesのサポート担当者の回答には、同期の向きがはっきり書かれています（Microsoft Q&A）。作り直しの前の説明なので細部は変わっている可能性がありますが、考え方は今も役に立ちます。

項目2023年の担当者の説明やること
同期の方法手動か、自動（毎週・隔週・毎月）営業時間を季節や祝日で変える店は自動にする
上書きの向きGBPのデータがBingの掲載を上書きする。Bingで直しても、GBPと食い違えば、どちらが新しくてもGBPの値になる同期中はBingで直さず、GBPを直す
Bing→GoogleBingの画面からGBPは直せない正本はGBPとサイトの2つにする
公開までの時間通常の公開の周期はおよそ10日。確認や編集のたびに周期がやり直しになる急ぎの変更は一度にまとめ、何度も直さない
住所Bingは住所が必須。GBPに住所がない（訪問型など）と警告が出る訪問型の店は、住所の扱いを画面で確かめる

つまり、同期をしている店にとって、Bing Placesは「GBPの写し」です。間違いを見つけたら、まずGBPとサイトを直し、Bingには同期で届くのを待ちます。同期をしていない店は、GBP・Bing・サイトの3か所をそれぞれ直す必要があり、ずれが起きやすくなります。

重複した掲載・知らない掲載を見つけたとき

  1. Bingマップで店名・電話番号・住所で検索し、自分の店の掲載がいくつあるかを数えます。移転前の住所や、昔の店名の掲載も探します。
  2. 重複は、別のデータの出どころから自動で作られた可能性があるとMicrosoftの担当者は答えています（Microsoft Q&A、2026-06）。
  3. 重複した方の確認（所有者の確認）は進めないでください。2つとも自分のものにすると、どちらが正しいかがかえってわかりにくくなります。
  4. サポートに、残したい掲載（Googleと同期している方など）と消したい掲載の両方の情報、所有者であることがわかる資料、GBPのリンク、画面の写しを送り、統合か削除を頼みます。地域と言語を選ぶとチャットで問い合わせられると担当者は案内しています。
  5. あわせてBingマップの掲載の「編集を提案」や「フィードバック」で重複を報告します。担当者は「うまくいくこともある」という書き方で、確実ではありません。

そろえる項目：Bing Places・GBP・サイトの対照表

AIは複数の出どころを読みます。同じ店の情報が場所によって違うと、どれを答えるかが揺れます。次の表の項目を、3か所で同じにします。

項目Bing Places・GBPサイト（本文と構造化データ）よくあるずれ
店名看板・登記と同じ正式名。宣伝文句を足さない会社概要・フッター・構造化データの name「駅前店」の有無、全角と半角、旧店名
住所建物名・階まで同じ書き方本文の住所と PostalAddress移転前の住所、丁目の書き方、建物名の省略
電話番号予約を受ける番号本文は 03-… のまま。構造化データは +81-3-… の形でもよい代表番号と店の番号の混在、使わなくなった番号
営業時間・休み通常の時間と、祝日・年末年始の特別な時間本文の表と openingHoursSpecificationサイトだけ直して、Bing・GBPが古いまま
業種（カテゴリ）店の中心の業種を1つ目に構造化データの型（Dentist、HairSalon など）取り込みでカテゴリが入っていない
ウェブサイトトップページか、その店舗のページのURL正規のURL（https、www の有無をそろえる）閉じたキャンペーンのページ、古いドメイン

祝日や年末年始の営業時間の書き方は営業時間・定休日・臨時休業のAI検索対策、複数の店舗がある場合は複数店舗のAI検索対策にまとめています。

WordPressでの手順：サイト側の事実をそろえる

  1. 会社概要やアクセスのページに、店名・住所・電話番号・営業時間を画像ではなく文字で書きます。Bing PlacesとGBPに入れた表記をそのまま使います。
  2. 使っているSEOプラグインやテーマが構造化データに出している店名・住所・電話番号を確かめます。無料版では住所や営業時間が出ていないことがよくあります。調べ方はSEOプラグインと店舗の構造化データにあります。
  3. Nurevo AEO（無料のWordPressプラグイン）を使う場合は、設定に店名・住所・電話番号・営業時間を入れます。住所は schema.org の PostalAddress として、日本の電話番号は構造化データでは +81 の国際表記で出します（入力した番号は変えません）。「10:00-19:00 火曜定休」のようなよくある書き方の営業時間は openingHoursSpecification に変換し、読み取れない書き方はそのまま出して推測はしません。SEOプラグインがすでに出している値は上書きせず、同じ @id に足りない事実だけを足します。0.9.1からはSEO SIMPLE PACK・VK All in One Expansion Unitと一緒に使っても重複しません。WordPress.orgで入手
  4. Bingがサイトを読めるようにします。［設定］＞［表示設定］の「検索エンジンでの表示」のチェックが外れているか、/robots.txt で Bingbot を止めていないかを確かめます。
  5. 営業時間を変えたら、サイト・GBP（同期していない場合はBing Placesも）を同じ日に直し、日付を記録します。

登録したあとの確かめ方

  1. Bingで店名を検索し、Bingマップの掲載の店名・住所・電話番号・営業時間が、サイトと同じかを見ます。
  2. Copilotに「（地域）の（業種）で（条件）のお店」「（店名）の営業時間は？」と聞き、答えと出典を記録します。回答は日によって変わるため、同じ質問を毎月同じ日に聞きます。
  3. Bing Webmaster ToolsのAI Performanceで、自社のページがMicrosoftのAIで出典になった回数と語句を見ます。
  4. アクセス解析の参照元で copilot.microsoft.com からの訪問を見ます。
  5. ChatGPTやPerplexityはBingとは別の仕組みです。AIでの登場率の測り方のように、決めた質問のセットで別に記録します。Nurevo AEOの無料のAIチェックは、接続したサイトに月1回、業種と地域から作った3つの質問をPerplexityに聞きます。継続して測るPro（月14,800円〜）も現在はPerplexityで測っています（ChatGPTは設定され次第）。

チェックリスト

  1. bing.com/forbusiness で、自分の店がすでに載っていないか探した
  2. GBPを使っていれば取り込み、使っていなければ手で登録して確認を済ませた
  3. 業種（カテゴリ）が入っているか画面で確かめた
  4. 同期の有無と、どこを正本にするか（GBPとサイト）を決めて記録した
  5. Bingマップで重複・旧住所・旧店名の掲載を探した
  6. 重複があれば、確認を進めずにサポートへ統合・削除を頼んだ
  7. 店名・住所・電話番号・営業時間・業種・URLを、Bing・GBP・サイトで同じにした
  8. サイトの構造化データの値も本文と同じにした
  9. Bingbot を robots.txt で止めていないか確かめた
  10. Copilotへの質問と答えを、日付を付けて記録した

制作会社・MEO会社が代わりに登録するとき

お客様の代わりに登録するときは、ログインに使うMicrosoftアカウントを誰のものにするかを最初に決めます。担当者が辞めても店が自分で入れるよう、店のアカウントで作り、制作会社は管理者として加えてもらう形が安全です。

毎月の保守では、GBP・Bing Places・サイトの対照表を1枚作り、ずれがないかを見る作業を足すと、AI検索への備えを報告に入れられます。月額のサービスにする方法は制作会社がAI検索対策を月額サービスにする方法、パートナー制度はパートナーのページをご覧ください。

よくある質問

Bing Placesは無料ですか？

はい。MicrosoftはBing Places for Businessを、BingとBingマップの掲載を作成・管理する無料のサービスとして説明しています。

Googleビジネスプロフィールがあれば、Bing Placesの登録は要りませんか？

自動では載りません。Bing Placesで「Googleから取り込む」を使うと、GBPの情報を元に掲載を作れます。同期を有効にすれば、その後のGBPの変更もBingに届きます。

Bing Placesで直したのに、元に戻ってしまいます。

GBPと同期していると、食い違う項目はGBPの値で上書きされると、2023年にBingのサポート担当者が説明しています。同期中は、GBPの側を直してください。

変更が反映されるまでどれくらいかかりますか？

2023年の担当者の回答では、公開の周期は通常およそ10日で、編集のたびにやり直しになるとされていました。2025年には、Googleからの取り込みは最大2日かかることがあると答えています。今の時間は画面の表示で確かめてください。

CopilotはBing Placesの情報を使って答えますか？

MicrosoftはCopilotとの連携を深めると発表していますが、今の回答でBing Placesがどう使われているかは公表していません。Bing Places・GBP・サイトの事実をそろえておくのが確かな準備です。

日本の店でも登録できますか？

今回読めたMicrosoftの資料には、対応する国の一覧も、日本での確認の方法も書かれていませんでした。登録の画面で国と住所を選べるか、どの確認の方法が出るかを確かめてください。

重複した掲載は自分で消せますか？

Microsoftのフォーラムの担当者は、サポートへの問い合わせを案内しています。残したい掲載と消したい掲載の情報、所有者であることを示す資料を送り、統合か削除を頼みます。重複した方の確認は進めないでください。

まず、AIがあなたの店のサイトを読めるか確認

登録不要の無料チェックで、構造化データの住所・電話番号・営業時間や、llms.txt、AI検索のクローラーの許可の状態がわかります。WordPressなら、Nurevo AEOで不足分を無料で整えられます。
