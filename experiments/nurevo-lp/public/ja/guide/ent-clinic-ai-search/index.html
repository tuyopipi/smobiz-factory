耳鼻咽喉科のAI検索対策：花粉症の時期の受付、舌下免疫療法、聞こえと補聴器の情報をAIに正しく読ませる手順

耳鼻咽喉科のAI検索対策でいちばん大切なのは、「いつ・誰が・どの条件で受けられるか」を、診療ごとのページに日付つきの文字で書くことです。耳鼻咽喉科は、花粉の季節に受付や予約の方法が変わり、舌下免疫療法には始められる時期があり、補聴器では医院と販売店の役割が分かれるため、AIが古い情報や別の事業者の情報を混ぜやすい分野です。そのうえで、子どもを何歳から診るかを書き、医療広告のルールを守ったまま、同じ事実を構造化データ・llms.txt・Googleビジネスプロフィールにそろえます。

作成日：2026年11月19日（JST）。舌下免疫療法の開始時期（日本耳鼻咽喉科免疫アレルギー感染症学会の委員会資料）、保険適用の時期（日本医事新報）、薬の承認と年齢（鳥居薬品の発表、日刊薬業）、出荷の状況（薬事日報）、補聴器の医療費控除（国税庁）と補聴器相談医・認定補聴器専門店（県の案内）、schema.orgの型（schema-dts 2.1.0の型定義）は同日に確認しました。厚生労働省の医療広告Q&Aの項目は2026年11月16日に確認した範囲です。

AIの回答は日や聞き方によって変わります。この記事の対策は、AIが医院の事実を正しく読める状態をつくるものです。AIの回答に必ず表示される・順位が上がることを保証するものではありません。この記事は法的・医学的な助言ではありません。個別の表現は管轄の保健所などで、薬の扱いは添付文書で確認してください。

耳鼻咽喉科で、患者さんがAIに聞くこと

耳鼻咽喉科の質問は、症状のほかに「季節」「年齢」「手続き」が入るのが特徴です。子どもの中耳炎や鼻水を調べる保護者、親の聞こえを心配する家族もAIに聞きます。よく出る質問の型は次の6つです。

質問の型例AIが答えに使う情報
地域×症状×時間「◯◯駅の近くで、土曜の午後に子どもの耳の痛みを診てもらえる耳鼻科」曜日ごとの診療時間、受付の締め切り、予約制か順番受付か、対象年齢
花粉症の時期「花粉症の薬だけもらいに行ける耳鼻科」「2月は混んでる？」季節の受付方法、オンライン受付の有無、混雑する時間帯の案内（医院の案内として）
舌下免疫療法「スギの舌下免疫療法はいつから始められる？子どもは何歳から？」スギとダニの違い、始められる時期、対象年齢、通院の頻度、新規の受付状況
聞こえ・補聴器「補聴器を買う前に耳鼻科に行くべき？医療費控除は？」聴力検査の内容、補聴器相談医がいるか、販売店との関係、書類の発行
めまい・耳鳴り「めまいの検査ができる耳鼻科」「耳鳴りは何科？」できる検査の名前、予約が必要か、所要時間
手術・紹介「鼻の日帰り手術ができる耳鼻科」「扁桃の手術はどこで？」院内でする手術と紹介する手術の区別、紹介先の種類、入院の有無

どの型も、AIが使えるのは条件が文字で書いてあるページです。診療時間が画像だけ、「花粉症の方は混雑します」だけ、舌下免疫療法の開始時期が書かれていない、というページは出典になりにくくなります。

上位の記事で抜けていたこと

「耳鼻科 AI検索対策」「クリニック LLMO」「ENT practice AI search」などで上位に出る記事を、日本語3本・英語5本読みました。日本語で耳鼻咽喉科に絞った記事はなく、クリニック・歯科全般の記事（医療広告のルールや医院情報の表記をそろえる話は実務的）と、AIに触れていないMEOの記事が中心でした。英語では、耳鼻咽喉科向けのAI検索の記事は米国のレビューサイトや認定制度を前提にした一般論で、「AIが医療の質問の63〜84%に出る」のような数字を出典なしで挙げる記事もありました。米国の耳鼻咽喉科学会の会報の記事は診察・請求でのAIの使い方が中心で、サイトの書き方は扱っていません。

どの記事にもなかったのは、次の4点です。この記事はここを中心に書きます。

  1. 花粉の季節に変わる受付・予約の情報を、AIに古い情報として残さない書き方。
  2. 舌下免疫療法のページに書く条件（スギとダニの開始時期の違い、対象年齢、保険、新規の受付状況）。
  3. 補聴器で、医院（検査・補聴器相談医）と販売店（販売・調整）を分け、医療費控除の書類を正しく案内する書き方。
  4. 耳鼻咽喉科を表すschema.orgの型（Otolaryngologic）と、WordPressでの具体的な設定、AIに出ているかの確かめ方。

季節で変わる受付は「期間つき」で書く

耳鼻咽喉科では、花粉の多い時期にWeb受付だけにする、受付の締め切りを早める、といった変更がよくあります。お知らせのページに「当面の間」と書いたまま季節が終わると、AIは翌年の夏になっても「予約はWebのみ」と答えかねません。季節の変更は、必ず期間を入れて書きます。

書くこと書き方の例避けたい書き方
変更の期間「2027年2月1日〜4月10日は、午前の受付をWeb受付のみにします」「花粉の時期はWeb受付のみ」「当面の間」
変わらない部分「診療時間・休診日は通常どおりです」変更点だけを書き、何が変わらないかを書かない
終わったあと期間が終わったらお知らせを消すか「終了しました」と書き、llms.txtから外す終わったお知らせを残したままにする
電話での相談電話の受付時間と、電話で答えられる内容（予約の可否など）「お電話でお問い合わせください」だけ

通常の診療時間は、お知らせとは別の固定のページに、曜日と時刻の表を文字で書きます。そこに季節の例外を混ぜないことで、AIが通常の時間と例外を区別しやすくなります。

舌下免疫療法のページ：開始時期・年齢・受付状況を書く

舌下免疫療法は、スギ花粉症とダニによるアレルギー性鼻炎に対して2014年から保険適用されています。日本医事新報。AIに聞かれやすいのは「いつ始められるか」と「子どもは何歳からか」です。日本耳鼻咽喉科免疫アレルギー感染症学会の鼻アレルギー診療ガイドライン委員会は、スギはシーズンを外して始めること、ダニは原則として開始時期の制限がないことを示しています（2023年7月現在の資料）。委員会の回答（PDF）。

年齢については、スギの舌下錠（シダキュア）は2017年9月に承認され、成人と小児に使える国内初の舌下錠と発表されました（臨床試験の対象は5〜64歳）。鳥居薬品の発表（PDF）。ダニの舌下錠（ミティキュア）は2018年2月に小児の追加承認を受け、それまでの「12歳以上」という制限がなくなりました。日刊薬業。実際に何歳から始めるかは医院の方針や診察で決まるため、ページには「当院では◯歳から、診察で判断します」のように自院の扱いを書きます。

供給にも注意が必要です。スギの舌下錠は需要の増加で2023年から限定出荷となり、2025年秋から段階的に出荷を増やす予定と報じられています。薬事日報（2025年2月14日）。新規の受付を止めている・待ちがある場合は、そのことを日付つきで書き、再開したら書き換えます。

  1. 治療の名前と、スギ・ダニのどちらに対応しているか（片方だけなら明記）。
  2. 始められる時期：スギはシーズンを外して始める、ダニは時期を問わない、など自院の方針。
  3. 対象年齢：自院で何歳から行うか、保護者の同伴が必要か。
  4. 流れ：診察と検査（アレルギーの確定）、初回の服用は院内で行うか、通院の頻度。
  5. 期間：自院が案内している治療の期間の目安（ある医療機関の資料では3年以上が推奨と案内されています。資料（PDF））。
  6. 費用：保険診療であること、自己負担の目安を書く場合は条件（負担割合・薬の日数）つきで。
  7. 新規の受付状況と、その更新日。

聞こえと補聴器：医院と販売店を分けて書く

補聴器は、買う前に耳鼻咽喉科で検査を受けることが自治体や学会の地方部会の案内で勧められています。補聴器相談医は日本耳鼻咽喉科頭頸部外科学会が委嘱する医師で、学会のサイトに名簿があります。販売・調整をするのは、公益財団法人テクノエイド協会が認定する認定補聴器技能者や認定補聴器専門店です。滋賀県：補聴器の購入をお考えの方へ、島根県の案内、補聴器相談医名簿。

医療費控除についても、AIがよく聞かれます。国税庁の情報では、補聴器相談医が「補聴器適合に関する診療情報提供書（2018）」で治療のために直接必要と認めた補聴器の購入費用は、一般的な水準を著しく超えない部分が医療費控除の対象になります（2018年4月16日）。国税庁：補聴器の購入費用に係る医療費控除の取扱い。医院が書けるのは「当院には補聴器相談医がいて、この書類を発行できるか」です。控除が受けられるかの判断は税務署にあるので、「必ず控除される」とは書きません。

  1. 聞こえのページに、聴力検査の種類と所要時間、予約が必要かを書く。
  2. 補聴器相談医が在籍しているなら、その医師の名前と曜日を書く。在籍していないなら書かない。
  3. 診療情報提供書を発行できるか、発行の費用（自費か）を書く。
  4. 医院の中や近くの補聴器販売店と連携している場合、同じ事業者か別の事業者かを書く。別なら、営業時間・電話番号・料金も分けて書く。
  5. 障害者手帳の補装具の制度は市区町村の窓口が扱うことを書き、金額は書かない。

子どもの受診：何歳から、誰と来るかを書く

耳鼻咽喉科は、中耳炎や鼻水で子どもが多く受診します。保護者がAIに「0歳でも診てもらえる耳鼻科」と聞いたとき、対象年齢が書かれていないと、AIは医院を候補から外すか、推測で答えます。

  1. 何歳から診るか（「0歳から」「乳児は要相談」など）。
  2. 保護者の同伴、子どもだけで受診できるか（年齢の目安つき）。
  3. 持ち物：保険証・医療証など、医院の案内として（医療費の助成の内容は自治体ごとなので、制度名と自治体の窓口を案内する）。
  4. 子どもの舌下免疫療法を行うか、何歳から行うか（上の節と同じ値にそろえる）。

医療広告のルールと、一般的な「AI対策」の助言がぶつかるところ

AI検索対策の記事では「口コミを増やす」「実績を見せる」がよく勧められます。医療機関のサイトでは、厚生労働省の医療広告ガイドラインとQ&Aに沿って扱いを決めます。

よくある助言医療機関での扱い（厚生労働省のQ&A）代わりにできること
患者さんの声を載せる治療の内容や効果についての体験談は掲載できない（Q1-18、Q2-9）流れ・期間・通院回数・費用の条件など、事実の説明を詳しくする
「花粉症が治る」「聞こえが戻る」と効果を見せる治療効果の表現には制限がある。術前・術後の写真も治療効果の表現として扱われる（Q2-8、Q3-14）何が書けるかは事例解説書と保健所で確認する
「地域No.1」「待たない耳鼻科」虚偽・誇大・比較優良の表示は禁止されている例として扱われる受付の方法や時間など、事実で書ける範囲だけを書く
自費の検査・手術を詳しく書く自由診療は、治療の内容・費用、主なリスク・副作用、相談に答える問い合わせ先を書くことが条件（Q6-10〜6-12）条件を満たす形で、費用と主なリスクを同じページに書く

WordPressの耳鼻咽喉科サイトでの設定手順

  1. WordPress.orgからNurevo AEO（無料）をインストールして有効化します。Yoast SEO・Rank Math・All in One SEO・Slim SEOはそのまま使えます。0.9.1からはSEO SIMPLE PACKやVK All in One Expansion Unitとも、構造化データを重複させずに併用できます。
  2. 初回の設定ウィザードで「クリニック・歯科」を選びます（型はMedicalBusinessになります）。そのあと設定画面の「業種（schema.org型）」欄を Otolaryngologic に変えます。この欄にはschema.orgの型名をそのまま入れられます。
  3. 医院名・住所・電話番号・説明を確認します。空欄の項目だけが既存の設定から補われ、入力済みの値は上書きされません。
  4. 営業時間は「月〜金 9:00-12:30 15:00-18:30 / 土 9:00-12:30」のように曜日と時刻だけを書きます。受付の締め切り・季節の受付方法は、本文の表とお知らせに書きます。
  5. 自費の検査や書類の発行など、料金を本文に書いているものだけを設定画面のサービスに1つずつ登録します。名前・説明・料金・通貨を入れると、料金つきのサービス（Service と Offer）として出力されます。料金は本文と同じ値にします。
  6. 舌下免疫療法・聞こえ・子どもの受診の各ページの編集画面のサイドバーで、そのページだけのFAQ（「スギはいつから始められますか」「何歳から診てもらえますか」「補聴器の書類は出せますか」）を入れます。体験談や効果を約束する答えは入れません。終わった季節のお知らせは「このページをllms.txtに載せない」にします。
  7. AEOスコアの画面で診断を実行し、不足をワンクリック修正で直します。外からどう見えるかは無料のAI可読性チェックで確かめます。

診療分野（medicalSpecialty）を足したいとき

Nurevo AEOは medicalSpecialty を自動では出しません。出したい場合は、テーマの functions.php か小さなプラグインで、事業の構造化データを変えるフィルター（webmcp_canary_business_node）を使います。

add_filter('webmcp_canary_business_node', function ($org, $settings) {
    // 本文に書いている診療分野だけを足す（小児を診ない医院は Pediatric を入れない）
    $org['medicalSpecialty'] = array('Otolaryngologic', 'Pediatric');
    return $org;
}, 10, 2);

AIに出ているかを確かめる

整えたあとは、患者さんや保護者が聞きそうな質問を「地域×症状×曜日」「地域×舌下免疫療法×開始時期」「地域×子ども×耳の痛み」「地域×補聴器×相談」の組み合わせで5〜10個つくり、ChatGPTやPerplexityに投げます。医院が名前やURLで出るか、開始時期・対象年齢・受付方法が正しく書かれているかを記録します。花粉の時期と、それ以外の時期の両方で確かめると、季節の情報が古いまま残っていないかが分かります。AIの回答は回ごとに変わるので、同じ質問を期間をあけて何度か確かめます。測り方はAIでの登場率の測り方にまとめています。

Nurevo AEOでは、Free・Standardプランでも月に1回、業種と地域から作った3つの質問（医院名は含めません）をPerplexityに投げ、回答に医院の名前やサイトが出たかを記録します。Proプラン（月14,800円〜）では、ベータ版のAI登場率の計測で、AIの回答に医院が出る割合を競合との比較・推移とあわせて見られます（現在の計測対象はPerplexity）。どちらも回答のサンプルを見るもので、すべての回答を観測するものではありません。

よくある質問

耳鼻咽喉科のAI検索対策は、何から始めればいいですか？

曜日ごとの診療時間と受付の締め切りを固定のページに文字で書き、季節の変更は期間つきのお知らせにすることからです。次に舌下免疫療法・聞こえ・子どもの受診のページに条件を書き、名前・住所・電話番号・診療時間を構造化データ・Googleビジネスプロフィールとそろえます。

舌下免疫療法の開始時期は、どう書けばいいですか？

スギとダニを分けて書きます。学会の委員会の資料では、スギはシーズンを外して始め、ダニは原則として開始時期の制限がないとされています。そのうえで、自院がいつ新規の受付をしているかを日付つきで書きます。

子どもの舌下免疫療法は何歳から、と書いてもいいですか？

自院の方針として書くのがよい方法です。ダニの舌下錠は2018年に「12歳以上」の制限がなくなり、スギの舌下錠は成人と小児に使える薬として承認されています。実際に始める年齢は診察で判断することも一緒に書きます。

補聴器の医療費控除について、医院のサイトに何を書けますか？

補聴器相談医が在籍しているか、「補聴器適合に関する診療情報提供書（2018）」を発行できるか、その費用です。控除が受けられるかは税務署の判断なので、「必ず控除される」とは書かず、国税庁の情報にリンクします。

構造化データの型は何を使えばいいですか？

schema.orgのOtolaryngologicが耳鼻咽喉科を表す型で、MedicalBusinessとLocalBusinessの一種です。小児も診るなら medicalSpecialty に Pediatric を足せます。補聴器の販売店が別の事業者なら、医院の情報に混ぜません。
