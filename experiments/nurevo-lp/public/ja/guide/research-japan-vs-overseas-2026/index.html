日本と海外のWeb制作会社の自社サイト15,838件に見るAI検索への対応の差（2026年11月）

日本のWeb制作会社の自社サイト2,486件と、海外25の国・地域の制作会社サイト13,352件のトップページ・robots.txt・llms.txt を同じ方法で調べました。llms.txt があったのは日本13.4%、海外29.6%（トップページが HTTP 202 を返したサイトを除く）で、比べた25の国・地域の中で日本が最も低い値でした。一方、meta description（日本90.7%・海外80.3%）や robots.txt（91.8%・87.6%）は日本のほうが高く、日本の「5項目は満たしているサイト」1,039件の94.9%は、欠けているのが llms.txt だけでした。

公開：2026年11月26日。データ：2026年11月12日集計。調査・執筆：Nurevo AEO（Bestie.合同会社）。Nurevo はAI検索対策（AEO）のツールと WordPress プラグインを提供しており、この分野に利害があります。

要点

  1. llms.txt があったのは、日本の制作会社サイトで13.4%（2,486件中333件）、海外で26.4%（13,352件中3,522件）、HTTP 202 を返した1,477件を除くと29.6%でした（p<0.001）。30件以上ある25の国・地域で比べると、日本は最下位（25位）で、1位はシンガポール（41.9%）でした。
  2. AI検索に関わる6項目をすべて満たすサイトは、日本10.4%、海外24.5%（202を除く）。ただし日本で5項目を満たすサイト1,039件のうち986件（94.9%）は、足りないのが llms.txt だけでした。6項目の平均は日本4.05、海外（202を除く）4.30です。
  3. meta description（日本90.7%・海外80.3%）、robots.txt（91.8%・87.6%）は日本のほうが高く、og:title（81.3%・81.4%）と canonical（84.6%・85.9%）は統計的な差がありませんでした。robots.txt でAIボットをブロックしていたのは日本1.3%・海外4.9%で、検索用のボット（OAI-SearchBot・Claude-SearchBot・PerplexityBot）をブロックしていたのはどちらも0.3%以下でした。

調査概要

  1. 対象：Web制作会社の自社サイト。当社の収集リストにある日本の制作会社サイト3,352件と、海外の制作会社サイト20,335件のうち、トップページに到達できた日本2,486件・海外13,352件（合計15,838件）です。一般企業のサイト全体ではありません。国・地域は収集リストの記載によります。
  2. 取得したもの：各サイトのトップページ、/robots.txt、/llms.txt、/llms-full.txt を1回ずつ（User-Agent：NurevoSurvey/1.0）。2026年11月上旬〜12日に取得し、11月12日に集計しました。
  3. 判定方法：llms.txt は、ステータス200で中身がHTMLではなく20文字を超えるテキストを「あり」としました。JSON-LD はトップページにあるかどうか、「壊れている」は JSON として読み込めないブロックが1つ以上あるもの。Organization系は @type に Organization・LocalBusiness・Corporation・ProfessionalService を含むもの。WordPress はトップページのHTMLに wp-content/・wp-includes/、または generator の WordPress 表記があるもの。
  4. AIボットのブロック：robots.txt で、各ボットに当てはまるグループの規則がトップページ（/）を Disallow にするか（最長一致）で判定しました。分母は robots.txt があるサイトです。「AIボットをブロック」は GPTBot・ClaudeBot・PerplexityBot・Google-Extended・CCBot・OAI-SearchBot のどれかをブロックしているものです。
  5. 「6項目」は、(1) llms.txt がある、(2) JSON-LD がある、(3) Organization または LocalBusiness の型がある、(4) robots.txt があり GPTBot・ClaudeBot・PerplexityBot・OAI-SearchBot のどれもブロックしていない、(5) meta description がある、(6) canonical がある、のうち当てはまる数（0〜6）です。この調査のための単純な数え方で、Nurevo の製品のスコア（0〜100）とは別のものです。
  6. HTTP 202：海外では1,477件（米国671件・豪州250件・英国140件など）のトップページがステータス202を返しました（日本は0件）。これらのページには JSON-LD も WordPress の痕跡もなく、ボット確認などの別のページが返った可能性があります。そのため、海外は「全体」と「202を除く（11,875件）」の両方を載せ、日本との比較と国別の表は202を除いた値を使っています。
  7. 英語圏6か国は米国・英国・カナダ・豪州・ニュージーランド・アイルランド（202を除いて7,461件）、その他の国・地域はそれ以外の19の国・地域（4,414件）です。p値は日本と海外（202を除く）の2×2のカイ二乗検定です。

結果：日本と海外の比較

日本が低かったのは llms.txt・JSON-LD・Organization系の型・LocalBusiness・FAQPage・microdata で、高かったのは WordPress の割合・meta description・robots.txt と、その中の Sitemap の記載でした。og:title・canonical と、JSON-LD が壊れている割合（日本1.7%・海外1.8%）には統計的な差がありませんでした。英語圏6か国とその他の国・地域を比べると、llms.txt（27.0%・34.0%）・FAQPage（8.7%・13.5%）・6項目すべて（22.5%・28.0%）は英語圏以外のほうが高めでした。

限界

  1. 対象はWeb制作会社の自社サイトで、一般企業のサイト全体ではありません。国・地域は当社の収集リストの記載によるもので、各国の制作会社全体を代表する標本ではありません。国によって件数の差が大きく、100件未満の国・地域もあります。
  2. トップページだけを見ています。robots.txt はトップページ（/）に対する判定で、一部のディレクトリだけのブロックや、ファイアウォール・CDN によるブロックは数えていません。llms.txt は有無だけを見て、中身の質は見ていません。
  3. 各サイト1回の取得で、到達できなかったサイトは除いています。HTTP 202 を返した1,477件は、実際のトップページとは違うページを見ている可能性があり、202以外でもボット確認のページなどが混じっている可能性はあります。
  4. SEOプラグインはHTMLの文字列による判定で、痕跡を消している場合や複数入っている場合は正しく分けられません。
  5. 今回の集計の一部には11月5日集計時の取得分を引き継いでいます。

当社の見方（意見）

ここからは事実ではなく当社の意見です。日本の制作会社サイトは、meta description や robots.txt といった従来のSEOの基本は海外より整っている一方、llms.txt と構造化データの一部（LocalBusiness・FAQPage）で差がありました。5項目を満たすサイトの大半は llms.txt だけが欠けている形なので、日本の差は「基本ができていない」というより「新しい項目にまだ手を付けていない」ことによる部分が大きいと見ています。llms.txt や構造化データがあればAIの回答に出る、というものではありません（当社の別の調査では、サイト側の対策と回答への登場に関係は見られませんでした）。それでも、会社の事実を機械が読める形で置いておくことは、手間の小さい準備として検討に値すると考えます。

よくある質問

日本の制作会社は海外よりAI検索への対応が遅れていますか？

llms.txt（日本13.4%・海外29.6%）、6項目すべて（10.4%・24.5%）、JSON-LD（69.4%・81.0%）は日本が低く、meta description（90.7%・80.3%）と robots.txt（91.8%・87.6%）は日本が高い結果でした（海外は HTTP 202 を除く、2026年11月、制作会社の自社サイト）。

日本は何位でしたか？

30件以上ある25の国・地域のうち、llms.txt の導入率は25位（最下位）、6項目すべては24位、JSON-LD は17位、6項目の平均は14位でした。

海外ではAIクローラーをブロックしているサイトが多いですか？

robots.txt があるサイトの4.9%で、日本（1.3%）より多いものの少数でした。ブロックの多くは学習用のボットで、検索用の OAI-SearchBot をブロックしていたのは0.2%でした。

HTTP 202 とは何ですか？

海外の1,477件のトップページが返したステータスです。JSON-LD などが見つからず、ボット確認などの別のページが返った可能性があるため、除いた値も載せています。
