仏壇店・石材店のAI検索対策：墓石の総額、工事できる霊園、墓じまい、仏壇の産地をAIに正しく読ませる手順

仏壇店・石材店のAI検索対策（AEO）で一番大事なのは、お客様が見積もりを取る前に知りたいことを、店のサイトに文字で書いておくことです。墓石なら、石の代金・彫刻・基礎工事・据え付けに分けた税込みの総額と、工事ができる霊園や墓地、墓じまいでお店がする作業としない作業。仏壇なら、大きさ・材料・どこで作られたか（伝統的工芸品なら産地名）、配達と古い仏壇の引き取りです。そのうえで、同じ事実をGoogleビジネスプロフィールと構造化データ（Store＋Service）に出します。

作成日：2026年11月26日（JST）。国民生活センター・総務省・滋賀県などのページは、本文に記したリンク先で2026年11月26日に確認しました。この記事は法的な助言ではありません。

AIの回答は日や聞き方によって変わります。この記事の対策は、AIがあなたの店の事実を正しく読める状態をつくるもので、AIの回答に必ず表示される・順位が上がることを保証するものではありません。

石材店・仏壇店がAIに聞かれること

お墓や仏壇は、多くの人にとって一生に何度も買うものではありません。そのため、AIには「いくらかかるのか」「どこまで頼めるのか」「この霊園で工事してもらえるのか」という、基本の質問が多くなります。霊園や墓地の区画そのものは霊園の運営者が答えることなので、この記事では、墓石を建てる・直す・片付ける石材店と、仏壇を売る店が答えるべきことに絞ります。

質問の例は、この記事の説明のための例です。実際の質問の頻度を調べたものではありません。
質問の型質問の例AIが答えに必要な事実
墓石の総額「◯◯市でお墓を建てるといくら？何が含まれる？」石・彫刻・基礎・据え付けに分けた税込みの金額、含まれないもの
工事できる場所「◯◯霊園で工事できる石材店は？」工事の実績や許可がある霊園・墓地の名前、霊園の規則で業者が決まっている場合の扱い
墓じまい「墓じまいを頼むといくら？手続きもしてくれる？」撤去・処分・整地の料金、1㎡あたりなどの単位、手続きの代行の有無
修理・追加彫刻「戒名を追加で彫ってもらえる？傾いた墓石は直せる？」追加彫刻・クリーニング・修理の料金と日数、保証の内容
仏壇の選び方「マンションに置ける小さな仏壇はある？」大きさ（高さ・幅・奥行き）、材料、価格、置き場所の例
仏壇の産地・引き取り「国産の仏壇はある？古い仏壇は引き取ってくれる？」製造地、伝統的工芸品かどうか、配達と古い仏壇の引き取りの料金

上位の解説記事に足りないこと

2026年11月26日に、日本語と英語で「石材店 AI検索対策」「monument company AI search」などの上位記事を11本読みました。日本語では、uravationの霊園・墓石の記事が、総額の内訳・改葬の手続き・宗派の書き方を詳しく扱っていますが、中心は霊園の区画で、構造化データは型の名前に触れるだけ、WordPressでの手順はありません。統計も出典の名前だけで、リンクはありません。サングローブの石材店の集客の記事は2025年10月に更新されていますが、AI検索には触れておらず、市場規模の数字に出典がありません。GMOのローカルAIOの記事は地域の店全般の内容で、数字の多くに出典がありません。仏壇店に絞った記事は見つかりませんでした。

英語では、石材の業界誌Stone Worldの記事（2025年6月）が「AIに聞いて結果を記録する」ことを勧めていますが、数字や手順はありません。Textaは出典のない「50件以上の口コミ」を基準に挙げています。葬儀の分野のAI登場率を調べた5Wのレポート（2026年4月）にも、墓石の店についての結果はありませんでした。どの記事にも、墓石の総額を分けて書く表、工事できる霊園の書き方、伝統的工芸品の表示の確かめ方、WordPressの設定はありません。この記事は、これらを埋めます。

墓石の料金は「総額の内訳」と「含まれないもの」で書く

墓石の値段は、石の代金だけを大きく書くと、AIもお客様も総額を取り違えます。お墓の工事には、石の加工、文字の彫刻、基礎工事、据え付け、古い墓石の撤去などが重なるからです。料金ページには、セットの価格を出す場合でも、何が入っていて何が入っていないかを文字で書きます。

金額は書き方の例です。自分の店の実際の料金と石の名前を書いてください。
書く項目書き方の例
石の代金和型8寸角・国産の◯◯石で◯◯万円、外国産の◯◯石で◯◯万円（税込）。石の名前と産地を書く
彫刻家名・建立者名・建立年月の彫刻を含む。戒名の追加彫刻は1名◯万円
基礎工事1.5㎡までの区画のコンクリート基礎を含む。それより広い区画は1㎡あたり◯万円
据え付け・運搬◯◯市内の霊園は含む。市外は距離で◯万円から（見積もりで先にお伝えします）
含まれないもの区画の使用料・管理料（霊園に払うもの）、開眼供養のお布施、古い墓石の撤去
総額の例1.5㎡の区画に和型の墓石を建てる場合：◯◯万円（税込、上の内訳の合計）

霊園に払う使用料・管理料と、石材店に払う工事の代金は、払う相手が違います。この2つを分けて書くと、AIが「お墓の総額」を聞かれたときに、取り違えが起きにくくなります。料金ページの書き方全般は料金ページのAI検索対策をご覧ください。

工事ができる霊園・墓地を名前で書く

お客様は、すでに区画を持っている霊園で工事を頼めるかどうかを知りたがります。霊園によっては、規則で工事のできる石材店が決まっていることがあります。その場合は、お客様がまず霊園の規則を確かめることになるので、店のサイトには「工事の実績がある霊園・墓地」と「指定を受けている霊園」を分けて、名前で書きます。

  1. 工事の実績がある霊園・墓地・寺院墓地の名前を、市区町村ごとに一覧にします。お寺の墓地は、お寺の了承を得てから載せます。
  2. 霊園から指定を受けている場合は、その霊園の名前と「指定石材店」であることを書きます。指定を受けていない霊園を指定と書かないでください。
  3. 工事の前に、霊園の管理事務所への届け出が必要な場合は、店が代わりに出すのか、お客様が出すのかを書きます。
  4. 対応エリアを市区町村名で書き、そこから遠い霊園は出張の料金の考え方を書きます。

墓じまい：店がする作業と、しない手続きを分けて書く

墓じまいと、遺骨をほかのお墓や納骨堂に移す改葬は増えています。総務省東北管区行政評価局のまとめでは、厚生労働省の衛生行政報告例による改葬の件数は、2014年度（平成26年度）の約8万4千件から、2024年度（令和6年度）には約17万6千件に増えています。総務省 東北管区行政評価局「墓じまいに関する情報収集結果」（PDF）

国民生活センターに寄せられた「墓」の相談は、2023年度1,046件、2024年度1,018件、2025年度1,077件です（2026年5月31日現在）。最近の事例として紹介されているのは、墓じまいや遺骨の移転のときにお寺から高額な離檀料を求められた、宗派が違うとわかった墓地の解約で解約料を求められた、といった内容です。国民生活センター：墓・葬儀サービス（2026年7月31日更新）。石材店が離檀料を決める立場にはありませんが、お客様は「誰に、何を、いくら払うのか」がわからずに困っています。

書き方の例です。手続きの代行の可否や料金は、自分の店の実際の対応を書いてください。
分けて書くこと書き方の例
店がする工事墓石の撤去・運搬・処分、基礎の撤去、整地（更地にして霊園に返す）
料金の単位1㎡あたり◯万円（税込）。重機が入れない区画は現地を見てからお伝えします
店がしない手続き改葬許可の申請（今のお墓がある市区町村に出します）、お寺への閉眼供養の依頼、離檀の相談
手続きの手伝い申請書の書き方の案内は無料。代行が必要な場合は、行政書士をご紹介します（例）
遺骨の取り出し取り出しは工事の日に立ち会いのもとで行います。新しい納骨先までの運び方の相談
期間の目安現地確認から工事まで◯週間ほど。霊園の届け出の受付日によって変わります

改葬の手続きの流れや必要な書類は自治体によって違うので、店のサイトでは「どこに申請するか」と「店が手伝えること」を書き、細かい要件は自治体の案内へのリンクにします。

仏壇：大きさ・材料・製造地を、事実どおりに書く

仏壇で書くべきことは、大きさ（高さ・幅・奥行き）、材料（木の種類、合板か無垢か、塗りの仕上げ）、どこで作られたか、価格です。とくに「国産」「伝統的工芸品」は、お客様が比べるときの大事な事実なので、正確に書きます。経済産業大臣が指定する伝統的工芸品は、全国で241品目あり（2025年10月27日時点）、彦根仏壇などの仏壇も含まれます。滋賀県：滋賀県の伝統的工芸品について。大阪仏壇は1982年11月1日、三河仏壇は1976年12月15日、広島仏壇は1978年に指定されています。大阪府・愛知県・広島市

伝統的工芸品には「伝統証紙」があり、滋賀県の説明では、伝統証紙が貼られている工芸品は、産地組合などが行う検査に合格したものです。滋賀県・伝統的工芸品産業振興協会の資料（PDF）。また「名古屋仏壇」は地域団体商標（商標登録第5098956号）になっています。中部経済産業局（PDF）

  1. 産地の名前（◯◯仏壇）は、その産地で作られ、証紙など確かめられる根拠があるものにだけ使います。「◯◯仏壇風」「◯◯仕立て」のような書き方で産地と誤解されないようにします。
  2. 海外で作った仏壇や、部品を海外で作って国内で仕上げた仏壇は、そのことをそのまま書きます。どの工程をどこでしたかを書くと、AIが条件つきで答えられます。
  3. モダン仏壇・小型仏壇は、置き場所の例（リビングの棚の上、幅◯cmの家具の上など）と寸法を書きます。
  4. 配達・据え付け、古い仏壇の引き取りの料金を書きます。引き取りの前にお寺に相談する人が多い場合は、「お寺へのご相談はお客様からお願いしています」のように、店がすることとしないことを書きます。

修理・追加彫刻・保証を、料金と日数で書く

お墓と仏壇は、買ったあとの相談も多い商品です。追加の彫刻、墓石のクリーニング、傾きや目地の補修、仏壇の洗浄（お洗濯）や修復などを、料金と日数で書いておくと、「◯◯市 墓石 修理」のような質問にもAIが答えやすくなります。

  1. 追加彫刻：1名あたりの料金、霊園で彫るか持ち帰って彫るか、日数。
  2. クリーニング・補修：1基あたりの料金の例、作業前の写真と作業後の報告の有無。
  3. 保証：何年、何が対象か（石の割れ、目地、基礎の沈み など）、地震などの災害のときの扱い。「永久保証」のような書き方より、条件を書きます。
  4. 仏壇の修復：洗浄・塗り直し・金箔の押し直しの料金の目安と、見積もりの方法（写真か、お店へ持ち込みか、出張か）。

店舗の情報とGoogleビジネスプロフィールをそろえる

石材店と仏壇店には、展示場やショールームを持つ店が多いので、住所・営業時間・定休日、駐車場、展示している墓石や仏壇の数を、サイトとGoogleビジネスプロフィールで同じにします。Googleのガイドラインでは、ビジネス名に地域名やサービス名を足すことは認められていません。Google：ビジネス情報のガイドライン。お盆・お彼岸・年末年始の営業も、決まったら早めに両方に書きます。くわしくは営業時間と休業日のAI検索対策をご覧ください。

  1. 石材店と仏壇店を両方している場合は、会社の情報は1つにまとめ、墓石のページと仏壇のページを分けます。
  2. 展示場が複数ある場合は、展示場ごとのページを作ります。複数店舗のAI検索対策
  3. ネットで仏壇・仏具を売っている場合は、送料・返品の条件を商品のページに書きます。ネットショップのAI検索対策

構造化データ：仏壇や墓石の専用の型はない。Store＋Service

schema.orgには、仏壇店や石材店のための専用の型はありません（schema-dts 2.1.0で確認、2026年11月26日）。Cemeteryは墓地という「場所」を表す型で、お店の型ではありません。店はStore（または LocalBusiness）で出し、墓石の建立・墓じまい・追加彫刻・仏壇の修復などを Service と Offer で、対応エリアを areaServed で書きます。Store の下には HomeGoodsStore（生活用品の店）や FurnitureStore（家具店）もありますが、仏壇店にぴったり合うものではないので、迷ったら Store で十分です。

WordPressの石材店・仏壇店のサイトでの設定手順

  1. WordPress.orgからNurevo AEO（無料）をインストールして有効化します。Yoast SEO・Rank Math・All in One SEO・SEO SIMPLE PACK・VK All in One Expansion Unitなどはそのまま使えます（構造化データは重複しません）。
  2. 初回の設定ウィザードで「小売店」を選びます。業種（schema.org型）は Store になります。別の型にしたい場合は、設定画面の「業種（schema.org型）」に型の名前を入力すると、その型で出力されます。
  3. 店名・住所・電話番号・営業時間を、Googleビジネスプロフィールと同じ表記で入れます。
  4. 墓石の建立・リフォーム・墓じまい・追加彫刻・クリーニング・仏壇の修復などを「サービス」に登録します（最大20件）。名前・料金・予約や問い合わせのURL・説明を入れ、説明に「含まれるもの・含まれないもの」を書きます。サービスは構造化データ（Service）とllms.txtに載ります。
  5. 対応エリア（areaServed）の入力欄はないので、構造化データにも入れたい場合は、下の webmcp_canary_business_node フィルターで足します。Yoast SEOなどが有効な場合は、そのプラグインがすでに出している値が優先されます。
  6. 墓じまいの手続き・工事できる霊園・仏壇の引き取り・保証の答えをよくある質問に入力し、Nurevo FAQブロック（または[nurevo_faq]ショートコード）を料金ページに置きます。書き方はFAQページのAI検索対策をご覧ください。
  7. /llms.txt を開き、料金・霊園の一覧・墓じまい・仏壇・よくある質問のページが載っているか確かめます。AEOスコアの画面で診断を実行し、不足を直します。
// テーマの functions.php か、子テーマ・コードスニペットのプラグインに追加します。
add_filter('webmcp_canary_business_node', function (array $node, array $settings) {
    $node['areaServed'] = array(
        array('@type' => 'City', 'name' => '◯◯市'),
        array('@type' => 'City', 'name' => '△△市'),
    );
    return $node;
}, 10, 2);

WordPress以外のサイトでも、確かめる項目は同じです。登録不要の無料チェックにURLを入れると、構造化データ・llms.txt・AIクローラの許可の状態がわかります。

整えたあとは、お客様が聞きそうな質問をAIに投げます。「◯◯市 墓じまい 石材店」「◯◯霊園 墓石 工事」「◯◯市 小さい仏壇 店」のような地域＋サービスの質問で名前が出るかに加えて、店の名前を入れて「墓じまいの料金は？」「手続きもしてくれる？」「古い仏壇を引き取ってくれる？」と聞き、答えがサイトの事実と合っているかを見ます。霊園の使用料が店の料金として答えられていないか、やめたサービスが出ていないかも確かめます。

AIの回答は回ごとに変わるので、同じ質問を期間をあけて何度か確かめ、結果を記録します。Nurevo AEOでは、Free・Standardプランでも月に1回、業種と地域から作った3つの質問（店の名前は含めません）をPerplexityに投げ、回答に名前やサイトが出たかを記録します。Proプラン（月14,800円〜）では、ベータ版のAI登場率の計測で、競合との比較と推移を見られます（現在はPerplexity）。どちらも回答の一部を見本として調べるもので、すべての回答を見ているわけではありません。くわしくはAIでの登場率の測り方をご覧ください。

よくある質問

石材店のAI検索対策は、何から始めればいいですか？

まず、墓石の料金を石・彫刻・基礎・据え付けに分けた税込みの総額で書き、霊園に払うお金と分けます。次に、工事の実績がある霊園の名前と、墓じまいで店がする工事・しない手続きを書きます。そのうえで、Googleビジネスプロフィールとそろえ、構造化データとllms.txtで出します。

墓石の価格をサイトに載せると不利になりませんか？

価格を載せると紹介されにくくなる、という公式の情報はありません。総額の例と内訳が書かれていれば、AIは「何が含まれていくらか」を条件つきで答えられます。区画の大きさや石で変わる場合は、条件と例を書きます。

墓じまいの手続きも、石材店のサイトに書くべきですか？

店が代わりにする作業と、お客様や他の人がする手続き（改葬許可の申請、お寺への依頼）を分けて書くことをおすすめします。手続きの細かい要件は自治体によって違うので、自治体の案内へのリンクを付けます。

仏壇の構造化データの型は何にすればいいですか？

schema.orgに仏壇店や石材店の専用の型はないので、Store か LocalBusiness にし、墓石の工事や仏壇の修復を Service で表します。Cemetery は墓地という場所の型で、お店には使いません。

海外で作った仏壇は、正直に書くと売れにくくなりませんか？

製造地を書くことでAIに紹介されにくくなる、という公式の情報はありません。どの工程をどこでしたかを事実どおりに書くと、AIは「国産を探している人」「価格を抑えたい人」それぞれに条件つきで答えられます。産地名や伝統的工芸品と誤解される書き方は避けてください。
