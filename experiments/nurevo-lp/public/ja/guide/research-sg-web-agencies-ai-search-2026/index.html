シンガポールのWeb制作会社の自社サイト641件に見るAI検索への対応（2026年11月）

シンガポールのWeb制作会社の自社サイト641件のトップページ・robots.txt・llms.txt を調べたところ、llms.txt があったのは38.8%（249件）、AI検索に関わる6項目をすべて満たしたのは32.4%で、どちらも到達100件以上の17か国の中で最も高い値でした（日本は13.4%・10.4%）。robots.txt でAIボットに言及しているサイトも22.0%と17か国で最も多い一方、実際にAIボットをブロックしていたのは5.7%（31件）で、海外の他の国と統計的な差は見られませんでした。

公開：2026年11月24日。データ：2026年11月12日集計。調査・執筆：Nurevo AEO（Bestie.合同会社）。Nurevo はAI検索対策（AEO）のツールと WordPress プラグインを提供しており、この分野に利害があります。国別レポートの7本目で、アジアの国ではインドに続く2本目です（これまでに米国・英国・オーストラリア・カナダ・フランス）。英語版もあります。

要点

  1. シンガポールのWeb制作会社の自社サイト641件では、llms.txt があったのが38.8%（249件）、AI検索に関わる6項目をすべて満たしたのが32.4%で、どちらも到達100件以上の17か国で最も高い値でした。インド（36.6%・29.9%）とは統計的な差が見られず（p=0.33・p=0.23）、オーストラリア（24.3%・20.8%）・米国（23.1%・18.9%）・日本（13.4%・10.4%）より高い値です（いずれも p<0.001）。
  2. WordPress のサイトどうしで比べても、シンガポールの llms.txt は46.3%で、シンガポール以外の海外の WordPress サイト（32.4%）やインドの WordPress サイト（39.5%）より高い値でした（p<0.001・p=0.007）。
  3. robots.txt があるサイト546件のうち、AIボットの名前を挙げていたのは22.0%（120件）で17か国で最も多く、そのうち86件はどのAIボットもブロックしていませんでした。実際にAIボットをブロックしていたのは5.7%（31件）で、インド（5.8%）・米国（4.3%）・シンガポール以外の海外（5.1%）と統計的な差はなく、日本（1.3%）より高い値です。GPTBot をブロックしていた28件のうち27件は OAI-SearchBot を許可していました。

調査概要

  1. 対象：Web制作会社の自社サイト。当社の収集リストで国がシンガポールとなっている制作会社サイト974件のうち、トップページに到達できた641件です。一般企業のサイト全体ではありません。比較には同じ調査のインド（1,554件）・フィリピン（241件）・オーストラリア（1,719件）・米国（4,472件）・日本（2,486件）・シンガポール以外の海外（12,711件）と、アジア太平洋で到達30件以上の国を使いました。
  2. 取得したもの：各サイトのトップページ、/robots.txt、/llms.txt、/llms-full.txt を1回ずつ（User-Agent：NurevoSurvey/1.0）。2026年11月上旬〜12日に取得し、11月12日に集計しました。
  3. 判定方法：llms.txt は、ステータス200で中身がHTMLではなく20文字を超えるテキストを「あり」としました。JSON-LD はトップページにあるかどうか、「壊れている」は JSON として読み込めないブロックが1つ以上あるもの。Organization系は @type に Organization・LocalBusiness・Corporation・ProfessionalService を含むもの。WordPress はトップページのHTMLに wp-content/・wp-includes/、または generator の WordPress 表記があるもの。SEOプラグインはトップページのHTMLの文字列で判定しました。
  4. AIボットのブロック：robots.txt で、各ボットに当てはまるグループの規則がトップページ（/）を Disallow にするか（最長一致）で判定しました。分母は robots.txt があるサイトです。「AIボットをブロック」は GPTBot・ClaudeBot・PerplexityBot・Google-Extended・CCBot・OAI-SearchBot のどれかをブロックしているもの。「AIボットに言及」は、Googlebot・Bingbot 以外の調査対象のボット名を User-agent 行に書いているものです。
  5. 「6項目」は、(1) llms.txt がある、(2) JSON-LD がある、(3) Organization または LocalBusiness の型がある、(4) robots.txt があり GPTBot・ClaudeBot・PerplexityBot・OAI-SearchBot のどれもブロックしていない、(5) meta description がある、(6) canonical がある、のうち当てはまる数（0〜6）です。この調査のための単純な数で、Nurevo の0〜100点のスコアとは別物です。
  6. HTTP 202：シンガポールでトップページがステータス202を返したのは47件（到達件数の7.3%）で、オーストラリア（14.5%）・米国（15.0%）・シンガポール以外の海外（11.3%）より少なく、インド（1.5%）より多い割合でした。202のページはほとんどの項目が「なし」になるため、国どうしの比較に影響します。ステータス200のサイト（594件）だけで見ると、シンガポールは llms.txt 41.9%・6項目すべて35.0%・平均4.70で、インドの200のサイト（37.2%・30.3%）よりやや高く（p=0.043・p=0.036）、米国の200のサイト（27.2%・22.3%）より高い値でした（p<0.001）。
  7. 統計：シンガポールと他の地域の差はカイ二乗検定で、件数が小さいAIボットのブロックや JSON-LD の壊れ率はフィッシャーの正確検定で確かめました。30件未満の区分は載せていません。

ブロックと言及の中身（事実）

  1. GPTBot をブロックしていた28件のうち27件は、OAI-SearchBot をブロックしていませんでした。
  2. 上の11種のAIボットのどれかをブロックしていた34件のうち25件は、GPTBot・ClaudeBot・anthropic-ai・Google-Extended・CCBot・Bytespider・Applebot-Extended の7つをまとめてブロックする同じ組み合わせでした。Bytespider だけが3件、CCBot と Bytespider が2件、CCBot だけが1件、そのほかの組み合わせが3件です。検索用の OAI-SearchBot・Claude-SearchBot・PerplexityBot までブロックしていたのは、そのうちの1件でした。
  3. robots.txt でAIボットの名前を挙げていたのは120件（robots.txt があるサイトの22.0%）で、シンガポール以外の海外（11.2%）・インド（15.0%）・米国（8.8%）・日本（2.5%）より多い割合でした（いずれも p<0.001）。そのうち86件（robots.txt があるサイトの15.8%）は、名前を挙げながらどのAIボットもトップページをブロックしていませんでした（シンガポール以外の海外は5.8%）。
  4. 名前を挙げてもブロックしていない86件のうち62件（72.1%）には llms.txt もありました。AIボットの名前がない robots.txt のサイトでは40.4%です（p<0.001）。この調査では、robots.txt や llms.txt をプラグインで作ったのか手で書いたのかは見ていません。
  5. AIボットのどれかをブロックしていた34件のうち11件には llms.txt もありました。
  6. robots.txt に Sitemap の行があったのは、robots.txt があるサイトの92.1%でした。

WordPress とSEOプラグイン

限界

  1. 対象はWeb制作会社の自社サイトで、一般企業のサイト全体ではありません。国は当社の収集リストの記載によるもので、シンガポールの制作会社全体を代表する標本ではありません。シンガポールに拠点を置く地域統括の会社や、他国の会社のシンガポール向けサイトが含まれている可能性があります。ボット別の件数やアジア太平洋の小さい国の値は小さい数です。
  2. トップページだけを見ています。robots.txt はトップページ（/）に対する判定で、一部のディレクトリだけのブロックや、ファイアウォール・CDN によるブロックは数えていません。llms.txt は有無と行数だけを見て、中身の質は見ていません。
  3. 各サイト1回の取得で、到達できなかったサイト（333件）は除いています。HTTP 202 を返した47件は、実際のトップページとは違うページを見ている可能性があります。
  4. SEOプラグインはHTMLの文字列による判定で、痕跡を消している場合や複数入っている場合は正しく分けられません。JavaScript で後から出す構造化データは数えていません。
  5. 今回の数字は2026年11月12日の集計です。週ごとに取り直すため、次の集計では値が変わることがあります。

読み方（意見）

ここからは当社の解釈です。シンガポールの制作会社サイトは、基本の項目のそろい方はインド・フィリピンと近く、llms.txt と「6項目すべて」で17か国の先頭にいました。WordPress のサイトどうしでも差があったので、プラグインの普及だけでなく、新しい仕組みを自社サイトで先に試す傾向がある可能性もありますが、この調査は原因を確かめていません。robots.txt でAIボットの名前を挙げながらブロックしないサイトが多いことは、AIボットの扱いを意識して書いているサイトが多いことを示しているのかもしれません。どのボットをブロックするかは各サイトの判断です。これらの項目がそろっていても、AIの回答に必ず出るわけではありません（別の調査では、サイト側の項目と回答への登場に関係は見られませんでした）。
