Web制作会社の自社サイトを、AI検索で選ばれる形にする手順

ChatGPTやPerplexityに「〇〇市でおすすめのホームページ制作会社は？」と聞くと、AIはウェブを検索し、制作会社のサイトや比較サイト・口コミなど複数のページを読んで答えをまとめます。自社が候補に入るには、「どこで・何を・いくらで・どんな実績で」作るのかを、自社サイトにAIが読める形で書き、外部の掲載情報とそろえ、決めた質問で定期的に確かめるのが近道です。AIの回答は日や回によって変わるため、必ず出る方法はありませんが、事実が読めない会社は候補に入りにくくなります。

作成日：2026年11月12日（JST）。Google・OpenAI・Perplexityの仕様は各社の公式ドキュメントに基づきます。仕様は変わることがあるため、最新の情報もあわせてご確認ください。

この記事は、お客様のAI検索対策ではなく、制作会社自身の集客のための記事です。お客様向けのサービス設計は制作会社がAI検索対策を月額サービスにする方法にまとめています。

AIは「おすすめの制作会社」をどうやって答えているか

ChatGPTの検索は OAI-SearchBot というクローラが集めた情報を使い、OpenAIは OAI-SearchBot を拒否したサイトはChatGPTの検索回答に表示されないとしています（OpenAI：クローラの概要）。Perplexityも PerplexityBot の許可を推奨しています（Perplexity：クローラ）。GoogleのAI OverviewsやAI Modeについて、Googleは追加の要件や特別な最適化はなく、通常のSEOのベストプラクティスが当てはまると説明しています（Google検索セントラル：AI機能とウェブサイト）。

つまり、AIは「検索して読めたページ」から答えを組み立てます。自社サイトはその材料の1つにすぎず、比較サイト・ポータル・口コミ・SNSなど自社の外のページも読まれます。制作会社ができるのは、(1) 自社サイトに事実を読める形で置く、(2) 外部の情報を同じ事実にそろえる、(3) 実際の回答を測る、の3つです。

制作会社サイトの現状：2,357件の調査から

Nurevoが2026年11月に国内Web制作会社の自社サイト2,357件のトップページを調べたところ、基本的なSEO設定はほぼ整っていた一方、AIが事業の事実を読み取るための項目は少数でした（調査レポート）。

AIを拒否している会社はほとんどないので、多くの制作会社にとっての課題は「読まれないこと」ではなく「読まれても、どこで何をいくらで作る会社かが伝わらないこと」です。なお、この調査はトップページだけを見ており、下層ページの状態は含みません。

AIに聞かれる質問と、自社サイトに置くべき答え

発注を考えている人がAIに聞く質問は、たいてい条件付きです。質問の型ごとに、AIが答えるために必要な事実と、それを置く場所を整理しました。

質問の例AIが必要とする事実置く場所
〇〇市でおすすめのホームページ制作会社は？所在地、対応エリア、オンラインでの打ち合わせの可否会社概要、フッター、構造化データ（address・areaServed）
飲食店のサイトが得意な制作会社は？得意な業種と、その業種の制作実績業種別の実績ページ、サービスページ
30万円くらいでサイトを作れる会社は？料金の目安と、その料金に含まれる作業料金ページ（税込・税別を明記）
WordPressで作って保守まで頼める会社は？使うCMS、保守プランの内容と月額サービスページ、保守プランのページ
急ぎで1か月以内に公開できる？制作期間の目安、進め方制作の流れのページ、FAQ
小さな会社でも相談できる？対象とする顧客の規模、最低発注額の有無サービスページ、FAQ

どの質問にも共通するのは、「ご相談ください」「柔軟に対応します」ではAIが答えを作れないことです。数字や地名、業種名をはっきり書くほど、条件付きの質問に当てはまる会社として読まれやすくなります。

手順1：会社の事実を、ページの文章として書く

  1. 会社概要：社名（屋号）、所在地、対応エリア（市区町村・都道府県名で）、設立年、人数、代表者、電話・メール、営業時間。対応エリアが全国ならそう書き、来社が必要かどうかも書きます。
  2. サービスと料金：制作プランごとに料金の目安、含まれる作業（ページ数、デザイン、スマホ対応、CMS、写真撮影の有無など）、制作期間の目安を表にします。「〇〇円〜」だけでなく、よくある構成でいくらになるかの例があるとAIが答えやすくなります。
  3. 実績：業種、地域、作ったもの（サイトの種類、ページ数）、担当した範囲、公開年を1件ずつ書きます。お客様の名前やURLを出すときは必ず許可を取り、許可がなければ「〇〇市の歯科医院（20ページ、WordPress）」のように書きます。
  4. 得意分野：得意な業種・規模・CMSを、実績へのリンク付きで書きます。実績のない業種を「得意」と書かないでください。AIが外部情報と食い違いを見つけると、かえって信頼されにくくなります。
  5. よくある質問：問い合わせで実際に聞かれる質問（料金、期間、保守、修正回数、契約期間、ドメインやサーバーの名義）に、短く具体的に答えます。

手順2：構造化データで「どこの・何の会社か」を出す

構造化データ（schema.orgのJSON-LD）は、ページの文章と同じ事実を機械が読みやすい形で出すものです。制作会社の場合は、Organization を基本にし、来客を受ける事務所があるなら LocalBusiness も使えます。schema.org には ProfessionalService という型もありますが、schema.orgはこの型を地域の事業者向けの汎用の型としては非推奨にしています（schema.org：ProfessionalService）。

プロパティ入れる内容メモ
name / url / logo社名、サイトのURL、ロゴ多くのSEOプラグインが無料版でも出している
address所在地（PostalAddress）調査では16.3%のサイトにしかなかった
telephone / email問い合わせ先ページに表示しているものと同じにする
areaServed対応エリア（都道府県名・市区町村名など）schema.org：areaServed
sameAs公式SNS、Googleビジネスプロフィールなど自社の外のプロフィール外部の情報と同じ会社だと結びつける
makesOffer / hasOfferCatalog制作・保守などのサービス料金ページの内容と一致させる

WordPressでは、Yoast SEO・Rank Math・All in One SEO などの無料版は、名前・URL・ロゴの Organization は出しても、住所や電話番号までは出さないことが多いです。足りない分だけを足し、同じ会社を2つ出さないようにします。手順はSEOプラグインに店舗の構造化データを足す方法を参照してください。Googleも、構造化データの内容をページに見えている内容と一致させることを求めています（Google：LocalBusinessの構造化データ）。

手順3：AIのクローラを止めていないか確かめる

  1. robots.txt：OAI-SearchBot・PerplexityBot・Googlebot をブロックしていないか確かめます。調査ではブロックしていた制作会社は1.3%でしたが、ステージング環境の設定が本番に残っている、といった事故は自社サイトでも起こります。
  2. セキュリティ系プラグイン・WAF・CDNのボット対策：robots.txt以外の仕組みでAIのクローラを止めていないか、設定画面で確かめます。
  3. 学習用クローラは別の判断：GPTBotのようなAIモデルの学習用のクローラを許可するかどうかは、AI検索への表示とは別の問題です。自社の方針として決めましょう。

手順4：llms.txt に会社の要約と主要ページを置く

llms.txt は、サイトの概要と主要なページをAI向けにまとめたテキストファイルです（/llms.txt）。会社の1行説明、対応エリア、サービスと料金ページ、業種別の実績ページ、FAQ、問い合わせページを並べます。調査では設置していた制作会社は13.6%でした。

ただし、Googleは自社のAI機能のために新しいAI向けファイルは不要としており、llms.txt を置けばAIに出るという保証はありません。補助として扱い、本文と構造化データを先に整えてください。書き方はllms.txtの書き方にまとめています。

手順5：自社の外の情報をそろえる

AIは自社サイト以外のページも読むため、外部の掲載情報が古いと、古い住所や終了したサービスが答えに混ざります。社名の表記、所在地、電話番号、対応エリア、主なサービスを、次の場所で同じにします。

  1. Googleビジネスプロフィール（事務所がある場合）
  2. 制作会社のポータル・比較サイト・マッチングサービスの掲載ページ
  3. 公式SNSのプロフィール、商工会議所や業界団体の会員ページ
  4. 求人サイトの会社情報、プレスリリース

口コミや比較記事を自分で用意したり、第三者を装って書かせたりするのはやめましょう。日本では2023年10月1日からステルスマーケティングが景品表示法の違反となり、事業者が第三者に依頼・指示した投稿はその事業者の広告として扱われます（消費者庁：ステルスマーケティング）。お客様に感想をお願いするのは構いませんが、内容を指示したり見返りを条件にしたりせず、関係を明示してください。

手順6：決めた質問で、月に1回測る

最後に、見込み客が実際に聞きそうな質問を10問ほど決め、毎月同じ条件でChatGPTやPerplexityに聞いて、自社が出たか（言及）、自社サイトが出典になったか（引用）、どのページが出典になったかを記録します。AIの回答は回によって変わるため、1問を何回か聞き、1回の結果で判断しないのがコツです。測り方の詳細はAIでの登場率の測り方にまとめています。

出典に比較サイトばかりが出るなら外部の掲載情報の見直し、競合だけが出るなら対応エリアや料金など条件の書き方の見直し、というように、結果を手順1〜5のどれに戻すかを決めると改善につながります。

チェックリスト

  1. 会社概要に、所在地・対応エリア・連絡先を文章で書いた
  2. 料金の目安と含まれる作業、制作期間の目安を書いた
  3. 業種・地域・範囲がわかる実績を、許可を取って載せた
  4. Organization（必要なら LocalBusiness）の構造化データに、住所・電話・対応エリアを入れ、ページの表示と一致させた
  5. SEOプラグインやテーマと、同じ会社を二重に出していない
  6. robots.txt・WAF・CDNで OAI-SearchBot・PerplexityBot・Googlebot を止めていない
  7. llms.txt に会社の要約と主要ページを並べた
  8. 外部の掲載情報（Googleビジネスプロフィール、ポータル、SNS）を同じ事実にそろえた
  9. 決めた質問を月1回、同じ条件で記録している

よくある質問

比較サイトに有料で掲載すれば、AIに出やすくなりますか？

わかりません。AIが比較サイトを出典にすることはありますが、どのサイトを読むかは質問や回によって変わり、掲載の効果を確かめた一次情報は見つかりませんでした。掲載するなら、自社サイトと同じ事実が書かれているかを必ず確認してください。

料金を公開しないと不利ですか？

「30万円くらいで」のような予算付きの質問には、料金がわからない会社は当てはめにくくなります。個別見積もりの場合も、よくある構成での目安や、料金に含まれる作業を書いておくと、AIも人も判断しやすくなります。

対応エリアを広く書けば、多くの地域で出ますか？

実際に対応していない地域まで書くのはおすすめしません。実績や外部の情報と食い違うと、正しく読まれない原因になります。全国対応ならそう書き、実績のある地域を具体的に示すほうが確実です。

ブログ記事を量産すればAIに出ますか？

量よりも、見込み客の質問に具体的に答えているかが大切です。料金・期間・保守・実績のように、発注前に聞かれる質問に事実で答えるページを先に整えましょう。

効果はどれくらいで出ますか？

決まった期間はありません。AIが新しい情報を読むまでの時間も、回答の変わり方もサービスごとに違います。月1回、同じ質問で記録し、推移で判断してください。
