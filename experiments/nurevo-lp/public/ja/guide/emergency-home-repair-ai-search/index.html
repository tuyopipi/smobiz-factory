水道修理・鍵開けなど駆けつけ修理のAI検索対策：料金の書き方・出張費・指定業者の番号をAIに正しく読ませる手順

水道修理・トイレのつまり・鍵開け・害虫駆除のような駆けつけ修理の業者のAI検索対策は、「◯円～」の安さを見せることではなく、出張費と見積もり費がかかるか、キャンセルはいくらか、作業の前に税込の総額を書面で示すか、市の指定を受けているか（指定番号と有効期間）を、ページ本文に条件まで書いて答えることです。この業種は国民生活センターや自治体が高額請求の注意を繰り返し出していて、AIもそれを読んで答えます。注意喚起に当てはまらないことを事実で示せるページが、AIにも人にも選ばれやすくなります。

作成日：2026年11月21日（JST）。国民生活センター、消費者委員会、埼玉県・大阪府・千葉市、各市の上下水道局のページと、上位の記事はこの日に読みました。schema.org の型は同じ日に schema-dts 2.1.0 で確認しました。

AIの回答は日や聞き方によって変わります。この記事の対策は、AIが業者の事実を正しく読める状態をつくるもので、AIの回答に必ず表示される・順位が上がることを保証するものではありません。また、法的な助言ではありません。表示や契約の扱いは、管轄の消費生活センターや弁護士に確かめてください。

困っている人はAIに何を聞くか

駆けつけ修理の相談は、急いでいて、しかもだまされたくない、という状況で来ます。「夜10時にトイレが詰まった。◯◯市で今から来てくれる業者は？」「鍵をなくして家に入れない。鍵開けはいくらぐらい？」「水道屋に頼むとき、ぼったくりを避けるには？」「ベランダに蜂の巣。駆除を頼むと高い？」といった質問です。

AIはこうした質問に、業者の名前を挙げるだけでなく、注意点を添えて答えることがよくあります。注意点の材料は、国民生活センターや自治体の注意喚起です。だから業者のサイトに、出張費・見積もり費・キャンセル料・作業前の総額提示・支払い方法・指定番号が書かれていないと、AIは一般論の注意だけを返し、業者を推す根拠を持てません。

なぜこの業種は「料金の書き方」がいちばん大事か

国民生活センターは2021年10月7日、トイレ修理・水漏れ・鍵・害虫駆除・給湯器などの「暮らしのレスキューサービス」の相談が増えていると発表しました。全国の相談は2016年度の2,437件から2020年度の5,882件に増え、ネット広告などの電子広告が関わる割合は19.2%から41.1%になりました。「950円～」の広告を見て頼んだら数十万円を請求された、という事例も載っています。国民生活センター（2021年10月7日）

消費者委員会の2025年8月4日の意見では、電子広告が関わる割合は2014年度の約15%から2024年度の約55%になっています。同じ資料のアンケート（700人、2025年3月）では、業者を選んだ決め手は「広告で安い金額を提示していたから」が約39%、「見積り無料との記載があったから」が36%、「検索結果の一番上に表示されていたから」が33%でした。トラブルの内容は「修理はされたが高額な請求をされた」が37%、「見積もり無料と書かれていたが実際は有料だった」が24%です。消費者委員会：レスキューサービスに関する消費者問題についての意見（PDF）

つまり、困った人が最初に見る「安さ」と「見積もり無料」の表示そのものが、トラブルの入口になってきました。AIはこうした公的な資料も読むので、下限の金額だけを大きく出すページは、AIにとっても推しにくい業者に見えます。逆に、総額の決まり方と、見積もりだけで断れることを書いたページは、注意喚起への答えになります。

行政処分で問題になった表示と、代わりの書き方

埼玉県は、水回り修繕の業者に景品表示法の措置命令を出しています（2024年2月8日付と2025年3月5日付。どちらも同じ日に特定商取引法の行政処分もあり）。問題とされたのは、実際より安く見える料金の表示と、根拠のない実績の表示でした。埼玉県（2024年2月9日発表）・埼玉県（2025年3月6日発表）

千葉市も、「見積もり無料」の広告で見てもらったら見積もりの費用を請求された、解錠「2,000円～」の広告で約10万円になった、害虫駆除で「追加料金なし」の広告から約7万円を請求された、といった相談を紹介しています。千葉市（2026年10月7日更新）。自社の広告や紹介サイトの掲載文にこうした表現が残っていないかも、サイトと一緒に見直します。

料金のページに書く7つのこと

  1. 出張費：かかるか、いくらか、エリアや時間帯で変わるか。「市内は無料、◯◯町は◯円」のように地名で書く。
  2. 見積もり費：現地で原因を調べて見積書を出すまでにかかる費用。「見積もりだけで断っても無料」なら、そう書く。
  3. キャンセル料：出発後・到着後・見積もり後のそれぞれでいくらか。
  4. 作業前の総額提示：作業内容と税込の総額を書いた見積書を渡し、了承をもらうまで作業しないこと。作業中に追加が必要になったら、作業を止めて改めて金額を示すこと。
  5. 作業別の総額の例：「トイレのつまり（ラバーカップなどで解消、30分程度）：税込◯円」のように、作業の中身・時間・部品の有無を条件として書き、作成した年月を添える。例は実際の請求から作り、作った数字を書かない。
  6. 夜間・休日の割増：時間帯と金額か割合。
  7. 支払い方法と書面：現金以外の方法、領収書・作業報告書を渡すこと。

大阪府は、呼ぶときに「見積もりのために来てほしい」とはっきり伝え、見積もりに料金がかかるか、キャンセル料がかかるかを前もって確かめるよう案内しています。大阪府 お問合せ集（2026年4月1日更新）。困った人が確かめたいことを先にページに書いておけば、AIも「この業者は見積もりだけなら無料と明記している」のように答えられます。料金の書き方の全体は料金ページをAIに正しく読ませる書き方もご覧ください。

訪問販売とクーリング・オフの案内

業者が消費者の家に行って契約するのは、特定商取引法の「訪問販売」に当たります。法律で決められた書面を受け取ってから8日以内ならクーリング・オフできます。消費者が自分で呼んだ場合は認められないことがありますが、大阪府は、広告の金額と実際の請求に明らかに大きな開きがある場合や、頼んだ修理と違う契約を勧められた場合はクーリング・オフできる可能性があると説明しています。大阪府

業者のサイトには、法律の解説を長く書く必要はありません。「契約のときに、特定商取引法に基づく書面をお渡しします」「クーリング・オフの扱いは書面に書いてあります」と、自社がしていることを短く書きます。どの場合に当たるかの判断を自社のサイトで言い切ることは避け、消費生活センター（消費者ホットライン188）を案内しておくと、AIが「業者自身が相談先を示している」と読める材料になります。

指定給水装置工事事業者の番号と有効期間を書く

水道の給水管や蛇口などの給水装置の工事は、各市の上下水道局が指定した「指定給水装置工事事業者」が行います。静岡市は、指定を受けていない者が工事をすることは条例で禁止されているとし、柏市は、指定を受けていない業者を使うと高額な請求や施工不良のトラブルにあうおそれがあると注意しています。静岡市（2026年3月10日更新）・柏市（2025年12月17日更新）。指定の要件には、給水装置工事主任技術者がいることなどがあり、市は指定業者の一覧を公開しています。福岡市（2026年11月1日更新）

指定には有効期間があります。2019年10月1日に施行された改正水道法で、指定は5年ごとの更新制になりました。千葉県・日本水道協会（PDF）

AIは、市が公開する指定業者の一覧と業者のサイトを照らし合わせられます。会社概要と料金のページに「◯◯市指定給水装置工事事業者　指定番号 第◯号（有効期間 ◯年◯月まで）」と、市ごとに文字で書きます。指定を受けていない市町村には、受けていないことと、その場合にできる作業・できない作業の自社の扱いを書きます。どの作業に指定が必要かは市によって案内が違うので、市の上下水道局で確かめた範囲だけを書きます。鍵や害虫駆除の業者も、持っている登録や団体の会員資格があれば、名前・番号・有効期間を同じように書き、持っていないものは書きません。

対応エリアと到着までの目安

対応エリアは地図の画像だけにせず、市区町村の名前を文字で書きます。到着までの目安は「最短15分」のような一番よい値だけではなく、「昼間の市内でおおむね30〜60分（◯年◯月〜◯月の実績）」のように、条件と根拠を添えます。混む時間帯や天気で遅れることも書いておきます。

24時間受付と24時間出動は違います。電話を受けるだけの時間帯と、実際に人が行ける時間帯を分けて書きます。営業時間の構造化データの書き方は営業時間・定休日・臨時休業をAIに正しく読ませる書き方にまとめています。

構造化データ：Plumber・Locksmith と見積もりのサービス

schema.org には、水道修理の Plumber、鍵の Locksmith、電気工事の Electrician、空調の HVACBusiness があり、どれも住宅・建設関係の HomeAndConstructionBusiness の下にあります。害虫駆除のための型はないので、HomeAndConstructionBusiness か LocalBusiness にして、駆除の作業を Service で表します。

Nurevo AEOで業種を Plumber にし、現地調査と見積もりをサービスに登録すると、次のような形になります（値は例です）。

Offer に 0 を入れてよいのは、本当に費用がかからない場合だけです。エリアや時間帯で出張費が変わるなら、サービスの名前と説明にその条件を書くか、金額を入れずに本文で説明します。修理の料金は作業で変わるので、構造化データには入れず、本文の総額の例に書きます。指定の情報は、下のフィルターで hasCredential として足せます。

WordPressの修理業者サイトでの設定手順

  1. WordPress.orgからNurevo AEO（無料）をインストールして有効化します。Yoast SEO・Rank Math・All in One SEO・Slim SEOはそのまま使えます。0.9.1からはSEO SIMPLE PACKやVK All in One Expansion Unitとも、構造化データを重複させずに併用できます。
  2. 初回の設定ウィザードで「その他」を選び、設定画面の「業種（schema.org型）」に Plumber（鍵なら Locksmith、電気工事なら Electrician、害虫駆除なら HomeAndConstructionBusiness）と入力します。
  3. 会社名・住所・電話番号・受付時間・説明を確認します。説明には、対応する作業、対応エリア、作業前に総額を示すことを短く書きます。
  4. サービスに、現地調査と見積もり、主な作業（トイレのつまり、蛇口の水漏れ、解錠など）を1つずつ登録します（最大20件）。料金の欄は入れた文字がそのまま price になるので、数字だけを入れます。作業で金額が変わるものは料金を空にして、説明に条件を書きます。予約ページのURLを入れると、予約の操作（ReserveAction）としても出力され、llms.txtにも1行ずつ載ります。
  5. 対応エリアと指定番号は、開発者向けの webmcp_canary_business_node フィルターで足します（下のコード。子テーマの functions.php かコードスニペットのプラグインに）。SEOプラグインを使っている場合は、そのプラグインの会社のノードにまとめられ、プラグイン側にすでにある値が優先されます。
  6. よく聞かれる質問（出張費、見積もりだけで断ったときの費用、キャンセル料、作業前の総額提示、夜間の割増、支払い方法、指定番号、クーリング・オフ）をFAQに入れ、Nurevo FAQブロック（または[nurevo_faq]ショートコード）を置きます。
  7. /llms.txt を開き、料金・対応エリア・会社概要・保証のページが載っているか確かめます。終わったキャンペーンのページは、Nurevo AEOパネルでllms.txtに載せない設定にできます。AEOスコアの画面で診断を実行し、不足を直します。
// 対応エリアと指定の情報を業者のノードに足す（値は本文と同じにする）
add_filter('webmcp_canary_business_node', function (array $node, array $settings) {
    $node['areaServed'] = array(
        array('@type' => 'AdministrativeArea', 'name' => '◯◯県◯◯市'),
        array('@type' => 'AdministrativeArea', 'name' => '◯◯県◯◯町'),
    );
    $node['hasCredential'] = array(
        '@type' => 'EducationalOccupationalCredential',
        'name' => '◯◯市指定給水装置工事事業者（指定番号 第◯◯号）',
        'recognizedBy' => array('@type' => 'GovernmentOrganization', 'name' => '◯◯市上下水道局'),
    );
    return $node;
}, 10, 2);

WordPress以外のサイトでも、確かめる項目は同じです。登録不要の無料チェックにURLを入れると、構造化データ・llms.txt・AIクローラの許可の状態を確かめられます。SEOプラグインとの併用はYoast・Rank Math・AIOSEOに店舗情報を追加する方法をご覧ください。

紹介サイト・検索広告・Googleビジネスプロフィールとそろえる

AIは、業者のサイトだけでなく、紹介サイトや比較記事、Googleビジネスプロフィールも読みます。会社名・住所・電話・対応エリア・受付時間・料金の書き方が場所ごとに違うと、どれが正しいか判断できません。掲載先を一覧にして、自社サイトの値に合わせます。とくに、紹介サイトや検索広告の文に「◯円～」「見積もり無料」だけが残っていると、サイトで条件を丁寧に書いても食い違いになります。

消費者委員会の意見は、被害の多くが検索連動型広告から始まっているとして、消費者に「検索結果の上位に表示されているということだけで信用しない」「可能な場合は相見積もりを入手する」よう呼びかけています。消費者委員会（PDF）。相見積もりされることを前提に、比べやすい形で書くのが近道です。

よくある質問

水道修理・鍵開けの業者のAI検索対策は、何から始めればいいですか？

料金のページに、出張費・見積もり費・キャンセル料と、作業前に税込の総額を示すことを書くことからです。次に、指定番号と有効期間、対応エリアを文字で書き、業種を Plumber などにした構造化データと、Googleビジネスプロフィール・紹介サイトの値をそろえます。

「◯円～」と書くのはだめですか？

下限を書くこと自体が禁じられているわけではありませんが、埼玉県の措置命令では、下限の料金を示しながら追加の作業で数万円〜数十万円を請求していた表示が問題とされました。下限を書くなら、その金額で終わる作業の中身を書き、作業別の総額の例を並べてください。

料金を細かく書くと、他社に比べられて不利になりませんか？

比べられることを前提にしたほうが安全です。消費者委員会の資料では、トラブルにあった人の多くが広告の安い金額や「見積り無料」の表示を決め手にしていました。条件まで書いた料金は、AIが注意点と一緒に自社を説明するときの根拠になります。

指定給水装置工事事業者の番号はどこに書けばいいですか？

会社概要と料金のページに、市ごとに「◯◯市指定給水装置工事事業者 指定番号 第◯号（有効期間 ◯年◯月まで）」と文字で書きます。指定は2019年10月1日施行の改正水道法で5年ごとの更新制になったので、更新したら書き直します。

害虫駆除の業者は、構造化データの型を何にすればいいですか？

schema.org に害虫駆除のための型はないので、HomeAndConstructionBusiness か LocalBusiness にして、駆除の作業を害虫ごとに Service で表します。値はページ本文と同じにしてください。

Nurevo AEOは無料で使えますか？

はい。会社の連絡先・受付時間・サービス・FAQの構造化データ、llms.txt、AIクローラ設定、AEOスコアは無料プランで使えます。有料プランは常に最新のルールセット（Standard、月3,000円）と、ベータ版のAI登場率の計測（Pro、月14,800円〜）を追加するものです。Nurevo AEO（WordPress.org）

対策すればChatGPTに必ず推薦されますか？

いいえ。AIの回答は変動し、どのツールや対策でも表示や順位は保証できません。できるのは、AIが業者の事実を正しく読める状態をつくり、どう説明されているかを継続して確かめることです。
