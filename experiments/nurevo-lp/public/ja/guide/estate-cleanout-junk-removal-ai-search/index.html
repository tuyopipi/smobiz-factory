遺品整理・不用品回収のAI検索対策：許可の区分、料金の決め方、買取と処分の違いをAIに正しく読ませる手順

遺品整理・不用品回収の会社のAI検索対策（AEO）で一番大事なのは、AIが「頼んで大丈夫な業者か」「結局いくらか」を答えられる事実を、サイトに文字で書くことです。具体的には、家庭のごみを運ぶための市町村の許可（一般廃棄物収集運搬業）を持っているか、持っていない場合はどの許可業者に運搬を任せるか、積み放題などの量の決め方と追加になる費用、家電4品目の扱い、買取（古物商許可）と処分を分けた書き方、遺品整理なら残す物の仕分けと立ち会いの方法です。そのうえで同じ事実を、Googleビジネスプロフィールと構造化データ（LocalBusiness＋Service）に出します。

作成日：2026年11月27日（JST）。国民生活センター・環境省・自治体・警察のページは、本文に記したリンク先で2026年11月27日に確認しました。この記事は法的な助言ではありません。許可の要件や扱いは市区町村によって違うので、営業する地域の担当の窓口で確かめてください。

AIの回答は日や聞き方によって変わります。この記事の対策は、AIがあなたの会社の事実を正しく読める状態をつくるもので、AIの回答に必ず表示される・順位が上がることを保証するものではありません。

遺品整理・不用品回収でAIに聞かれること

不用品回収と遺品整理は、料金のトラブルや無許可の業者の話題がよく報じられる分野です。そのため、AIに投げられる質問も「安いところ」だけでなく「ちゃんとした業者か」「あとから高くならないか」が多くなります。AIがこうした質問に答えるには、許可・料金の決め方・追加料金の条件が、どこかに文字で書かれている必要があります。

質問の例は、この記事の説明のための例です。実際の質問の頻度を調べたものではありません。
質問の型質問の例AIが答えに必要な事実
許可「◯◯市で家庭の不用品を回収できる許可業者は？」一般廃棄物収集運搬業の許可の市町村名と番号、または運搬を任せる許可業者の名前
総額「軽トラック1台分でいくら？何が別料金？」量の決め方（荷台のどこまでか）、含まれるもの、追加になる費用と金額
家電「冷蔵庫と洗濯機も一緒に持っていける？」家電4品目の扱い、リサイクル料金と運搬料金、家電リサイクル券
買取「まだ使える家具は買い取ってもらえる？」古物商許可の公安委員会名と番号、買取の明細の出し方、処分費との相殺のしかた
遺品整理「実家の片付けで、写真や書類は残してもらえる？」仕分けの方法、貴重品・書類の扱い、立ち会いなしの対応、供養の手配
日程・キャンセル「明日来られる？キャンセル料は？」最短の日程、見積もりの方法（訪問・写真）、キャンセル料の条件

上位の解説記事に足りないこと

2026年11月27日に、日本語と英語で「遺品整理 AI検索対策」「junk removal AI search」などの上位記事を10本読みました。日本語では、uravationの不用品回収・遺品整理の記事（2026年8月28日）が、許可の区分・料金の変動条件・口コミの扱いを公的なリンク付きでくわしく扱っています。ただし、家電リサイクル法には触れておらず、構造化データの例とWordPressでの手順はありません。同じサイトの便利屋の記事も、家庭ごみの回収と買取を分ける考え方は同じですが、遺品整理の具体的な書き方はありません。サングローブの不用品回収の集客の記事（2026年7月更新）は広告・MEO・チラシの話が中心で、AI検索と許可の書き方は扱っていません。神戸新聞NEXTの記事（2026年10月29日）は、AIが比較サイトや予約サイトをよく挙げることを紹介していますが、業者がどうすればいいかは書いていません。

英語では、Textaの不用品回収と遺品の処分（estate liquidation）のページは同じひな形で、「50件以上の口コミ」などの基準に出典がありません。FindSkill（2026年6月）とThe Haulers Edge（2026年8月）はGoogleビジネスプロフィールやChatGPTでの確かめ方に触れますが、料金の書き方や引き取れない物の一覧はありません。Workiz（2026年5月更新）は構造化データの種類を挙げますが、業種に合わせた例はありません。どの記事にも、量の決め方と追加料金を表にした料金の書き方、家電と危険物の扱い、買取と処分の分け方、WordPressでの設定はありません。この記事は、これらを埋めます。

まず許可を書く：家庭のごみは市町村の許可か、許可業者への委託

家庭から出る不用品を、お金をもらって集めて運ぶには、原則として市町村長の「一般廃棄物収集運搬業」の許可が必要です。環境省：不用品回収業者に関する調査結果（2011年5月23日）。環境省のQ&Aは、産業廃棄物処理業の許可や古物商の許可では、家庭から出る廃棄物を回収できないと説明しています。環境省：廃家電・粗大ごみの無許可回収業者 Q&A。杉並区・千葉市も同じ注意を出しています。杉並区（2025年6月10日更新）・千葉市（2025年7月30日更新）

一方で、消費者は許可のことをよく知りません。環境省の2011年の調査では、不用品回収業者を使った人のうち、その業者の許可を「わからない」と答えた人が84.5%でした。環境省（2011年5月23日）。古い調査ですが、だからこそ、許可の情報は業者のサイトに「どこの、何の許可か」まで書いておく意味があります。

許可の範囲や扱いは市区町村によって違います（千葉市では、許可業者でも家庭のごみを扱えるのは一時的に大量に出るごみなどに限られます）。自分の許可の内容どおりに書いてください。
書く項目書き方の例
一般廃棄物収集運搬業の許可◯◯市 一般廃棄物収集運搬業 許可 第◯◯号（許可の範囲：◯◯市内の家庭から出る◯◯）。許可のある市町村を全部、名前で書く
許可を持っていない場合運搬と処分は◯◯市の許可業者「◯◯（例）」に任せています。当社は仕分け・運び出し・梱包を行います
古物商許可◯◯県公安委員会 第◯◯号。まだ使える品の買取に使う許可で、ごみの回収の許可ではないことを書く
産業廃棄物収集運搬業の許可お店や会社から出る廃棄物のための許可であることを書き、家庭の不用品の回収の根拠にしない
許可のない地域◯◯町は許可がないため、町の粗大ごみの受付や、町の許可業者をご案内します

許可番号は、トップページのフッターだけでなく、料金ページと会社概要、対応エリアのページにも同じ表記で書きます。許可のない市町村を「対応エリア」に入れると、AIが「その地域で回収できる」と答えてしまうおそれがあります。

料金は「量の決め方」と「追加になる費用」で書く

国民生活センターには、不用品回収サービスの相談が2018年度1,354件、2019年度1,457件、2020年度1,788件、2021年度2,231件寄せられています（2022年度は9月末までで857件）。紹介されている事例には、「軽トラックパック7,000円」の広告を見て頼んだら当日に25万円を請求された、「詰め放題」が荷台の囲い（あおり）の高さまでだった、1台分を2台分として請求された、といったものがあります。国民生活センター：不用品回収サービスのトラブル（2022年11月2日公表、11月11日更新）

つまり、AIとお客様が知りたいのは「1台いくら」だけではなく、その1台に何がどこまで入って、何が別になるかです。料金ページには、パックの価格を出す場合でも、次の項目を文字で書きます。

金額と条件は書き方の例です。自分の会社の実際の料金と、自治体の決まりに合った内容を書いてください。
書く項目書き方の例
量の決め方軽トラック1台分＝荷台の囲い（あおり）の高さまで。2tトラックは◯㎥まで。写真で例を示す
含まれるもの作業員2名、運び出し、運搬、処分費（税込）
追加になる費用3階以上の階段作業 1階ごとに◯円、解体が必要な家具 1点◯円、エアコンの取り外し 1台◯円
家電4品目リサイクル料金（メーカーと品目ごとに決まった額）と収集運搬料金は別。家電リサイクル券をお渡しします
引き取れない物消火器・ガスボンベ・塗料・農薬・医療系の廃棄物など。処分先のご案内の有無
見積もりとキャンセル訪問見積もりは無料。作業日の前日までのキャンセルは無料、当日は◯円。見積もり後に金額が変わる条件

国民生活センターは消費者に、複数の業者から見積もりを取り、作業内容・料金・キャンセル料と「追加料金がかからないこと」を確かめるよう勧めています。国民生活センター。サイトにこの4つが書いてあれば、AIがその業者を説明するときの材料になります。料金ページ全般の書き方は料金ページのAI検索対策をご覧ください。

家電4品目は、料金の内訳と流れを書く

エアコン、テレビ、冷蔵庫・冷凍庫、洗濯機・衣類乾燥機の4品目は、家電リサイクル法の対象です。引き渡すときには、リサイクル料金と収集運搬料金がかかり、家電リサイクル券が発行されます。環境省 Q&A。国民生活センターの資料では、買い替えのときは新しい製品を買う店が、処分だけのときは買った店が引き取ることになっています。国民生活センター

  1. 4品目を引き取る場合は、リサイクル料金と収集運搬料金を分けて書き、家電リサイクル券の控えを渡すことを書きます。
  2. 引き取らない場合は、そのことと、お客様が使える方法（買った店、自治体の案内）へのリンクを書きます。
  3. パソコンや小型の家電など、4品目以外の扱いも、自治体の決まりに合わせて書きます。

買取と処分を分けて書く：古物商許可はごみの許可ではない

まだ使える品を買い取って売るには、古物商の許可が必要です。古物の売買・交換を仕事として行う場合の許可で、買い取る場所も、営業所かお客様の住所などに決められています。愛知県警察：古物営業法の解説（2025年12月15日公開）。ただし、古物商の許可は、ごみを回収する許可ではありません。環境省 Q&A

環境省の2024年3月の報告書では、古物商の許可を持つ業者が引き取りの記録を渡していなかったため、自治体がその品を一般廃棄物と判断し、無許可の回収として扱った例が紹介されています。チラシに書かれた古物商許可の真偽が確かめられない、という自治体の声もあります。環境省：令和5年度 適正なリユースの促進及び違法な不用品回収業者対策 報告書（PDF）

  1. 買取の品と、処分する品の料金を、見積もりと明細で分けて書きます。「買取額を処分費から差し引く」場合は、その計算を明細に残すことを書きます。
  2. 買い取った品には、買取の明細（品名・数・金額）を渡すことを書きます。
  3. 「無料回収」と書く場合は、何が無料で、どんなときに費用がかかるかを書きます。杉並区・千葉市は、無料をうたって集めたあとで料金を求める業者への注意を出しています。杉並区・千葉市

遺品整理：仕分け・貴重品・立ち会い・誰が決めるかを書く

国民生活センターに寄せられた遺品整理サービスの相談は、2013年度73件から2017年度105件と増え、2018年度は6月末までで31件（前年の同じ時期は16件）でした。事例には、見積もりのときにせかされて契約した、高額なキャンセル料を求められた、見積もりの2倍を請求された、「処分しないように」と頼んだ物まで処分された、といったものがあります。国民生活センター：遺品整理サービスの契約トラブル（2018年7月19日）

遺品整理では、料金に加えて「大事な物をどう扱うか」が、お客様の一番の心配です。次のことを、作業の流れのページに書きます。

  1. 仕分けの方法：「残す物」「売る物」「処分する物」をどう決めるか。事前に印を付けてもらうのか、当日に一緒に確認するのか。
  2. 貴重品・書類・写真：現金、通帳、権利書、写真や手紙が見つかったときの扱い（まとめて保管し、作業の終わりにお渡しする など）。
  3. 立ち会い：立ち会いなしで作業する場合の鍵の受け渡し、作業前と作業後の写真の報告。
  4. 誰が決めるか：依頼する人と、片付ける家の持ち主や家族が違う場合に、誰の同意をもらって作業するか。
  5. 供養・ハウスクリーニング・賃貸の退去：自社でするか、提携先に頼むか、しないか。
  6. 資格の書き方：遺品整理士などの民間の資格は、国の許可とは別のものとして書きます。

比較サイト・予約サイトの掲載と、Googleビジネスプロフィールをそろえる

神戸新聞NEXTの記事（2026年10月29日）は、株式会社ブランディングワークスの2026年9月の調査として、ChatGPTとGeminiに不用品回収サービスのおすすめを聞いた54件の回答で、くらしのマーケットが51.9%、ミツモアが50.0%の回答に出たと紹介しています。神戸新聞NEXT。調べた回答の数は少なく、元の調査の資料はリンクされていませんが、AIが個別の業者より比較サイト・予約サイトを挙げることがある、という点は覚えておく価値があります。

  1. 比較サイト・予約サイトに載せている場合は、会社名・許可番号・料金の決め方・対応エリアを、自社サイトと同じにします。
  2. Googleビジネスプロフィールの名前に「◯◯市 不用品回収 即日」のような地域名やサービス名を足すことは、ガイドラインで認められていません。Google：ビジネス情報のガイドライン
  3. 口コミの依頼のしかたには決まりがあります。口コミ・お客様の声とAI検索をご覧ください。引っ越しと一緒に頼まれることが多い場合は、引越し会社のAI検索対策、ハウスクリーニングもしている場合は家事代行・ハウスクリーニングのAI検索対策もあわせてご覧ください。

構造化データ：専用の型はない。LocalBusiness＋Service

schema.orgには、不用品回収や遺品整理のための専用の型はありません（schema-dts 2.1.0で確認、2026年11月27日）。RecyclingCenterはリサイクルの施設を表す型なので、施設を持って営業している場合でなければ使いません。会社はLocalBusinessで出し、不用品回収・遺品整理・買取などを Service と Offer で、対応エリアを areaServed で、許可を hasCredential で書きます。

WordPressの遺品整理・不用品回収のサイトでの設定手順

  1. WordPress.orgからNurevo AEO（無料）をインストールして有効化します。Yoast SEO・Rank Math・All in One SEO・SEO SIMPLE PACK・VK All in One Expansion Unitなどはそのまま使えます（構造化データは重複しません）。
  2. 初回の設定ウィザードで「その他」を選びます。業種の型を指定しない設定で、住所・電話番号・営業時間のどれかが入っていれば LocalBusiness として出力されます。
  3. 会社名・住所・電話番号・受付時間を、Googleビジネスプロフィールと同じ表記で入れます。
  4. 不用品回収（トラックの大きさごと）・遺品整理・生前整理・買取・家電の引き取りなどを「サービス」に登録します（最大20件）。名前・料金・見積もり依頼のURL・説明を入れ、説明に「含まれるもの・追加になるもの」を書きます。サービスは構造化データ（Service）とllms.txtに載ります。
  5. 対応エリア（areaServed）と許可（hasCredential）の入力欄はないので、下の webmcp_canary_business_node フィルターで足します。値は本文と同じにします。Yoast SEOなどが有効な場合は、そのプラグインがすでに出している値が優先されます。
  6. 許可・追加料金・家電・買取・貴重品の扱いの答えをよくある質問に入力し、Nurevo FAQブロック（または[nurevo_faq]ショートコード）を料金ページに置きます。書き方はFAQページのAI検索対策をご覧ください。
  7. /llms.txt を開き、料金・許可・遺品整理の流れ・よくある質問のページが載っているか確かめます。AEOスコアの画面で診断を実行し、不足を直します。
// 対応エリアと許可を事業者のノードに足す（値は本文と同じにする）
add_filter('webmcp_canary_business_node', function (array $node, array $settings) {
    $node['areaServed'] = array(
        array('@type' => 'City', 'name' => '◯◯市'),
    );
    $node['hasCredential'] = array(
        array(
            '@type' => 'EducationalOccupationalCredential',
            'name' => '一般廃棄物収集運搬業の許可（◯◯市 第◯◯号）',
            'recognizedBy' => array('@type' => 'GovernmentOrganization', 'name' => '◯◯市'),
        ),
        array(
            '@type' => 'EducationalOccupationalCredential',
            'name' => '古物商許可（◯◯県公安委員会 第◯◯号）',
            'recognizedBy' => array('@type' => 'GovernmentOrganization', 'name' => '◯◯県公安委員会'),
        ),
    );
    return $node;
}, 10, 2);

よくある質問

不用品回収のAI検索対策は、何から始めればいいですか？

まず、家庭のごみを運ぶ許可（一般廃棄物収集運搬業）の市町村名と番号、または運搬を任せる許可業者を書きます。次に、トラック1台分などの量の決め方、含まれるもの、追加になる費用とキャンセル料を料金ページに書きます。そのうえで、Googleビジネスプロフィールと比較サイトの掲載をそろえ、構造化データとllms.txtで出します。

一般廃棄物の許可を持っていない場合は、どう書けばいいですか？

持っていない許可を持っているように書かないでください。運搬と処分を任せる許可業者がいる場合は、その名前と、自社がする作業（仕分け・運び出しなど）を分けて書きます。いない地域は、自治体の粗大ごみの受付や許可業者の案内を書きます。

古物商許可があれば、家庭の不用品を回収できますか？

環境省は、古物商の許可や産業廃棄物処理業の許可では、家庭から出る廃棄物を回収できないと説明しています。古物商許可は、まだ使える品を買い取って売るための許可として書きます。

料金を「〜円から」と書くのは問題ですか？

「〜円から」だけだと、AIもお客様も総額を取り違えやすくなります。量の決め方、含まれるもの、追加になる費用の条件と金額を一緒に書き、総額の例を1つ載せることをおすすめします。

遺品整理の料金を構造化データに入れるべきですか？

部屋の広さや物の量で大きく変わる場合は、Offer に1つの金額を入れず、本文に総額の例と条件を書きます。トラック1台分のように決まった料金があるサービスは、本文と同じ金額で Offer に入れられます。

この対策で、ChatGPTに必ず紹介されますか？

いいえ。AIの回答は変わるもので、どの道具や方法でも、表示や順位は保証できません。できるのは、許可・料金の決め方・買取と処分の違い・遺品の扱いをAIが読みやすい形で出し、出ているか・正しいかを確かめ続けることです。
