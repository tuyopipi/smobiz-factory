ニュージーランドのWeb制作会社の自社サイト417件に見るAI検索への対応（2026年11月）

ニュージーランドのWeb制作会社の自社サイト417件のトップページ・robots.txt・llms.txt を調べたところ、llms.txt があったのは25.4%（106件）で、日本の13.4%より高く、オーストラリア（24.3%）・米国（23.1%）・英国（21.5%）とは統計的な差が見られませんでした。AI検索に関わる6項目をすべて満たすサイトは20.9%で、オーストラリア（20.8%）とほぼ同じ、日本の2倍です。国内向けの .co.nz ドメインのサイトは、.com のサイトより llms.txt（18.2%・34.4%）も「6項目すべて」（13.6%・32.8%）も低めでした。

公開：2026年11月28日。データ：2026年11月12日集計。調査・執筆：Nurevo AEO（Bestie.合同会社）。Nurevo はAI検索対策（AEO）のツールと WordPress プラグインを提供しており、この分野に利害があります。国別レポートの10本目です（これまでに米国・英国・オーストラリアなど）。日本と海外25の国・地域の全体の比較はこちらです。

要点

  1. ニュージーランドのWeb制作会社の自社サイト417件のうち、llms.txt があったのは25.4%（106件）。日本（13.4%）より高く（p<0.001）、オーストラリア（24.3%、p=0.68）・米国（23.1%、p=0.31）・英国（21.5%、p=0.13）とは差が見られませんでした。トップページが HTTP 202 を返した37件を除くと27.9%です。
  2. AI検索に関わる6項目をすべて満たすサイトは20.9%（87件）で、日本（10.4%）の2.0倍、オーストラリア（20.8%）とほぼ同じでした。6項目の平均は3.80（オーストラリア3.77・日本4.05）です。
  3. ドメイン別では、.co.nz のサイト132件の llms.txt は18.2%、.com のサイト122件は34.4%でした（p=0.005）。WordPress のサイトどうしで比べても20.9%と41.2%で（p=0.004）、差が残りました。

調査概要

  1. 対象：Web制作会社の自社サイト。当社の収集リストで国がニュージーランドとなっている制作会社サイト544件のうち、トップページに到達できた417件です。一般企業のサイト全体ではありません。比較には同じ調査のオーストラリア（1,719件）・米国（4,472件）・英国（942件）・日本（2,486件）・ニュージーランド以外の海外（12,935件）を使いました。
  2. 取得したもの：各サイトのトップページ、/robots.txt、/llms.txt、/llms-full.txt を1回ずつ（User-Agent：NurevoSurvey/1.0）。2026年11月上旬〜12日に取得し、11月12日に集計しました。
  3. 判定方法：llms.txt は、ステータス200で中身がHTMLではなく20文字を超えるテキストを「あり」としました。JSON-LD はトップページにあるかどうか、「壊れている」は JSON として読み込めないブロックが1つ以上あるもの。Organization系は @type に Organization・LocalBusiness・Corporation・ProfessionalService を含むもの。WordPress はトップページのHTMLに wp-content/・wp-includes/、または generator の WordPress 表記があるもの。SEOプラグインはトップページのHTMLの文字列で判定しました。
  4. AIボットのブロック：robots.txt で、各ボットに当てはまるグループの規則がトップページ（/）を Disallow にするか（最長一致）で判定しました。分母は robots.txt があるサイトです。「AIボットをブロック」は GPTBot・ClaudeBot・PerplexityBot・Google-Extended・CCBot・OAI-SearchBot のどれかをブロックしているものです。
  5. 「6項目」は、(1) llms.txt がある、(2) JSON-LD がある、(3) Organization または LocalBusiness の型がある、(4) robots.txt があり GPTBot・ClaudeBot・PerplexityBot・OAI-SearchBot のどれもブロックしていない、(5) meta description がある、(6) canonical がある、のうち当てはまる数（0〜6）です。この調査のための単純な数で、Nurevo の0〜100点のスコアとは別物です。
  6. HTTP 202：ニュージーランドでは37件（到達した417件の8.9%）のトップページがステータス202を返しました（オーストラリア14.5%・米国15.0%・英国14.9%・日本0件）。これらには JSON-LD も WordPress の痕跡も robots.txt も llms.txt もなく、ボット確認などの別のページが返った可能性があります。そのため、202を除いた値も並べています。
  7. 統計：ニュージーランドと他の地域の差はカイ二乗検定で確かめました。30件未満の区分は載せていません。地域（都市）は544件中470件が空欄のため分けていません。

結果：ニュージーランドとオーストラリア・米国・英国・日本の比較

ニュージーランドの値は、ほとんどの項目でオーストラリアと1ポイント前後の差しかなく、llms.txt・「6項目すべて」・AIボットのブロックのどれも、オーストラリア・米国・英国・ニュージーランド以外の海外全体との間に統計的な差は見られませんでした。FAQPage は7.4%で、オーストラリア（10.3%）より低めでしたが差ははっきりしません（p=0.09）。JSON-LD が壊れていたのは JSON-LD があるサイトの1.0%で、比べた地域の中ではいちばん低い値です。日本と比べると、llms.txt・FAQPage・「6項目すべて」が高く、meta description・canonical・robots.txt は低めです。低めの項目は202を返した37件の影響を受けており、202を除くと meta description 76.3%、canonical 85.3%、robots.txt 86.1% です。

ブロックの中身（事実）

  1. GPTBot をブロックしていた15件のうち13件（86.7%）は、OAI-SearchBot をブロックしていませんでした（オーストラリア56件中55件、米国128件中119件）。
  2. 11種のAIボット（表の Googlebot・Bingbot 以外）のどれかをブロックしていた21件のうち13件（61.9%）は、GPTBot・ClaudeBot・anthropic-ai・Google-Extended・CCBot・Bytespider・Applebot-Extended の7つをまとめてブロックする同じ組み合わせでした（オーストラリア64.6%・米国58.5%）。CCBot だけ・Bytespider だけが各2件です。
  3. OAI-SearchBot・ChatGPT-User・Claude-SearchBot・PerplexityBot のどれかをブロックしていたのは2件（robots.txt があるサイトの0.6%）でした。
  4. robots.txt でAIボットの名前を挙げていながら、どれもトップページをブロックしていないサイトが13件ありました（robots.txt があるサイトの4.0%）。
  5. AIボットをブロックしていた21件のうち4件（19.0%）には llms.txt もありました。

ドメイン別：.co.nz と .com

到達できた417件のドメインは、.co.nz が132件、.com が122件、そのほかが163件でした（.co.nz 以外の .nz は27件で30件未満のため表に載せていません）。.co.nz のサイトは .com のサイトより llms.txt（18.2%・34.4%、p=0.005）も「6項目すべて」（13.6%・32.8%、p<0.001）も低めでした。WordPress の割合も .co.nz のほうが低い（68.9%・83.6%）ため、WordPress のサイトどうしでも比べましたが、llms.txt は20.9%（91件中）と41.2%（102件中）で差が残りました（p=0.004）。202を除いても20.0%と36.2%です（p=0.009）。

この調査では、ドメインと取引先の地域（国内中心か海外中心か）の関係は調べていません。

当社の見方（意見）

ここからは事実ではなく当社の意見です。ニュージーランドの制作会社サイトは、どの項目でもオーストラリアとよく似た水準でした。目立ったのは .co.nz と .com の差で、.com のサイトに国外の取引先を意識した会社が多いといった理由が考えられますが、この調査では確かめていません。5項目のサイトの9割は llms.txt だけが欠けており、残りの1項目は比較的足しやすいものです。AIボットのブロックは少数で、ほとんどが学習用のボットに限っていました。どのボットを止めるかは各社の判断ですが、AI検索に出たい場合は、検索用のボットまで止めていないかを確かめる価値があります。どれを整えてもAIの回答に出ることが保証されるわけではありません（別の調査では、サイト側の項目と登場の間に関係は見られませんでした）。

よくある質問

ニュージーランドの制作会社は日本よりAI検索への対応が進んでいますか？

llms.txt（ニュージーランド25.4%・日本13.4%）と「6項目すべて」（20.9%・10.4%）はニュージーランドが高く、JSON-LD は70.3%と69.4%で差は見られませんでした。meta description や canonical は日本のほうが高めです（2026年11月、Web制作会社の自社サイト）。

ニュージーランドとオーストラリアで違いはありますか？

llms.txt（25.4%・24.3%）、6項目すべて（20.9%・20.8%）、AIボットのブロック（5.8%・4.7%）のどれも、統計的な差は見られませんでした。FAQPage はオーストラリアが高め（7.4%・10.3%）ですが、差ははっきりしません。

.co.nz と .com で違いはありますか？
