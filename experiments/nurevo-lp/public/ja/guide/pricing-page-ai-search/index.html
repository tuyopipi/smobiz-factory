料金ページをAIに正しく読ませる書き方：税込表示・条件つきの料金・改定のときの手順

AIに料金を正しく答えてもらうには、料金を画像やPDFではなくHTMLの文字で書き、1つの金額ごとに「税込か税抜か」「何に対する料金か（1回・1か月・1人）」「含まれるもの」「条件」「いつの料金か」を同じ行に書きます。料金が決まらない仕事でも「お問い合わせください」だけにせず、下限と決まり方と条件つきの例を書きます。改定したら、同じ日に料金を載せた全ページと構造化データを直し、古い料金のページは残しません。

作成日：2026年11月20日（JST）。BtoB・SaaSの料金ページに書く項目はBtoB・SaaSのAI検索対策で、よくある質問の書き方はFAQページとAI検索で扱いました。この記事は業種を問わず「料金の書き方」そのものに絞り、店舗・教室・士業・ネットショップ・BtoBのどれにも使える形で書きます。

AIの回答は日・聞き方・使うサービスによって変わります。この記事の手順は、AIが料金を読み違えにくいページを作り、正しく確かめるためのもので、回答に出ることや金額が正しく伝わることを保証するものではありません。

AIの検索がどのくらい会社の料金ページを使っているかの参考に、AI検索の計測会社 Profound が公開した調査があります。クラウド企業100社の料金について6つのAIの回答約7,600件を調べたところ、会社の料金ページがどこかで引用された回答は46%、最初の出典だったのは12%で、それ以外は比較サイトや掲示板などが使われていました（Profound（2026-09-03）、調査会社自身の調査で、対象は海外のSaaS企業）。自社の料金ページを正確にすることは前提で、外部の掲載先の料金もそろえる必要がある、ということです。

「料金ページ AI検索」「pricing page AI search」などで上位の日本語の記事と英語の記事を読みました（2026-11-20）。どの記事も「料金を文字で書く」「本文と構造化データを合わせる」は共通でした。一方、税込・税抜の書き方、決まった料金がない仕事の書き方の具体例、割引や通常価格の表示のルール、WordPressでの手順は、ほぼどの記事にもありませんでした。

英語の記事はどれもSaaSが前提で、店舗やサービス業の「1回いくら」「条件で変わる」料金を扱った記事は見つかりませんでした。この記事はそこを埋めます。

料金の1行に入れる6つの要素

AIは「◯◯はいくら？」と聞かれると、ページから金額の部分を抜き出して答えます。そのとき金額の近くに条件がないと、条件を落として答えたり、別の行の条件を付けてしまったりします。料金は1つずつ、次の6つを同じ行（または同じ表の行）に書きます。

要素書く例抜けると起きること
金額5,500円—
税込か税抜か（税込）税抜の金額を総額として伝えられる
単位1回／1か月／1人／1時間／1㎡月額が1回分として伝えられる
含まれるものシャンプー・ブロー込み追加料金の有無を聞かれても答えられない
条件学生は550円引き（学生証の提示）条件つきの値段が全員の値段として伝えられる
いつの料金か2026年12月1日からの料金改定前か後か区別できない

悪い例：「カット 5,000〜」。良い例：「カット（シャンプー・ブロー込み）1回 5,500円（税込）。学生は550円引き（学生証の提示）。2026年12月1日からの料金です。」

日本で消費者に向けて前もって料金を示すときは、消費税を含めた総額の表示が求められています。ウェブサイトや広告も対象です（国税庁：タックスアンサー No.6902）。税抜の金額を併記するのは構いませんが、総額が分かる書き方にします。表の見出しに一度だけ「表示はすべて税込です」と書くより、金額ごとに（税込）と書くほうが、AIが行だけを抜き出したときにも伝わります。

決まった料金がない仕事は「下限・決まり方・例」で書く

工事、士業の報酬、制作、出張サービスなど、内容で料金が変わる仕事は多くあります。それでも「お見積もりします」「お問い合わせください」だけだと、AIは「料金は公開されていません」としか答えられず、料金を書いている他社の名前が先に出やすくなります。正確な金額が書けなくても、次の3つは書けます。

  1. 下限：「税込33,000円から」。いちばん安い条件も一緒に書く（「6畳1部屋・平日の場合」など）
  2. 決まり方：何で金額が変わるか（広さ、件数、距離、日数、緊急かどうか）と、その単価が分かるなら単価
  3. 条件つきの例：よくある依頼の例を2〜3通り、条件をすべて書いて金額と作成した月を添える

例：「戸建ての外壁塗装（30坪・2階建て・足場込み）の例：税込1,320,000円（2026年11月の見積もり例）。面積・塗料・下地の傷みで変わります。現地調査と見積もりは無料です。」この形なら、AIは「この条件ならこのくらい」と答えられ、人も問い合わせる前に予算の見当が付きます。

無料のものは「無料」とはっきり書きます。見積もり、初回相談、出張費、キャンセル料のように、お客さまが迷うものほど、0円であることを文字で書いておく価値があります。

割引・キャンペーン・「通常価格」の書き方

期間限定の値段は、期間を書かないと、終わったあともAIが「今の値段」として答えることがあります。キャンペーンは「2026年12月1日〜12月31日のご予約まで」のように始まりと終わりを書き、終わったらその日のうちにページから外すか「終了しました」と書き換えます。

「通常価格◯円のところ◯円」のように比べる値段を並べる表示（二重価格表示）には、景品表示法のルールがあります。消費者庁は、比べる値段に過去の販売価格を使う場合、それが「最近相当期間にわたって販売されていた価格」でなければ、いつ・どのくらいの期間その値段だったかを正しく書かないと不当表示のおそれがある、としています。実際に売ったことのない値段や、メーカーが決めていない「希望小売価格」を比べる値段に使うのも問題になる例として挙げられています（消費者庁：二重価格表示）。AIは比べる値段もそのまま拾うので、根拠のない「通常価格」は人にもAIにも誤解のもとになります。

料金を改定するとき：古い料金を残さない手順

AIが古い料金を答えるいちばん多い原因は、料金ページ以外のどこかに古い金額が残っていることです。改定の前に、料金が載っている場所を洗い出しておきます。

  1. サイト内を古い金額で検索する（WordPressなら管理画面の投稿・固定ページの検索、ブログ記事、お知らせ、FAQ、PDFのパンフレット）
  2. 料金ページに「2026年12月1日に料金を改定しました」と書き、いつからの料金かを明記する
  3. 構造化データの金額（プラグインやテーマの設定、手書きのJSON-LD）を同じ日に直す
  4. Googleビジネスプロフィール、予約サイト、比較サイト、SNSのプロフィールの料金を同じ日に直す
  5. 古い料金だけを書いた記事は、削除するか、冒頭に「この記事の料金は改定前のものです。現在の料金は料金ページへ」と書いてリンクする
  6. 改定の日付と、直した場所の一覧を記録しておく（あとでAIの答えを確かめるときに使う）

各AIが新しい料金を反映するまでの日数は公開されていません。改定の数日後から数週間後に、同じ質問で確かめます（確かめ方は後半に書きます）。

AIが読める形にする：画像・PDF・タブ・JavaScriptを確かめる

デザインの都合で料金表を画像にしていると、人には読めてもAIのクローラーには読めない場合があります。PDFだけ、タブを押さないと出ない料金、JavaScriptで後から表示する料金も、読み取れるかどうかはAIのサービスごとに違い、公開されていません。料金はHTMLの文字と表（table要素）で書くのが確実です。Profound の調査でも、料金ページの一部が本文から読めない状態のサイトがありました（公開している料金ページ77件のうち、AIが読める状態だったのは57件）。

自分のページの料金がHTMLの文字として入っているかは、次のコマンドで確かめられます。

curl -s https://example.jp/price/ | grep -E "円|税込|税抜"
# 何も出なければ、料金は画像・PDF・JavaScript の中にあり、HTMLの本文にはありません

コマンドを使わない場合は、ブラウザで料金ページを開き、ページのソースを表示して金額で検索しても同じことが分かります。

構造化データ：Offer と PriceSpecification の書き方

構造化データは、本文に書いた料金を機械が読みやすい形でも示すものです。本文の代わりにはなりません。GoogleはAI機能のために特別な構造化データは要らず、構造化データは表示されている本文と一致させるよう案内しています（AI機能とウェブサイト、2026-11-18に確認）。書くなら、次の決まりを守ります。

  1. 金額（price）は数字だけ。カンマ・「円」・「〜」を入れず、通貨は priceCurrency に「JPY」のように書く（schema.org/price の使い方の説明）
  2. 税込かどうかは PriceSpecification の valueAddedTaxIncluded（true / false）で示せる（PriceSpecification）
  3. 幅のある料金は minPrice・maxPrice、期間のある料金は validFrom・validThrough（Offer なら priceValidUntil）
  4. 月額などの単位は UnitPriceSpecification の billingDuration・unitText、通常価格とセール価格の区別は priceType（UnitPriceSpecification）
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "Service",
  "name": "カット（シャンプー・ブロー込み）",
  "provider": { "@id": "https://example.jp/#business" },
  "offers": {
    "@type": "Offer",
    "price": 5500,
    "priceCurrency": "JPY",
    "priceSpecification": {
      "@type": "UnitPriceSpecification",
      "price": 5500,
      "priceCurrency": "JPY",
      "valueAddedTaxIncluded": true,
      "unitText": "1回",
      "validFrom": "2026-12-01"
    }
  }
}
</script>
<!-- 金額は数字だけ（カンマ・円・〜を入れない）。本文の「5,500円（税込）」と同じ値にする -->

書いたら Schema Markup Validator で文法を確かめます。Googleの検索結果での特別な表示（リッチリザルト）の条件は型ごとに違うので、商品やサービスで狙う場合はGoogleの各型のドキュメントで確かめてください（この記事を書いた回は、Googleの商品のドキュメントを直接は読めていません）。ChatGPTやPerplexityが料金の構造化データを使うと明記した公式の資料は、調べた範囲では見つかりませんでした。

WordPressでの手順（Nurevo AIOの場合）

Nurevo AIO（無料、旧表示名 Nurevo AEO）では、設定画面の「サービス」に登録した料金が、Service の構造化データ（Offer の price と priceCurrency）と llms.txt に出ます。次の順で進めます。

  1. 先に料金ページの本文を、この記事の6つの要素で整える（構造化データより本文が先）
  2. サービスを登録する（最大20件）。「料金」の欄には数字だけ（5500）を入れ、「通貨」に JPY を入れる。入れた文字はそのまま出るので「5,500円〜」とは入れない
  3. Nurevo の Offer には税込かどうかの印が付かないので、税込かどうか・含まれるもの・条件は「説明（1文・任意）」と本文に書く。「説明」は llms.txt のサービスの行にも載る
  4. 「所要時間（分）」を入れると、料金と一緒に llms.txt と構造化データに出る（例：- カット — 60 min · JPY 5500）
  5. 「サービスを掲載するページID」に料金ページのIDを入れると、サービスの構造化データがそのページに出る（0はフロントページ）
  6. BtoB・SaaSのサイトは「料金ページ（BtoB）」にURLを入れると、llms.txt の Key facts に「Pricing」として載る
  7. WooCommerce の商品の Product と Offer は WooCommerce に任せ、Nurevo は重ねて出さない。商品の価格は WooCommerce の設定で直す
  8. 料金のよくある質問（追加料金、キャンセル料、支払い方法）は、料金ページ専用のFAQにする。Yoast SEO・Rank Math・All in One SEO・Slim SEO と一緒でも二重にならず、SEO SIMPLE PACK・VK All in One Expansion Unit とも併用できる（0.9.1から）

改定のときは、本文・Nurevo のサービスの料金・FAQの答えを同じ日に直します。お客様のサイトを保守している制作会社は、料金改定の更新を保守の作業範囲に入れておくと、食い違いを防げます。月額で支援する制作会社向けにパートナー制度があります。

確かめ方：料金の質問を決めて記録する

料金が正しく伝わっているかは、同じ質問を同じAIに、日を変えて何回か聞いて記録します。1回の答えだけで判断しないでください。

質問の例見ること
「（店名）のカットの料金は？」金額・税込かどうか・含まれるものが合っているか
「（地域）で（サービス）が1万円以内でできるところは？」社名なしの質問で候補に入るか。料金の条件つきの質問は、料金が書いていないと外されやすい
「（店名）のキャンセル料は？」0円や割合が正しいか
「（店名）は値上げした？」改定前の料金を答えていないか。出典のURLはどこか

記録するのは、日付・AIのサービス名・質問・答えた金額・出典のURLです。出典が比較サイトや古いブログ記事なら、そこを直します。Nurevoの無料プランとStandardでは、月に1回、業種と地域から作った社名なしの質問3つをNurevoのサービスがPerplexityに聞き、名前が出たか・サイトが引用されたかを表示します。Pro（月14,800円〜、ベータ）は最大20問をPerplexityで計測します（ChatGPTは設定され次第）。料金の質問は手で記録してください。詳しくはAIでの登場率の測り方へ。

公開前のチェックリスト

  1. 料金がHTMLの文字で書かれている（画像・PDF・タブの中だけではない）
  2. 金額ごとに（税込）（税抜）が書いてある。消費者向けは総額が分かる
  3. 金額ごとに単位（1回・1か月・1人など）が書いてある
  4. 含まれるもの・追加料金・無料のものが書いてある
  5. 決まった料金がない仕事は、下限・決まり方・条件つきの例を書いた
  6. キャンペーンに始まりと終わりの日付がある。比べる値段に根拠がある
  7. 料金ページに「いつからの料金か」が書いてある
  8. サイト内の古い料金をすべて直した
  9. 構造化データの金額が数字だけで、本文と同じ値
  10. Googleビジネスプロフィール・予約サイト・比較サイトの料金も同じ

よくある質問

料金を公開すると、AIに出やすくなりますか？

出ることは保証できません。ただ「1万円以内」のような料金の条件がついた質問では、料金が書いていないページは答えに使いようがありません。少なくとも下限と決まり方を書くと、AIが答えに使える材料ができます。

税抜の表示だけではいけませんか？

日本で消費者に向けて料金を示すときは、消費税を含めた総額の表示が求められています（国税庁 タックスアンサー No.6902）。税抜の金額を一緒に書くのは構いません。AIの読み違いを防ぐためにも、金額ごとに（税込）と書くのがおすすめです。

料金表を画像にしたままではだめですか？

画像を読めるかどうかはAIのサービスごとに違い、公開されていません。デザインとして画像を残すのは構いませんが、同じ内容をHTMLの文字か表でも書いてください。

AIが古い料金を答えます。どうすればいいですか？

AIが示した出典のURLを確かめ、そのページの料金を直すか、改定前の料金であることを冒頭に書きます。サイト内の古い記事、Googleビジネスプロフィール、比較サイトも見直してください。反映までの日数は公開されていないので、数日後から数週間後に同じ質問で確かめます。

構造化データだけで料金を伝えられますか？

いいえ。構造化データは本文の料金を補うもので、本文と一致させる必要があります。本文に書いていない料金を構造化データだけに入れないでください。

見積もり制なので金額を書けません。

正確な金額でなくても、下限（「税込◯円から」とその条件）、金額が何で変わるか、条件をすべて書いた見積もりの例を2〜3通り書けます。見積もりが無料なら、それもはっきり書きます。

WordPressの料金欄に「5,500円〜」と入れてもいいですか？

Nurevo の「料金」欄は、入れた文字がそのまま構造化データの price に出ます。schema.org は数字だけを使うよう説明しているので、5500 と入れ、「〜から」や税込かどうかは本文と「説明」に書いてください。

AIがサイトを読める状態かを確かめる

無料チェックは登録不要です。URLを入れると、AIクローラーの許可、構造化データ、llms.txtの状態が分かります。WordPressなら無料のプラグインで、サービスと料金を構造化データとllms.txtに出し、SEOプラグインと重ならないように整えられます。
