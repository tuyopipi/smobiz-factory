画像・動画とAI検索：代替テキスト、キャプション、動画の文字起こしをAIに読ませる手順

ChatGPT・Perplexity・GoogleのAIに画像や動画の情報を使ってもらうには、その中身を「文字」でもページに書いておくことが基本です。Googleは画像の内容を代替テキスト（alt）・周りの文章・画像認識を合わせて理解すると説明していますが、ほかのAIがページの画像をどこまで読み取るかは公開されていません。料金表やメニューを画像だけで載せず本文にも書き、写真には何の写真かが分かる代替テキストを、動画には要約と文字起こしをページに付けてください。YouTubeの動画は、OtterlyAIの調査ではPerplexityとGoogleのAIで多く引用されていました。

作成日：2026年11月26日（JST）。対象は、写真や動画を多く使う店・会社のサイト運営者と、サイトを作る制作会社の方です。WordPressでの手順と、コマンドを使った確かめ方も書いています。

AIの仕組みは各社が予告なく変えることがあり、AIの回答は日や聞き方によっても変わります。この記事の手順は、画像や動画の情報が読まれるための準備で、AIの回答に出ることを保証するものではありません。

よく読まれている記事と、足りないこと

「画像 AI検索 代替テキスト」「YouTube AI検索 引用」「optimize images and videos for AI search」などで上位に出る日本語4本・英語7本を、2026年11月26日に読みました。日本語は、Uravation（画像）（2026年9月5日更新）、Uravation（動画）（9月5日更新）、Ahrefs（7月10日更新）、マーケドリブン（11月26日）。英語は、Search Engine Land、Texta、Wistia（1月23日）、iPullRank（11月18日更新）、AltText.ai（6月15日）、Digiday（9月23日）と、OtterlyAIの調査の元の記事です。

「AIは画像や動画を見ているのではなく、周りの文字を読んでいる」「動画は文字起こしが大事」という方向はほぼ共通でした。一方で、次の点はあまり書かれていませんでした。

足りない点この記事で書いていること
「◯倍引用されやすい」などの数字に、調べ方が書かれていないものがある調べ方が公開されている調査（Googleの説明、OtterlyAIの1億件超の調査）の数字だけを使い、分からないことは分からないと書く
YouTubeの話と、自社サイトの画像・動画の話が分かれていない「自社サイトの画像」「自社サイトの動画」「YouTube」に分けて手順を書く
店や会社のサイトでよくある画像（料金表・メニュー・地図・施工事例）ごとの扱いがない画像の種類ごとに、代替テキストに書くことと、本文に書くことを表にした
WordPressでどこに書くかがないメディアライブラリ・画像ブロック・埋め込みブロック・アイキャッチでの手順と、VideoObjectを足すコード
直したかどうかの確かめ方がない代替テキストの抜けと、画像の中だけにある事実を見つけるコマンド

答え：AIは画像と動画から何を受け取っているか（分かっている範囲）

分かっていること出典サイトでやること
Googleは、画像の内容を代替テキスト・画像認識・ページの内容を合わせて理解する。代替テキストは画像の情報の中でいちばん大事、と説明しているGoogle：画像SEOのベストプラクティス（2026年3月2日更新）意味のある画像には、何が写っているかが分かる代替テキストを付ける
Googleは <img> の src にある画像を見つけるが、CSSの背景画像は索引に入れない同上大事な写真を背景画像にしない
ChatGPT・Claude・Perplexityの主なクローラーはJavaScriptを実行しない。CSSの ::before・::after の文字はテストした6つのAIのどれにも読まれなかったVercel（2024年12月）、Writesonic（2026年3月）後から読み込む画像ギャラリーや装飾の中に事実を置かない
ChatGPTやPerplexityが、検索のときにページの画像の中の文字を読み取っているかどうかは、各社の説明に書かれていない（各社の公開情報で確認できず）画像の中の料金・時間・条件は、読まれない前提で本文にも書く
Googleは、<video>・<embed>・<iframe>・<object> で置かれた動画を見つける。1本の動画を見せるのが主な目的のページ（再生ページ）を作るよう勧めているGoogle：動画SEOのベストプラクティス大事な動画は、その動画のためのページを作る
YouTubeの引用の多くはPerplexity（38.7%）とGoogleのAI Overviews（36.6%）・AI Mode（19.6%）で、ChatGPTは4.4%だったOtterlyAI（2026年3月2日、6つのAI・30日間・1億件超の引用）YouTubeに出す動画も、説明欄に要点を文字で書く

まとめると、どのAIにも確実に届くのは、ページの最初のHTMLに入っている文字です。画像や動画は、その文字を補うものとして考えるのが安全です。

自社サイトの画像：種類ごとに、代替テキストと本文に書くこと

すべての画像に長い代替テキストを付ける必要はありません。飾りの画像は代替テキストを空（alt=""）にし、意味のある画像に、何が写っているかを短く書きます。料金や時間などAIに答えてほしい事実は、代替テキストではなく本文に書くのが基本です。

画像の種類代替テキストに書くこと（例）本文にも書くこと
料金表・メニュー表の画像「カットとカラーの料金表（税込み）」など、何の表か表の中身をすべて。WordPressならテーブルブロックで書く
商品・料理の写真「季節の野菜のランチプレート（スープ付き）」名前・価格・量・アレルギーなど
施工事例・作例の写真「築30年の戸建て、浴室をユニットバスに交換した後」工事の内容・期間・費用の目安・地域
地図・アクセスの図「駅の東口から店までの道順の図」住所・駅からの道順・駐車場の台数と場所
グラフ・図解「2025年と2026年の問い合わせ件数の比較のグラフ」グラフの数字を本文か表に。出典と時期も
スタッフ・院長の写真「院長 山田太郎」名前・資格・経歴（人物のページの作り方）
ロゴ会社名・店名（会社名は本文と構造化データに入っていればよい）
飾り・背景・区切りの画像空にする（alt=""）なし

代替テキストは、目の見えない方が画面読み上げで聞くための文でもあります。キーワードを並べるのではなく、写真を見ていない人に一言で伝える文にしてください。Googleも、代替テキストにキーワードを詰め込むことを悪い例として挙げています（Google：画像SEO）。

画像で、ほかに整えること

  1. キャプション：写真の下に一文を付けると、本文の一部として読まれます。施工事例なら「工期5日・費用は約80万円（税込み）」など、事実を入れます。
  2. ファイル名：「IMG_0023.jpg」より「bathroom-unit-after.jpg」のように、何の画像かが分かる名前にします（Googleも説明的なファイル名を勧めています）。
  3. 画像の近くに説明の文章を置く：Googleは、画像の周りの文章やキャプションからも内容を読み取ると説明しています。
  4. ページの代表の画像：Googleは、og:image や構造化データの画像から、ページを代表する画像を選ぶと説明しています。ロゴや文字ばかりの画像ではなく、内容が分かる写真を設定します。
  5. 形式とサイズ：Googleが対応している形式は BMP・GIF・JPEG・PNG・WebP・SVG・AVIF です。srcset や picture を使うときも、通常の src を残します。

自社サイトの動画：要約と文字起こしをページに書く

YouTubeの動画を埋め込んでも、その動画の字幕や説明欄の文字は、あなたのページのHTMLには入りません。埋め込みは iframe で、中身はYouTubeのページにあるからです。動画で伝えている事実を自社のページでも読んでほしいなら、動画の下に文字で書きます。

  1. 大事な動画（初めての方への流れ、施術・工事の説明、商品の使い方など）は、その動画のためのページを作る。Googleは、1本の動画を見せることが主な目的のページを「再生ページ」と呼び、作るよう勧めています。動画を紹介するブログ記事は再生ページには当たりません（Google：動画SEO）。
  2. 動画の下に、3〜5行の要約を書く。料金・所要時間・対象・注意点など、動画の中で言っている事実を文章にします。
  3. その下に文字起こしを載せる。YouTubeの自動字幕を元にしてもよいですが、店名・商品名・数字の聞き間違いを必ず直します。長い場合は「詳細」ブロックなどで開閉にしても、文字がHTMLに入っていれば読まれます（JavaScriptとAIのクローラー）。
  4. 動画に料金や電話番号のテロップを出しているなら、その数字が本文にもあるか確かめる。動画の中だけの文字は、読まれない前提で考えます。
  5. VideoObject の構造化データを付ける。Googleが必須としているのは name（題名）・thumbnailUrl（サムネイル）・uploadDate（公開日）で、description・duration・embedUrl なども勧めています（Google：動画の構造化データ）。YouTubeなど他社のプレーヤーを使う場合も、構造化データは勧められています。
  6. 見どころの時刻（キーモーメント）を伝えたい場合は、Clip の構造化データか、YouTubeの説明欄の時刻を使う。Clip はGoogle検索のすべての言語で、YouTubeの説明欄の時刻もすべての言語で使われます。

YouTubeに出す動画：説明欄とチャプター

OtterlyAIは、ChatGPT・AI Overviews・AI Mode・Perplexity・Copilot・Gemini の6つで、30日間に集めた1億件を超える引用を調べ、YouTubeの動画が引用されるときの傾向をまとめています（OtterlyAI：The YouTube Citation Study 2026、2026年3月2日）。

調査で分かったこと数字
引用されたYouTubeのうち、通常の長さの動画と、ショート動画94%と5.7%
引用された動画の長さ10〜20分が32.1%、5〜10分が26.1%、20分超が17.6%
再生回数・登録者数と、引用の多さの相関どちらも r = -0.03（ほぼ関係なし）
説明欄の長さと、引用の多さの相関r = 0.31（弱い〜中くらい）
引用された動画のうち、再生回数が1,000回未満のもの40.83%
時刻付きの引用が出たAIGoogleだけ（AI Overviews 73%・AI Mode 27%）

調査した側も、相関は原因を示すものではなく、すでに引用された動画だけを調べたので「最初に引用されるかどうか」より「繰り返し引用されるか」の傾向だ、と書いています。それでも、再生回数が少ない小さな店や会社の動画でも引用されうること、説明欄の文字が手がかりになりうることは、準備の方針として使えます。

説明欄には、動画で答えている質問と答えの要点、店名・地域・料金などの事実、自社サイトの該当ページのURLを書きます。チャプターを付けるときは、YouTubeの決まり（最初の時刻は 00:00、3つ以上を時刻の順に、1つのチャプターは10秒以上）に従います（YouTubeヘルプ：動画のチャプター）。字幕は自動字幕のまま使わず、固有名詞と数字を直しておきます。

WordPressでの手順

  1. 代替テキスト：メディアライブラリで画像を開き、「代替テキスト」欄に書きます。画像ブロックを選んだ右側の設定にも同じ欄があります。飾りの画像は空のままにします。
  2. キャプション：画像ブロックの下の「キャプションを追加」に、事実を一文で書きます。
  3. 料金表・メニュー：画像で作った表を載せている場合は、同じ内容をテーブルブロックでも書きます。画像は残してかまいません。
  4. 動画：YouTubeは「埋め込み」ブロック（YouTube）で置き、その下に段落ブロックで要約、「詳細」ブロックか段落で文字起こしを書きます。
  5. アイキャッチ：投稿・固定ページに内容の分かるアイキャッチ画像を設定します。無料のプラグインNurevo AEOは、アイキャッチがあれば、そのページの構造化データ（WebPage・BlogPosting）に image として入れます。WooCommerceの商品は、商品のメイン画像を入れます。
  6. VideoObject：Nurevo AEO は VideoObject を自動では出しません。動画のページに足したい場合は、次のように開発者向けのフィルター webmcp_canary_schema_graph で追加できます。Yoast SEO・Rank Math・AIOSEO・SEO SIMPLE PACK・VK All in One Expansion Unit と一緒に使っても、構造化データは重複しません。動画用のプラグインやSEOプラグインがすでに VideoObject を出している場合は、二重にしないでください。
<?php
// 動画を載せた固定ページ（ID 123）に VideoObject を足す例。
// 子テーマの functions.php か、小さなプラグインに書きます。
add_filter('webmcp_canary_schema_graph', function (array $bundle) {
    if (!is_page(123)) {
        return $bundle;
    }
    $bundle['extra'][] = array(
        '@type'        => 'VideoObject',
        'name'         => '初めての方へ：カウンセリングから仕上げまで（6分）',
        'description'  => '予約から会計までの流れ、所要時間、料金に含まれるものを説明します。',
        'thumbnailUrl' => 'https://example.com/wp-content/uploads/2026/11/flow-thumb.jpg',
        'uploadDate'   => '2026-11-20T10:00:00+09:00',
        'duration'     => 'PT6M30S',
        'embedUrl'     => 'https://www.youtube.com/embed/XXXXXXXXXXX',
        'publisher'    => array('@id' => $bundle['org_id']),
    );
    return $bundle;
});

題名・説明・サムネイルのURL・公開日・長さ（PT6M30S は6分30秒）は、実際の動画に合わせて書き換えます。足したら、ページのソースで VideoObject が入っていることを確かめ、Googleのリッチリザルト テストで誤りがないかを見ます。

確かめ方

パソコンの「ターミナル」で、ページの画像と文字を確かめられます。料金表やメニューなど、画像の多いページで試してください。

# 1) ページの画像のうち、alt が無いもの・空のものを数える
URL="https://example.com/menu/"
curl -sS -L --compressed "$URL" -o page.html
echo "画像の数:   $(grep -o '<img[^>]*>' page.html | wc -l)"
echo "alt なし:   $(grep -o '<img[^>]*>' page.html | grep -vc 'alt=')"
echo "alt が空:   $(grep -o '<img[^>]*>' page.html | grep -c 'alt=""')"

# 2) alt の中身を一覧にする（「画像1」「IMG_0023」などが無いか見る）
grep -o '<img[^>]*>' page.html | grep -o 'alt="[^"]*"' | sort | uniq -c | sort -rn | head -30

# 3) 画像に入れていた料金や時間が、本文の文字にもあるか
for WORD in "カット 4,400円" "最終受付 19:00" "駐車場 3台"; do
  if grep -qF "$WORD" page.html; then echo "あり  $WORD"; else echo "なし  $WORD"; fi
done

# 4) 動画のページに、要約・文字起こし・VideoObject が入っているか
grep -c 'VideoObject' page.html
grep -o '<iframe[^>]*youtube[^>]*>' page.html | head -5

「alt なし」が多いときは、メディアライブラリで代替テキストを入れます。「alt が空」は飾りの画像なら問題ありません。3で「なし」と出た事実は、画像や動画の中にしかない可能性が高いので、本文に書き足します。

コマンドを使わない場合は、ページを開いて右クリックの「ページのソースを表示」で、料金や時間を Ctrl＋F（Mac は Command＋F）で探します。画像の中にしかない文字は、ここでは見つかりません。

直したあとは、AIに同じ質問をして変化を見ます。1回の結果で判断せず、同じ質問を何度か、日を変えて測ってください（AIでの登場率の測り方）。Nurevo の Pro では、AIの回答に自社が出ているかを測れます（いまは Perplexity で計測、ベータ）。

チェックリスト

  1. 料金表・メニュー・営業時間の画像と同じ内容が、本文の文字（表）にもある
  2. 意味のある画像に、何が写っているかが分かる短い代替テキストがある
  3. 飾りの画像の代替テキストは空にしてある
  4. 代替テキストにキーワードを並べていない
  5. 施工事例・作例の写真に、事実の入ったキャプションがある
  6. 大事な写真を、CSSの背景画像や後から読み込むギャラリーだけに置いていない
  7. 大事な動画には、その動画のためのページがあり、要約と文字起こしが本文にある
  8. 動画のテロップの料金・電話番号が、本文にもある
  9. 動画のページに VideoObject（name・thumbnailUrl・uploadDate）がある
  10. YouTubeの説明欄に要点と自社ページのURLがあり、チャプターは決まりに沿っている

よくある質問

ChatGPTやPerplexityは、ページの画像の中の文字を読みますか？

各社の公開情報には書かれておらず、分かりません。ChatGPTは送った画像を読み取れますが、検索のときにページの画像まで読むかは別の話です。料金や時間などの事実は、読まれない前提で本文にも書いてください。

すべての画像に代替テキストを付けるべきですか？

意味のある画像には付け、飾りの画像は空にします。全部を埋めると、画面読み上げで聞く人にとって邪魔になり、大事な画像の説明も目立たなくなります。

代替テキストは何文字くらいがよいですか？

決まった文字数はありません。写真を見ていない人に一言で何の写真かが伝わる長さにします。料金などの細かい事実は、代替テキストではなく本文に書きます。

YouTubeに動画を出していれば、自社サイトに載せなくてもよいですか？

YouTubeの動画も引用されることがありますが、そのときの出典はYouTubeのページです。自社のページを出典にしてほしいなら、自社サイトにも動画のページを作り、要約と文字起こしを書いてください。

再生回数が少ない動画でも引用されますか？

OtterlyAIの調査では、引用された動画の40.83%が再生回数1,000回未満でした。再生回数より、何の質問に答えている動画かが文字で分かることが大事だと考えられます。ただし、引用されることを保証するものではありません。

ショート動画は作らないほうがよいですか？

OtterlyAIの調査では引用の94%が通常の長さの動画でしたが、ショート動画を作る意味がないとまでは言えません。AIの引用を狙うなら、質問に答える数分以上の動画を優先し、ショートは別の目的で使うのが無理のない分け方です。

VideoObject を付ければ、AIの回答に動画が出ますか？

保証はできません。VideoObject はGoogleが動画を理解する手がかりで、ほかのAIがどう使うかは公開されていません。要約と文字起こしを本文に書くことのほうが、どのAIにも届きやすい準備です。

画像や動画の多いページを、AIに読める形に

無料のチェックは登録不要です。URLを入れると、構造化データ・llms.txt・AIのクローラーの扱いを確かめられます。WordPressなら、無料のプラグインでアイキャッチ画像も含めた構造化データを出せます。
