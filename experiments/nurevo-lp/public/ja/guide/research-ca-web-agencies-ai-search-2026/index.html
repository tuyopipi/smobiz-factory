カナダのWeb制作会社の自社サイト908件に見るAI検索への対応（2026年11月）

カナダのWeb制作会社の自社サイト908件のトップページ・robots.txt・llms.txt を調べたところ、llms.txt があったのは22.9%（208件）で、米国（23.1%）・英国（21.5%）・オーストラリア（24.3%）とほぼ同じ、日本（13.4%）の1.7倍でした。AI検索に関わる6項目をすべて満たすサイトは18.9%で、米国と同じ値です。robots.txt でAIボットをブロックしていたのは3.5%で、GPTBot をブロックしていた19件はすべて ChatGPT の検索用ボット（OAI-SearchBot）をブロックしていませんでした。

公開：2026年11月22日。データ：2026年11月12日集計。調査・執筆：Nurevo AEO（Bestie.合同会社）。Nurevo はAI検索対策（AEO）のツールと WordPress プラグインを提供しており、この分野に利害があります。国別レポートの5本目です（これまでに米国・英国・オーストラリア・インド）。英語版とフランス語版もあります。

要点

  1. カナダのWeb制作会社の自社サイト908件のうち、llms.txt があったのは22.9%（208件）。米国（23.1%、p=0.95）・英国（21.5%、p=0.52）・オーストラリア（24.3%、p=0.45）と差は見られず、日本（13.4%）の1.7倍でした（p<0.001）。
  2. AI検索に関わる6項目をすべて満たすサイトは18.9%（172件）で米国と同じ値、6項目の平均は3.58でした。到達100件以上の17か国の中では llms.txt が12位で、英語圏の米国・英国・オーストラリアと同じ中位にいます。
  3. robots.txt があるサイト660件のうち、AIボットをブロックしていたのは3.5%（23件、米国4.3%・日本1.3%）。GPTBot をブロックしていた19件はすべて OAI-SearchBot を許可しており、検索用・質問時の取得に使われる4つのボットのどれかをブロックしていたのは1件（0.2%）でした。

調査概要

  1. 対象：Web制作会社の自社サイト。当社の収集リストで国がカナダとなっている制作会社サイト1,335件のうち、トップページに到達できた908件です。一般企業のサイト全体ではありません。比較には同じ調査の米国（4,472件）・英国（942件）・オーストラリア（1,719件）・日本（2,486件）・カナダ以外の海外（12,444件）を使いました。
  2. 取得したもの：各サイトのトップページ、/robots.txt、/llms.txt、/llms-full.txt を1回ずつ（User-Agent：NurevoSurvey/1.0）。2026年11月上旬〜12日に取得し、11月12日に集計しました。
  3. 判定方法：llms.txt は、ステータス200で中身がHTMLではなく20文字を超えるテキストを「あり」としました。JSON-LD はトップページにあるかどうか、「壊れている」は JSON として読み込めないブロックが1つ以上あるもの。Organization系は @type に Organization・LocalBusiness・Corporation・ProfessionalService を含むもの。WordPress はトップページのHTMLに wp-content/・wp-includes/、または generator の WordPress 表記があるもの。SEOプラグインはトップページのHTMLの文字列で判定しました。
  4. AIボットのブロック：robots.txt で、各ボットに当てはまるグループの規則がトップページ（/）を Disallow にするか（最長一致）で判定しました。分母は robots.txt があるサイトです。「AIボットをブロック」は GPTBot・ClaudeBot・PerplexityBot・Google-Extended・CCBot・OAI-SearchBot のどれかをブロックしているものです。
  5. 「6項目」は、(1) llms.txt がある、(2) JSON-LD がある、(3) Organization または LocalBusiness の型がある、(4) robots.txt があり GPTBot・ClaudeBot・PerplexityBot・OAI-SearchBot のどれもブロックしていない、(5) meta description がある、(6) canonical がある、のうち当てはまる数（0〜6）です。この調査のための単純な数で、Nurevo の0〜100点のスコアとは別物です。
  6. HTTP 202：カナダでトップページがステータス202を返したのは122件（到達件数の13.4%）で、米国（15.0%）・英国（14.9%）・オーストラリア（14.5%）と近い割合です。202のページはほとんどの項目が「なし」になります。ステータス200のサイト（786件）だけで見ると、llms.txt は26.5%、「6項目すべて」は21.9%、JSON-LD は78.6%で、米国の200のサイト（27.2%・22.3%）とも差は見られませんでした（p=0.73・p=0.85）。
  7. 統計：カナダと他の地域の差はカイ二乗検定で確かめました。30件未満の区分は載せていません。

結果：カナダと米国・英国・オーストラリア・日本の比較

カナダの値は、ほとんどの項目で米国・英国・オーストラリアと1〜3ポイント以内でした。llms.txt・「6項目すべて」・JSON-LD・AIボットのブロックのどれも、米国・英国・オーストラリアとの間に統計的な差は見られません。FAQPage（8.0%）は米国（6.2%）よりわずかに高い値でした（p=0.048）。カナダ以外の海外全体（llms.txt 26.6%・6項目すべて22.0%）と比べると、llms.txt と「6項目すべて」はやや低い値です（p=0.016・p=0.034）。日本と比べると、llms.txt は1.7倍、「6項目すべて」は1.8倍で、JSON-LD は同じくらい（68.1%・69.4%、p=0.47）でした。一方、meta description（67.3%・90.7%）・canonical（71.3%・84.6%）・robots.txt（72.7%・91.8%）は日本が高く、これには202を返すサイトや WordPress 以外のサイトの割合の違いが関わっています。

ブロックの中身（事実）

  1. GPTBot をブロックしていた19件は、すべて OAI-SearchBot をブロックしていませんでした。米国は128件中119件、英国は28件中28件、オーストラリアは56件中55件です。
  2. 上の11種のAIボットのどれかをブロックしていた25件のうち15件（60.0%）は、GPTBot・ClaudeBot・anthropic-ai・Google-Extended・CCBot・Bytespider・Applebot-Extended の7つをまとめてブロックする同じ組み合わせでした（米国58.5%・英国77.1%・オーストラリア64.6%）。
  3. OAI-SearchBot・ChatGPT-User・Claude-SearchBot・PerplexityBot のどれかをブロックしていたのは1件（robots.txt があるサイトの0.2%）でした。
  4. robots.txt でAIボットの名前を挙げていながら、どれもトップページをブロックしていないサイトが41件ありました（robots.txt があるサイトの6.2%、米国4.4%）。
  5. AIボットをブロックしていた23件のうち8件（34.8%）には llms.txt もありました（米国34.0%）。

  4. SEOプラグインはHTMLの文字列による判定で、痕跡を消している場合や複数入っている場合は正しく分けられません。
  5. 今回の集計の一部には11月5日集計時の取得分を引き継いでいます。

当社の見方（意見）

ここからは事実ではなく当社の意見です。カナダの制作会社サイトは、llms.txt・構造化データ・AIボットの扱いのどれも米国・英国・オーストラリアとほとんど同じで、英語圏の制作会社がよく似た道具（WordPress と Yoast SEO・Rank Math など）を使っていることの表れかもしれません（この調査では因果は確かめていません）。AIボットのブロックは少数で、ブロックしているサイトも学習用のボットに限っており、検索用のボットまで止めていたのは1件だけでした。どのボットを止めるかは各社の判断です。WordPress 以外のサイトでは、llms.txt や構造化データがほとんど見つかりませんでした（202を除いても llms.txt 5.9%）。どれを整えてもAIの回答に出ることが保証されるわけではありません（別の調査では、サイト側の項目と登場の間に関係は見られませんでした）。

自社やお客様のサイトを確かめる

無料チェックで、llms.txt・構造化データ・AIクローラーの許可状況を1分ほどで確認できます。WordPress なら Nurevo WebMCP プラグインで llms.txt を出し、会社の事実を構造化データに加えられます。お客様のサイトにまとめて入れたい制作会社の方はパートナー制度をご覧ください。

よくある質問

カナダの制作会社のAI検索への対応は米国と違いますか？

ほとんど同じでした。llms.txt はカナダ22.9%・米国23.1%、「6項目すべて」はどちらも18.9%で、AIボットのブロック率（3.5%・4.3%）にも統計的な差は見られませんでした（2026年11月、Web制作会社の自社サイト）。

日本と比べるとどうですか？

llms.txt は日本（13.4%）の1.7倍、「6項目すべて」は日本（10.4%）の1.8倍でした。JSON-LD は同じくらい（68.1%・69.4%）で、meta description・canonical・robots.txt は日本のほうが高い値でした。

カナダではAIクローラーをブロックしているサイトが多いですか？

robots.txt があるサイトの3.5%（23件）で少数です。ほとんどは学習用のボットで、検索用・質問時の取得に使われる4つのボットのどれかをブロックしていたのは1件だけでした。
