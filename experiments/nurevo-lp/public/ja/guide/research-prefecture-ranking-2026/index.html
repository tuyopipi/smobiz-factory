都道府県別に見たAI検索対応：国内Web制作会社の自社サイト2,098件を調査（2026年11月）

所在地が分かる国内Web制作会社の自社サイト2,098件を都道府県別に集計したところ、到達件数が30件以上ある23都道府県では、AI検索に関わる6項目の平均は3.69（京都府）〜4.38（広島県）、llms.txt の導入率は5.9%（新潟県）〜22.5%（広島県）でした。ただし1都道府県あたりの件数が少なく、この差は統計的にははっきりしません（カイ二乗検定 p＝0.36）。地方別では、llms.txt は11.8〜15.0%の範囲に収まりました。

公開：2026年11月16日。データ：2026年11月12日集計。調査・執筆：Nurevo AEO（Bestie.合同会社）。Nurevo はAI検索対策（AEO）のツールと WordPress プラグインを提供しており、この分野に利害があります。

要点

  1. 到達件数30件以上の23都道府県で、6項目の平均がいちばん高かったのは広島県（4.38、40件）、次いで岐阜県（4.36、50件）、神奈川県（4.35、80件）。いちばん低かったのは京都府（3.69、39件）でした。国内全体の平均は4.05です。
  2. llms.txt の導入率は、広島県22.5%（40件中9件）、北海道20.9%（129件中27件）、岐阜県18.0%（50件中9件）が高く、新潟県5.9%（34件中2件）、沖縄県6.1%（33件中2件）、福岡県7.0%（57件中4件）が低めでした。
  3. ただし都道府県による差は統計的にははっきりしません（23都道府県の比較で、llms.txt は p＝0.36、5項目以上の割合は p＝0.56、JSON-LD は p＝0.79）。6つの地方で比べても llms.txt は11.8〜15.0%（p＝0.90）で、東京都（16.4%）と東京都以外（12.8%）の差も数ポイントでした。

調査概要

  1. 対象：Web制作会社の自社サイト。国内では制作会社であることを確認できた3,352件で、そのうちトップページに到達できたのは2,486件。このうち当社の収集リストで所在地（都道府県）が分かる2,098件を都道府県別に集計しました（所在地不明は388件）。一般企業のサイト全体ではありません。
  2. 取得したもの：各サイトのトップページ、/robots.txt、/llms.txt、/llms-full.txt を1回ずつ（User-Agent：NurevoSurvey/1.0）。2026年11月上旬〜12日に取得し、11月12日に集計しました。
  3. 判定方法：llms.txt は、ステータス200で中身がHTMLではなく20文字を超えるテキストを「あり」としました。JSON-LD はトップページにあるかどうか、Organization系は @type に Organization・LocalBusiness・Corporation・ProfessionalService を含むもの。WordPress は、トップページのHTMLに wp-content/・wp-includes/、または generator の WordPress 表記があるもの。AIボットのブロックは、robots.txt で GPTBot・ClaudeBot・PerplexityBot・Google-Extended・CCBot・OAI-SearchBot のいずれかについて、トップページ（/）が Disallow になるか（最長一致）で判定し、分母は robots.txt があるサイトです。
  4. 「6項目」は、(1) llms.txt がある、(2) JSON-LD がある、(3) Organization または LocalBusiness の型がある、(4) robots.txt があり GPTBot・ClaudeBot・PerplexityBot・OAI-SearchBot のどれもブロックしていない、(5) meta description がある、(6) canonical がある、のうち当てはまる数（0〜6）です。この調査のための単純な数で、Nurevo の0〜100点のスコアとは別物です。
  5. 都道府県は収集リストの所在地で、「鹿児島県鹿児島市」のような市区町村つきの表記は都道府県にまとめました。到達件数が30件未満の24県は表に載せず、地方別の集計にだけ含めています。地方は、北海道・東北（7道県）、関東（7都県）、中部（新潟・富山・石川・福井・山梨・長野・岐阜・静岡・愛知）、近畿（三重を含む7府県）、中国・四国（9県）、九州・沖縄（8県）としました。

差はどのくらい確かか

1都道府県あたりの件数は30〜299件で、40件の県では1件の違いが2.5ポイントになります。そこで、都道府県ごとの割合の違いが偶然の範囲を超えるかをカイ二乗検定で確かめました。23都道府県の比較では llms.txt が p＝0.36、5項目以上の割合が p＝0.56、JSON-LD が p＝0.79、6つの地方の llms.txt は p＝0.90 で、いずれも「差がある」とは言えない水準でした。

つまり、このデータからは「どの都道府県の制作会社がAI検索への対応で進んでいるか」ははっきり言えません。ランキングは目安として読み、順位の上下を地域の実力差と受け取らないでください。

ほかに見えたこと（事実）

  1. AIボットを robots.txt でブロックしていたのは、どの都道府県でも0〜3件でした（国内全体で robots.txt がある2,281件中29件、1.3%）。
  2. 6項目の平均が低めだった京都府（76.9%）と宮城県（79.4%）は、WordPress の割合も低めでした。国内全体では WordPress のサイトの6項目の平均は4.2、WordPress 以外は2.1です（スコア分布の調査）。WordPress かどうかの違いが都道府県の値に表れている可能性がありますが、この調査ではそれ以上は確かめていません。
  3. 東京都（299件）と東京都以外（1,799件）を比べると、llms.txt は16.4%と12.8%、6項目の平均は4.16と4.02、5項目以上は55.5%と51.0%でした。

限界

  1. 対象はWeb制作会社の自社サイトで、一般企業のサイト全体ではありません。都道府県ごとの件数は当社の収集リストに載っている数で、その都道府県の制作会社の数や分布を表すものではありません（たとえば東京都は299件で、実際の事業者数の比率とは異なります）。
  2. 所在地は収集リストの記載によるもので、本社と制作拠点が違う会社や、記載の誤りがありえます。所在地不明の388件は都道府県別には入っていません。
  3. トップページだけを見ています。robots.txt はトップページ（/）に対する判定で、一部のディレクトリだけのブロックや、ファイアウォール・CDN によるブロックは数えていません。llms.txt は有無だけを見て、中身の質は見ていません。
  4. 各サイト1回の取得で、到達できなかったサイトは除いています。今回の集計の一部には11月5日集計時の取得分を引き継いでいます。
  5. 件数が30〜299件と少なく、順位は数件の違いで入れ替わります。統計的な検定でも、都道府県の差ははっきりしませんでした。

当社の見方（意見）

ここからは事実ではなく当社の意見です。今回のデータでは、AI検索への対応は「どこにある制作会社か」より、「個々のサイトで何をしているか」の違いのほうが大きいように見えます。都道府県や地方の平均で比べるより、自社やお客様のサイトで llms.txt・構造化データ・canonical などが抜けていないかを1つずつ確かめるほうが役に立つと考えます。どれを整えてもAIの回答に出ることが保証されるわけではありません（別の調査では、サイト側の項目と登場の間に関係は見られませんでした）。
