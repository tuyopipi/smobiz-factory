メディア掲載ページの作り方：AI検索と読者に、第三者の報道を正しく見つけてもらう手順

AIの回答の出典は、新聞・専門誌・比較記事など、お金を払っていない第三者のページが大半を占めるという調査があります。自社サイトの「メディア掲載」ページは、それ自体が第三者の評価になるわけではありませんが、媒体名・日付・見出し・元の記事へのリンクを1か所にまとめることで、AIと読者が独立した報道にたどり着く入り口になります。記事の画像を貼らずにリンクで紹介し、お金を払って載せた記事は「広告」とわかるように分けることが前提です。

作成日：2026年11月25日（日本時間）。調査の数字は Muck Rack（2025年12月・2026年5月）と BuzzStream（2026年3月）の公開資料、著作権とステルスマーケティングの規制は日本新聞協会・消費者庁の資料と業界紙の記事を同日に読んで確認しました。

メディア掲載のページを作っても、AIの回答に会社が必ず出る・順位が上がるということはありません。AIの回答は日々変わり、出典の選び方も公表されていません。この記事は、すでにある報道を正しく、規則を守って見せるための手順です。

AIは何を出典にしているか：3つの調査

「アーンドメディア（お金を払わずに得た掲載）がAIの出典の多くを占める」という話はよく引用されますが、調査によって数え方が大きく違います。主な3つを並べます。

調査対象わかったこと
Muck Rack「What Is AI Reading?」2026年5月2,500万件超のリンク、ChatGPT・Claude・Gemini、17業種アーンドメディアが約84%、そのうち報道（ジャーナリズム）は全体の約27%。広告・記事広告は0.3%。日付のわかる報道の引用の57%は直近12か月の記事
Muck Rack「What is AI Reading?」2025年12月100万件超のリンク、2025年7〜12月、Gemini・Perplexity・Claude・ChatGPT報道は25%弱、アーンドメディアは82%。プレスリリースは1.2%から約6%に増えた
BuzzStream（2026-03-09、04-08更新）約400万件の引用、3,600の質問、10業種、2026年1月27日から1週間、ChatGPT・GoogleのAIモード・AIによる概要・Geminiニュース媒体は引用の14.09%。ブランドを知る質問では7.26%、くらべて選ぶ質問では約18%。通信社の配信サイトは全体の0.21%、企業自身のプレスリリース・ニュースルームは全体の2.98%（ChatGPTでは18.15%）

出典：Muck Rack 2026年5月）、Muck Rack 2025年12月、BuzzStream。いずれも自社の製品を売る会社の調査で、Muck Rack の2026年5月版は Perplexity を含みません。BuzzStream の質問は大手ブランドが中心で、ChatGPTの18.15%が何を母数にした数字かは明記されていません。日本語の質問での割合を示した調査は見つかりませんでした。

「アーンドメディアは25%」という見出しの発表もありますが（LeadCoverage の発表）、Muck Rack の元の資料では25%弱は報道だけの割合で、アーンドメディア全体は82%です。数字を引用するときは元の資料まで確かめてください。

3つの調査から言えるのは、①AIは広告よりも第三者の記事を出典にしやすい、②その中で報道が占めるのは一部で、比較記事や口コミ、業界のサイトなども多い、③くらべて選ぶ質問ほど報道が使われやすい、という傾向までです。

自社のメディア掲載ページは何の役に立つか

自社サイトに「〇〇新聞に掲載されました」と書いても、それは会社自身の発信で、独立した評価にはなりません。役に立つのは次の3つです。

  1. 入り口になる：媒体名・日付・見出し・URLがそろっていれば、AIの検索や読者、記者、Wikipediaの編集者が元の記事にたどり着けます。
  2. 事実をそろえる：記事に書かれた会社名・所在地・商品名が古くなっていても、掲載ページに「当時」の事実と今の事実を並べておけば、混同を防げます。
  3. 確かめられる形にする：「テレビで話題」のような書き方は確かめようがありません。番組名と放送日があれば、AIも読者も裏付けを探せます。

BuzzStream の調査では、ChatGPTで企業自身のニュースルームが出典になる割合が他のAIより高く出ています。自社のページも読まれる可能性はありますが、中身が報道の一覧であることが前提です。

3つの置き場所の役割

置き場所書く人AIにとっての意味注意
第三者の記事（新聞・専門誌・Web媒体）媒体の記者・編集者独立した情報源。くらべる質問で使われやすい内容は会社が決められない
プレスリリース（自社のお知らせ・配信サービス）会社会社自身の発表として読まれる。事実の一次情報配信しただけでは報道にはならない
自社のメディア掲載ページ会社第三者の記事への入り口と、事実の対照表記事のコピーや誇張をしない

1件ごとに書く8つの項目

日本新聞協会のQ&Aは、記事を紹介する検索サービスについて、媒体名・日付・見出し・ごく短い抜粋・URLを表示し、元の記事へのリンクを付けることが重要だとしています（検索サービス向けの資料ですが、紹介の形の目安になります。日本新聞協会）。自社のページでは、次の8項目を文字で書きます。

項目書き方の例理由
媒体名〇〇新聞（朝刊・地域面）どこが書いたかが独立性の判断材料
掲載日・放送日2026年9月14日AIは新しい報道を多く引用する傾向
見出し・番組名記事の見出しをそのまま検索で元の記事を見つけるため
種類取材記事／インタビュー／寄稿／テレビ／ラジオ読者が中身を想像できる
区分取材／広告・タイアップ／プレスリリースの転載広告を報道と混ぜないため
取り上げられた内容新しい工場の稼働と地元雇用について（自分の言葉で1文）記事の文章を写さずに要点を伝える
リンク元の記事のURL（紙面だけの場合は「紙面のみ」）裏付けにたどり着ける
補足記事中の所在地は移転前のものです古い事実との混同を防ぐ

新しい順に並べ、年ごとに見出しを付けると、AIにも読者にも読みやすくなります。リンクが切れた記事は、消さずに「掲載元で公開終了」と書いて残します。

やってはいけないこと：著作権とステルスマーケティング

  1. 記事の画像・スキャン・スクリーンショットを貼らない：コピー、スキャン、撮影、ネット記事のコピー＆ペースト、画面の印刷は複製にあたり、原則として著作権者の許諾が必要です。社内のイントラネットへの掲載でも、2023年の判決で日本経済新聞に約696万円、中日新聞に約133万円の支払いが命じられています（アドタイ 2026-07-03）。載せたい場合は媒体に転載の許諾を申し込みます。
  2. 記事の文章を長く写さない：要点は自分の言葉で1〜2文にまとめ、詳しくは元の記事へのリンクで読んでもらいます。
  3. 媒体のリンクの決まりを確かめる：媒体によっては、リンクの方針で商品の宣伝などの商用利用を断っている場合があります（日本新聞協会のQ&A）。媒体のロゴを並べる場合も、許可を取ってからにします。
  4. お金を払った記事は「広告」と書く：2023年10月1日から、一般の消費者が広告と気づけない広告は景品表示法違反です。対象には新聞・雑誌・テレビ・ラジオ・SNSも含まれ、責任を負うのは広告主の事業者です（消費者庁）。記事広告・タイアップ記事を掲載実績に並べるなら、「広告（タイアップ）」と区分を書き、取材記事と分けます。
  5. 記事広告から自社へのリンクは、媒体側で rel="sponsored" などを付けるようGoogleは求めています（Google：外部リンクの属性）。掲載を頼むときに確かめておきます。
  6. 誇張しない：「各メディアで話題」「テレビで紹介多数」のように、確かめられない書き方は避け、1件ずつ事実で書きます。

構造化データ：見えている一覧だけをマークアップする

schema.org では、会社（Organization）を取り上げた記事を subjectOf で、受賞を award（文字）で書けます。Googleのリッチリザルトの対象ではなく、AIがこの項目を使うと公表している会社もありません。書くなら、ページに見えている一覧と同じ内容だけにします。Googleの構造化データのガイドラインは、ページで見えない内容をマークアップしないよう求めています（Google：構造化データの一般的なガイドライン）。

<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "Organization",
  "@id": "https://example.co.jp/#organization",
  "name": "株式会社サンプル",
  "url": "https://example.co.jp/",
  "award": "第10回 地域ものづくり大賞 優秀賞（2025年）",
  "subjectOf": [
    {
      "@type": "NewsArticle",
      "headline": "（記事の見出しをそのまま）",
      "datePublished": "2026-09-14",
      "url": "https://news.example.jp/articles/12345",
      "publisher": { "@type": "Organization", "name": "（媒体名）" }
    }
  ]
}
</script>

見出しと日付は記事のとおりに書き、媒体の記事ではない広告は入れません。会社の構造化データ全体の整え方は会社概要ページのAI検索対策にあります。

WordPressでの手順

  1. 固定ページで「メディア掲載」（または「掲載実績・受賞」）を作り、URLを /media/ などの短い英字にします。画像のギャラリーではなく、表かリストで8項目を文字で書きます。
  2. プレスリリースは投稿（お知らせ）に、第三者の記事はこのページに、と置き場所を分けます。会社概要のページとフッターからこのページにリンクします。
  3. 外部の記事へのリンクは通常のリンクでかまいません。リンク切れはプラグインや定期的な目視で確かめ、切れたものに注記を付けます。
  4. Nurevo AEO（無料のWordPressプラグイン）の llms.txt は、最近更新した公開済みのページと投稿を30件まで並べます。掲載ページを長く更新しないと一覧から外れることがあるため、残したい場合はフィルター webmcp_canary_llms_txt_lines で「メディア掲載」の行を足します（下の例）。ページごとの設定で llms.txt から外すこともできます。
  5. subjectOf を会社の構造化データに足すときは、フィルター webmcp_canary_business_node を使います。Yoast SEO・Rank Math・All in One SEO・Slim SEO が有効な場合、値はそれらの会社の情報にまとめられ、プラグインがすでに出している値が優先されます。0.9.1 からは SEO SIMPLE PACK・VK All in One Expansion Unit と一緒に使っても構造化データは重複しません。
  6. 入れたら、/llms.txt とページのソース（application/ld+json）で、一覧と同じ内容が出ているかを確かめます。WordPress.orgで入手
// 掲載実績のページを、更新日にかかわらず llms.txt に載せる
add_filter('webmcp_canary_llms_txt_lines', function (array $lines) {
    $lines[] = '## メディア掲載';
    $lines[] = '';
    $lines[] = '- [メディア掲載・受賞](https://example.co.jp/media/): 媒体名・日付・見出し・元の記事へのリンクの一覧';
    $lines[] = '';
    return $lines;
});

確かめ方

  1. ChatGPT・Perplexity・GoogleのAIモードに「（社名）はどんな会社？」「（地域）で（業種）を選ぶならどこ？」「（社名）の評判は？」と聞き、答えと出典のURLを日付付きで記録します。
  2. 出典に出てきた記事が掲載ページにあるか、逆に掲載ページの記事がまったく出ないかを見ます。出典が古い記事ばかりなら、補足欄で今の事実を書き足します。
  3. Googleアナリティクス4で、掲載ページへのAIのサービスからの流入と、元の記事のサイトからの流入を見ます。Search Consoleでは社名の検索の変化を見ます。
  4. AIの回答は日によって変わるため、同じ質問を毎月同じ日に聞きます。決めた質問のセットで記録する方法はAIでの登場率の測り方にあります。
  5. Nurevo AEO の無料のAIチェックは、接続したサイトに月1回、業種と地域から作った3つの質問を Perplexity に聞きます。継続して測る Pro（月14,800円〜）も現在は Perplexity で測っています（ChatGPTは設定され次第）。

チェックリスト

  1. 掲載ページに、媒体名・日付・見出し・種類・区分・内容・リンク・補足を文字で書いた
  2. 記事の画像・スキャン・スクリーンショットを許諾なしに貼っていない
  3. 記事の文章を長く写さず、要点を自分の言葉で書いた
  4. お金を払った記事は「広告（タイアップ）」と区分を書いた
  5. プレスリリースと第三者の記事を分けて置いた
  6. 「話題」「多数」など確かめられない表現を使っていない
  7. リンク切れの記事に注記を付けた
  8. 会社概要とフッターから掲載ページにリンクした
  9. 構造化データを使うなら、見えている一覧と同じ内容だけにした
  10. AIへの質問と答え・出典を、日付を付けて記録した

制作会社が掲載実績の整理を保守に入れるには

多くのお客様のサイトには、紙面の写真を並べただけの「メディア掲載」ページがあります。保守の作業として、①写真の一覧を8項目の文字の表に直す、②広告と取材を分ける、③許諾のない画像を外してリンクに替える、④四半期ごとに新しい掲載とリンク切れを確かめる、を提案すると、作業の範囲が説明しやすくなります。

記事広告を「報道」と書いてほしい、ランキングサイトに有料で載せたいといった依頼の判断と断り方はAI検索の不正な手法を頼まれたらにまとめています。AI検索の整備を月額の保守に入れる方法はパートナーのページをご覧ください。

よくある質問

メディア掲載ページを作れば、AIに出やすくなりますか？

必ずとは言えません。AIが出典にしやすいのは第三者の記事そのもので、自社の掲載ページはその入り口です。媒体名・日付・見出し・リンクがそろっていれば、AIや読者が元の記事を見つけやすくなります。

新聞記事の写真を掲載ページに貼ってもいいですか？

原則として著作権者の許諾が必要です。スキャンや撮影、スクリーンショットも複製にあたります。許諾がなければ、媒体名・日付・見出しを文字で書き、元の記事にリンクしてください。

記事広告やタイアップ記事も掲載実績に載せていいですか？

載せることはできますが、「広告（タイアップ）」とわかるように書き、取材記事と分けてください。2023年10月から、広告と気づけない広告は景品表示法違反になり、責任は広告主にあります。

プレスリリースを配信すれば、メディア掲載になりますか？

なりません。配信サービスのページは会社自身の発表です。記者が取材して書いた記事が出て、はじめてメディア掲載です。掲載ページでもプレスリリースは別に分けます。

テレビやラジオの紹介はどう書けばいいですか？

局名・番組名・放送日・コーナー名と、紹介された内容を1文で書きます。見逃し配信や番組のページがあればリンクし、なければ「放送のみ」と書きます。番組の画面の写真は許諾なしに使わないでください。

古い記事は消したほうがいいですか？

消す必要はありません。新しい順に並べ、記事中の所在地や商品が今と違う場合は補足欄に今の事実を書きます。リンクが切れたら「掲載元で公開終了」と注記して残します。

構造化データは必須ですか？

必須ではありません。まずページに文字で一覧を書くことが大切です。schema.org の subjectOf などで書くこともできますが、Googleのリッチリザルトの対象ではなく、AIが使うと公表された項目でもありません。

まず、AIがあなたの会社のサイトを読めるか確認

登録不要の無料チェックで、会社の構造化データ、llms.txt、AI検索のクローラーの許可の状態がわかります。WordPressなら、Nurevo AEOで不足分を無料で整えられます。
