ハウスクリーニング・家事代行のAI検索対策：料金と追加料金、破損の補償、鍵の預かりをAIに正しく読ませる手順

ハウスクリーニングと家事代行のAI検索対策（AEO）で一番大事なのは、お客様が家に人を入れる前に気にすることを、サイトに文字で書いておくことです。具体的には、箇所ごと・時間ごとの税込みの料金と「追加料金がかかる条件」、作業中に物が壊れたときの補償と保険、鍵を預かるかどうかとその管理の仕方、スタッフの研修や資格、キャンセル規定です。そのうえで、対応エリアを市区町村名で書き、Googleビジネスプロフィールと構造化データ（HomeAndConstructionBusiness＋Service＋areaServed）に同じ事実を出します。

作成日：2026年11月25日（JST）。国民生活センター・厚生労働省・内閣官房・経済産業省のページは、本文に記したリンク先で2026年11月25日に確認しました。この記事は法的な助言ではありません。

AIの回答は日や聞き方によって変わります。この記事の対策は、AIがあなたのサービスの条件を正しく読める状態をつくるもので、AIの回答に必ず表示される・順位が上がることを保証するものではありません。水回りや鍵の緊急対応は緊急の住まいの修理のAI検索対策をご覧ください。

ハウスクリーニングと家事代行で、AIに聞かれることは違う

ハウスクリーニングは、エアコンや浴室などの箇所を、道具と洗剤を持ったスタッフが単発で掃除するサービスです。家事代行は、掃除・洗濯・料理などの家事を、時間単位で定期的に任せるサービスです。同じ会社が両方を出していることも多いのですが、お客様がAIに聞く質問は違うので、サイトではページを分け、それぞれの質問に答えます。

質問の例は、この記事の説明のための例です。実際の質問の頻度を調べたものではありません。
質問の型質問の例AIが答えに必要な事実
料金（ハウスクリーニング）「◯◯市でエアコンクリーニング、お掃除機能付きはいくら？」機種・台数ごとの税込み料金、追加料金の条件、作業時間の目安
料金（家事代行）「家事代行を週1回2時間頼むと月いくら？」1時間あたりの料金、最低の時間、交通費、契約期間、入会金の有無
補償「作業中に壊されたらどうなる？保険はある？」賠償責任保険の加入、補償の範囲と対象外、連絡の期限
鍵と留守「留守のあいだに来てもらえる？鍵は？」留守中の作業の可否、鍵の預かりの方法と記録、返し方
スタッフ「どんな人が来る？毎回同じ人？」雇用か委託か、研修、資格や認証、担当の固定の有無
キャンセル「前日にキャンセルしたら料金はかかる？」キャンセル料の時期と割合、日程変更の扱い

上位の解説記事に足りないこと

2026年11月25日に、日本語と英語で「ハウスクリーニング AI検索対策」「cleaning business AI search」などの上位記事を14本読みました。日本語ではuravationの記事が、料金を即答できる形で書くこと、損害保険と補償を載せること、対応エリアを市区町村で書くことを勧めていて、方向はこの記事と同じです。ただ、構造化データは名前を挙げるだけで、WordPressでの手順と、AIに出ているかの確かめ方はありません。サングローブの記事などの集客の解説は、SEO・MEO・チラシなどの手段の一覧が中心で、AI検索の具体的な手順はありませんでした。出典のない反応率や広告費の相場が書かれている記事も複数ありました。

英語では、MarchexやJobberが保険や身元確認を「信頼の材料」として載せることを勧め、eSEOspaceはGoogleのサービス提供地域の決まりを出典つきで説明しています。一方で、「口コミが50〜100件必要」のような出典のない基準を書いている記事もありました（Texta）。どの記事にも、追加料金のトラブルの公的な事例、鍵の預かりの具体的な決め方、キャンセル規定の書き方、WordPressでの設定はありませんでした。この記事は、これらを埋めます。

料金は「箇所ごとの税込み料金」と「追加料金がかかる条件」で書く

国民生活センターは2025年2月に、ハウスクリーニングのトラブルについて注意を呼びかけました。電話で5,000円と聞いて換気扇の掃除を頼んだところ、浴室・洗面所・トイレの掃除を次々に追加され、約60万円の契約になった事例や、エアコンの掃除で部品が壊れたあと業者と連絡が取れなくなった事例が紹介されています。消費者へのアドバイスは、複数の会社から見積もりを取ってサービス内容と料金を比べること、壊れたときの補償を契約前に確かめることです。国民生活センター：ハウスクリーニングのトラブルにご注意（2025年2月28日）

お客様が見積もりを比べ、AIが「いくらか」に答えるには、料金の本体だけでなく、何をすると追加になるかが文字で書かれている必要があります。消費者に前もって示す価格は、税込みの総額で書きます。

金額は説明のための例です。自分の実際の料金を書いてください。
書く項目書き方の例
箇所・機種ごとの料金壁掛けエアコン（お掃除機能なし）1台11,000円、お掃除機能付き19,800円（税込）
作業時間の目安1台90分前後。2台目からは1台あたり60分前後
追加料金の条件防カビ仕上げ1台1,650円。汚れの状態で追加になる作業は、作業前に金額をお伝えし、ご了承いただいてから行います
かからないもの出張費・駐車場代（対応エリア内）、洗剤・道具代はかかりません
家事代行の料金1時間3,300円（税込）、1回2時間から。交通費1回550円。入会金なし、定期は月4回から
総額の例お掃除機能なしのエアコン2台なら22,000円（防カビ仕上げなし）

料金を画像だけで出している場合は、同じ内容を本文に文字でも書きます。料金ページの書き方全般は料金ページのAI検索対策をご覧ください。

破損したときの補償：保険の有無、範囲、連絡の期限を書く

国民生活センターのアドバイスにあるとおり、お客様は「壊れたらどうなるか」を契約前に知りたいと考えています。AIに「保険に入っている業者は？」と聞かれたときに答えられるように、補償について次の項目を書きます。「万全の補償」のようなあいまいな言葉ではなく、条件を書くのがポイントです。

書き方は例です。補償の範囲や条件は、加入している保険の内容に合わせて書いてください。
書く項目書き方の例
保険の加入作業中の事故に備えて、賠償責任保険に加入しています（保険会社名は任意）
補償の範囲作業中に当社のスタッフがお客様の物を壊したり汚したりした場合
対象外作業前からあった不具合、経年劣化による故障、現金・貴金属など
連絡の期限作業後7日以内にご連絡ください。写真をいただくと手続きが早く進みます
作業前の確認エアコンは作業前に動作を確認し、気になる点があれば作業前にお伝えします

関連して、国民生活センターは2026年6月に、エアコンの修理のトラブルの相談が2021年度の451件から2025年度の1,251件に増えたと公表し、作業の前に内容と費用を確かめること、業者が帰る前に一緒に動作を確かめることを勧めています。国民生活センター：エアコン修理のトラブルに注意（2026年6月3日）。これは修理の話ですが、「作業前に金額を伝える」「帰る前に一緒に確認する」を自社の手順として書いておくことは、エアコンクリーニングでもお客様の不安に直接答えます。

鍵の預かりと留守中の作業：するか・しないか、どう管理するか

家事代行では「留守のあいだに来てもらえるか」がよく聞かれます。介護関連サービス事業協会の「生活支援サービス提供事業者が遵守すべきガイドライン」（2025年3月30日策定、経済産業省のサイトに掲載）は、掃除や洗濯などの家事支援も対象に含め、鍵はやむを得ない場合にだけ預かり、預かり証・マニュアル・持ち出しの記録で管理するよう求めています。ガイドライン（PDF）。主に高齢の利用者を念頭に置いたガイドラインですが、鍵の扱いを書くときの項目として参考になります。

  1. 留守中の作業を受けるか受けないかを、はっきり書きます（例：「初回は在宅をお願いしています。2回目以降は、鍵をお預かりして留守中に作業できます」）。
  2. 鍵を預かる場合は、預かり証を出すこと、保管の方法、持ち出しの記録、契約が終わったときの返し方を書きます。
  3. スマートロックやキーボックスを使う場合は、その方法と、暗証番号の扱いを書きます。
  4. 作業中の写真の撮影や、終わったあとの報告（チャット・メール）の有無を書きます。

スタッフ・資格・認証：あるものだけを、正確な名前で書く

ハウスクリーニングには、厚生労働省の技能検定の職種として「ハウスクリーニング」があり、合格するとハウスクリーニング技能士と名乗れます。厚生労働省のページでは、在宅の家屋や不動産物件を対象に、浴室・台所などや設備機器を清掃する職種と説明され、試験の案内は指定試験機関の公益社団法人全国ハウスクリーニング協会のサイトに案内されています。厚生労働省：ハウスクリーニング技能士

家事代行には、一般社団法人全国家事代行サービス協会が運営し、日本規格協会が審査する「家事代行サービス認証」があります。2016年に作られた第三者の認証で、安全・安心、サービスの品質、接遇の3つの観点で審査します。内閣官房 資料（PDF）。経済産業省の調査報告書によると、2025年1月末時点の認証事業者は19社です。経済産業省 令和6年度 調査報告書（PDF）

  1. 資格や認証は、持っているものだけを正式な名前で書きます。級、取得した人数、認証の取得日など、自社の事実を添えると、AIがそのまま答えに使えます。
  2. スタッフが社員か業務委託か、採用のときに何を確認しているか、研修の時間や内容を、言える範囲で書きます。
  3. 「毎回同じスタッフか」「スタッフを変えられるか」を書きます。家事代行では、とくによく聞かれます。
  4. スタッフの顔写真や名前を出す場合は、本人の同意を取ってから載せます。

キャンセルと日程変更：時期と割合で書く

「前日のキャンセルは料金がかかるか」に答えられるように、キャンセル料を時期と割合で書きます。上のガイドラインも、契約の前に解約・キャンセル料などの予定金額を示すよう求めていて、キャンセル料は事業者の損害を超えないこと（消費者契約法第9条）にも触れています。

時期と割合は説明のための例です。自分の実際の規定を書いてください。
決めて書くこと書き方の例
キャンセル料前々日まで無料、前日は料金の50%、当日は100%
日程変更前日の18時までなら無料で変更できます
家事代行の定期の解約解約は前月末までにご連絡ください。違約金はありません
天候や災害台風などで伺えない場合は、無料で日程を変更します

国民生活センターは、一定の要件にあてはまる場合にはクーリング・オフなどが使える場合があると案内しています。自宅で契約を結ぶ場合など、自社の契約にどの決まりがあてはまるかは、専門家に確認してください。規定は料金ページと予約ページに同じ文で書きます。予約の流れは予約ページのAI検索対策をご覧ください。

対応エリア：市区町村名で書き、Googleビジネスプロフィールとそろえる

ハウスクリーニングと家事代行は、お客様の家に行くサービスなので、「◯◯市に来てくれるか」に答えられるよう、対応エリアを市区町村名で書きます。エリア外の交通費の計算の仕方も書いておきます。店舗で客を迎えない場合、Googleビジネスプロフィールでは「サービス提供地域」のビジネスとして住所を表示しない決まりで、地域は最大20件、拠点から車でおよそ2時間を超えない範囲とされています。ビジネス名に地域名やサービス名を足すことは認められていません。Google：ビジネス情報のガイドライン・サービス提供地域の管理。くわしい設定は出張撮影のAI検索対策でも説明しています。

  1. サイトの対応エリア、Googleビジネスプロフィールのサービス提供地域、くらしのマーケットなどのポータルの対応地域を、同じ地域にします。
  2. 料金・補償・キャンセル規定も、ポータルとサイトで同じ内容にします。場所ごとに違うと、AIが古い情報を使うことがあります。
  3. フランチャイズの加盟店は、本部のサイトの店舗ページと自店のサイトで、エリアと料金が食い違わないようにします。

構造化データ：清掃の専用の型はない。HomeAndConstructionBusiness＋Service

構造化データは、本文に書いた料金・エリア・補償の写しとして使い、本文と同じ内容にします。構造化データだけに書いた事実は、お客様にもAIにも伝わりにくくなります。

WordPressのハウスクリーニング・家事代行サイトでの設定手順

  1. WordPress.orgからNurevo AEO（無料）をインストールして有効化します。Yoast SEO・Rank Math・All in One SEO・SEO SIMPLE PACK・VK All in One Expansion Unitなどはそのまま使えます（構造化データは重複しません）。
  2. 初回の設定ウィザードで「その他」を選び、設定画面の「業種（schema.org型）」に HomeAndConstructionBusiness と入力します。「専門サービス」を選ぶと ProfessionalService になるため選びません。
  3. 名前・電話番号・受付時間を入れます。店舗がなく住所を公開しない場合は、住所の欄を空のままにします。住所が空なら、Nurevo AEOは address を出力しません（AEOスコアの診断では住所が不足として数えられますが、公開しない方針なら空欄のままで構いません）。
  4. 箇所ごとのクリーニングと家事代行のプランを「サービス」に登録します（最大20件）。名前・時間（分）・料金・予約のURL・説明を入れ、説明に追加料金の条件を書きます。サービスは構造化データ（Service）とllms.txtに載ります。
  5. Nurevo AEOには対応エリア（areaServed）の入力欄がありません。構造化データにも入れたい場合は、下の webmcp_canary_business_node フィルターで足します。Yoast SEOなどが有効な場合は、そのプラグインがすでに出している値が優先されます。
  6. 補償・鍵の預かり・スタッフ・キャンセルの答えをよくある質問に入力し、Nurevo FAQブロック（または[nurevo_faq]ショートコード）を料金ページか予約ページに置きます。書き方はFAQページのAI検索対策をご覧ください。
  7. /llms.txt を開き、料金・エリア・補償・予約・よくある質問のページが載っているか確かめます。AEOスコアの画面で診断を実行し、不足を直します。
// テーマの functions.php か、子テーマ・コードスニペットのプラグインに追加します。
add_filter('webmcp_canary_business_node', function (array $node, array $settings) {
    $node['areaServed'] = array(
        array('@type' => 'City', 'name' => 'さいたま市'),
        array('@type' => 'City', 'name' => '川口市'),
        array('@type' => 'City', 'name' => '戸田市'),
    );
    return $node;
}, 10, 2);

WordPress以外のサイトでも、確かめる項目は同じです。登録不要の無料チェックにURLを入れると、構造化データ・llms.txt・AIクローラの許可の状態がわかります。

AIに出ているか、正しく答えているかを確かめる

整えたあとは、お客様が聞きそうな質問をAIに投げます。「◯◯市 エアコンクリーニング お掃除機能付き」「◯◯市 家事代行 週1回」のような地域＋サービスの質問で名前が出るかに加えて、自分の会社の名前を入れて「保険には入っている？」「キャンセル料は？」「留守中でも頼める？」と聞き、答えがサイトの事実と合っているかを見ます。古い料金や、やめたサービスが答えに出ていないかも確かめます。

AIの回答は回ごとに変わるので、同じ質問を期間をあけて何度か確かめ、結果を記録します。Nurevo AEOでは、Free・Standardプランでも月に1回、業種と地域から作った3つの質問（事業の名前は含めません）をPerplexityに投げ、回答に名前やサイトが出たかを記録します。Proプラン（月14,800円〜）では、ベータ版のAI登場率の計測で、競合との比較と推移を見られます（現在はPerplexity）。どちらも回答の一部を見本として調べるもので、すべての回答を見ているわけではありません。くわしくはAIでの登場率の測り方をご覧ください。

よくある質問

ハウスクリーニングのAI検索対策は、何から始めればいいですか？

まず、箇所ごとの税込み料金と、追加料金がかかる条件を料金ページに文字で書きます。次に、破損したときの補償と保険、キャンセル規定を書きます。そのうえで、対応エリアを市区町村名で書き、Googleビジネスプロフィールとそろえ、構造化データとllms.txtで出します。

ハウスクリーニングと家事代行は、同じページでいいですか？

ページを分けることをおすすめします。ハウスクリーニングは箇所ごとの単発の料金、家事代行は時間あたりの料金と定期の契約が中心で、お客様がAIに聞く質問も違います。会社の情報は1つにまとめ、サービスごとのページを分けます。

料金を高めに書くと、AIに紹介されにくくなりますか？

料金の高さで紹介されるかどうかが決まる、という公式の情報はありません。大事なのは、料金と追加料金の条件が正確に書かれていて、AIが条件つきで答えられることです。安さを強調した広告と実際の請求の違いは、国民生活センターが注意を呼びかけているトラブルの一つです。

構造化データの型は何にすればいいですか？

schema.orgに清掃や家事代行の専用の型はないので、HomeAndConstructionBusiness か LocalBusiness にし、箇所ごとのクリーニングや家事代行のプランを Service で表します。DryCleaningOrLaundry は衣類のクリーニング店の型です。

資格や認証がないと、AIに紹介されませんか？

資格や認証がないと紹介されない、という公式の情報はありません。持っている資格や認証は正式な名前で書き、ない場合は、研修の内容や補償の条件など、確かめられる事実を書きます。持っていない資格や認証を書かないでください。

この対策で、ChatGPTに必ず紹介されますか？

いいえ。AIの回答は変わるもので、どの道具や方法でも、表示や順位は保証できません。できるのは、料金・補償・鍵・キャンセルの事実をAIが読みやすい形で出し、出ているか・正しいかを確かめ続けることです。
