WordPress と WordPress 以外で比べたAI検索への対応：Web制作会社の自社サイト14,361件（2026年11月）

Web制作会社の自社サイトのうち、トップページが通常どおり（HTTP 200）返った14,361件を WordPress（12,376件）とそれ以外（1,985件）に分けて比べました。トップページに構造化データ（JSON-LD）があったのは WordPress で88.8%、それ以外で17.6%、llms.txt は29.6%と9.8%でした。一方、robots.txt でAIボットをブロックしていたのは WordPress 以外のほうが多く（13.3%と3.7%）、そのほとんどは学習用とされるボットでした。日本だけを見ても、WordPress 以外（191件）は JSON-LD 28.3%、robots.txt 45.0%で、WordPress（72.9%・95.6%）との差がはっきりしていました。

公開：2026年11月20日。データ：2026年11月12日集計。調査・執筆：Nurevo AEO（Bestie.合同会社）。Nurevo はAI検索対策（AEO）のツールと WordPress プラグインを提供しており、この分野、とくに WordPress に利害があります。WordPress サイトの中でのSEOプラグイン別の違いは別のレポートにまとめています。

要点

  1. Web制作会社の自社サイトで、トップページに JSON-LD の構造化データがあったのは WordPress で88.8%（12,376件中）、WordPress 以外で17.6%（1,985件中）。llms.txt は29.6%と9.8%、AI検索に関わる6項目をすべて満たすのは24.9%と4.7%でした。
  2. 日本の WordPress 以外のサイト（191件）は、JSON-LD 28.3%（WordPress 72.9%）、robots.txt 45.0%（同95.6%）、canonical 42.9%（同88.1%）、llms.txt 6.3%（同14.0%）。FAQPage だけは3.1%と3.9%で差が見られませんでした（p=0.73）。
  3. robots.txt でAIボットをブロックしていたのは WordPress 以外のほうが多く、日本9.3%（86件中8件、WordPress 1.0%）、海外13.8%（643件中89件、WordPress 4.3%）。ブロックはほぼ学習用とされるボットで、検索用・質問時の取得に使われる4つのボットのどれかをブロックしていたのは、海外の WordPress 以外で5件（0.8%）、日本の WordPress 以外で0件でした。

調査概要

  1. 対象：Web制作会社の自社サイト。当社の収集リストにある制作会社サイト23,687件のうち、トップページに到達できた15,838件（日本2,486件・海外13,352件）です。一般企業のサイト全体ではありません。
  2. 取得したもの：各サイトのトップページ、/robots.txt、/llms.txt、/llms-full.txt を1回ずつ（User-Agent：NurevoSurvey/1.0）。2026年11月上旬〜12日に取得し、11月12日に集計しました。
  3. WordPress の判定：トップページのHTMLに wp-content/・wp-includes/、または generator の WordPress 表記があるものを WordPress としました。到達できた15,838件のうち12,376件（78.1%）が WordPress で、日本は92.3%（2,295件）、海外は75.5%（10,081件）です。WordPress 以外の内訳（独自開発、ほかのCMSやノーコードツールなど）はこの調査では判定していません。
  4. HTTP 202：海外の WordPress 以外のサイトのうち1,477件は、トップページがステータス202を返しました（日本と WordPress のサイトは0件）。これらには viewport・JSON-LD・WordPress の痕跡がどれもなく、ボット確認などの別のページが返った可能性が高いため、表の「WordPress 以外」からは除き、含めた値は本文で示します。
  5. 判定方法：llms.txt は、ステータス200で中身がHTMLではなく20文字を超えるテキストを「あり」としました。JSON-LD はトップページにあるかどうか、「壊れている」は JSON として読み込めないブロックが1つ以上あるもの。Organization系は @type に Organization・LocalBusiness・Corporation・ProfessionalService を含むもの。
  6. AIボットのブロック：robots.txt で、各ボットに当てはまるグループの規則がトップページ（/）を Disallow にするか（最長一致）で判定しました。分母は robots.txt があるサイトです。「AIボットをブロック」は GPTBot・ClaudeBot・PerplexityBot・Google-Extended・CCBot・OAI-SearchBot のどれかをブロックしているものです。
  7. 「6項目」は、(1) llms.txt がある、(2) JSON-LD がある、(3) Organization または LocalBusiness の型がある、(4) robots.txt があり GPTBot・ClaudeBot・PerplexityBot・OAI-SearchBot のどれもブロックしていない、(5) meta description がある、(6) canonical がある、のうち当てはまる数（0〜6）です。この調査のための単純な数で、Nurevo の0〜100点のスコアとは別物です。
  8. 統計：差はカイ二乗検定で確かめ、件数の少ない日本の WordPress 以外はフィッシャーの正確確率検定を使いました。30件未満の区分は載せていません。

結果：項目ごとの比較

ほぼすべての項目で WordPress のサイトが高く、差がいちばん大きいのは JSON-LD・Organization系の型・canonical・robots.txt でした。逆に WordPress 以外のほうが高かったのは「AIボットをブロック」と「AIボットに言及」の2つだけです。JSON-LD が壊れている割合（1.4〜1.9%）は、どの区分でもほぼ同じでした。

日本の WordPress 以外のサイトは、meta description（76.4%）は WordPress（91.9%）に近い一方、JSON-LD・canonical・robots.txt が低く、6項目では1〜2項目の層が厚くなっています（下の分布）。海外の WordPress 以外のサイトは、meta description も20.1%と低い値でした。この差には、判定方法の限界（後述）が影響している可能性があります。

海外の WordPress 以外を202を返した1,477件も含めて数えると（3,271件）、llms.txt 5.6%、JSON-LD 9.0%、6項目すべて2.6%、6項目の平均0.61 になります。

WordPress どうしで比べても、日本と海外の差は残ります。llms.txt は日本の WordPress 14.0%、海外の WordPress 33.1%、6項目すべては10.8%と28.0%でした（どちらも p<0.001）。WordPress 以外どうしでは、llms.txt（6.3%と10.1%、p=0.11）、6項目すべて（どちらも4.7%）、AIボットのブロック（9.3%と13.8%、p=0.31）に差は見られませんでした。

robots.txt が無いサイト

WordPress 以外のサイトで最も目立つのは robots.txt が無いことでした。日本の WordPress 以外191件のうち105件（55.0%）、海外の WordPress 以外（202除く）1,794件のうち1,151件（64.2%）で、/robots.txt にテキストの robots.txt がありませんでした（HTMLのページが返った場合も「なし」に数えています）。WordPress では日本4.4%、海外3.1%です。

robots.txt が無いことは、それだけでAIボットを拒否していることにはなりません。この調査の「6項目」では (4) を満たさない扱いにしているため、WordPress 以外のサイトの点数が低めに出る一因になっています。

ブロックの中身（事実）

  1. 海外の WordPress 以外で11種のAIボットのどれかをブロックしていた93件のうち73件（78.5%）は、GPTBot・ClaudeBot・anthropic-ai・Google-Extended・CCBot・Bytespider・Applebot-Extended の7つをまとめてブロックする同じ組み合わせでした。海外の WordPress では465件中268件（57.6%）です。
  2. GPTBot をブロックしていたサイトのうち、ChatGPT の検索用ボット OAI-SearchBot はブロックしていなかったのは、海外の WordPress 以外で85件中83件、海外の WordPress で363件中346件（95.3%）、日本では WordPress 21件・WordPress 以外7件のすべてでした。
  3. robots.txt でAIボットの名前を挙げていながら、どれもトップページをブロックしていないサイトは、海外の WordPress 以外で75件（robots.txt があるサイトの11.7%）、海外の WordPress で585件（6.0%）でした。
  4. AIボットをブロックしていたサイトのうち llms.txt もあったのは、海外の WordPress で423件中162件（38.3%）、海外の WordPress 以外で89件中9件でした。

限界

  1. 対象はWeb制作会社の自社サイトで、一般企業のサイト全体ではありません。収集リストは代表標本ではありません。日本の WordPress 以外は191件（robots.txt があるのは86件）と少なく、ボット別の件数は小さい数です。
  2. トップページのHTMLだけを、JavaScript を実行せずに見ています。表示の後で JavaScript が構造化データやメタタグを足すサイトでは「なし」になります。WordPress 以外のサイトにはこの影響を受けるものが含まれる可能性があります。
  3. meta description は、name 属性が content 属性より前にある書き方だけを数えています。逆の順で書くツールで作られたサイトは「なし」になるため、WordPress 以外の meta description の値は低めに出ている可能性があります。
  4. WordPress の判定はHTMLの痕跡によるもので、痕跡を消している WordPress や、WordPress をデータの管理だけに使う構成は「WordPress 以外」に入ります。
  5. robots.txt はトップページ（/）に対する判定で、一部のディレクトリだけのブロックや、ファイアウォール・CDN によるブロックは数えていません。llms.txt は有無だけを見ています。各サイト1回の取得で、到達できなかったサイトは除いています。今回の集計の一部には11月5日集計時の取得分を引き継いでいます。
  6. WordPress かどうかと各項目の関係は同時に見られたというだけで、WordPress が原因であることを示すものではありません。

当社の見方（意見）

ここからは事実ではなく当社の意見です。WordPress のサイトで構造化データや canonical がそろっているのは、SEOプラグインやテーマがこれらを自動で出すことが多いためと考えます。WordPress は robots.txt のファイルを置かなくても応答する仕組みを持っており、robots.txt の有無の差もその影響が大きいと見ています。WordPress 以外のサイトでは、同じことを手で、またはツールの設定で入れる必要があるため、抜けが出やすいのかもしれません。

AIボットのブロックが WordPress 以外で多い理由は、この調査からは分かりません。7つの学習用ボットをまとめて止める同じ組み合わせが多いことから、ホスティングやCDNの機能、ひな形の robots.txt が使われている可能性もあります。どのボットを止めるかは各社の判断ですが、AI検索に出たい場合は、検索用のボットまで止めていないかを確かめる価値があります。どれを整えてもAIの回答に出ることが保証されるわけではありません（別の調査では、サイト側の項目と登場の間に関係は見られませんでした）。

自社やお客様のサイトを確かめる

無料チェックで、llms.txt・構造化データ・AIクローラーの許可状況を1分ほどで確認できます。WordPress 以外のサイトでも使えます。WordPress なら Nurevo WebMCP プラグインで llms.txt を出し、会社の事実を構造化データに加えられます。お客様のサイトにまとめて入れたい制作会社の方はパートナー制度をご覧ください。

よくある質問

WordPress のサイトはAI検索に有利ですか？

この調査では、WordPress のサイトのほうが構造化データ・llms.txt・canonical などがそろっている割合が高いことが分かりました（JSON-LD 88.8%と17.6%）。ただし、これはサイトの状態の違いで、AIの回答に出やすいかどうかを測ったものではありません。

WordPress 以外のサイトでいちばん多い抜けは何ですか？

robots.txt が無いこと（日本の WordPress 以外の55.0%）と、トップページに構造化データが無いこと（同71.7%）でした。日本では meta description は76.4%にありました。

WordPress 以外のサイトはAIクローラーをブロックしていますか？

robots.txt があるサイトのうち、日本9.3%（8件）、海外13.8%で、WordPress（1.0%・4.3%）より多い値でした。ほとんどは学習用とされるボットで、検索用のボットまでブロックしていたのは1%未満です。

この数字を記事で使えますか？

はい。出典「Nurevo AEO 調査（nurevo.jp）」と、このページへのリンクを明記すれば、自由に引用・転載できます。

あなたのサイトのAI対応を確認

無料チェックで、llms.txt・構造化データ・AIクローラーの許可状況が分かります。WordPress 以外のサイトでも使えます。AIの回答に出ることを保証するものではありません。
