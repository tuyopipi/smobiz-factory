ブラジルのWeb制作会社の自社サイト261件に見るAI検索への対応（2026年11月）

ブラジルのWeb制作会社の自社サイト261件のトップページ・robots.txt・llms.txt を調べたところ、llms.txt があったのは34.1%（89件）で、到達100件以上の17か国の中でシンガポール・インドに次ぐ3位でした（米国23.1%、日本13.4%）。AI検索に関わる6項目をすべて満たしたのは25.3%で、スペイン語圏の中南米4か国（メキシコ・コロンビア・アルゼンチン・チリ、18.3%）や米国（18.9%）より高く、スペイン（27.4%）とは統計的な差が見られませんでした。AIボットをブロックしていたのは5.5%（12件）で、検索用のボットをブロックしていたのは、すべてのボットを拒否していた1件だけでした。

公開：2026年11月25日。データ：2026年11月12日集計。調査・執筆：Nurevo AEO（Bestie.合同会社）。Nurevo はAI検索対策（AEO）のツールと WordPress プラグインを提供しており、この分野に利害があります。国別レポートの8本目で、中南米の国では初めてです（これまでに米国・英国・オーストラリア・インド・カナダ・フランス・シンガポール）。英語版とポルトガル語（ブラジル）版もあります。

要点

  1. ブラジルのWeb制作会社の自社サイト261件のうち、llms.txt があったのは34.1%（89件）で、到達100件以上の17か国でシンガポール（38.8%）・インド（36.6%）に次ぐ3位でした。米国（23.1%）・ブラジル以外の海外全体（26.2%）より高く（p<0.001・p=0.004）、日本（13.4%）の2.5倍です。スペイン（31.9%、p=0.59）との間に統計的な差は見られませんでした。
  2. AI検索に関わる6項目をすべて満たしたのは25.3%（66件）、6項目の平均は4.11でした。スペイン語圏の中南米4か国（18.3%・3.09）より高く（6項目すべて p=0.040）、JSON-LD（74.7%・54.8%）・meta description・canonical・robots.txt でも差が大きく（いずれも p<0.001）、WordPress の割合（76.6%・47.7%）も大きく違いました。WordPress のサイトどうしで比べると、llms.txt はブラジル38.5%、中南米4か国38.3%とほぼ同じでした。
  3. robots.txt があるサイト217件のうち、AIボットをブロックしていたのは5.5%（12件）で、米国（4.3%、p=0.39）・ブラジル以外の海外（5.1%）と統計的な差はなく、日本（1.3%）より高い値です。GPTBot をブロックしていた11件のうち10件は OAI-SearchBot を許可しており、検索用・質問時の取得に使われる4つのボットをブロックしていたのは、Googlebot も含めてすべてのボットを拒否していた1件だけでした。

調査概要

  1. 対象：Web制作会社の自社サイト。当社の収集リストで国がブラジルとなっている制作会社サイト383件のうち、トップページに到達できた261件です。一般企業のサイト全体ではありません。比較には同じ調査のスペイン語圏の中南米4か国（メキシコ116件・コロンビア81件・アルゼンチン76件・チリ50件、計323件）・スペイン（248件）・ポルトガル（46件）・米国（4,472件）・日本（2,486件）・ブラジル以外の海外（13,091件）を使いました。
  2. 取得したもの：各サイトのトップページ、/robots.txt、/llms.txt、/llms-full.txt を1回ずつ（User-Agent：NurevoSurvey/1.0）。2026年11月上旬〜12日に取得し、11月12日に集計しました。
  3. 判定方法：llms.txt は、ステータス200で中身がHTMLではなく20文字を超えるテキストを「あり」としました。JSON-LD はトップページにあるかどうか、「壊れている」は JSON として読み込めないブロックが1つ以上あるもの。Organization系は @type に Organization・LocalBusiness・Corporation・ProfessionalService を含むもの。WordPress はHTMLに wp-content・wp-includes・WordPress の generator があるものです。
  4. AIボットのブロック：robots.txt で、各ボットに当てはまるグループの規則がトップページ（/）を Disallow にするか（最長一致）で判定しました。分母は robots.txt があるサイトです。「AIボットをブロック」は GPTBot・ClaudeBot・PerplexityBot・Google-Extended・CCBot・OAI-SearchBot のどれかをブロックしているもの。「AIボットに言及」は Googlebot・Bingbot 以外の11種のAIボットのどれかを User-agent で名指ししているものです。
  5. 「6項目」は、(1) llms.txt がある、(2) JSON-LD がある、(3) Organization または LocalBusiness の型がある、(4) robots.txt があり GPTBot・ClaudeBot・PerplexityBot・OAI-SearchBot のどれもブロックしていない、(5) meta description がある、(6) canonical がある、のうち当てはまる数（0〜6）です。この調査のための単純な目安で、AIの回答に載るかどうかを示すものではありません。
  6. HTTP 202：ブラジルでトップページがステータス202を返したのは9件（到達件数の3.4%）で、米国（15.0%）・ブラジル以外の海外（11.2%）より少ない割合でした。202のページはほとんどの項目が「なし」になるため、国どうしの比較に影響します。ステータス200のサイトだけで比べた値も本文に書きました。
  7. 統計：ブラジルと他の地域の差はカイ二乗検定で、件数が小さいAIボットのブロックはフィッシャーの正確検定で確かめました。30件未満の区分は載せていません（ポルトガルとチリのAIボットのブロック率は、robots.txt があるサイトが30件未満のため「—」）。

結果：ブラジルと中南米・スペイン・ポルトガル・米国・日本の比較

ブラジルは llms.txt（34.1%）・FAQPage（13.4%）・6項目すべて（25.3%）で、米国とブラジル以外の海外より高い値でした（llms.txt は対米国 p<0.001・対海外 p=0.004、FAQPage は対米国 p<0.001・対海外 p=0.023、6項目すべては対米国 p=0.011・対海外 p=0.17）。スペインとは llms.txt・6項目すべて・JSON-LD のどれも統計的な差がなく（p=0.59・0.59・0.15）、ポルトガル（46件）とも llms.txt に差は見られませんでした（26.1%、p=0.29）。

スペイン語圏の中南米4か国と比べると、ブラジルは JSON-LD（74.7%・54.8%）・Organization系の型（68.2%・51.4%）・meta description（77.4%・60.4%）・canonical（79.7%・60.4%）・robots.txt（83.1%・67.2%）が16〜20ポイント高く（いずれも p<0.001）、WordPress の割合も76.6%と47.7%で大きく違いました。WordPress のサイトだけで比べると、llms.txt はブラジル38.5%・中南米4か国38.3%とほぼ同じで、全体の差の多くは WordPress の割合の違いと重なっています。

ステータス200のサイトだけ（ブラジル252件）で比べても、llms.txt は35.3%で米国（27.2%、p=0.005）・ブラジル以外の海外（29.5%、p=0.046）より高く、スペイン（33.8%、p=0.72）とは差がありませんでした。6項目すべては26.2%で、米国（22.3%、p=0.15）・海外（24.5%、p=0.53）との差ははっきりしなくなります。

ブロックの中身（事実）

  1. GPTBot をブロックしていた11件のうち10件は、OAI-SearchBot をブロックしていませんでした。残りの1件は、Googlebot・Bingbot を含むすべてのボットのクロールを拒否していたサイトです（AIボットの名前は挙げていませんでした）。
  2. 上の11種のAIボットのどれかをブロックしていた13件のうち7件は、GPTBot・ClaudeBot・anthropic-ai・Google-Extended・CCBot・Bytespider・Applebot-Extended の7つをまとめてブロックする同じ組み合わせでした。残りは、すべてのボットを拒否する1件、Bytespider だけ・CCBot だけが各1件、ほかの組み合わせが3件です。
  3. robots.txt でAIボットの名前を挙げていたのは29件（robots.txt があるサイトの13.4%）で、そのうち17件はどのAIボットもトップページをブロックしていませんでした。
  4. AIボットをブロックしていた12件のうち6件には llms.txt もありました。
  5. robots.txt に Sitemap の行があったのは、robots.txt があるサイトの88.5%でした。

llms.txt の中身と、5項目のサイトに欠けていたもの

  1. llms.txt があった89件の行数の中央値は64行でした。llms-full.txt があったのは9件（3.4%）です。
  2. 6項目のうち5項目を満たしたサイトは99件で、そのうち83件（83.8%）は欠けていた1項目が llms.txt でした。
  3. 6項目に1つも当てはまらなかったサイトは37件（14.2%）で、そのうち9件はステータス202、28件はステータス200で返ったものの、構造化データ・meta description・canonical・robots.txt・llms.txt のどれも見つからなかったサイトでした（robots.txt があったのは1件）。JavaScript で後から中身を出すサイトは、この調査では「なし」になります。
