ChatGPT広告・AI Overviews広告とAI検索対策（AEO）の違い：代理店がお客様に説明すること、準備すること

ChatGPT広告は、回答の下に「広告」と表示される枠をお金で買うもので、回答の本文や出典は買えません。OpenAIは「広告はChatGPTの回答に影響しない」と明言しています。AI検索対策（AEO）は、回答そのものに会社や店が名前や出典として選ばれるようにする作業です。2つは別の作業なので、代理店は見積もり・サイトの準備・測り方・報告を分けて扱うのが基本です。

作成日：2026年11月22日（JST）。対象は、リスティング広告やSNS広告を運用する広告代理店、AI検索対策を提供する制作会社・SEO会社です。お客様から「ChatGPTに広告が出せるなら、AI対策はいらないのでは」「広告を出せばAIに勧めてもらえるのか」と聞かれたときに、そのまま使える説明を目指しました。

AIの回答も広告の表示も、日・聞き方・利用者のプランや国によって変わります。この記事は表示を保証する方法ではなく、2つの違いを正しく説明し、混ぜずに準備・測定するための手順です。提供状況は2026年11月22日に公式の資料で確かめた内容で、今後変わります。

OpenAIは「広告はChatGPTの回答に影響しない」「会話の内容は広告主に渡さない」と書いています（OpenAI）。つまり、広告費を増やして回答の中の推薦や出典を増やす、という説明はできません。逆に、広告費と出典の関係を外部から検証した公開データも、今回は見つかりませんでした。お客様には「公式の説明ではそうなっている」と伝えるのが正確です。

お客様によく聞かれる3つの質問と答え方

  1. 「ChatGPTに広告を出せば、AIに勧めてもらえますか？」→いいえ。広告は回答の下の別の枠に「広告」として出ます。回答の中で勧められるかどうかは、広告とは別に決まるとOpenAIは説明しています。
  2. 「広告を出せるなら、AI検索対策はいりませんか？」→役割が違います。広告は無料・Goプランの利用者にだけ、出稿している間だけ表示されます。回答の中の名前や出典は、有料プランの利用者や、広告のないAI（Perplexity など）にも届き、出稿を止めてもすぐには消えません。
  3. 「どちらから始めればいいですか？」→まず、サイトの事実（店名・住所・料金・営業時間・サービス）が正確でそろっているかを確かめます。広告の飛び先もAIの回答も、同じサイトの情報を読むからです。そのうえで、すぐに見込み客を集めたい商品があれば広告を、名前を聞かれたときに正しく答えてほしい情報はAI検索対策で整えます。

業種によっては、答えが変わります。歯科・クリニックなどの医療、金融、酒類のように、AIの回答画面の広告が出せない・出しにくい業種では、AIの回答に名前が出るかどうかはAI検索対策だけで決まります。広告の提案と同時に、その旨を一言添えると誤解が起きません。

サイト側の準備：OAI-AdsBot と OAI-SearchBot は別のボット

OpenAIのクローラは目的ごとに分かれています（OpenAIのボットの説明）。OAI-SearchBot はChatGPTの検索の回答にサイトを出すためのもので、これを止めたサイトはChatGPTの検索の回答に出ません。OAI-AdsBot は広告として登録されたページだけを読み、規約に合っているかの確認と、広告をいつ出すかの判断に使われます。OAI-AdsBot が集めたデータは、AIの学習には使われないと書かれています。

広告主向けの案内では、OAI-AdsBot は「許可しなければならない」、OAI-SearchBot も許可を推奨、とされています。さらに、robots.txt だけでは足りない場合があり、ファイアウォールやCDNのボット対策で弾かれていないかも確かめるよう書かれています（OpenAI ヘルプ）。アクセスを直しても、広告の審査に通ることは保証されません。

# robots.txt に OAI-AdsBot / OAI-SearchBot を止める行がないか
curl -s https://example.jp/robots.txt | grep -i -A3 "oai-\|user-agent: \*"

# 広告の飛び先がボット対策で弾かれていないか（403 や確認画面が返らないか）
curl -s -o /dev/null -w "%{http_code}\n" \
  -A "Mozilla/5.0 AppleWebKit/537.36 (KHTML, like Gecko); compatible; OAI-AdsBot/1.0; +https://openai.com/adsbot" \
  https://example.jp/lp/

上のコマンドは確かめ方の例です。example.jp と /lp/ をお客様のドメインと広告の飛び先に置き換えます。ボット対策のサービスは、名乗るユーザーエージェントだけでなくIPアドレスなども見ていることが多いので、200が返っても本物のボットが通る保証にはなりません。ボット対策の管理画面の記録も確かめてください。

WordPressでの設定：Nurevo AEO を使っている場合

Nurevo AEO（WordPress.orgの無料プラグイン）は、AI検索のクローラ（OAI-SearchBot・ChatGPT-User・Claude-SearchBot・Claude-User・PerplexityBot・Perplexity-User）を robots.txt で許可します。お客様が /wp-admin/ などに書いている既存の制限は、そのまま適用されます。学習用のクローラ（GPTBot など）はお客様の robots.txt に任せ、ワンクリックで許可・拒否を選べます。学習用を拒否しても、AI検索やAEOスコアには影響しません。

OAI-AdsBot は初期の一覧に入っていません。広告として登録したページしか読まないボットで、広告を出さないサイトには関係がないためです。ChatGPT広告を出すお客様のサイトで、robots.txt に明示しておきたい場合は、フィルターで足せます。

// 子テーマの functions.php か mu-plugins に置く例
// （ChatGPT広告を出すお客様のサイトだけ）
add_filter('webmcp_canary_robots_search_agents', function ($agents) {
    $agents[] = 'OAI-AdsBot';
    return $agents;
});

足したあとは https://ドメイン/robots.txt を開き、許可のグループに OAI-AdsBot が入っていることを確かめます。サーバーに robots.txt のファイルを直接置いているサイトでは、WordPressの自動の robots.txt は使われないので、そのファイルを直接書き換えます。

広告の飛び先ページの内容は、広告をいつ出すかの判断にも使われます。飛び先の料金・条件が、サイトの構造化データや料金ページと食い違っていないかも同時に確かめます。AIの回答の材料と広告の材料が同じサイトなので、ここをそろえることが両方に効きます。

測り方を分ける：広告の数字とAIの回答への登場を混ぜない

  1. 広告の成果は、広告の管理画面と、飛び先のページのタグ・URLのパラメータで測ります。AI検索対策の報告には入れません。
  2. AIの回答への登場は、決まった質問を決まった日にAIに聞き、回答の本文や出典に名前・URLが出たかを記録します。AIでの登場率の測り方の手順が使えます。
  3. ChatGPTの無料プランで確かめると、回答の下に広告が出ることがあります。広告として出たものは「登場」に数えず、記録に「広告あり」と別に書きます。
  4. Google の AI Overviews の中に出る広告は、Google 広告の報告では「上部の広告」として報告され、AI Overviews の枠だけを狙って配信することもできません（Google 広告ヘルプ）。「AI Overviews の広告の成果」を、別の数字のように報告しないようにします。
  5. Perplexity は報道によれば広告から手を引いており、回答に出るかどうかは広告と関係ありません。Nurevo の Pro プランのAI登場率の計測は現在 Perplexity が対象（ChatGPTは設定され次第）なので、広告の影響を受けない数字として扱えます。

見積もりと報告の分け方

広告とAI検索対策を両方受けるときは、見積もりを「広告費（媒体に払うお金）」「広告の運用費」「AI検索対策の作業費」に分けます。報告書も2つに分け、広告の表示回数・クリックと、AIの回答への登場を同じグラフに載せません。AI検索対策を月額で続ける作業範囲はAI検索対策を月額サービスにする方法で扱っています。

契約書や提案書では、「広告を出すとAIに推薦される」「AIの回答で上位に出る」とは書きません。OpenAI自身が広告は回答に影響しないと説明しており、AIの回答は変わるからです。書けるのは「広告は回答の下の広告枠に表示される」「AI検索対策はサイトの事実を正確にし、AIが読める形にする作業」という事実です。

制作会社・代理店向けには、社名・ロゴ入りの月次レポートを毎月自動で送る機能と、複数のお客様のサイトを1つの画面で見る機能があります。詳しくはパートナープログラムをご覧ください。料金は Free 0円、Standard 月3,000円、Pro 月14,800円〜です。

チェックリスト

  1. お客様に、広告は回答の下の別枠で、回答の中身や出典は買えないと説明した。
  2. お客様の業種が、ChatGPT・Google の広告の対象外になっていないか、最新のポリシーで確かめた。
  3. 広告の対象外の業種では、AIの回答に出る手段はAI検索対策だけだと伝えた。
  4. サイトの店名・住所・料金・営業時間を、広告の飛び先・構造化データ・Googleビジネスプロフィールでそろえた。
  5. robots.txt で OAI-SearchBot と OAI-AdsBot を止めていないことを確かめた。
  6. CDN・ファイアウォールのボット対策で、広告の飛び先が弾かれていないことを確かめた。
  7. AIの回答への登場の記録で、広告として出たものを別に書く欄を作った。
  8. 見積もりを広告費・運用費・AI検索対策の作業費に分けた。
  9. 提案書・契約書に「AIに推薦される」「上位に出る」などの約束を書いていない。
  10. 提供状況（国・プラン・広告の場所）を、提案の前に公式のページで確かめ直した。

よくある質問

ChatGPT広告を出すと、回答の中で自社が勧められやすくなりますか？

OpenAIは、広告はChatGPTの回答に影響しないと説明しています。広告は回答の下に「広告」と分けて表示されるもので、回答の中で勧められるかどうかとは別です。広告費と回答の関係を外部から検証した公開データは、今回は見つかりませんでした。

日本でChatGPT広告は出せますか？

出せます。OpenAIの2026年8月11日の追記に、日本での開始が明記されています。表示されるのは無料プランとGoプランの、ログインした大人の利用者で、Plus・Pro・Business・Enterpriseには表示されません。

GoogleのAI Overviewsの中に、日本で広告を出せますか？

2026年11月22日時点の Google 広告ヘルプでは、AI Overviews の中の広告は英語で12か国が対象で、日本は入っていません。AI Overviews の上下に出る通常の検索広告は、日本でも対象です。AI モードの広告も、2026年10月28日の発表に日本の記載はありません。

歯科やクリニックはChatGPT広告を出せますか？

OpenAIは、健康・メンタルヘルス・政治などの話題の近くには広告を出さないとしています。医療の質問への回答に広告で出るのは難しいと考え、診療内容や診療時間を正確に載せるAI検索対策を先に進めるのが現実的です。

OAI-AdsBot を robots.txt で許可すると、学習に使われますか？

OpenAIの説明では、OAI-AdsBot は広告として登録されたページだけを読み、集めたデータはAIの学習に使われません。学習に使われるのは GPTBot で、別に扱えます。

AIの回答への登場率を測るとき、広告はどう扱えばいいですか？

広告として出たものは登場に数えず、「広告あり」と別に記録します。広告の成果は広告の管理画面で測り、AI検索対策の報告と混ぜないのが基本です。

広告とAI検索対策、予算が少ないならどちらですか？

まず、サイトの事実を正確にそろえることです。広告の飛び先もAIの回答も同じサイトを読むので、ここは両方に効きます。そのうえで、すぐに集客したい商品があれば広告、名前を聞かれたときに正しく答えてほしい情報はAI検索対策で整えます。どちらの場合もAIの回答は変わるため、結果は記録しながら判断します。

広告の飛び先とサイトを、AIがどう読んでいるか確認

無料チェックは登録不要で、URLを入れるだけで構造化データ・llms.txt・AIクローラの許可の状態がわかります。広告の提案の前に、サイトの事実がそろっているかを確かめられます。
