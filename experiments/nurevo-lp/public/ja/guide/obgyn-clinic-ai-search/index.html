産婦人科・婦人科のAI検索対策：分娩予約の期限、費用、無痛分娩の情報をAIに正しく読ませる手順

産婦人科のAI検索対策でいちばん大切なのは、「何週までに、どうやって分娩を予約するか」「費用はいくらで、出産育児一時金とどう関係するか」「無痛分娩をどの体制で行うか」を、日付つきの文字でサイトに書くことです。妊娠が分かった人は、病院を選ぶ前にAIへ質問します。そのとき医院のサイトに条件が書かれていないと、AIは古い口コミや比較サイト、別の病院の情報で答えます。そのうえで、同じ事実を出産なび・産科医療補償制度の表示・構造化データ・Googleビジネスプロフィールにそろえます。

作成日：2026年11月20日（JST）。出産育児一時金（協会けんぽ）、2026年の健康保険法等の改正（厚生労働省の概要資料）、出産なび（厚生労働省のリーフレットと検討会資料）、妊婦健診の回数（厚生労働省告示と調査）、無痛分娩の情報公開の項目（厚生労働省の自主点検表 令和7年5月版）、産科医療補償制度（政府広報オンライン）、schema.orgの型（V30.1）は同日に確認しました。厚生労働省の医療広告Q&Aの項目は2026年11月16日に確認した範囲です。

AIの回答は日や聞き方によって変わります。この記事の対策は、AIが医院の事実を正しく読める状態をつくるものです。AIの回答に必ず表示される・順位が上がることを保証するものではありません。この記事は法的・医学的な助言ではありません。個別の表現は管轄の保健所などで確認してください。

妊娠中の人と家族が、AIに聞くこと

産婦人科の質問は、症状よりも「時期」「費用」「体制」が中心です。里帰り出産を考える人や、パートナー・親が代わりに調べることもあります。婦人科の外来では、検診やピル、更年期の相談が多くなります。よく出る質問の型は次の6つです。

質問の型例AIが答えに使う情報
分娩の予約「◯◯市で出産できる病院、何週までに予約が必要？」分娩を扱うか、予約の期限（週数）、予約の方法、予約金の有無、紹介状が必要か
費用「◯◯クリニックの出産費用は？一時金でいくら足りる？」費用の目安と条件（個室・時間外など）、直接支払制度に対応しているか
無痛分娩「無痛分娩ができる産院」「24時間対応？」実施しているか、計画分娩か、麻酔を担当する医師、実施件数、追加費用
里帰り出産「里帰り出産は受け入れている？いつ転院すればいい？」受け入れの有無、連絡の時期、受診してほしい週数
妊婦健診だけ「健診だけ通えて、出産は別の病院の産婦人科」健診のみの受け入れ、提携する分娩先、受診券が使えるか
婦人科の外来「土曜に子宮がん検診を受けられる婦人科」「女性医師がいる？」曜日ごとの診療時間、検診の種類と予約の要否、医師の担当日

どの型も、AIが使えるのは条件が文字で書いてあるページです。ある会社がChatGPTのクリニック検索の回答5,460件を調べたプレスリリースでは、料金の質問の回答の96%で、クリニック自身のサイトが出典に使われていました（2026年9月、調査会社自身の調査）。プレスリリース。費用や予約の条件は、自院のサイトに書くほど答えに使われやすい情報です。

上位の記事で抜けていたこと

「産婦人科 AI検索対策」「婦人科 LLMO」「OB-GYN AI search optimization」などで上位に出る記事を、日本語7本・英語6本読みました。日本語は、クリニック全般のAI対策の記事（医療広告のルールや医院情報の表記をそろえる話は実務的）と、AIに触れていない産婦人科の集患の記事に分かれ、産婦人科の項目は表の1行程度でした。英語は、ツールの紹介や6ステップの一般論が中心で、「口コミが50件あればよい」「Perplexityは30〜60日で反映」のような出典のない数字もありました。

どの記事にもなかったのは、次の5点です。この記事はここを中心に書きます。

  1. 分娩予約の期限・方法を、AIが答えに使える形で書くこと。
  2. 費用を、出産育児一時金（50万円）と、2026年に法改正された新しい仕組みに触れながら、正しい範囲で書くこと。
  3. 無痛分娩の情報を、厚生労働省の自主点検表にある公開項目と同じ内容でサイトに書くこと。
  4. 出産なび・産科医療補償制度の表示と、サイトの事実を一致させること。
  5. 産婦人科を表すschema.orgの型（Obstetric・Gynecologic）と、WordPressでの設定、AIに出ているかの確かめ方。

分娩の予約：期限は「週数」と「方法」で書く

分娩予約の期限は施設によって大きく違います。たとえば愛育病院のFAQは「分娩予約は通常8〜9週」、日本赤十字社医療センターの案内は「20週まで」としています。愛育病院（PDF）、日赤医療センター（PDF）。AIは「何週までに予約が必要か」をそのまま聞かれるので、「お早めに」ではなく週数で書きます。

書くこと書き方の例避けたい書き方
予約の期限「分娩予約は妊娠20週までにお願いします」「お早めにご予約ください」だけ
予約の方法「初診の際に外来で予約します。電話・Webでは受け付けていません」方法を書かない
予約金「予約金◯円（分娩費用に充当）」のように、有無と扱い金額だけ書き、返金や充当の扱いを書かない
受け入れの状況「2027年5月の分娩予定の方は受付を終了しました（2026年11月20日現在）」「現在混み合っています」だけ、日付なし
里帰り出産受け入れの有無、連絡してほしい時期、受診してほしい週数「ご相談ください」だけ

受け入れの状況は、月ごとに変わる情報です。お知らせのページに日付を入れて書き、状況が変わったら書き換えます。終わった案内を残したままにすると、AIは数か月後も「受付終了」と答えかねません。

費用：一時金との関係と、変わる予定の制度を正しく書く

2023年4月1日以降の出産では、出産育児一時金は、産科医療補償制度に加入する医療機関で妊娠22週以降に出産した場合、子ども1人につき50万円です（22週未満は48.8万円）。医療機関が健康保険から直接受け取る「直接支払制度」を使うと、本人は一時金を超えた分だけを支払います。協会けんぽ：出産育児一時金。

仕組みは変わる予定です。2026年6月5日に公布された健康保険法等の一部を改正する法律では、分娩の費用について全国一律の基本単価を決め、健康保険から医療機関に支払う形（現物給付）にし、あわせて妊婦に一律の現金給付を行うとしています。施行は公布から2年以内で政令で定める日で、当分の間は医療機関ごとに今の仕組みを続けることもできます。厚生労働省：改正の概要（PDF）、検討会資料（2026年10月1日、PDF）。開始日や金額は、この記事の作成日の時点では決まっていません。

そのため、費用のページには次のように、条件と日付をつけて書きます。「出産は無料になります」のような、まだ決まっていない書き方はしません。

  1. 費用の目安と、その条件（経腟分娩・帝王切開、個室か大部屋、平日昼か夜間・休日、無痛分娩の追加費用）。
  2. 直接支払制度に対応しているか。
  3. 産科医療補償制度に加入しているか（一時金の金額に関わるため）。
  4. 「◯年◯月時点の金額です」という日付。
  5. 新しい制度について書くなら「施行日は未定。決まり次第このページを更新します」と書き、決まったら書き換える。

無痛分娩：自主点検表にある公開項目と同じ内容を書く

厚生労働省の無痛分娩の自主点検表（令和7年5月版）は、無痛分娩を行う施設が、自院のサイトと無痛分娩関係学会・団体連絡協議会（JALA）のサイトで公開し、少なくとも年1回更新する項目を挙げています。自主点検表（PDF）。この項目は、AIが「この産院の無痛分娩は安全か」と聞かれたときに答えに使える、具体的な事実でもあります。

  1. 診療実績（実施件数など）。
  2. 標準的な説明文書と、標準的な方法（計画分娩か、24時間対応か）。
  3. 急変したときの体制と、危機対応のシミュレーションの実施歴。
  4. 麻酔の管理者・担当医の研修歴や講習会の受講歴、救急蘇生コースの有効期限。
  5. 日本産婦人科医会の偶発事例・妊産婦死亡報告事業への参画。
  6. ウェブサイトの更新日時。

「痛くない」「安心の無痛分娩」のような効果や安全を約束する言葉ではなく、これらの事実を書きます。JALAのサイトに載せた内容と、自院のサイトの内容は同じにします。

出産なび・産科医療補償制度と、サイトの事実をそろえる

出産なびは、厚生労働省が2024年5月30日に始めた、全国の分娩施設のサービスや費用を見られるサイトです。直接支払制度を使い年間21件以上の分娩を扱う施設が載り（それより少ない施設も希望すれば掲載）、2026年2月20日時点で2,097施設が載っています。費用の情報は請求のデータから四半期ごとに更新されます。出産なびのリーフレット（PDF）、検討会資料（PDF）。AIは公的なサイトと医院のサイトの両方を読むので、食い違いがあると、どちらかが間違っていると判断されかねません。

どこに載る情報かサイトとそろえること確かめ方
出産なび無痛分娩の有無、立ち会い・母子同室などのサービス、費用自院の掲載を開き、サイトの記載と1項目ずつ比べる。費用は四半期ごとに見直す
産科医療補償制度加入していること（加入している施設はシンボルマークを表示）日本医療機能評価機構の加入分娩機関の検索で確かめる。政府広報オンライン
JALAのサイト無痛分娩の公開項目年1回以上の更新のたびに、サイトも同じ内容にする
Googleビジネスプロフィール・医療情報ネット名前・住所・電話番号・診療時間・診療科変更したら同じ日にすべてを直す

妊婦健診と婦人科の外来：誰が、いつ、何を受けられるか

妊婦健診は、厚生労働省の告示で示された間隔で受けると全部で14回ほどになり、2022年4月1日時点ですべての市区町村が14回以上を公費で助成しています（多くは受診券の形）。厚生労働省告示、厚生労働省の調査（PDF）。助成の金額や使い方は自治体ごとに違うので、医院のサイトには「どの自治体の受診券が使えるか」を書き、金額は書きません。

  1. 妊婦健診だけの受け入れを行うか、分娩はどこと連携しているか（「◯週以降は提携先で」など）。
  2. 使える受診券の自治体（里帰りで他の自治体の受診券を使う場合の扱いも）。
  3. 婦人科の外来は、曜日ごとの診療時間と、子宮がん検診などの検診の種類、予約が必要か。
  4. 女性医師の担当日を書くなら、曜日と名前で書く。担当日が変わったら同じ日に直す。
  5. 自費の診療（ピルの処方など）は、費用・主なリスクや副作用・問い合わせ先を同じページに書く（医療広告のルール）。

医療広告のルールと、一般的な「AI対策」の助言がぶつかるところ

AI検索対策の記事では「口コミを増やす」「実績を見せる」がよく勧められます。医療機関のサイトでは、厚生労働省の医療広告ガイドラインとQ&Aに沿って扱いを決めます。出産の体験は書きたくなる内容ですが、とくに注意が必要です。

よくある助言医療機関での扱い（厚生労働省のQ&A）代わりにできること
出産した人の声を載せる治療の内容や効果についての体験談は掲載できない（Q1-18、Q2-9）入院の流れ・日数・持ち物・費用の条件など、事実の説明を詳しくする
「痛くない無痛分娩」「安心のお産」治療効果の表現には制限がある（Q2-8、Q3-14）無痛分娩の公開項目（実績・体制・研修歴）を事実として書く
「地域で一番選ばれる産院」虚偽・誇大・比較優良の表示は禁止されている例として扱われる分娩件数など、事実で書ける範囲だけを書く
自費の診療を詳しく書く自由診療は、治療の内容・費用、主なリスク・副作用、相談に答える問い合わせ先を書くことが条件（Q6-10〜6-12）条件を満たす形で、費用と主なリスクを同じページに書く

出典：厚生労働省：医療広告等ガイドラインに関するQ&A（PDF）、事例解説書（PDF）。FAQは「分娩の予約は何週までですか」「直接支払制度は使えますか」のような事実の質問にします。

構造化データ：Obstetric・Gynecologicの型

schema.orgには、産科と婦人科を表す型があります（2026年11月20日にschema.org V30.1で確認）。

型・プロパティ意味産婦人科での使い方
Obstetric妊娠・出産を扱う分野。MedicalBusinessの一種で、LocalBusinessの一種分娩を扱う医院の型に。住所・電話番号・診療時間をそのまま持てる
Gynecologic女性の生殖器とその病気を扱う分野。MedicalBusinessの一種分娩を扱わない婦人科・レディースクリニックの型に
medicalSpecialty診療の分野。値に Obstetric・Gynecologic がある両方を診るなら、型を1つ選び、もう一方を medicalSpecialty に足す
Service と offers提供するサービスと、その料金自費の検診・予約金など、料金を本文に書いているものだけを登録する

Googleは、AIによる概要などのために特別な構造化データは不要で、構造化データはページに見えている内容と一致させるよう案内しています。Google：AI features and your website。分娩費用は条件で変わるので、構造化データに1つの固定の料金として入れないでください。

WordPressの産婦人科サイトでの設定手順

  1. WordPress.orgからNurevo AIO（無料、旧表示名 Nurevo AEO）をインストールして有効化します。Yoast SEO・Rank Math・All in One SEO・Slim SEOはそのまま使えます。0.9.1からはSEO SIMPLE PACKやVK All in One Expansion Unitとも、構造化データを重複させずに併用できます。
  2. 初回の設定ウィザードで「クリニック・歯科」を選びます（型はMedicalBusinessになります）。そのあと設定画面の「業種（schema.org型）」欄を Obstetric（分娩を扱わないなら Gynecologic）に変えます。この欄にはschema.orgの型名をそのまま入れられます。
  3. 医院名・住所・電話番号・説明を確認します。空欄の項目だけが既存の設定から補われ、入力済みの値は上書きされません。
  4. 営業時間は「月〜金 9:00-12:00 14:00-17:00 / 土 9:00-12:00」のように外来の曜日と時刻だけを書きます。分娩は24時間対応であることや、時間外の連絡先は本文に書きます。
  5. 自費の検診や予約金など、料金を本文に書いているものだけを設定画面のサービスに1つずつ登録します。名前・説明・料金・通貨を入れると、料金つきのサービス（Service と Offer）として出力されます。料金は本文と同じ値にします。
  6. 分娩予約・費用・無痛分娩の各ページの編集画面のサイドバーで、そのページだけのFAQ（「分娩の予約は何週までですか」「直接支払制度は使えますか」「無痛分娩は24時間対応ですか」）を入れます。体験談や効果を約束する答えは入れません。終わった受付の案内は「このページをllms.txtに載せない」にします。
  7. AEOスコアの画面で診断を実行し、不足をワンクリック修正で直します。外からどう見えるかは無料のAI可読性チェックで確かめます。

診療分野（medicalSpecialty）を足したいとき

Nurevo AIOは medicalSpecialty を自動では出しません。出したい場合は、テーマの functions.php か小さなプラグインで、事業の構造化データを変えるフィルター（webmcp_canary_business_node）を使います。

add_filter('webmcp_canary_business_node', function ($org, $settings) {
    // 本文に書いている診療分野だけを足す（分娩を扱わない婦人科は Obstetric を入れない）
    $org['medicalSpecialty'] = array('Obstetric', 'Gynecologic');
    return $org;
}, 10, 2);

AIに出ているかを確かめる

整えたあとは、妊娠中の人や家族が聞きそうな質問を「地域×出産×予約の期限」「地域×無痛分娩」「地域×里帰り出産」「地域×婦人科×土曜×検診」の組み合わせで5〜10個つくり、ChatGPTやPerplexityに投げます。医院が名前やURLで出るか、予約の期限・費用の条件・無痛分娩の体制が正しく書かれているかを記録します。AIの回答は回ごとに変わるので、同じ質問を期間をあけて何度か確かめます。費用や制度を書き換えたあとは、古い金額が答えに残っていないかも見ます。測り方はAIでの登場率の測り方にまとめています。

Nurevo AIOでは、Free・Standardプランでも月に1回、業種と地域から作った3つの質問（医院名は含めません）をPerplexityに投げ、回答に医院の名前やサイトが出たかを記録します。Proプラン（月14,800円〜）では、ベータ版のAI登場率の計測で、AIの回答に医院が出る割合を競合との比較・推移とあわせて見られます（現在の計測対象はPerplexity）。どちらも回答のサンプルを見るもので、すべての回答を観測するものではありません。

よくある質問

産婦人科のAI検索対策は、何から始めればいいですか？

分娩予約の期限を週数で、予約の方法と一緒に書くことからです。次に費用のページに条件と日付を書き、無痛分娩を行うなら公開項目を載せます。最後に、名前・住所・電話番号・診療時間を構造化データ・Googleビジネスプロフィール・出産なびとそろえます。

出産費用は、サイトにどう書けばいいですか？

費用の目安を、分娩の方法・部屋・時間帯などの条件と「◯年◯月時点」の日付つきで書きます。直接支払制度に対応しているか、産科医療補償制度に加入しているかも書きます。2026年の法改正による新しい仕組みは、施行日が決まっていないことを明記し、決まったら更新します。

「出産が無料になる」と書いてもいいですか？

決まっていないことを決まったように書くのは避けます。2026年6月5日公布の改正法は、分娩の基本単価を健康保険から医療機関に払う形にするとしていますが、施行は公布から2年以内の政令で定める日で、当分の間は今の仕組みを選べる施設もあります。

無痛分娩について、何を書けばいいですか？

厚生労働省の自主点検表にある公開項目です。診療実績、標準的な説明文書と方法、急変時の体制、麻酔担当医の研修歴などを、JALAのサイトと同じ内容で書き、少なくとも年1回更新します。「痛くない」など効果を約束する言葉は使いません。

構造化データの型は何を使えばいいですか？

分娩を扱うならschema.orgのObstetric、分娩を扱わない婦人科ならGynecologicです。どちらもMedicalBusinessとLocalBusinessの一種です。両方を診るなら、もう一方を medicalSpecialty に足せます。

対策すればChatGPTに産婦人科が必ず出ますか？
