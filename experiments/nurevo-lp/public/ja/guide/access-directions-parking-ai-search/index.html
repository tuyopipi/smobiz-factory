アクセス・駐車場・行き方のページをAIに正しく読ませる書き方：住所の表記から入口・駐車場まで

AIに行き方や駐車場を正しく答えてもらうには、アクセスのページに「住所（建物名・階まで）」「最寄り駅と出口・徒歩分数とその測り方」「入口の目印」「駐車場の有無・台数・場所・料金」「自転車・バイク・バリアフリー」を、地図や写真だけでなくHTMLの文字で書きます。そのうえで、住所の表記をサイト・Googleビジネスプロフィール・ポータルで1つにそろえ、構造化データには本文と同じ住所と入口の座標を入れます。駐車場がない場合も「駐車場はありません。近くのコインパーキングをご利用ください」と書くと、AIが推測で答えにくくなります。

作成日：2026年11月21日（JST）。営業時間は営業時間・定休日・臨時休業の書き方、予約は予約ページの書き方で扱いました。この記事は、店舗・クリニック・教室・事務所・宿など、人が訪れる場所を持つ事業者に向けて、「どうやって行くか」「車で行けるか」をAIに正しく伝える方法に絞ります。

AIの回答は日・聞き方・使うサービスによって変わります。この記事の手順は、AIがアクセス情報を読み違えにくい状態を作り、確かめるためのもので、回答に出ることや正しく答えられることを保証するものではありません。

この記事では、上の記事が答えている質問（何を書くか・表記をそろえる・属性）をすべて扱ったうえで、徒歩分数の測り方の基準、駐車場の書き方の型、Googleの資料に沿った住所と座標の書き方、Nurevo を使ったWordPressの手順、AIへの確かめ方を足します。

アクセスのページに書く8つのこと

店舗情報のページか、独立した「アクセス」のページに、次の8つを書きます。地図を埋め込む場合も、地図の中身はAIが読めるとは限らないので、文字で同じことを書きます。

書くこと書く例抜けると起きること
住所（郵便番号・建物名・階）〒150-0000 東京都渋谷区例町1-2-3 例ビル3階建物名や階のない住所が広まり、入口で迷う人が出る
最寄り駅・路線・出口・徒歩分数JR山手線「例駅」東口から徒歩4分（約300m）別の駅や出口で案内される
道順（目印を2〜3個）東口を出て右へ。コンビニの角を左に曲がり、2つ目の信号の手前、1階が薬局のビルです近くまで来て迷う。電話の問い合わせが増える
入口と階入口はビルの正面ではなく、左側の通路の奥です。エレベーターで3階へビルは分かっても入口が分からない
駐車場専用駐車場2台（ビル裏、番号7・8）。満車のときは近くのコインパーキングをご利用ください（料金の補助はありません）AIが「駐車場あり」「なし」を推測する
自転車・バイク自転車はビル前の駐輪スペースに停められます。バイクは停められません停められない場所に停める人が出る
バリアフリー・ベビーカーエレベーターあり。入口に2cmの段差があります。車いすの方は事前にお電話ください行けるかどうか判断できない
バス・タクシー・車での行き方例バス「例町」停留所から徒歩1分。車は例通りから入れます（一方通行のため反対側からは入れません）車で来る人が入口の道を間違える

悪い例：「駅近！駐車場あり。詳しくは地図をご覧ください」。良い例：「JR例駅 東口から徒歩4分（約300m）。〒150-0000 東京都渋谷区例町1-2-3 例ビル3階。入口はビル左側の通路の奥です。専用駐車場2台（ビル裏、番号7・8）。満車のときは近くのコインパーキングをご利用ください」。

「駐車場あり」だけでは、台数・場所・無料かどうか・提携かどうかが分かりません。提携駐車場なら、駐車場の名前・住所・割引の条件（「◯円以上のご利用で1時間無料」など）を書きます。条件が変わったら、その日にページを直します。

「徒歩◯分」の書き方：測り方を決めて書き添える

徒歩分数は、書く人によって測り方がばらばらになりやすい数字です。日本の不動産広告には決まった基準があり、道路に沿った距離で80mを徒歩1分とし、80mに満たない端数は1分に切り上げます。信号の待ち時間や坂道は考えません（不動産の表示に関する公正競争規約の施行規則。三菱地所ハウスネットの用語集の説明による）。店舗やクリニックがこの基準に従う決まりはありませんが、基準をそろえておくと、ポータルの表示とサイトの表示が食い違いにくくなります。

  1. どの出口から、建物のどの入口までを測ったかを決める（「東口改札から、ビルの入口まで」）
  2. 道に沿った距離を地図アプリで測り、80mで1分として計算し、端数は切り上げる。「約300m」と距離も書くと、AIも人も確かめやすい
  3. 出口が複数ある大きな駅では、いちばん近い出口を書き、ほかの出口から来る場合の目安も1行添える
  4. ポータル・Googleビジネスプロフィールの説明文に別の分数が書かれていないか確かめ、同じ数字にそろえる

「駅から徒歩1分」と書くのは、本当に駅の出口の目の前にある場合だけにします。誇張した分数は、来た人の口コミで食い違いとして表に出ます。

住所の表記を1つにそろえる

AIは、サイト・Googleビジネスプロフィール・ポータル・SNSの情報を合わせて、同じ事業者かどうかを判断していると考えられています（どの情報をどう突き合わせているかは公開されていません）。住所の書き方が掲載先ごとに違うと、同じ店として結び付かなかったり、建物名や階を落とした住所が答えに使われたりします。次の5つを決め、全部の掲載先で同じにします。

  1. 番地の書き方（「1-2-3」か「1丁目2番3号」か）。どちらでもよいので1つに決める
  2. ハイフンの文字（半角の「-」に統一するなど）と、数字の全角・半角
  3. 建物名と階（「例ビル3階」）。建物名が変わったら、その日に全部の掲載先を直す
  4. 都道府県から書くかどうか（構造化データには都道府県まで入れる）
  5. 英語の住所を載せる場合は、日本語の住所と同じ場所だと分かる書き方（建物名のローマ字を含める）

移転したときは、新しい住所をアクセスのページに書き、「2026年◯月◯日に移転しました（旧住所：…）」と1行残します。旧住所のページを消すだけでは、外部サイトに残った旧住所とサイトの情報が結び付かず、AIが古い住所を答え続けることがあります。

Googleビジネスプロフィールの属性で駐車場とバリアフリーを設定する

Googleビジネスプロフィールには「属性」という項目があり、Google検索・Googleマップなどに表示されます。属性には事業者が自分で編集できるものと、来店した人の情報をもとに入るものがあります。バリアフリーの属性には、車いすで入れる入口・トイレ・席・エレベーター、車いすに対応した駐車場があり、「車いすに対応した駐車場」は、障がいのある方のための駐車スペースがある場合に「はい」を選ぶものです。編集後の確認には通常10分ほど、長い場合は30日かかることがあると書かれています（ビジネスの属性を管理する、2026-11-21確認）。表示される属性は業種によって違います。

GoogleのAIによる概要やAIモードがプロフィールの属性をどう使うかは公開されていません。ただ、プロフィールはGoogleマップと検索に表示される情報そのものなので、サイトの駐車場・バリアフリーの記述と同じ内容にしておきます。台数・料金・提携の条件のように属性で表せないことは、サイトの本文と、プロフィールの説明文に書きます。

構造化データ：住所・座標・地図・設備

Googleのローカルビジネスの構造化データのドキュメント（2026年9月更新）では、name と address が必須、geo（緯度・経度）は推奨のプロパティです。住所は PostalAddress の streetAddress・addressLocality・addressRegion・postalCode・addressCountry に分けて書く例が載っており、緯度・経度は小数点以下5桁以上の精度が必要とされています。座標は地図アプリで入口の位置を確かめて入れます（ビルの中心ではなく、人が入る入口のほうが道案内に合います）。

Googleのドキュメントには載っていませんが、schema.org には地図のURLを示す hasMap、設備を表す amenityFeature（LocationFeatureSpecification で名前と値を書く）、一般の人が訪れられるかを示す publicAccess があります。hasMap や amenityFeature をGoogleや他のAIが使うと明記した公式の資料は、調べた範囲では見つかりませんでした。付けても害はありませんが、本文に書いたことの言い換えとして付けるものです。

構造化データの住所・座標・駐車場の台数は、本文と同じ値にします。書いたら リッチリザルトテスト や Schema Markup Validator で文法を確かめます。複数の店舗がある場合は、店舗ごとのページに、その店舗の住所と座標を1つずつ書きます（複数拠点の事業者のAI検索対策）。

WordPressでの手順（Nurevo AIOの場合）

Nurevo AIO（無料、旧表示名 Nurevo AEO）では、設定画面の「住所」に入れた文字が、店の構造化データ（PostalAddress の streetAddress）と llms.txt の「Address」の行に、入れたとおりに出ます。次の順で進めます。

  1. 先にアクセスのページの本文を、この記事の8つのことで整える（構造化データより本文が先）
  2. 「住所」の欄には、サイトの本文・Googleビジネスプロフィールと同じ表記で、郵便番号・建物名・階まで入れる。欄の文字は分割されず、1つの文字列として出る
  3. Nurevo は住所から緯度・経度を推測して出すことはしない。座標を出したい場合は、開発者向けの webmcp_canary_business_node フィルターで geo を足す（下のコード）。hasMap・amenityFeature も同じフィルターで足せる
  4. SEOプラグインやテーマが店の名前・住所・電話・営業時間まで出している場合、Nurevo は店の情報を重ねて出さないので、フィルターは効かない。そのときはそのプラグインやテーマの設定で座標を入れる。Yoast SEO・Rank Math・All in One SEO・Slim SEO と一緒でも二重にならず、0.9.1からは SEO SIMPLE PACK・VK All in One Expansion Unit とも併用できる
  5. プラグインの診断の「重要情報の網羅」では、名前・住所・電話・営業時間・位置・URLがそろっているかを確かめられる
  6. ネットショップやBtoBとして設定したサイトでは、営業時間と位置（geo）は出ない（訪れる場所がないため）
add_filter('webmcp_canary_business_node', function ($org, $settings) {
    // 入口の座標とアクセスのページ。本文と同じ値にする
    $org['geo'] = array(
        '@type'     => 'GeoCoordinates',
        'latitude'  => 35.65812,
        'longitude' => 139.70164,
    );
    $org['hasMap'] = home_url('/access/');
    $org['amenityFeature'] = array(
        array('@type' => 'LocationFeatureSpecification', 'name' => '専用駐車場（2台）', 'value' => true),
    );
    return $org;
}, 10, 2);

子テーマの functions.php や、コードを追加するプラグインに書きます。書いたら、ページのソースかリッチリザルトテストで、店の情報に geo が入っていることを確かめます。移転や駐車場の変更のときは、欄・フィルター・本文の3か所を同じ日に直します。

お客様のサイトを保守している制作会社は、移転・駐車場の契約変更・建物名の変更を「その日に全掲載先を直す」作業として保守に入れておくと、直し忘れを防げます。月額で支援する制作会社向けにパートナー制度があります。

直したあとの確かめ方

直した日と、2〜4週間後に、同じ質問をAIに聞いて記録します。反映までの日数はどのAIも公開していません。

聞く質問正しい答えの条件
「（事業者名）の住所は？」建物名・階まで今の住所。移転前の住所でない
「（事業者名）に（最寄り駅）から行くには？」サイトに書いた出口と徒歩分数
「（事業者名）に駐車場はある？」サイトに書いた有無・台数・提携の条件
「（事業者名）は車いすで入れる？」サイトとGoogleビジネスプロフィールの記述と同じ
「（地域）で駐車場のある（業種）は？」名前が出たか、出たならアクセスのページが引用されたか

記録するのは、日付・AIのサービス名・質問・答え・出典のURLです。出典がポータルや古いチラシなら、そこを直します。Nurevoの無料プランとStandardでは、月に1回、業種と地域から作った社名なしの質問3つをNurevoのサービスがPerplexityに聞き、名前が出たか・サイトが引用されたかを表示します。Pro（月14,800円〜、ベータ）は最大20問をPerplexityで計測します（ChatGPTは設定され次第）。駐車場や行き方の質問は手で記録してください。詳しくはAIでの登場率の測り方へ。

公開前のチェックリスト

  1. 住所が郵便番号・建物名・階まで、HTMLの文字で書いてある
  2. 最寄り駅・路線・出口・徒歩分数と距離が書いてあり、測り方（どこからどこまで）を決めた
  3. 目印を2〜3個入れた道順と、入口の場所・階が書いてある
  4. 駐車場の有無・台数・場所・料金（提携なら条件）が書いてある。ない場合も「ありません」と書いた
  5. 自転車・バイク・バリアフリー・ベビーカーについて書いてある
  6. 住所の表記がサイト・Googleビジネスプロフィール・ポータル・SNSで同じ
  7. Googleビジネスプロフィールの属性（駐車場・バリアフリー）がサイトの記述と同じ
  8. 構造化データの住所・座標（小数点以下5桁以上）が本文と同じ
  9. 移転前の住所・終わった駐車場の情報がページ・PDF・ブログに残っていない
  10. AIへの質問を決め、直した日と2〜4週間後に記録した

よくある質問

地図を埋め込んでいれば、文字で書かなくてもいいですか？

文字でも書いてください。埋め込み地図の中身や画像の案内図をAIが読めるかは、サービスごとに違い、公開されていません。地図は人のための補助と考え、駅・出口・徒歩分数・入口・駐車場を本文に書きます。

駐車場がありません。書かないほうがいいですか？

「駐車場はありません」と書くほうが確実です。書かないと、AIがほかのサイトの情報や推測で答えることがあります。近くのコインパーキングの探し方や、公共交通での来方を添えます。

「徒歩◯分」はどう計算すればいいですか？

決まりはありませんが、日本の不動産広告の基準（道に沿った距離で80mを1分、端数は切り上げ）にそろえると、ポータルの表示と食い違いにくくなります。どの出口から入口までを測ったかも書き、距離も添えます。

構造化データに座標を入れないとAIに出ませんか？

そうとは限りません。Googleのドキュメントでは geo は推奨のプロパティで、必須は name と address です。ChatGPTやPerplexityが座標を使うかは公開されていません。まず本文と住所の表記を整え、座標は入口の位置を確かめて入れます。

hasMap や amenityFeature は付けるべきですか？

付けても構いませんが、Googleのドキュメントには載っておらず、AIが使うと明記した公式の資料も見つかりませんでした。本文に書いた地図のページや駐車場の情報を、同じ内容で言い換えるものとして付けます。

移転しました。古い住所がAIに出続けます。

サイト・Googleビジネスプロフィール・ポータル・SNSの住所を同じ日に直し、アクセスのページに移転日と旧住所を1行残します。AIが出典として示したURLを確かめ、古いページやPDFなら直すか消します。反映までの日数は公開されていないので、数週間後に同じ質問で確かめます。

Nurevoの「住所」の欄には、建物名や階まで入れていいですか？

入れてください。欄の文字はそのまま構造化データの streetAddress と llms.txt の「Address」に出ます。サイトの本文・Googleビジネスプロフィールと同じ表記にそろえます。

AIが読める状態か、無料で確かめる

無料の診断は登録不要で、URLを入れるだけでAIのクローラーの許可・構造化データ・llms.txt を確認できます。WordPressなら無料のプラグインで、住所・電話・営業時間を構造化データと llms.txt に出せます。SEOプラグインの出力とは重複しません。
