予約ページをAIに正しく読ませる書き方：予約方法・受付期限・キャンセル規定と、AIの中で予約できる仕組み

AIに予約のことを正しく答えてもらうには、自社サイトに予約ページを1つ決め、「予約の方法（ネット・電話・LINE）」「予約が必要か、当日や予約なしでも行けるか」「何日前まで・何日先まで受け付けるか」「キャンセルの期限と料金」「正式な予約先の一覧」を、画像や予約システムの埋め込みの中ではなくHTMLの文字で書きます。ChatGPTやGoogleのAIの中で予約まで進む仕組みは、2026年11月時点では主に飲食店向けで、OpenTableなどの予約サービスとの連携で動いています。自社サイトの予約ページは、その連携がなくてもAIが予約のルールを読みに来る場所です。

作成日：2026年11月21日（JST）。営業時間・定休日の書き方は営業時間・定休日をAIに正しく読ませる書き方、料金の書き方は料金ページの書き方で扱いました。この記事は、美容室・クリニック・飲食店・教室・宿泊・出張サービスなど、予約を受ける業種に共通する「予約ページ」に絞ります。

AIの回答は日・聞き方・使うサービスによって変わります。この記事の手順は、AIが予約のルールを読み違えにくいページを作り、正しく確かめるためのもので、回答に出ることやAIの中で予約できるようになることを保証するものではありません。

予約ページに書く8つの事実

予約について聞かれる質問は、だいたい次の8つに分かれます。それぞれに1〜2文で答える段落か表の行を、予約ページの本文に用意します。

事実書く例AIに聞かれる質問
予約の方法ネット予約（24時間）、電話（10時〜19時）、LINE（返信は営業時間内）「（店名）はどうやって予約する？」
予約が必要か予約制。予約なしでも空きがあれば受け付けます（待ち時間あり）「予約なしで行ける？」
受付の期限前日の20時まで。当日は電話のみ「当日予約できる？」
どこまで先か2か月先まで「来月の予約はもう取れる？」
所要時間カットは約60分「どのくらい時間がかかる？」
キャンセル規定前日までは無料。当日のキャンセルは料金の50%。連絡は電話で「キャンセル料はかかる？」
支払い・前金予約時の支払いはなし。来店時に現金・カード・QR決済「前払いが必要？」
対象・持ち物初めての方は問診票の記入で10分早めに。子ども連れ可「初めてでも大丈夫？」「子どもを連れて行ける？」

書くときは、どの文も単独で読んで意味が通るようにします。AIはページから1文だけを抜き出して答えることがあるので、「上記の通り」「こちらから」のような前後に頼る言い方は避けます。悪い例：「ご予約はこちらから。キャンセルは早めにご連絡ください。」良い例：「ネット予約は24時間、電話予約は10時〜19時に受け付けています。キャンセルは前日までは無料で、当日のキャンセルは料金の50%をいただきます。」

予約の有無で変わることも書きます。予約の人を優先する店なら「予約なしの方は、予約の方の合間にご案内します」、完全予約制なら「予約のない方はご案内できません」とはっきり書くと、AIが「予約なしでも大丈夫です」と誤って答えることを減らせます。

予約サイトを複数使っているとき：正式な窓口を決める

美容室や飲食店では、自社の予約システム、予約サイト、電話、LINEなど、予約先がいくつもあるのが普通です。AIは見つけた予約先をそのまま案内するので、やめた予約サイトや古い電話番号が残っていると、そちらを案内されることがあります。次の順で整理します。

  1. 使っている予約先をすべて書き出す（自社システム、予約サイト、Googleビジネスプロフィールの予約リンク、電話、LINE、SNSのDM）
  2. やめた予約先の掲載を消すか、「現在は受け付けていません」と書き換える
  3. 予約ページの本文に「ご予約は次の方法で受け付けています」として、使っている予約先だけを並べる
  4. メニューやコースごとに予約URLが分かれているなら、メニューごとの正式なURLを1つ決める（トップページへのリンクより、メニューの予約画面へ直接つながるURL）
  5. キャンセル規定・受付期限を、自社サイトと各予約サイトで同じにする。違う場合は、どの予約先にどの規定が適用されるかを書く
  6. 予約サイトやGoogleビジネスプロフィールの説明文から、自社サイトの予約ページへリンクする

Googleビジネスプロフィールの予約のリンクには決まりがあります。オーナー確認が済んでいること、リンク先がその店専用のページで、そこで予約を完了できること、SNS・メッセージアプリ・アプリストア・短縮URLは使えないこと、ログインやCAPTCHAなしで開けて200を返すこと、などです（ビジネスリンクのポリシー）。Reserve with Google に対応した予約サービスを使う方法もあり、自分で入れたリンクには実績のデータが出ない、と案内されています（予約サービス経由の予約）。

空き状況は書かない。確かめ方を書く

「土曜はいつも空いています」「平日は予約なしでも大丈夫」のような空き状況を本文に書くと、AIは状況が変わってもその文を使い続けることがあります。各AIがページを読み直す間隔は公開されていません。空き状況は予約システムで見るものとして、本文には「空き状況はネット予約の画面でご確認ください。当日の空きは電話でお問い合わせください」のように、確かめ方を書きます。

混みやすい時間帯を書くなら「土日の午後は混み合うため、予約をおすすめします」のように、変わりにくい傾向として書きます。実際より空いているように見せる書き方は、人にもAIにも誤解のもとになります。

AIが読める形にする：埋め込み・画像・ログインを確かめる

予約システムの多くは、予約画面を別のサイトから埋め込む形（iframe）やJavaScriptで表示します。人には見えても、埋め込みの中の文字が予約ページの本文として読まれるかはAIのサービスごとに違い、公開されていません。予約のルールは、埋め込みの外側、予約ページそのものの本文に書くのが確実です。予約フォームは埋め込みのままで構いません。

自分の予約ページが、ログインなしで開けて本文にルールを持っているかは、次のコマンドで確かめられます。

# 予約ページが、ログインなし・200で、本文に予約のルールを持っているか
curl -s -o /dev/null -w "%{http_code}\n" https://example.jp/reserve/
curl -s https://example.jp/reserve/ | grep -E "キャンセル|予約受付|当日"
# 何も出なければ、ルールは画像・予約システムの埋め込み・JavaScriptの中にあります

ChatGPTの検索に載るには、OAI-SearchBot のクロールを許可し、サーバーやCDNが OpenAI の公開しているIPアドレスからのアクセスを通すことが大切だと案内されています（OpenAI ヘルプ）。予約ページだけをボット対策で止めていないかも確かめてください。AIの代理の操作で予約を受けたい事業者向けに、Stripe はボット対策の見直しや WebMCP の利用を挙げていますが、これは決済まで含めた先の話です（Stripe）。

構造化データ：ReserveAction は付けてよいが、期待しすぎない

schema.org には「予約する」という行動を表す ReserveAction があり、サービスに予約のURLを結び付けて書けます。ただし、ChatGPT・Perplexity・GoogleのAI機能が ReserveAction を予約に使うと書いた公式の資料は、調べた範囲では見つかりませんでした。GoogleはAI機能のために特別な構造化データは要らず、構造化データは見えている本文と一致させるよう案内しています（AI機能とウェブサイト、2026-11-18に確認）。付けても害は小さいものの、予約ボタンが出るようになるものではありません。

付ける場合は、次のように Service（サービス）ごとに予約URLを指す形にします。Nurevo AIO が出力する形と同じです。

<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "Service",
  "@id": "https://example.jp/#nurevo-service-1",
  "name": "カット（シャンプー・ブロー込み）",
  "provider": { "@id": "https://example.jp/#business" },
  "additionalProperty": {
    "@type": "PropertyValue",
    "name": "duration",
    "value": 60,
    "unitCode": "MIN",
    "unitText": "minutes"
  },
  "offers": { "@type": "Offer", "price": "5500", "priceCurrency": "JPY" },
  "potentialAction": {
    "@type": "ReserveAction",
    "target": { "@type": "EntryPoint", "urlTemplate": "https://example.jp/reserve/cut/" },
    "result": { "@type": "Reservation", "name": "カット（シャンプー・ブロー込み）" }
  }
}
</script>

ポイントは、Reservation（予約そのもの）を単独で書かないことです。Reservation だけを書くと「予約がすでにある」という意味になり、事実と違います。ReserveAction の結果（result）として書けば「この操作で予約ができる」という意味になります。書いたら Schema Markup Validator で文法を確かめます。

WordPressでの手順（Nurevo AIOの場合）

Nurevo AIO（無料、旧表示名 Nurevo AEO）では、設定画面の「サービス」に入れた予約URLが、Service の構造化データの ReserveAction と llms.txt に出ます。次の順で進めます。

  1. 先に予約ページの本文を、この記事の8つの事実で整える（構造化データより本文が先）
  2. サービスを登録する（最大20件）。「サービス名」「所要時間（分）」「料金」「通貨」に加えて「予約URL」に、そのメニューの予約画面のURLを入れる
  3. 予約URLを入れたサービスは、llms.txt でサービス名が予約URLへのリンクになる（例：- カット — 60 min · JPY 5500）
  4. 予約プラグイン（Amelia など）の中身は読み取らない。所要時間や予約URLの誤った値を事実として出さないためで、値は手で入れる
  5. 「サービスを掲載するページID」に予約ページかメニューページのIDを入れると、サービスの構造化データがそのページに出る（0はフロントページ）
  6. キャンセル料・当日予約・予約なしの来店は、よくある質問に登録する。Yoast SEO・Rank Math・All in One SEO・Slim SEO と一緒でも二重にならず、SEO SIMPLE PACK・VK All in One Expansion Unit とも併用できる（0.9.1から）
  7. 予約先を変えたときは、本文・Nurevo の予約URL・FAQの答え・Googleビジネスプロフィールを同じ日に直す

お客様のサイトを保守している制作会社は、「予約先の変更」を保守の作業範囲に入れておくと、予約サイトの乗り換えのたびに古いURLが残るのを防げます。月額で支援する制作会社向けにパートナー制度があります。

確かめ方：予約の質問を決めて記録する

予約のルールが正しく伝わっているかは、同じ質問を同じAIに、日を変えて何回か聞いて記録します。1回の答えだけで判断しないでください。

質問の例見ること
「（店名）は予約が必要？」予約制か、予約なしでも行けるかが合っているか
「（店名）は当日予約できる？」受付の期限と方法（電話のみ等）が合っているか
「（店名）のキャンセル料は？」期限と料金が合っているか。出典が古い予約サイトではないか
「（店名）の予約方法は？」案内された予約先が、いま使っている正式な窓口か
「（地域）で今日予約できる（業種）は？」社名なしの質問で候補に入るか。予約ボタンが出るか（飲食店の場合）

記録するのは、日付・AIのサービス名・質問・答え・出典のURLです。出典が古い予約サイトやブログ記事なら、そこを直します。Nurevoの無料プランとStandardでは、月に1回、業種と地域から作った社名なしの質問3つをNurevoのサービスがPerplexityに聞き、名前が出たか・サイトが引用されたかを表示します。Pro（月14,800円〜、ベータ）は最大20問をPerplexityで計測します（ChatGPTは設定され次第）。予約の質問は手で記録してください。詳しくはAIでの登場率の測り方へ。

よくある質問

サイトに何を書けば、ChatGPTに予約ボタンが出ますか？

サイトの書き方で予約ボタンが出る仕組みにはなっていません。OpenAI のヘルプでは、予約ボタンはChatGPTが対応する予約サービス（OpenTable・Resy・Yelp）の掲載とお店を結び付けられたときだけ出る、とされています。サイトには予約のルールを正しく書き、使っている予約サービスの掲載を正しく保つのが、店にできることです。

ReserveAction を付ければ、AIから予約が入りますか？

そうした公式の説明は見つかっていません。ReserveAction は付けても害は小さいものですが、予約を増やす効果は確かめられていません。先に本文の予約のルールを整えてください。

予約システムの埋め込みだけで、本文がありません。

埋め込みの中の文字が予約ページの本文として読まれるかはAIのサービスごとに違い、公開されていません。予約フォームは埋め込みのままでよいので、その上か下に、予約方法・受付期限・キャンセル規定を文字で書いてください。

予約サイトのキャンセル規定と、自社サイトの規定が違います。

AIはどちらを答えるか分かりません。できれば同じにし、違う場合は「ネット予約は前日まで無料、予約サイト経由の予約は各サイトの規定に従います」のように、どの予約先にどの規定が適用されるかを書いてください。

空き状況をサイトに書いたほうがAIに出やすくなりますか？

空き状況は変わるので、本文に書くと古い情報がAIの答えに残るおそれがあります。本文には空きの確かめ方を書き、空きそのものは予約システムで見てもらいます。

飲食店以外でも、AIの中で予約できるようになりますか？

Googleは2025年8月に、AIモードでの予約の代行を地域のサービスの予約にも広げる予定と発表しましたが、この記事を書いた時点で日本で使えるという公式の発表は確認できていません。今できることは、予約ページとGoogleビジネスプロフィールの予約リンクを正しく保つことです。

予約ページを変えたら、AIの答えはいつ変わりますか？

各AIが反映するまでの日数は公開されていません。変更の数日後から数週間後に、同じ質問で確かめてください。答えに古い予約先が出る場合は、出典のURLを確かめ、そのページを直します。

AIがサイトを読める状態かを確かめる

無料チェックは登録不要です。URLを入れると、AIクローラーの許可、構造化データ、llms.txtの状態が分かります。WordPressなら無料のプラグインで、サービスと予約URLを構造化データとllms.txtに出し、SEOプラグインと重ならないように整えられます。
