プレスリリースをAI検索に読まれる形に整える：本文の型・原本の置き方・制作会社の代行メニュー

AIはプレスリリースを出典に使います。8万件余りのAIの回答を調べた調査では、回答の15.05%が少なくとも1本のリリースを出典に挙げ、その6割は配信サービスのページでした。引用されやすくするには、冒頭の3行に「誰が・何を・いつ・数字」を書き、数字には時点と数え方を付け、同じ内容の原本をお客様の自社サイトに置きます。リリース内のリンクを検索順位のために作り込むのはGoogleのスパムの決まりに触れるため、やりません。

作成日：2026年11月25日（日本時間）。調査の数字は Optyino.ai（株式会社Wallabee）の2026年7月の発表、Muck Rack・Meltwater の公開資料、リンクの決まりは Google のスパムに関するポリシー（2026年11月24日更新）を同日に読んで確認しました。

この記事は、お客様のプレスリリースの作成や配信を手伝っている制作会社・代理店向けです。リリースを整えても、AIの回答に会社が必ず出るわけではありません。AIの回答は日々変わり、出典の選び方も公表されていません。ここでは、正しい事実がAIと記者に伝わる形にする手順と、それを月額の作業として説明する方法を書きます。

AIはプレスリリースをどれくらい出典にしているか

調査によって数え方が違い、数字は大きくずれます。「回答のうちリリースを1本でも出典にした割合」と「出典のURL全体に占めるリリースの割合」は別の数字なので、混ぜないことが大切です。

調査対象わかったこと
Optyino.ai（2026-07-11発表）2026年4月21日〜7月8日、120の質問（金融・住宅・家電・BtoBサービス）、81,895件の回答回答の15.05%がリリースを1本以上出典にした。出典のURL全体ではリリースは2.20%。リリースのURLの60.5%がPR TIMES、上位5つのサイトで69.4%
同上（AIごと、回答に占める割合）APIで集めた回答ChatGPT（GPT-5 mini）42.84%（件数が少ない）、ChatGPT（GPT-5.2）27.33%、Perplexity 21.45%、GoogleのAIモード 20.68%、AIによる概要 12.81%、Claude 6.00%、Copilot 2.90%
Muck Rack（2025年12月）100万件超のリンク、2025年7〜12月出典に占めるプレスリリースが1.2%から約6%に増えた
Meltwater（2026-06-26、09-29更新）8つのAI、800万件超の出典（自社ツールのデータ）2026年5月はプレスリリースが出典の0.2%（4月は0.4%）

出典：Optyino.ai の発表（PR TIMES）、Muck Rack 2025年12月、Meltwater。いずれも関連する製品を売る会社の調査です。Optyino.ai の調査は API で集めた回答で、分類は自動、質問は4つの分野に偏っており、モデルの更新で数字が変わると発表自体に書かれています。Meltwater の数え方の詳細は公開されていません。

3つから言えるのは、①AIはリリースを出典に使うことがあり、②その割合は質問の分野とAIによって大きく違い、③出典のURL全体の中では小さな割合にとどまる、ということまでです。「リリースを出せばAIに出る」とは言えません。

引用されるのは、どのURLか

Optyino.ai の調査では、出典になったリリースのURLの60.5%がPR TIMESのページでした。AIが出典に挙げるのは、多くの場合お客様のサイトではなく配信サービスのページです。また、回答の本文の中にリンクが張られていたのは0.63%で、ほとんどは回答の下の出典の欄に並んでいました。

ここから、制作会社の作業として次の2つが大切になります。

  1. 配信先のページだけで事実がわかるように書く：AIが読むのは配信先の1ページです。会社の正式名・所在地・日付・数字を、リリースの中で完結させます。
  2. お客様のサイトに原本を置く：配信先は後から直せないことがあります。訂正や価格の変更を書き足せる原本を自社サイトに置き、リリースの末尾からリンクします。AIや記者が「今の正しい事実」を確かめる先になります。

AIと記者の両方が読める本文の型

上位の記事が勧める書き方は、ほぼ「逆三角形（大事なことを先に）」と「質問に答える見出し」にまとまります。それを1本のリリースの型にしたのが下の例です。お客様から材料を集めるときの聞き取りの表にも使えます。

【タイトル】（社名）、（何を）（いつから）（どこで）開始　※数字があれば入れる
【要約（3行）】
・何が新しいか（1文）
・誰の役に立つか（1文）
・数字・期間・場所（1文）
【リード】（日付）、（正式な社名）（本社：市区町村、代表者：氏名）は、……
【本文】見出しごとに1つの事実。数字には「（2026年10月末時点、自社集計）」のように時点と数え方
【よくある質問】記者と読者が聞きそうな質問を3〜5個、答えは2〜3文
【コメント】担当者の名前・役職と、本人の言葉（言い切れる事実だけ）
【会社概要】正式名・所在地・設立・事業内容・URL（自社サイトの会社概要と同じ表記）
【原本】自社サイトのこのリリースのURL／お問い合わせ先

会社概要の表記は、お客様のサイトの会社概要・Googleビジネスプロフィールと1文字までそろえます。社名や所在地の書き方がばらばらだと、AIが別の会社として扱うおそれがあります。会社概要ページの整え方は会社概要ページのAI検索対策にあります。

書き換えの例

よくある書き方書き換え理由
業界初の画期的なサービスを開始（社名）、（市区町村）で（サービス名）を12月1日から開始。初年度の目標は50社確かめられない言葉より、日付・場所・数字のほうが引用されやすく、誤解も生まない
多くのお客様にご好評いただいています2026年10月末時点で導入は128社（自社集計）数字に時点と数え方を付けると、AIも記者も裏付けとして扱える
詳しくはWebで料金：月額3万円（税別）から。対象：従業員50人以下の会社AIは配信先のページだけを読むことが多い。リンク先に頼らない
弊社／当社初出で正式な社名、以降は略称を1つに決める社名の揺れは別の会社に見える原因になる
調査の結果、7割が満足2026年10月1〜14日、インターネット調査、全国の20〜60代500人。「満足」「やや満足」の合計72.4%調査の方法がないと、数字だけが切り取られて広まる

調査リリースは「方法」を本文に書く

調査の数字はAIの回答に引用されやすい材料ですが、方法が書かれていない数字は、引用されても誤って広まります。期間・方法・対象・人数・設問・集計の仕方を本文に書きます。

Optyino.ai の発表自体がよい例です。期間、質問の数と分野、回答の件数に加えて、「分類は自動」「APIの回答で実際の画面と違うことがある」「モデルの更新で変わる」という限界まで書かれています。お客様の調査でも、限界を書くことは信頼を下げるのではなく、正しく引用されるための材料になります。

やってはいけないこと：リンクの作り込みと量産

  1. リリースのリンクを検索順位のために作り込まない：Googleのスパムに関するポリシーは、リンクスパムの例として、他のサイトで配布される記事・ゲスト投稿・プレスリリース内の作為的なアンカーテキストのリンクを挙げています（Google：スパムに関するポリシー）。この例は2013年に加わりました（Search Engine Land）。リンクは「会社のサイト」「このリリースの原本」のように素直に書きます。
  2. 有料の配信や記事広告のリンクには rel="nofollow" または rel="sponsored" が付いていれば、Googleのポリシー違反にはならないとされています。配信サービスがどう扱っているかを確かめておきます。
  3. 言い回しを変えた同じリリースを量産しない：Googleは、検索順位の操作を主な目的に大量のページを作ることを「大量生成されたコンテンツの不正使用」としています。ニュースのない月にリリースを出すより、事実が変わったときに1本出すほうが、お客様の信用を守れます。
  4. 確かめられない最上級を使わない：「No.1」「業界初」は根拠を本文に書けるときだけにします。広告の表示の決まり（景品表示法など）にも関わります。
  5. AIに読ませるためだけの文章を足さない：見えない文字や、本文と関係のないキーワードの羅列は、読者にも記者にも害になります。

お客様から「AIに出るリリースを大量に」と頼まれたときの判断と断り方はAI検索の不正な手法を頼まれたらにまとめています。

WordPressで、お客様のサイトに原本を置く手順

  1. 投稿に「プレスリリース」のカテゴリを作り、一覧のURLを /news/press/ のような短い英字にします。配信した文章と同じ内容を、配信日と同じ日に公開します。
  2. 抜粋（要約）の欄に、型の「要約（3行）」をそのまま入れます。Nurevo AEO（無料のWordPressプラグイン）は、SEOプラグインがないサイトでは、投稿の構造化データ（BlogPosting）の説明に抜粋を使い、抜粋がなければ本文の冒頭を使います。見出し・公開日・更新日・著者・アイキャッチ画像も入り、発行元は会社の情報を指します。
  3. Yoast SEO・Rank Math・All in One SEO・Slim SEO が有効なサイトでは、記事の構造化データはそれらのプラグインのものがそのまま使われます。0.9.1 からは SEO SIMPLE PACK・VK All in One Expansion Unit と一緒に使っても重複しません。
  4. 訂正や価格の変更があれば、本文を書き換えたうえで、冒頭に「2026年12月3日 訂正：料金を〇〇に改めました」と日付つきで追記します。配信先のページにも訂正を依頼し、両方の表記をそろえます。
  5. Nurevo AEO の llms.txt は、最近更新した公開済みのページと投稿を30件まで並べます。リリースが多いサイトでは古いものが外れるため、一覧のページを常に載せたい場合はフィルター webmcp_canary_llms_txt_lines で行を足します（下の例）。載せたくない投稿は、投稿ごとの設定で llms.txt から外せます。
  6. 入れたら、/llms.txt と投稿のソース（application/ld+json）で、抜粋と日付が本文と同じになっているかを確かめます。WordPress.orgで入手
// llms.txt に「プレスリリース一覧」の行を常に載せる
add_filter('webmcp_canary_llms_txt_lines', function (array $lines) {
    $lines[] = '## プレスリリース';
    $lines[] = '';
    $lines[] = '- [プレスリリース一覧](https://example.co.jp/news/press/): 当社の発表の原本（日付・訂正の履歴つき）';
    $lines[] = '';
    return $lines;
});

制作会社の代行メニューの作り方

リリースの代行を「1本いくら」の作業だけで終わらせず、AIと記者に読まれる形に整える作業を月額の保守に組み込むと、お客様に成果の確かめ方まで説明できます。料金は会社ごとに決めるものなので、ここでは作業の分け方だけを示します。

作業頻度成果物確かめること
材料の聞き取りリリースごと型に沿った聞き取りの表数字に時点と数え方があるか
本文の作成・書き換えリリースごと配信用の本文と要約3行社名・所在地が会社概要と同じか
原本の公開リリースごと自社サイトの投稿（抜粋・日付つき）配信先から原本にリンクしたか
訂正の管理随時訂正の追記と配信先への依頼両方の表記がそろったか
AIの回答の記録月1回決めた質問の答えと出典のURLの記録出典が配信先か原本か、内容が正しいか

配信サービスの料金は別にかかります。たとえば共同通信PRワイヤーは、公式ページでスポット1本78,000円、年5本186,000円（いずれも税別）と案内しています（共同通信PRワイヤー、2026年11月25日に確認）。お客様の見積もりでは、配信費と作業費を分けて書きます。

AI検索の整備全体を月額の保守にする方法は制作会社がAI対策を月額サービスにする方法、第三者の記事を一覧にする掲載実績のページはメディア掲載ページの作り方にあります。パートナーの条件はパートナーのページをご覧ください。

確かめ方

  1. リリースのテーマに合う質問を3〜5個決めます（例：「（地域）で（サービス）を始めた会社は？」「（社名）の（サービス名）の料金は？」）。配信の前の日と、2〜4週間後に同じ質問をChatGPT・Perplexity・GoogleのAIモードに聞きます。
  2. 答えに社名が出たか、内容が正しいか、出典が配信先・原本・第三者の記事のどれかを、日付と一緒に表に記録します。
  3. 内容が古い・違う場合は、原本の訂正と配信先への依頼を先にします。AIの答えの直し方はAIでの登場率の測り方の記録の方法と合わせて進めます。
  4. Googleアナリティクス4で原本の投稿へのAIのサービスからの流入を、Search Consoleで社名やサービス名の検索の変化を見ます。
  5. Nurevo AEO の無料のAIチェックは、接続したサイトに月1回、業種と地域から作った3つの質問を Perplexity に聞きます。継続して測る Pro（月14,800円〜）も現在は Perplexity で測っています（ChatGPTは設定され次第）。

チェックリスト

  1. 冒頭の3行に、誰が・何を・いつ・数字を書いた
  2. 数字に時点と数え方を付けた
  3. 調査リリースに期間・方法・対象・人数・限界を書いた
  4. 会社概要の表記をお客様のサイトの会社概要と同じにした
  5. 「業界初」「No.1」は根拠を本文に書けるときだけ使った
  6. リンクは作り込まず、会社のサイトと原本を素直に示した
  7. 同じ内容を言い回しだけ変えて何本も出していない
  8. お客様のサイトに原本を公開し、抜粋に要約3行を入れた
  9. 訂正は日付つきで追記し、配信先にも依頼した
  10. 決めた質問の答えと出典を、配信前と2〜4週間後に記録した

よくある質問

プレスリリースを配信すれば、AIに会社が出ますか？

必ずとは言えません。8万件余りの回答の調査では、リリースを出典にした回答は15.05%で、AIや質問の分野によって大きく違いました。正しい事実が伝わる形に整えることが、できる準備です。

AIが出典にするのは配信サービスのページですか、自社サイトですか？

調査ではリリースのURLの60.5%がPR TIMESでした。配信先のページだけで事実がわかるように書き、訂正できる原本を自社サイトに置いて、両方の表記をそろえます。

リリースにリンクをたくさん入れたほうがいいですか？

いいえ。他のサイトで配布されるリリース内の作為的なアンカーテキストのリンクを、Googleはリンクスパムの例に挙げています。会社のサイトと原本へのリンクを素直に入れるだけで十分です。

よくある質問（Q&A）をリリースに入れる意味はありますか？

記者と読者が聞きそうな質問に2〜3文で答えておくと、AIが答えの一部として使える形になります。ただし効果を示した公式の説明はなく、中身が事実であることが前提です。

自社サイトに同じ文章を載せると、重複になりませんか？

自社の発表の原本を自社サイトに置くことは、検索順位の操作を目的とした量産とは違います。言い回しだけを変えた同じリリースを何本も出すことは避けてください。

構造化データは必要ですか？

必須ではありません。WordPressの投稿として公開すれば、Nurevo AEO またはSEOプラグインが記事の構造化データを出します。AIがリリースの構造化データを使うと公表している会社はありません。

効果はどのくらいで確かめられますか？

反映までの期間は公表されていません。配信前の日と2〜4週間後に同じ質問をして、答えと出典を記録してください。AIの回答は日によって変わるため、月1回など決まった間隔で続けます。

まず、お客様のサイトをAIが読めるか確認

登録不要の無料チェックで、会社の構造化データ、llms.txt、AI検索のクローラーの許可の状態がわかります。WordPressなら、Nurevo AEOで不足分を無料で整えられます。
