ポータル・比較サイト・地図アプリの自社情報の直し方：AIが読んでいる掲載先を見つけ、正しい事実にそろえる手順

AIの回答に古い住所・営業時間・電話番号が出るとき、直す相手はAIではなく、AIが出典にしている掲載先です。まず自社サイトに「正しい事実の表」を置き、AIの回答の出典と古い情報の文字で掲載先を探し、Googleビジネスプロフィール・地図アプリ・業種のポータル・比較サイトの順に、それぞれの窓口で直します。海外の調査では、AIの出典の4割前後が掲載サイトでした。

作成日：2026年11月27日（JST）。掲載先のヘルプ・規約と調査のページは、本文のリンク先で2026年11月27日に確認しました。掲載先の手順や画面は変わることがあるので、作業の前に各社のヘルプで確かめてください。

AIの回答は日や聞き方によって変わります。掲載先を直しても、AIの回答にいつ反映されるかは各社とも公表しておらず、この記事の方法でAIに必ず正しく表示されることは保証できません。直すのは「AIが読む元の情報」で、効果は期間をあけて確かめます。

AIはどの掲載先を読んでいるか：分かっている数字

「AIは掲載サイトを読んでいるのか」は、2024年から2026年にかけて海外でいくつか調べられています。どれも米国・英国などのデータで、日本の掲載サイト（食べログ、ホットペッパー、エキテンなど）がどれだけ出典になっているかを調べた公開データは、確認できた範囲ではありません。

数字は各調査のページから。BrightLocal（2026）は要約文でYelpを8.53%と書いており、表の値（9.53%）と食い違っています。この記事は表の値を使いました。Yextは掲載情報の管理サービスの会社で、調べ方も対象もそれぞれ違うため、数字を足したり直接比べたりはできません。
調査対象分かったこと
BrightLocal（2026年8月26日公開、11月13日更新）米国・英国・オーストラリアの1,355拠点、Google AIによる概要・AIモード・ChatGPT、出典 約197万件出典の割合（表の値）：Googleビジネスプロフィール 28.63%、Yelp 9.53%、Facebook 2.23%、Tripadvisor 1.79%、OpenTable 1.18%。ChatGPTではGoogleビジネスプロフィールは上位に入らず、Yelpが回答の80%で出典に出た

BrightLocal（2024年12月12日）米国、ChatGPTで800回検索（2024年11月）出典は事業者のサイト58%、記事などでの言及27%、掲載サイト15%。このときはYelp・Facebook・Googleマップは掲載サイトの出典に出なかった

読み取れることは3つです。1つ目、事業者のサイトと掲載サイトは、どの調査でもAIの出典の大きな部分を占めます。2つ目、AIごとに使う掲載サイトが違い、2024年と2026年でも変わっています（ChatGPTのYelpがその例です）。3つ目、だから「このサイトに載れば十分」という決め打ちはできず、自分の業種と地域で、AIが実際に出典にしている掲載先を調べるのが確実です。

古い情報が残るとどうなるかについて、Birdeye（2026年3月17日更新）は、閉業したクリニックや飲食店を営業中として示したAIがあったと書いています（割合は示されていません）。

上位の解説記事に足りないこと

2026年11月27日に、「サイテーション AI検索」「掲載情報 修正 AI」「fix wrong business info AI」などの上位記事を日本語5本・英語5本読みました。日本語では、サングローブ（2026年9月16日更新）と0120.co.jp（10月20日更新）がNAP（名前・住所・電話）の統一と掲載先の棚卸しを手順にしていますが、どちらもMEO（地図検索）の話が中心で、AIの回答のどこから古い情報が来ているかの調べ方はありません。アシストは検索の演算子で言及を探す方法を書きますが、調査の数字に出典がありません。uravation（9月5日更新）とkoukoku.jp（11月27日更新）はAIの回答の直し方を扱いますが、掲載先ごとの直し方は「正しい情報に更新する」の一言です。

英語では、Thrive（2026年9月16日）とSEO.com（11月20日更新）が「出典をたどって元を直す」流れを、Semrush（5月8日）とthestacc（7月10日更新）がAIごとの報告の方法を書いています。PushLeads（11月21日更新）は数字が多いものの、ほとんどにリンクがありません。10本とも、掲載先の運営者に出す依頼文の例、移転や閉業のときに直す順番、WordPress側で何を書くか、直したあとの確かめ方の記録の形がありませんでした。この記事はそこを埋めます。

手順1：直す前に「正しい事実の表」を1枚作る

掲載先を直す前に、正しい事実を1か所にまとめます。担当者や時期によって「例カフェ中央店」「例カフェ 中央」と表記が揺れていると、掲載先ごとに違う名前で登録され、AIが同じ店だと判断しにくくなります。表は社内用ですが、同じ内容を自社サイトの店舗ページ・会社概要にも書き、掲載先への依頼で「確認できる資料」として示します。

正しい事実の表（例）　最終更新：2026-11-27　担当：◯◯
正式な名前 ：例カフェ 中央店（「例カフェ中央店」「例カフェ 中央」は使わない）
住所       ：〒000-0000 ◯◯県◯◯市中央1-2-3 例ビル2階
電話       ：00-0000-0000（予約・問い合わせ共通）
営業時間   ：火〜日 11:00-20:00（ラストオーダー 19:30）／定休日 月曜（祝日は営業、翌火曜休み）
サイト     ：https://example.jp/ （店舗ページ https://example.jp/shop/chuo/）
予約       ：https://example.jp/reserve/ （電話でも可）
変更の予定 ：2027-01-10 から 営業時間を 11:00-21:00 に変更
過去の情報 ：旧住所 ◯◯市本町4-5-6（2025-03 に移転）／旧電話 00-1111-1111（使用停止）

ポイントは「過去の情報」の行です。旧住所・旧電話番号・旧店名は、次の手順で古い掲載を探すための検索語になります。営業時間の書き方（祝日・年末年始・ラストオーダー）は営業時間・定休日のAI検索対策にまとめています。

手順2：AIが実際に使っている掲載先を見つける

掲載先は数百あり得ますが、全部を直す必要はありません。先に、AIの回答に影響していそうな掲載先を見つけます。

  1. AIに聞く：ChatGPT・Perplexity・Google（AIによる概要・AIモード）に、店名入りの質問（「例カフェ 中央店の定休日は？」）と、店名なしの質問（「◯◯市中央で月曜もやっているカフェは？」）を聞きます。回答に出典のリンクが付いたら、そのURLを全部書き写します。
  2. 古い情報の文字で探す：Googleで、旧住所・旧電話番号・旧店名を""で囲んで検索します（例："00-1111-1111"）。出てきたページは、AIがいつか読む可能性のある古い掲載です。
  3. 主な地図アプリを見る：Googleマップ、Appleのマップ、Bingの地図で店名を検索し、同じ店が2つ出ないか（重複）、閉業や移転前の場所が残っていないかを見ます。
  4. 業種のポータルを見る：飲食なら食べログ・ぐるなび・ホットペッパーグルメ、美容ならホットペッパービューティー、宿なら予約サイト、医療なら病院検索のサイトなど、業種の主な掲載先を店名で検索します。
  5. 表にする：見つけた掲載先ごとに、URL・間違っている項目・誰が直せるか（自社・運営者・筆者）・AIの出典に出たか、を1行で書きます。

直す順番は、「AIの出典に出た掲載先」→「Googleビジネスプロフィールと地図アプリ」→「業種の主なポータル」→「その他の掲載先・記事」です。AIの回答は回ごとに変わるので、出典は1回の結果で決めつけず、日をあけて2〜3回聞いて重なるものを優先します。

手順3：掲載先ごとの直し方

掲載先によって、直せる人と窓口が違います。自社が管理者として登録できる掲載先は自分で直し、できない掲載先は運営者に依頼します。

手順4：運営者・筆者への依頼文の型

自分で直せない掲載先には、メールか問い合わせフォームで依頼します。運営者は多くの依頼を受けるので、どのページの・どの項目を・何に直すかと、確認できる資料を1通に入れると、確認の手間が減ります。

件名：【掲載情報の訂正のお願い】例カフェ 中央店（◯◯市）

◯◯（サイト名）ご担当者様

いつもお世話になっております。例カフェ 中央店の◯◯と申します。
貴サイトの次のページに掲載いただいている当店の情報に、古い内容がありましたので、訂正をお願いできますでしょうか。

対象ページ：https://（掲載ページのURL）
訂正をお願いしたい箇所：
・住所　　掲載：◯◯市本町4-5-6　→　正：◯◯市中央1-2-3 例ビル2階（2025年3月に移転しました）
・定休日　掲載：水曜　→　正：月曜（祝日は営業、翌火曜休み）

確認いただける資料：当店の公式サイトの店舗ページ https://example.jp/shop/chuo/
（必要でしたら、店舗の電話 00-0000-0000 にご確認ください）

掲載いただいていることに感謝しております。お手数をおかけしますが、よろしくお願いいたします。

例カフェ 中央店　◯◯（店長）
メール：info@example.jp

書くときのポイント：対象ページのURLと、「掲載」と「正」を並べた行を必ず入れます。理由（移転・電話番号の変更など）を一言添えると、運営者が古い情報だと判断しやすくなります。掲載そのものへのお礼を入れ、削除や順位の変更など、訂正以外のお願いは混ぜません。

返事がないときは、2〜3週間あけて1回だけ送り直し、それでも直らなければ表に「依頼済み・未反映」と書いて次に進みます。何度も送ったり、別の名前で提案を繰り返したりするのはやめましょう。

移転・名前の変更・閉業・重複のときの順番

大きな変更は、直す順番を間違えると古い情報と新しい情報が混ざります。次の順で進めます。

順番はこの記事の提案です。Googleの再確認の決まりは、Googleビジネスプロフィールのヘルプによります。
変更直す順番注意すること
移転自社サイト（新住所と「◯年◯月に移転」の一文）→ Googleビジネスプロフィール（同じプロフィールの住所を変更）→ Apple・Bing → 業種のポータル → その他新しいプロフィールを作らず、今のプロフィールの住所を変える。移転後はGoogleで再度のオーナー確認が必要
名前の変更自社サイト（旧名も「旧◯◯」と一度書く）→ Googleビジネスプロフィール → 各掲載先旧名で検索する人とAIのために、しばらくは旧名もサイトに残す
閉業（1店舗だけ）自社サイト（閉店の日と、近くの店舗）→ Googleビジネスプロフィールで閉業に → 各掲載先ページは消さず、閉店のお知らせとして残すと、AIが閉業を読める
重複残すほうを決める → Googleマップの「重複」で報告 → 各掲載先で統合か削除を依頼口コミが多いほうを残すことが多い。統合できるかは掲載先しだい

店舗が複数ある場合の、店舗ごとのページと掲載の分け方は複数店舗のAI検索対策をご覧ください。

WordPress側でやること：サイトをいちばん正しい情報源にする

掲載先を直しても、自社サイトが古ければ元に戻ります。BrightLocalの調査でも、出典の件数の4割強は事業者自身のサイトでした。サイトには次の4つを置きます。

  1. 店舗ページか会社概要に、正しい事実の表と同じ内容を文字で書く（画像だけにしない）。最終更新日も書く。
  2. 移転・名前の変更・閉業は、お知らせの記事だけでなく、店舗ページの本文に一文で書く。
  3. 構造化データ（LocalBusiness）とllms.txtに、同じ名前・住所・電話・営業時間を出す。Nurevo AEOでは、事業者情報の画面に入れた内容が構造化データと /llms.txt の両方に出るので、表記が1か所でそろいます。
  4. 自社が管理している掲載先のページは、構造化データの sameAs に入れる（下のコード）。Nurevo AEOの事業者情報の画面には sameAs の欄がないため、開発者向けのフィルター webmcp_canary_business_node で足します。
// 自社が管理している掲載先のページを sameAs として事業者のノードに足す
// （管理していないページ・まとめ記事は入れない。URLは掲載先の正式なページ）
add_filter('webmcp_canary_business_node', function (array $node, array $settings) {
    $node['sameAs'] = array(
        'https://www.instagram.com/example_cafe/',
        'https://tabelog.com/（店舗会員として管理している当店のページ）',
    );
    return $node;
}, 10, 2);

sameAs には、自社が管理している公式のページだけを入れます。まとめ記事や、管理者登録していない掲載ページは入れません。Nurevo AEO 0.9.1 以降は、SEO SIMPLE PACK・VK All in One Expansion Unit と一緒に使っても構造化データが重複しません。

確かめ方：同じ質問で、期間をあけて記録する

掲載先を直したら、手順2と同じ質問を、2〜4週間ごとに聞き直します。AIの回答は回ごとに変わり、BrightLocalの調査でも同じ質問の繰り返しで同じ事業者が出る重なりは20〜33%でした。1回の回答で「直った」「直っていない」と判断せず、次の項目を記録します。

記録する項目例
日付・AI・質問2026-12-15、Perplexity、「◯◯市中央で月曜もやっているカフェは？」
店が出たか出た／出ない
回答の事実定休日を「水曜」と答えた（古い）／「月曜」と答えた（正しい）
出典のURL回答に付いたリンク（掲載先の表の行と照らし合わせる）
前回からの変化出典から旧住所のまとめ記事が消えた、など

Nurevo AEOでは、Free・Standardプランでも月に1回、業種と地域から作った3つの質問（店名は含めません）をPerplexityに投げ、回答に名前やサイトが出たかを記録します。Proプラン（月14,800円〜）では、ベータ版のAI登場率の計測で、競合との比較と推移を見られます（現在はPerplexity）。どちらも回答の一部を見本として調べるもので、すべての回答を見ているわけではありません。くわしくはAIでの登場率の測り方をご覧ください。

やってはいけないこと

  1. 一括登録のツールなどで、同じ店の掲載を新しく増やす（重複が増え、古い掲載が残ったままになる）。
  2. 移転のときに、Googleビジネスプロフィールを新しく作り直す（今のプロフィールの住所を変える）。
  3. 掲載先ごとに名前や電話番号の表記を変える（「正しい事実の表」の表記に合わせる）。
  4. AIに直接「正しい情報」を何度も入力して直そうとする（回答の評価ボタンでの報告はできますが、元の掲載が古いままでは直りません）。
  5. 口コミや記事を自分で書いて、古い情報を埋もれさせようとする。

チェックリスト

  1. 正しい事実の表を作り、旧住所・旧電話番号・旧店名も書いた
  2. 自社サイトの店舗ページに、表と同じ事実を文字で書き、最終更新日を入れた
  3. ChatGPT・Perplexity・Googleに店名あり・なしの質問をして、出典のURLを書き写した
  4. 旧住所・旧電話番号を""で囲んで検索し、古い掲載を表にした
  5. Googleビジネスプロフィールの名前・住所・電話・営業時間を表と同じにした
  6. Googleマップ・Appleのマップ・Bingで、重複と閉業・移転前の場所がないか見た
  7. 業種の主なポータルで、自社が管理できる掲載は自分で直した
  8. 直せない掲載先に、URL・項目・正しい値・資料を入れた依頼を出した
  9. 構造化データとllms.txtの表記が表と同じで、sameAsは管理しているページだけにした
  10. 2〜4週間後に同じ質問で聞き直す日を決め、記録の表を作った

よくある質問

AIの回答の間違いは、AIの会社に連絡すれば直りますか？

回答の評価ボタンなどで報告はできますが、AIは掲載先や自社サイトの情報をもとに答えるため、元の情報が古いままでは同じ間違いが出続けることがあります。まず出典になっている掲載先と自社サイトを直し、報告はそのあとに補助として使います。

掲載サイトは、どこまで直せばいいですか？

全部を直す必要はありません。AIの回答の出典に出た掲載先、Googleビジネスプロフィールと地図アプリ、業種の主なポータルを優先します。古い情報の文字で検索して見つかった掲載は、表にして順に依頼します。

ChatGPTはGoogleビジネスプロフィールを読んでいますか？

米国・英国・オーストラリアを調べたBrightLocalの2026年の調査では、ChatGPTの出典でGoogleビジネスプロフィールは上位に入らず、Yelpが多く使われていました。日本で同じ傾向かを調べた公開データは見つかっていません。GoogleのAIによる概要やAIモードでは、Googleビジネスプロフィールが最も多い出典でした。

食べログの情報が古いとき、店舗会員にならないと直せませんか？

店舗会員になると、管理画面から自分で直せます。店舗会員でない場合は、食べログの利用規約が案内している問い合わせフォームから、正しくない情報を伝えられます。

比較サイトの運営者が直してくれません。どうすればいいですか？

2〜3週間あけて1回だけ依頼を送り直し、それでも直らなければ記録して次に進みます。その間も、自社サイトとGoogleビジネスプロフィールに正しい事実を書いておけば、AIが別の出典から正しい情報を読める可能性が高まります。

直してから、AIの回答に反映されるまでどれくらいかかりますか？

各社とも公表しておらず、決まった期間はありません。掲載先によっては、反映の前に運営者の確認もあります。2〜4週間ごとに同じ質問で聞き直し、記録して変化を見ます。

Nurevo AEOは無料で使えますか？

はい。業種・住所・営業時間・サービス・FAQの構造化データ、llms.txt、AIクローラの設定、AEOスコア、月1回の無料AIチェックは無料プランで使えます。有料プランでは、常に最新のルール（Standard、月3,000円）と、ベータ版のAI登場率の計測（Pro、月14,800円〜）が加わります。WordPress.orgのNurevo AEOから無料で入れられます。

まず、AIがあなたのサイトの事実を読めるか確かめる

掲載先を直す前に、いちばん正しい情報源になる自社サイトの状態を確かめましょう。無料チェックでは、構造化データ・llms.txt・AIクローラの許可の状態が、登録なしでわかります。
