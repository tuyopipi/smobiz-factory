GA4でAIからの流入を見る方法：ChatGPT・Perplexityからの訪問の見分け方と、見えないもの

GA4では、まず「集客」＞「トラフィック獲得」の「AI アシスタント」チャネルを見ます。Googleはこのチャネルを、ChatGPT・Gemini・DeepSeek・Copilot・Grokなどから来た訪問としています。ここに入らないAI（Perplexityなど）は参照元の列で確かめ、必要ならAIサービスのドメインを並べたカスタムチャネルグループを作ると、過去の期間も含めて一つの行で追えます。ただし、GoogleのAIによる概要・AIモードからの訪問は「オーガニック検索」に入り、参照元を伝えない訪問は「ダイレクト」に入るため、GA4だけでAIの影響をすべて数えることはできません。

作成日：2026年11月10日。Google アナリティクスのヘルプ、OpenAI・Perplexityの公式ドキュメントで、同日に確認した内容です。画面の名前や仕様は変わることがあるため、最新のヘルプもあわせてご確認ください。

この記事で扱うのは「AIの回答からリンクをクリックしてサイトに来た訪問」です。AIの回答の中で名前が出たか、サイトが出典に使われたか（登場率）は、クリックされなければGA4には残りません。そちらの測り方はAIでの登場率の測り方にまとめています。なお、AIの回答は日や回によって変わり、どんな対策をしてもAIからの訪問が必ず増えるわけではありません。

AIからの訪問は、GA4のどこに入るか

同じ「AIから来た人」でも、来かたによってGA4での入り先が変わります。最初にこの違いを知っておくと、数字の読み間違いを防げます。

AI アシスタント チャネルに入るサービスの範囲は、Googleのヘルプでは「〜など」と例で書かれています。PerplexityやClaudeがどちらに入っているかは、自社のレポートの参照元の列で確かめてください。

ChatGPTについては、OpenAIが「ChatGPTの検索結果からのリンクには utm_source=chatgpt.com を自動で付ける」としています（OpenAI：パブリッシャー・開発者向けFAQ）。そのため、ブラウザが参照元を送らない場合でも、このパラメータが残っていれば参照元は chatgpt.com として記録されます。URLをコピーしたときにパラメータが消えていれば、ダイレクトになります。

手順1：GA4がサイトに正しく入っているか確認する（WordPressの場合）

  1. WordPressなら、Google公式のプラグイン「Site Kit by Google」でGA4をつなぐのがわかりやすい方法です（WordPress.org：Site Kit by Google）。テーマの設定欄や別のプラグインですでにタグを入れている場合は、どちらか一方にします。二重に入っていると、訪問が二重に数えられます。
  2. GA4の「レポート」＞「リアルタイム」を開いたまま、自分のスマホでサイトを開き、訪問が表示されることを確認します。
  3. キャッシュ系のプラグインやCDNを使っている場合は、変更後にキャッシュを消してから確認します。

手順2：標準の「AI アシスタント」チャネルを見る

  1. GA4の「レポート」＞「集客」＞「トラフィック獲得」を開きます。
  2. 表の最初の列が「セッションのデフォルト チャネル グループ」になっていることを確認し、「AI アシスタント」の行を探します。行がない場合は、その期間にこのチャネルに入った訪問がなかったということです。
  3. 表の上の「＋」から、2つ目のディメンションに「セッションの参照元」を足すと、AI アシスタントの中身（chatgpt.com、gemini.google.com など）がわかります。
  4. 続けて、最初の列を「セッションの参照元」に切り替え、検索窓に perplexity や claude と入れて、AI アシスタント以外の行に入っているAIがないかを見ます。

手順3：取りこぼしを拾うカスタムチャネルグループを作る

標準のチャネルに入らないAIがある、または過去の期間とも比べたい場合は、自分でチャネルグループを作ります。Googleのヘルプによると、カスタムチャネルグループは過去のデータにもさかのぼって適用できます（Google アナリティクス ヘルプ：カスタム チャネル グループ）。

  1. 「管理」＞「データの表示」＞「チャネルグループ」を開きます。
  2. 「デフォルト チャネル グループ」の「コピーして新規作成」を選びます。ゼロから作るより、既存のチャネルがそのまま残るので安全です。
  3. グループ名を「AIを分けたチャネル」などにし、「新しいチャネルを追加」でチャネル名を「AI（すべて）」とします。
  4. 条件に「参照元」「正規表現に一致」を選び、次の章の正規表現を貼り付けます。
  5. 「並べ替え」で、このチャネルを「オーガニック検索」「参照」より上に移します。Googleのヘルプにあるとおり、訪問は上から順に見て最初に条件が合ったチャネルに入るため、下に置くと参照などに先に取られます。
  6. 保存したら、トラフィック獲得レポートの最初の列の切り替えから、作ったグループを選びます。

カスタムチャネルグループは、通常のGA4プロパティでは2つまで（GA4 360では5つまで）、1つのグループにチャネルは50個までです。また、BigQueryへのエクスポートには含まれません（いずれも同ヘルプ）。

そのまま使える正規表現と、書くときの注意

参照元の条件に、次の正規表現を使えます（2026年11月時点で主なAIサービスのドメインを並べたもの）。

chatgpt\.com|chat\.openai\.com|(www\.)?perplexity\.ai|claude\.ai|gemini\.google\.com|copilot\.microsoft\.com|copilot\.com|chat\.deepseek\.com|grok\.com

GA4の正規表現は、何も付けなければ「完全一致」で判定されます（Google アナリティクス ヘルプ：正規表現）。そのため上の書き方では、chatgpt.com そのものには一致し、chatgpt.com を一部に含む別のドメインには一致しません。

  1. 貼る前に、自社のレポートで実際に出ている参照元の値を見て、足りないドメインがあれば | で区切って足します。AIサービスのドメインは変わることがあります。
  2. openai.com は入れていません。開発者向けのドキュメントなど、AIの回答以外から来た訪問も混ざるためです。
  3. 「ai を含む」「gpt を含む」のような広い書き方は、AIと関係ないサイトからの訪問まで拾うことがあるので、ドメインを並べる書き方をおすすめします。
  4. ドットは \. と書きます。ただの . は「どの1文字でもよい」という意味になります。

手順4：AIから来た人が、どのページで何をしたかを見る

AIからの訪問は、件数よりも「どのページに着いたか」「問い合わせや予約につながったか」を見ると、サイトのどこがAIに使われているかがわかります。

  1. 「探索」＞「自由形式」を開き、ディメンションに「セッションの参照元」「ランディング ページ」、指標に「セッション」「キーイベント」を入れます。
  2. フィルタで「セッションの参照元」「正規表現に一致」に上の正規表現を入れると、AIからの訪問だけになります。
  3. 着地が多いページは、AIがあなたのサイトのどこを回答に使っているかの手がかりです。そのページの事実（料金、営業時間、対応地域など）が最新か、まず確認しましょう。
  4. 問い合わせ・予約・購入をキーイベントに設定していない場合は、先に設定します。設定前の期間の数は後から出せません。

GA4で見えないものと、ほかの道具の分担

道具わかることわからないこと
GA4（標準の AI アシスタント）設定なしで、主なAIからのクリックを一つの行で見られるGoogleの例にないAIの一部、AIによる概要・AIモード、参照元のない訪問
GA4（カスタムチャネルグループ）自分で決めたAIの範囲で、過去の期間も含めて一つの行で見られる参照元のない訪問。ドメインの追加は自分で行う
Search ConsoleGoogleのAI機能（AIによる概要・AIモード）に表示されたサイトも、検索パフォーマンスの「ウェブ」の数字に含まれます（Google：AI機能とウェブサイト）ChatGPTやPerplexityなど、Google以外のAI
サーバーのアクセスログAI検索のクローラが読みに来ているか。OpenAIは OAI-SearchBot と ChatGPT-User（OpenAI：クローラ）、Perplexityは PerplexityBot と Perplexity-User（Perplexity：クローラ）を公開しています読まれたことと、回答に出たこと・クリックされたことは別
登場率の計測AIの回答に名前が出たか、サイトが出典になったか（クリックされなくても）クリック後の行動。AIでの登場率の測り方

AIの回答は、リンクをクリックされないまま読み終えられることも多い形式です。GA4のAIの行が少なくても、AIの回答に出ていないとは限りませんし、逆にAIの行が増えたことだけで「AIでの評価が上がった」とも言えません。クリック（GA4）と登場（回答の記録）を分けて追うのが確実です。

AIからの訪問が0のとき、先に確認すること

  1. AI検索のクローラを robots.txt で止めていないか。止めていると、AIはページを読んで出典にすることができません。セキュリティ系のプラグインやCDNのボット対策が、意図せず止めていることもあります。
  2. 期間が短すぎないか。小さなサイトでは、AIからの訪問は月に数件ということも普通です。3か月程度の期間で見ます。
  3. 参照元の列で、AIのドメインが「参照」やほかのチャネルに入っていないか。
  4. GA4のタグが全ページに入っているか（手順1）。

参考までに、WordPressプラグインのNurevo AEOは、AI検索のクローラ（OAI-SearchBot、ChatGPT-User、Claude-SearchBot、Claude-User、PerplexityBot、Perplexity-User）にページを読ませるrobots.txtのルール、構造化データ、llms.txtをサーバー側で出力します。Nurevo AEOは公開ページに外部のスクリプトを加えず、訪問者のデータも送らないため、訪問数の計測はGA4などのアクセス解析で行います。AIの回答に名前が出ているかは、接続したFree・Standardのサイトなら、業種と地域から作った3つの質問を月1回Perplexityに聞く無料のAIチェックで確認でき、決めた質問を継続して測る計測はPro（月14,800円〜、現在はPerplexityで計測）にあります。

よくある質問

GA4に「AI アシスタント」の行が出てきません。設定が必要ですか？

標準のチャネルなので設定は不要です。行がないのは、その期間にこのチャネルに入った訪問がなかったためです。参照元の列でAIのドメインがほかのチャネルに入っていないかも確認してください。

Perplexityからの訪問はどこに入りますか？

Googleのヘルプでは、AI アシスタント チャネルの例にPerplexityの名前はありません。「参照」に入っていることもあるため、セッションの参照元で perplexity.ai を探すか、カスタムチャネルグループで確実にAIの行にまとめてください。

GoogleのAIによる概要（AI Overviews）からの訪問だけを数えられますか？

GA4ではできません。Googleは、AIによる概要とAIモードからの訪問をオーガニック検索に含めるとしています。GoogleのAI機能での表示は、Search Consoleの検索パフォーマンスで、通常の検索とあわせて見ることになります。

ChatGPTのアプリから来た人は数えられますか？

ChatGPTの検索結果のリンクには utm_source=chatgpt.com が付くとOpenAIは説明しているので、それが残っていれば chatgpt.com として数えられます。参照元もパラメータも残らない開き方では、GA4ではダイレクトになり、区別できません。

カスタムチャネルグループを作ると、元のレポートが変わってしまいますか？

変わりません。デフォルト チャネル グループはそのまま残り、作ったグループはレポートの切り替えで選んだときだけ使われます。過去の期間にもさかのぼって適用できます。

AIからの訪問を増やす方法はありますか？

保証できる方法はありません。できるのは、AI検索のクローラがページを読める状態にし、料金・営業時間・対応地域などの事実をはっきり書き、構造化データやllms.txtで伝わりやすくすることです。そのうえで、GA4のAIの行と登場率を分けて、毎月同じ方法で記録していきます。

AIがあなたのサイトを読める状態か、まず確認

登録不要の無料チェックで、構造化データ、llms.txt、AI検索のクローラへの対応など、AIが読む情報の状態がわかります。WordPressなら、Nurevo AEOで不足分を無料で整えられます。
