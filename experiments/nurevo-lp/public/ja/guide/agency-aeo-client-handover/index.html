AI検索対策の契約を終える・引き継ぐときの手順：制作会社がお客様に渡すもの、止めるもの

AI検索対策の契約を終えるときは、①AI向けの出力（構造化データ・llms.txt・robots.txtの記述）を残すか止めるかをお客様と決め、②設定・ページごとの設定・自作のコード・計測の記録を渡し、③自社のアカウント・報告・支払いの関わりを外し、④最後に公開中のサイトで出力を確かめる、の順で進めます。ドメインやサーバーの引き継ぎの記事は多いのですが、AI向けの出力はプラグインやコードの中にあり、止め方を間違えると、会社の住所や営業時間が構造化データから黙って消えます。

作成日：2026年11月16日（JST）。対象は、お客様のサイトでAI検索対策（AEO・GEO・LLMOとも呼ばれます）をしてきた制作会社・SEO会社・MEO会社・WordPress保守会社です。始め方は初回診断と提案書の作り方、続け方はAI検索対策を月額サービスにする方法で扱っています。この記事はその終わり方です。

AIの回答は日や聞き方によって変わります。この記事の手順は、引き継ぎで事実が消えたり食い違ったりしないようにするためのもので、引き継ぎ後もAIの回答に表示されることを保証するものではありません。

よく読まれている引き継ぎの記事に書かれていないこと

「制作会社 乗り換え」「client offboarding checklist」で上位に出る日本語と英語の記事を12本読みました。ドメインの名義、サーバーの契約者、WordPressの管理者アカウント、ソースコードの著作権、引き継ぎのメールの書き方は、どの記事も丁寧に扱っています。一方で、AI検索に関わる次の項目は、ほとんど書かれていませんでした。

2026年11月16日に読んだ記事での傾向です。記事ごとの良し悪しではなく、AI検索の項目が抜けやすいという点だけを挙げています。
抜けていた項目引き継ぎで起きること
構造化データ（JSON-LD）を誰が出しているかプラグインを外すと、SEOプラグインの構造化データに足していた住所・電話・営業時間だけが消える。表示は何も変わらないので気づかれにくい
/llms.txtプラグインが返していた場合、止めると返らなくなる。手で置いたファイルなら、中身が古いまま残る
robots.txtのAI向けの記述AI検索のクローラを許可する行や、学習用クローラの扱いが、誰の判断で入ったのか分からなくなる
ページごとの設定「このページをllms.txtに載せない」やページ専用のFAQは、全体の設定とは別に保存されていることが多く、書き出しから漏れる
計測の記録毎月AIに聞いた質問と結果が制作会社の手元にしかなく、次の担当が同じ条件で比べられない
自社ブランドの月次レポート契約が終わった後も、自動送信が止まらずに届き続ける

Googleの「SEO 業者の利用を検討する」は、業者を選ぶときの質問として、サイトに加えた変更をすべて共有するかを尋ねるよう勧めています（Google 検索セントラル）。引き継ぎの資料は、その約束を最後に果たす場でもあります。

最初に決めること：AI向けの出力を「残す」「止める」「移す」

解約の連絡を受けたら、まず次の3つのどれにするかをお客様と決めます。決めないまま制作会社のアカウントやコードを外すと、意図せず「止める」になります。

選ぶもの向いている場合やること
残してお客様に渡すお客様が自分で（または次の会社が）同じ仕組みで続けるプラグインはそのまま。管理者・設定・記録をお客様に渡し、自社の関わりだけを外す
止めるお客様がAI向けの出力を望まない、サイトを閉じる・作り直す出力を止めてから、プラグインやコードを外す。外す前に設定を書き出して渡す
別の仕組みに移す次の会社が別のプラグインや自作のコードで出す今の出力の一覧を渡し、切り替えの日を決める。同じ日に旧い出力を止め、二重や空白の期間を作らない

どれを選んでも、「何が、どこから、どのページに出ているか」の一覧が先に必要です。次の節の表を引き継ぎ資料の1ページ目にします。

引き継ぎ資料の1ページ目：AI向けの出力の一覧

「誰が足しているか」が重要です。表示されないデータなので、書いておかないと次の担当には分かりません。
出力確認する場所資料に書くこと
会社・店舗の構造化データページのソースの application/ld+json、リッチリザルトテストどのプラグイン（またはテーマ・コード）が出しているか、どの項目を誰が足しているか
FAQ・サービスの構造化データFAQを表示しているページFAQを置いたページのURL、質問の数
/llms.txtブラウザで https://ドメイン/llms.txt自動で作っているのか、手で置いたファイルか。載せないようにしたページ
robots.txtのAI向けの記述https://ドメイン/robots.txt許可しているAI検索のクローラ、学習用クローラの扱い（そのまま・許可・拒否）と、決めた日・決めた人
ページごとの設定各ページの編集画面、WP-CLI構造化データやllms.txtから外したページ、ページ専用のFAQ
自作のコード子テーマの functions.php、mu-plugins、自社の小さなプラグイン何を変えるコードか、どのファイルにあるか

自作のコードは見落としやすい項目です。制作会社が自社の小さなプラグインや mu-plugins に構造化データやllms.txtを変えるコードを置いている場合、そのプラグインを外すと変更も消えます。お客様に残すなら、ファイルごと渡すか、お客様の子テーマに移してから外します。

外すと何が消えるか：Nurevo AEOの場合

自社の製品（WordPress.orgの無料プラグイン）について、実際の動きを書いておきます。他のプラグインでも、同じ観点で確かめてください。

  1. 無料の出力（構造化データ・llms.txt・AI検索のクローラの許可）は、お客様のサイトのサーバーでプラグインが作っています。Nurevoのサービスへの接続やキーがなくても動くので、制作会社のアカウントとの接続を外しても出力は止まりません。
  2. Yoast SEO・Rank Math・All in One SEO・Slim SEOと併用している場合、Nurevo AEOはそれらの構造化データの中に、足りない住所・電話・営業時間・業種・FAQ・サービスを足しています。プラグインを止めると、SEOプラグインの構造化データは残りますが、足していた項目はなくなります。
  3. robots.txtの記述は、WordPressが自動で作るrobots.txtに行を足す仕組みです。プラグインを止めると足していた行はなくなります。サーバーに robots.txt のファイルを直接置いているサイトでは、そのファイルの中身が使われます。
  4. /llms.txt はプラグインが返しているので、止めると返らなくなります。
  5. プラグインを削除（アンインストール）すると、設定・FAQ・サービス・診断の記録の控え、ページごとの設定まで、プラグインが保存したものがすべて消えます。マルチサイトでは全サイト分です。削除の前に、次の節の書き出しを済ませます。
  6. Standardプランをやめると、プラグインは同梱の基準で動き続けます。今の出力が止まったり悪くなったりはしません。Proをやめると、AI登場率の計測（ベータ版、現在はPerplexityが対象）の画面が使えなくなります。有料プランはいつでも解約でき、解約はその請求期間の末日に効力を生じ、その期間の料金は返金されません（利用規約 第5条）。

渡すもの：設定・ページごとの設定・記録

Nurevo AEOでは、管理画面のNurevoのメニューの「設定 › ツール」またはWP-CLIで設定をJSONファイルに書き出せます。入るのは、出力のオン・オフ、事業の情報（名前・説明・住所・電話・営業時間・業種・URL・メール）、サイトの種類と方針ページのURL、FAQ、サービスです。キー・トークン・プラン・接続の情報は入らず、それらを含むファイルは読み込めません。

ページごとの設定（llms.txtや構造化データから外したページ、ページ専用のFAQ）はこのファイルに入りません。WP-CLIで一覧を出して、資料に貼ります。

# 1. Settings, FAQ and services (no keys, tokens or plan)
wp nurevo export --file=nurevo-handover.json

# 2. Per-page settings are not in that file: list them
wp post list --post_type=any --meta_key=_nurevo_exclude_llms --fields=ID,post_title,post_type
wp post list --post_type=any --meta_key=_nurevo_exclude_schema --fields=ID,post_title,post_type
wp post list --post_type=any --meta_key=_nurevo_faq --fields=ID,post_title,post_type

# 3. What the site publishes right now (schema / llms.txt / AI crawler rules)
wp nurevo status

計測の記録も渡します。毎月聞いた質問、聞いた日・AI・回数、名前が出たか・サイトが引用されたか、の表です。自社ブランドの月次レポートは印刷してPDFにできるので、契約期間の分をまとめて渡すと、次の担当が同じ条件で続けられます。測り方そのものはAIでの登場率の測り方にまとめています。

書き出したファイルには、住所・電話・メールなどお客様の事業の情報が入ります。メールに添付して終わりにせず、お客様が受け取ったことを確かめ、自社の手元の控えは契約に沿って削除します。

止めるもの：アカウント・報告・支払い

項目やること注意
WordPressの管理者お客様の管理者アカウントがあることを確かめてから、制作会社のアカウントを削除する。投稿の書き手になっている場合は、削除時にお客様のアカウントに付け替える最後の管理者を消さない
Search Console・Googleアナリティクス・Googleビジネスプロフィールお客様のGoogleアカウントがいちばん上の権限を持っていることを確かめてから、制作会社のアカウントを外す権限の名前と手順は各サービスのヘルプで確認する。Search Consoleは確認用のファイルやタグが残っていないかも見る
Nurevoのダッシュボードサイトを自社のダッシュボードから外す。お客様が続けるなら、お客様のアカウントでサイトを追加し、ペアリングコードを入れ直すペアリングコードは設定ファイルでは引き継がれない
自社ブランドの月次レポート契約の最終月の報告を送ったら、自動送信を止める止め忘れると、契約後も届き続ける
有料プランの支払いお客様が自分で契約している場合、続けるか解約するかはお客様が決める制作会社の判断だけで解約・変更しない
AI診断ウィジェット・紹介ページお客様のサイトに自社のウィジェットを置いていた場合は外す自社サイトに置いているものはそのままでよい

有料プランは、もともとお客様ご本人の同意を得てお客様が契約するものです（パートナープログラム）。解約や継続も、お客様の判断として案内します。

引き継ぎ後の確かめ方

最後に、公開中のサイトで出力を確かめ、その結果を引き継ぎ資料の最後のページに残します。作業した日と、確かめた日を分けて書きます。

  1. トップページ・会社概要・FAQのページをリッチリザルトテストにかけ、会社・店舗の情報が1つにまとまっているか、住所・電話・営業時間が残っているか（または止めたなら消えているか）を見る。
  2. /llms.txt と /robots.txt をブラウザで開き、選んだとおりになっているか見る。
  3. wp nurevo status で、構造化データ・llms.txt・AIクローラの記述の出力が選んだとおりか確かめる（プラグインを残す場合）。
  4. 別の仕組みに移した場合は、同じ会社の情報が2つの構造化データで出ていないかを確かめる。
  5. 会社名を入れた質問をいくつかAIに聞き、住所・営業時間などが引き継ぎ前と食い違っていないかを記録する（回答は変わるので、結果は記録として渡す）。

次の契約のために：最初の契約書に入れておくこと

  1. AI向けの出力に使うプラグインやコードと、その設定はお客様のものとし、契約の終わりに書き出して渡すこと。
  2. WordPress・Search Console・Googleビジネスプロフィールなどの最上位の権限はお客様のアカウントが持ち、制作会社は追加の利用者として入ること。
  3. robots.txtで学習用クローラを許可するか拒否するかは、お客様が決めること。
  4. 毎月の計測の記録は、契約の終わりにまとめて渡すこと。
  5. 契約が終わったら、制作会社のアカウント・自動の報告・ウィジェットを外す日を決めておくこと。

引き継ぎのチェックリスト

  1. 残す・止める・移すのどれにするか、お客様と決めて記録した。
  2. AI向けの出力の一覧（何が・どこから・どのページに）を作った。
  3. 設定を書き出し、ページごとの設定の一覧を添えた。
  4. 自作のコードを、ファイルごと渡すか、お客様の側に移した。
  5. 計測の記録と月次レポートのPDFを渡した。
  6. お客様が最上位の権限を持っていることを確かめてから、制作会社のアカウントを外した。
  7. 月次レポートの自動送信と、お客様のサイトの自社ウィジェットを止めた。
  8. 有料プランの継続・解約はお客様が決めた。
  9. 公開中のサイトで構造化データ・llms.txt・robots.txtを確かめ、結果を残した。
  10. 書き出したファイルの自社の控えを、契約に沿って削除した。

よくある質問

解約したら、お客様のサイトのAI検索対策は止まりますか？

仕組みによります。Nurevo AEOの無料の出力はお客様のサイトの中で作られているので、制作会社との接続やNurevoのアカウントを外しても止まりません。プラグインを止めるか削除したときに止まります。他の仕組みでは、制作会社のサーバーやアカウントに依存していないかを確かめてください。

プラグインを消すだけで片付きますか？

おすすめしません。SEOプラグインに足していた住所・営業時間などが構造化データから消え、設定やページごとの設定も削除されます。先に残すか止めるかを決め、設定を書き出してから外してください。

次の制作会社が別のプラグインを使う場合は？

切り替えの日を決め、新しい仕組みで出し始めた日に古い出力を止めます。両方が動く期間があると、同じ会社が2つの構造化データで出ることがあります。切り替えた後にリッチリザルトテストで確かめてください。

書き出した設定ファイルを別のサイトに読み込めますか？

できます。読み込み先にない項目は今の値が残り、キー・トークン・プランは入っていないので接続は引き継がれません。サイトごとに違う項目（店名・住所など）を確かめてから読み込みます。

robots.txtの学習用クローラの設定は、元に戻すべきですか？

決まりはありません。お客様が自分で判断できるよう、今どうなっているか、いつ誰が決めたかを資料に書いて渡します。Nurevo AEOでは、学習用クローラを拒否してもAI検索やAEOスコアには影響しません。

引き継ぎの後、AIでの表示が下がったら制作会社の責任ですか？

AIの回答は引き継ぎと関係なく変わるため、下がったことだけで原因は決められません。引き継ぎ資料に出力の一覧と確かめた結果を残しておけば、事実が消えたのか、AIの回答が変わったのかを切り分けられます。

紹介したお客様が解約したら、紹介報酬はどうなりますか？

紹介報酬は、紹介したお客様が有料プランを使っている間の支払いが対象です。細かい扱いはパートナー承認時の案内に従い、分からない点はNurevoに問い合わせてください。

引き継ぎの前と後に、AIがサイトをどう読んでいるか確認

無料チェックは登録不要で、URLを入れるだけで構造化データ・llms.txt・AIクローラの許可の状態がわかります。引き継ぎ資料の「確かめた結果」に使えます。
