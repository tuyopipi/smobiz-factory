学習塾のAI検索対策：対象学年・コース・料金・体験授業をAIに正しく読ませる手順

学習塾のAI検索対策（AEO）の中心は、対象学年・コース・授業形式（集団・個別・オンライン）・料金の総額・時間割・体験授業の申し込み方法・校舎の場所を、ページ本文と構造化データで正確に、矛盾なく公開することです。「◯◯駅の近くで中学生の数学を個別に見てくれる塾」「月謝はいくらくらい？」といった保護者や生徒の質問に、AIが推測せずに答えられる材料をそろえます。合格実績や「No.1」の表示は、AIに強く見せる材料ではなく、根拠を示せる範囲で正確に書くものです。

作成日：2026年11月12日（JST）。Google・schema.org・消費者庁・公正取引委員会の情報は、この日に各公式ページで確認したものです。

AIの回答は日や聞き方によって変わります。この記事の対策は、AIが塾の事実を正しく読める状態をつくるもので、AIの回答に必ず表示される・順位が上がることを保証するものではありません。法律の扱いは一般的な説明で、個別の判断は専門家や所管の窓口に確認してください。

保護者と生徒はAIに何を聞いているか

塾を探す質問は、地域・学年・科目・目的・形式・曜日・料金が組み合わさるのが特徴です。たとえば「◯◯駅の近くで、中2の数学が苦手な子を個別に見てくれる塾」「高校受験の集団塾と個別指導の違いと料金の目安」「部活が終わった後の20時から通える塾」「オンラインで英検の対策ができる塾」のような聞き方です。ChatGPT、Perplexity、GoogleのAIによる概要などは、ウェブ上の情報を読んでこうした質問に答えをまとめます。

AIが答えに使えるのは、文字として読めて、ほかの情報と食い違わない事実です。料金表が画像だけ、「料金はお問い合わせください」だけで目安がない、校舎ページごとに授業時間が違う、体験授業の申込ページへのリンクがない、という状態では、AIはあなたの塾を答えに使いにくく、使ったとしても不正確な説明になりやすくなります。チェーン塾の情報ばかりが答えに出る地域ほど、個人塾が自分の事実をはっきり書いておく意味があります。

構造化データの型：EducationalOrganization と Course

schema.org には「学習塾」専用の型はありません。塾そのものは EducationalOrganization（教育機関）で表すのが近い選び方です。この型は Organization と CivicStructure（施設）の下位の型で、美容室や歯科医院が使う LocalBusiness の下位ではありません。住所・電話・営業時間などは書けますが、「LocalBusiness の店舗情報」として扱われるとは限らない点を知っておきましょう。地域の店舗として見せたい塾が LocalBusiness と EducationalOrganization の両方を書く例もありますが、どちらでも、ページに見えている事実と一致していることが前提です。

コースは Course で、名前・説明・提供者（provider）・対象（educationalLevel）・料金（offers）を書けます。曜日や時間、対面かオンラインかは、コースの開講単位である CourseInstance（hasCourseInstance でつなぐ）の courseMode・courseSchedule・courseWorkload で表せます。

Googleの検索結果での扱いは変わってきています。Googleは2025年6月、コースの詳細を表示する「Course Info」を含む7つの表示を段階的に終了すると発表しました（Google 検索セントラル ブログ、2025年6月12日）。3つ以上のコースを並べる「コースリスト」の説明ページは2026年11月12日時点でも公開されています（Google：コースリスト）が、表示される保証はありません。構造化データは「検索で目立つ飾り」ではなく、AIや検索エンジンに事実を誤解なく渡すための書き方だと考えるのが安全です。

料金ページと特定商取引法：書き方がそのままAIの答えになる

日本の学習塾は、契約期間が2か月を超え、金額（入塾金・授業料・教材費などの合計）が5万円を超えると、特定商取引法の「特定継続的役務提供」にあたります。この場合、契約前の概要書面と契約後の契約書面の交付、契約書面を受け取ってから8日以内のクーリング・オフ、中途解約のルールがあります。中途解約で塾が請求できる額の上限は、授業開始前は1万1,000円、開始後は提供済みの授業料に加えて2万円か1か月分の授業料のいずれか低い額です。家庭教師は別の区分で上限も違います（消費者庁 特定商取引法ガイド：特定継続的役務提供）。

AIに料金を聞かれたとき、月謝だけが読み取られると、保護者は「思っていたより高い」と感じます。料金ページには、月謝に加えて入塾金・教材費・季節講習・模試代など、年間でかかるものを並べ、学年とコースごとの総額の例を書いておきましょう。解約やクーリング・オフの説明ページがあれば、料金ページからリンクしておくと、AIが「途中でやめられるか」という質問にも事実で答えやすくなります。

安く見せる書き方には注意が必要です。2023年3月2日には、個別指導塾の時間あたりの授業料などの表示が、実際より有利に見えるとして景品表示法の措置命令が出ています（公正取引委員会 報道発表、2023年3月2日）。AIは表示をそのまま要約するので、誤解を招く表示はAIの答えでも誤解を広げます。

合格実績と「No.1」：根拠を添えて書く

合格実績は保護者がよく聞く項目ですが、数え方を書かない数字は、AIにとっても保護者にとっても比べられない数字です。2011年には、ほかの塾の生徒や授業を受けていない生徒を含めた大学合格実績の表示に措置命令が出た例があります（消費者委員会 資料、2011年11月24日）。実績ページには「◯年度、在籍生◯人のうち」「講習のみの受講生は含まない」など、対象と数え方を必ず添えます。

「地域満足度No.1」のような表示も慎重に。消費者庁は2024年9月26日の報告書で、No.1表示に合理的な根拠があると言えるには、比較する対象・調査に答える人・調査の方法・表示と結果の一致が適切である必要があるとし、利用したことのない人にサイトの印象を聞くような調査をもとにした表示は問題となるおそれがあると示しました。この調査では学習塾・予備校の広告主にも聞き取りをしています（消費者庁：No.1表示に関する実態調査報告書）。AIは強い言葉より確かめられる事実を使うので、根拠を示せない表示は本文にも構造化データにも入れないのが安全です。

WordPressの塾サイトで設定する手順

  1. WordPress.org から Nurevo AEO（無料）を入れて有効にします。Yoast SEO・Rank Math・All in One SEO・Slim SEO・SEO SIMPLE PACK・VK All in One Expansion Unit を使っていれば、そのまま残して構いません。
  2. 初期設定のウィザードには塾向けのカードがないので、「その他」を選びます。そのあと設定画面の「Business type (schema.org type)」に EducationalOrganization と入力します。Nurevo AEO はこの型を事業者の型として扱い、塾名・住所・電話・授業時間・説明を出します。空欄の項目だけが既存の設定から補われ、入力済みの内容は上書きされません。
  3. 設定画面の「サービス」に、コースを1つずつ登録します。コース名・1回の時間（分）・料金・通貨・カテゴリー（例：高校受験）・申込URL（体験授業の申込ページ）・説明を入れると、塾に結びついた Service として、料金は Offer、申込URLは予約のアクションとして出され、llms.txt にもコースの行が載ります。料金は数字だけで入力し、説明には月謝なのか1回あたりなのかを書きます。
  4. Nurevo AEO が出すのは Service で、Course や CourseInstance は出しません。コースを Course として書きたい場合は、テーマやほかのプラグイン、手書きの JSON-LD で足し、同じコースが別の内容で二重にならないようにします。
  5. よくある質問を入力し、Nurevo のFAQブロックまたは [nurevo_faq] ショートコードを表示したいページに置きます。「体験授業は無料ですか」「途中から入れますか」「振替はできますか」など、保護者が実際に聞く質問を選びます。
  6. AEOスコアの画面で診断を実行し、チェック表に出る修正を適用します。構造化データ、llms.txt、AIクローラ（OAI-SearchBot、PerplexityBot、Claude-SearchBot など）の許可は無料プランで使えます。
  7. 外から見た状態を 無料のAI読み取りチェック で確かめ、授業時間や料金が Googleビジネスプロフィールや塾の比較サイトと一致しているかも見直します。

AIの答えに出ているかを確かめる

準備ができたら、保護者が聞きそうな質問（地域＋学年＋科目や目的＋形式）をAIに聞き、塾の名前やURLが出るか、料金や授業時間が正しく説明されているかを見ます。答えは毎回変わるので、同じ質問を日を空けて何回か聞き、記録をとります。新学期・夏期講習・受験直前など、問い合わせが増える時期の前に確かめると、直す時間がとれます。体験授業の申込フォームに「何で知りましたか」の選択肢として「AI（ChatGPTなど）」を足しておくと、AI経由の申し込みも数えられます。測り方の詳しい手順は AIでの登場率の測り方 にまとめています。

Nurevo AEO の Free と Standard（月3,000円）には、月1回の確認があります。業種と地域から作った3つの質問（塾の名前は使いません）を Perplexity に聞き、答えに塾の名前やサイトが出たかを記録します。Pro（月14,800円〜）では、AIの答えにどのくらいの割合で出るか、競合との比較、推移を測るAI登場率の計測（ベータ、現在は Perplexity）が使えます。どちらも答えの一部を抜き出して見るもので、すべての回答を観測するものではありません。

よくある質問

学習塾のAI検索対策は何から始めればいいですか？

対象学年・コース・授業形式・料金の総額・時間割・体験授業・校舎の場所を、画像ではなく文字でページに正しく書くことからです。そのうえで同じ事実を構造化データとllms.txtで公開し、Googleビジネスプロフィールや比較サイトと一致させます。

塾の構造化データはどの型を使えばいいですか？

schema.orgに学習塾専用の型はないため、塾はEducationalOrganization、コースはCourseで表すのが近い選び方です。EducationalOrganizationはLocalBusinessの下位の型ではない点に注意してください。どの型でも、ページに見えている内容と一致させることが前提です。

料金を「お問い合わせください」にしていても大丈夫ですか？

AIは書かれていない料金を答えられないため、「料金が分からない塾」として扱われやすくなります。月謝・入塾金・教材費・講習費を税込で書き、学年とコースごとの年間の総額の例を載せるのがおすすめです。

合格実績はAI検索で有利になりますか？

実績はよく聞かれる情報ですが、数え方のない数字は比べられません。年度・対象・数え方を添えて正確に書いてください。他塾の生徒を含めるなど実際と違う表示は、景品表示法の問題になった例があります。
