出張撮影のAI検索対策：撮影エリア、出張費、撮影場所の許可、雨天時の扱いをAIに正しく読ませる手順

出張撮影のカメラマンのAI検索対策（AEO）で一番大事なのは、「どこまで来てくれるか」「全部でいくらか」「雨ならどうなるか」をAIが答えられるように、サイトに文字で書くことです。具体的には、撮影エリアを「近郊」ではなく市区町村名で書き、出張費を含めた総額の例を1つ示し、撮影場所の許可を誰が取って誰が払うかを書き、雨天・延期・キャンセルの規定を条件つきで載せます。スタジオがない場合は、自宅の住所を出さずに、Googleビジネスプロフィールを「サービス提供地域」で作り、サイトの構造化データには areaServed で地域を入れます。

作成日：2026年11月25日（JST）。Googleビジネスプロフィールの決まりと、公園での撮影の決まり（杉並区・世田谷区・港区・東京都）は、本文に記した公式のページで2026年11月25日に確認しました。この記事は法的な助言ではありません。撮影場所の扱いは、その場所の管理者に確認してください。

AIの回答は日や聞き方によって変わります。この記事の対策は、AIがあなたの撮影の条件を正しく読める状態をつくるもので、AIの回答に必ず表示される・順位が上がることを保証するものではありません。写真館（スタジオ）の場合は写真館のAI検索対策をご覧ください。

上位の解説記事に足りないこと

2026年11月25日に、日本語と英語で「出張撮影 AI検索対策」「photographer AI search」などの上位記事を14本読みました。日本語でカメラマン向けのAI検索の記事は、写真館（スタジオ）を前提にしたuravationの記事が中心で、料金を「持ち帰る総額」で書くことや行事ごとのページの更新は具体的ですが、出張撮影の撮影エリアや撮影場所の許可は扱っていません。クラウドワークスや@SOHOの記事は、拘束時間・出張費・データ・キャンセル料の相場を依頼する側に向けて説明していて、見積もりの項目を知るのに役立ちますが、相場の数字に出典はなく、AI検索の話はありません。

英語では、FormatやPhotoBizの記事が、ポートフォリオの文章や口コミ、外部のサイトでの言及を勧めていて、方向は妥当です。ただ、どちらも自社のサービスの宣伝を含み、構造化データは型の名前を挙げるだけでした。DEV Communityの記事は結婚式のカメラマン向けの JSON-LD の例と、出張費の書き方に触れている点が参考になります。一方で、どの記事にも、自宅の住所を出さずにエリアを示す方法（Googleの決まり）、撮影場所の許可の書き方、雨天とキャンセルの規定の書き方、WordPressでの手順、出ているかの確かめ方はありませんでした。この記事は、これらの抜けを埋めます。

撮影エリアは「近郊」ではなく、市区町村名と出張費で書く

「首都圏どこでも」「近郊は出張費無料」のような書き方では、AIは「◯◯市に来てくれるか」に答えられません。市区町村名を並べ、出張費を範囲ごとに金額で書きます。範囲の外も「応相談」だけでなく、交通費の計算の仕方を書いておくと、条件つきで紹介されやすくなります。

金額は説明のための例です。
書き方AIにとっての読みやすさ直し方の例
「近郊は出張費無料」どこが近郊か判断できない「横浜市・川崎市は出張費無料」
「関東一円対応」範囲が広く、出張費がわからない「神奈川県内と東京都23区は出張費3,300円（税込）、それ以外は交通費の実費」
「遠方応相談」だけ来てもらえるか判断できない「上記以外は、横浜駅からの往復の交通費（実費）と、片道2時間を超える場合は宿泊費をいただきます」

スタジオがないなら：Googleビジネスプロフィールは「サービス提供地域」で

お客様のところへ行って撮影し、自宅などで客を迎えない場合、Googleビジネスプロフィールでは「サービス提供地域」のビジネスとして扱われます。Googleのガイドラインは、こうした事業者は住所をお客様に表示しないよう求めていて、自宅で事業をしている配管業者を例に挙げています。看板のある店舗がなく、お客様のもとへ出向く事業は、サービス提供地域のプロフィールを1つ持てます。Google：ビジネス情報のガイドライン

サービス提供地域は、市区町村や郵便番号などで最大20件まで設定できます。半径での指定はできず、範囲は拠点から車でおよそ2時間を超えないこととされています（業種によっては、より広い範囲が適切な場合もあると書かれています）。変更が表示されるまで最大48時間かかることがあります。Google：サービス提供地域の管理

  1. 看板を出して客を迎える撮影スペースがある場合は、住所とサービス提供地域の両方を入れる「ハイブリッド」の扱いになります。看板がない場所は店舗として扱われません。
  2. 私書箱や、実際に仕事をしていないバーチャルオフィスの住所は使えません。
  3. ビジネス名は、サイトや名刺で使っている実際の名前にします。「◯◯市 出張撮影 七五三」のように地域名やサービス名を足すことは認められておらず、プロフィールの停止につながることがあります。
  4. サイトに書く撮影エリアと、プロフィールのサービス提供地域を同じ地域にします。どちらかだけを変えると、AIがどちらを使うか定まりません。

雨天・延期・キャンセルは、時期と割合で書く

屋外の出張撮影では、雨と子どもの体調不良による変更が避けられません。「雨天の場合はご相談」だけでは、AIは「雨なら無料で延期できるか」に答えられません。判断の時刻、延期の回数と期限、費用を書きます。

規定は料金ページと予約ページの両方に同じ文で書きます。予約の流れの書き方は予約ページのAI検索対策をご覧ください。

作例とお客様の写真：文章をそえて、掲載の同意を取る

  1. 作例のギャラリーは、写真だけでなく、撮影の場面・場所・季節・時間帯を短い文章で書きます（例：「11月の山下公園、午後3時、七五三の家族写真」）。AIや検索エンジンは、写真の中身よりも、まわりの文章とalt属性から読み取ります。
  2. お客様の写真をサイトやSNSに載せるときは、撮影の前に、掲載してよいか・どこに載せるか・顔をぼかすかを書面かメールで確認し、記録を残します。予約ページに「作例として掲載をお願いすることがあります。お断りいただいても料金は変わりません」のように書いておくと、トラブルを防げます。
  3. 口コミは、お客様に書いてもらうよう頼むことはできますが、星の数を条件にしたり、謝礼と引き換えにしたりしないでください。くらしのマーケットのようなポータルでは、口コミの規約にも従います。

WordPressの出張撮影サイトでの設定手順

  1. WordPress.orgからNurevo AEO（無料）をインストールして有効化します。Yoast SEO・Rank Math・All in One SEO・SEO SIMPLE PACK・VK All in One Expansion Unitなどはそのまま使えます（構造化データは重複しません）。
  2. 初回の設定ウィザードで「その他」を選び、名前・電話番号・受付時間を入れます。スタジオがなく自宅を公開しない場合は、住所の欄を空のままにします。住所が空なら、Nurevo AEOは address を出力しません。電話か受付時間が入っていれば、型は LocalBusiness になります。AEOスコアの診断では住所が不足として数えられますが、自宅を公開しない方針なら空欄のままで構いません。
  3. 事業の説明に、拠点の市、スタジオがないこと、撮影エリアと出張費、撮影する場面を書きます。
  4. 撮影のプランを「サービス」に登録します（最大20件）。名前・時間（分）・料金・予約のURL・説明を入れ、説明に出張費が無料の範囲、データの枚数と納品の期限、撮影場所の使用料の扱いを書きます。サービスは構造化データ（Service）とllms.txtに載ります。
  5. Nurevo AEOには撮影エリア（areaServed）の入力欄がありません。構造化データにも入れたい場合は、下の webmcp_canary_business_node フィルターで足します。Yoast SEOなどが有効な場合は、そのプラグインがすでに出している値が優先されます。
  6. 雨天・延期・キャンセル、撮影場所の許可、データの受け取り方などをよくある質問に入力し、Nurevo FAQブロック（または[nurevo_faq]ショートコード）を料金ページか予約ページに置きます。書き方はFAQページのAI検索対策をご覧ください。
  7. /llms.txt を開き、料金・撮影エリア・予約・作例・よくある質問のページが載っているか確かめます。AEOスコアの画面で診断を実行し、不足を直します。
// テーマの functions.php か、子テーマ・コードスニペットのプラグインに追加します。
add_filter('webmcp_canary_business_node', function (array $node, array $settings) {
    $node['areaServed'] = array(
        array('@type' => 'City', 'name' => '横浜市'),
        array('@type' => 'City', 'name' => '川崎市'),
        array('@type' => 'AdministrativeArea', 'name' => '神奈川県'),
        array('@type' => 'AdministrativeArea', 'name' => '東京都23区'),
    );
    return $node;
}, 10, 2);

WordPress以外のサイトでも、確かめる項目は同じです。登録不要の無料チェックにURLを入れると、構造化データ・llms.txt・AIクローラの許可の状態がわかります。

AIに出ているか、正しく答えているかを確かめる

整えたあとは、依頼する人が聞きそうな質問をAIに投げます。「◯◯市 出張撮影 七五三」「◯◯公園で家族写真を撮ってくれるカメラマン」のような地域＋場面の質問で名前が出るかに加えて、自分の名前を入れて「出張費はいくら？」「雨の日はどうなる？」と聞き、答えがサイトの事実と合っているかも見ます。エリアの外の地域で紹介されていないかも確かめます。

AIの回答は回ごとに変わるので、同じ質問を期間をあけて何度か確かめ、結果を記録します。Nurevo AEOでは、Free・Standardプランでも月に1回、業種と地域から作った3つの質問（事業の名前は含めません）をPerplexityに投げ、回答に名前やサイトが出たかを記録します。Proプラン（月14,800円〜）では、ベータ版のAI登場率の計測で、競合との比較と推移を見られます（現在はPerplexity）。どちらも回答の一部を見本として調べるもので、すべての回答を見ているわけではありません。くわしくはAIでの登場率の測り方をご覧ください。

よくある質問

出張撮影のAI検索対策は、何から始めればいいですか？

まず、撮影エリアを市区町村名で書き、出張費を範囲ごとに金額で書きます。次に、プランごとの総額の例と、雨天・延期・キャンセルの規定を料金ページに文字で書きます。そのうえで、Googleビジネスプロフィールのサービス提供地域をサイトと同じ地域にそろえ、構造化データとllms.txtで出します。

自宅で仕事をしています。住所を出さないとAIに紹介されませんか？

住所を出さなくても、撮影エリアを市区町村名で書けば、地域の質問に答えるための事実はそろいます。Googleのガイドラインも、客を迎えないサービス提供地域の事業者には住所を表示しないよう求めています。サイトと構造化データでは areaServed で地域を示し、自宅の住所はどこにも書かないようにします。

撮影エリアはいくつまで書けますか？

サイトには制限はありませんが、実際に行ける範囲だけを書きます。Googleビジネスプロフィールのサービス提供地域は最大20件で、拠点から車でおよそ2時間を超えない範囲とされています。半径での指定はできません。

公園での撮影に許可はいりますか？

管理者によって違います。たとえば杉並区は業としてのSNSや雑誌の掲載写真などに事前の申請を求め、家族や友人のスナップなど個人利用は不要としています。世田谷区は商用目的の撮影は規模にかかわらず申請が必要としています。お金を受け取る出張撮影がどちらにあたるかは、撮る前に管理者に確認してください。

キャンセル料は何％にすればいいですか？

決まった割合はありません。消費者契約法では、同じ種類の契約の解除で生じる平均的な損害を超える部分は無効とされています。実際にかかる費用をもとに決め、時期と割合をサイトに書き、迷う場合は専門家に相談してください。

Nurevo AEOは無料で使えますか？

はい。業種・連絡先・受付時間・サービス・FAQの構造化データ、llms.txt、AIクローラの設定、AEOスコア、月1回の無料AIチェックは無料プランで使えます。有料プランでは、常に最新のルール（Standard、月3,000円）と、ベータ版のAI登場率の計測（Pro、月14,800円〜）が加わります。WordPress.orgのNurevo AEO

この対策で、ChatGPTに必ず紹介されますか？

いいえ。AIの回答は変わるもので、どの道具や方法でも、表示や順位は保証できません。できるのは、撮影エリアと料金・規定の事実をAIが読みやすい形で出し、出ているか・正しいかを確かめ続けることです。
