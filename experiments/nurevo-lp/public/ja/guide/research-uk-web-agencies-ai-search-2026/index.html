英国のWeb制作会社の自社サイト942件に見るAI検索への対応（2026年11月）

英国のWeb制作会社の自社サイト942件のトップページ・robots.txt・llms.txt を調べたところ、llms.txt があったのは21.5%（203件）で、日本の13.4%より高く、米国の23.1%とは統計的な差が見られませんでした。robots.txt でAIボットをブロックしていたのは4.7%（33件）で、GPTBot をブロックしていた28件はすべて、ChatGPT の検索用ボット（OAI-SearchBot）をブロックしていませんでした。

公開：2026年11月18日。データ：2026年11月12日集計。調査・執筆：Nurevo AEO（Bestie.合同会社）。Nurevo はAI検索対策（AEO）のツールと WordPress プラグインを提供しており、この分野に利害があります。国別レポートの2本目です（1本目は米国）。

要点

  1. 英国のWeb制作会社の自社サイト942件のうち、llms.txt があったのは21.5%（203件）。日本（13.4%）より高く（p<0.001）、米国（23.1%）とは差が見られませんでした（p=0.31）。トップページが HTTP 202 を返した140件を除くと25.3%です。
  2. AI検索に関わる6項目をすべて満たすサイトは17.7%（167件）で、日本（10.4%）の約1.7倍、米国（18.9%）とほぼ同じでした。JSON-LD は68.8%で、日本（69.4%）・米国（69.0%）と変わりません。
  3. robots.txt があるサイト699件のうち、AIボットをブロックしていたのは4.7%（33件、日本1.3%）。GPTBot をブロックしていた28件はすべて OAI-SearchBot を許可しており、PerplexityBot・Claude-SearchBot・ChatGPT-User をブロックしていたサイトは0件でした。

調査概要

  1. 対象：Web制作会社の自社サイト。当社の収集リストで国が英国となっている制作会社サイト1,555件のうち、トップページに到達できた942件です。一般企業のサイト全体ではありません。比較には同じ調査の米国（4,472件）・日本（2,486件）・英国以外の海外（12,410件）を使いました。
  2. 取得したもの：各サイトのトップページ、/robots.txt、/llms.txt、/llms-full.txt を1回ずつ（User-Agent：NurevoSurvey/1.0）。2026年11月上旬〜12日に取得し、11月12日に集計しました。
  3. 判定方法：llms.txt は、ステータス200で中身がHTMLではなく20文字を超えるテキストを「あり」としました。JSON-LD はトップページにあるかどうか、「壊れている」は JSON として読み込めないブロックが1つ以上あるもの。Organization系は @type に Organization・LocalBusiness・Corporation・ProfessionalService を含むもの。WordPress はトップページのHTMLに wp-content/・wp-includes/、または generator の WordPress 表記があるもの。SEOプラグインはトップページのHTMLの文字列で判定しました。
  4. AIボットのブロック：robots.txt で、各ボットに当てはまるグループの規則がトップページ（/）を Disallow にするか（最長一致）で判定しました。分母は robots.txt があるサイトです。「AIボットをブロック」は GPTBot・ClaudeBot・PerplexityBot・Google-Extended・CCBot・OAI-SearchBot のどれかをブロックしているものです。
  5. 「6項目」は、(1) llms.txt がある、(2) JSON-LD がある、(3) Organization または LocalBusiness の型がある、(4) robots.txt があり GPTBot・ClaudeBot・PerplexityBot・OAI-SearchBot のどれもブロックしていない、(5) meta description がある、(6) canonical がある、のうち当てはまる数（0〜6）です。この調査のための単純な数で、Nurevo の0〜100点のスコアとは別物です。
  6. HTTP 202：英国では140件のトップページがステータス202を返しました（日本は0件）。これらのページには JSON-LD も WordPress の痕跡もなく、ボット確認などの別のページが返った可能性があります。そのため、202を除いた値も並べています。
  7. 統計：英国と他の地域の差はカイ二乗検定で確かめました。30件未満の区分は載せていません。

結果：英国と米国・日本の比較

英国の値は、ほとんどの項目で米国と1〜2ポイント以内でした。日本と比べると、llms.txt・FAQPage・「6項目すべて」が高く、meta description・canonical・robots.txt は低めです。英国の低い項目は、202を返した140件（ほぼすべての項目が「なし」になる）の影響を受けています。202を除くと meta description 81.4%、canonical 85.4%、robots.txt 86.8% です。英国以外の海外全体（12,410件）と比べると、英国は llms.txt（21.5%と26.7%、p<0.001）と「6項目すべて」（17.7%と22.1%、p=0.002）が低めでした。

ボット別のブロック率

英国で robots.txt があるサイト699件について、ボットごとにトップページをブロックしている割合です。学習用とされるボット（Bytespider・CCBot・anthropic-ai・ClaudeBot・Google-Extended・GPTBot・Applebot-Extended）は3.9〜4.7%で、米国より少し高く、日本の3〜4倍でした。検索用やユーザーの質問に答えるときに使われるボットは、OAI-SearchBot の1件だけで、ChatGPT-User・Claude-SearchBot・PerplexityBot は0件。Googlebot・Bingbot も0件です。

ブロックの中身（事実）

  1. GPTBot をブロックしていた28件は、すべて（100%）OAI-SearchBot をブロックしていませんでした。米国では128件中119件（93.0%）です。
  2. 上の11種のAIボットのどれかをブロックしていた35件のうち27件（77.1%）は、GPTBot・ClaudeBot・anthropic-ai・Google-Extended・CCBot・Bytespider・Applebot-Extended の7つをまとめてブロックする同じ組み合わせでした（米国は58.5%）。
  3. robots.txt でAIボットの名前を挙げていながら、どれもトップページをブロックしていないサイトが30件ありました（robots.txt があるサイトの4.3%）。
  4. AIボットをブロックしていた35件のうち12件（34.3%）には llms.txt もありました。

WordPress とSEOプラグイン

英国の制作会社サイトの73.4%（691件）が WordPress でした（202を除くと86.2%）。WordPress のサイトは llms.txt 28.1%、JSON-LD 92.6%、6項目の平均4.81 で、WordPress 以外（251件、うち140件が202）は llms.txt 3.6%、6項目の平均0.31 でした。SEOプラグインは Yoast SEO が58.0%、Rank Math が20.7%で、日本（AIOSEO 35.2%・Yoast 14.4%）とは傾向が違い、米国（Yoast 56.4%・Rank Math 18.0%）に近い構成です。AIOSEO（25件）と SEOPress（4件）は30件未満のため表に載せていません。

llms.txt があった割合は Rank Math 34.3%、Yoast SEO 27.7%、プラグインを検出できなかったサイト20.3%でした。この調査では llms.txt をプラグインで作ったのか手で置いたのかは見ていません。

限界

  1. 対象はWeb制作会社の自社サイトで、一般企業のサイト全体ではありません。国は当社の収集リストの記載によるもので、英国の制作会社全体を代表する標本ではありません。英国は942件で、米国（4,472件）より少ないため、ボット別の件数などは小さい数です。
  2. トップページだけを見ています。robots.txt はトップページ（/）に対する判定で、一部のディレクトリだけのブロックや、ファイアウォール・CDN によるブロックは数えていません。llms.txt は有無だけを見て、中身の質は見ていません。
  3. 各サイト1回の取得で、到達できなかったサイト（613件）は除いています。HTTP 202 を返した140件は、実際のトップページとは違うページを見ている可能性があります。
  4. SEOプラグインはHTMLの文字列による判定で、痕跡を消している場合や複数入っている場合は正しく分けられません。
  5. 今回の集計の一部には11月5日集計時の取得分を引き継いでいます。

当社の見方（意見）

ここからは事実ではなく当社の意見です。英国の制作会社サイトは、米国とほぼ同じ水準で、日本との差は llms.txt と「全部そろっているか」に表れていました。AIボットのブロックは少数で、ブロックしているサイトも学習用のボットに限り、検索用のボットはほぼ通していました。どのボットを止めるかは各社の判断ですが、AI検索に出たい場合は、検索用のボットまで止めていないかを確かめる価値があります。どれを整えてもAIの回答に出ることが保証されるわけではありません（別の調査では、サイト側の項目と登場の間に関係は見られませんでした）。
