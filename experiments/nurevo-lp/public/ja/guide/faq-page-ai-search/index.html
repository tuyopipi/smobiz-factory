FAQページとFAQ構造化データはAI検索に効くか：2026年の扱いと、AIに使われる書き方

GoogleのFAQリッチリザルト（検索結果に質問と答えが折りたたみで出る表示）は、2026年5月7日から表示されなくなったと報じられています。ただし FAQPage は schema.org の型として今も有効で、すでに付けているマークアップを急いで消す必要はありません。一方、FAQPage を付けるとChatGPTやPerplexity、GoogleのAIによる概要の出典に選ばれやすくなる、と公式に説明した資料は確認できませんでした。AI検索のために効くのは、マークアップより先に、実際に聞かれる質問に本文で短く正確に答えるFAQそのものです。

作成日：2026年11月19日（JST）。ブログ記事の書き方はブログ記事をAIに引用される形にする方法、店舗の構造化データ全体はSEOプラグインとローカルビジネスの構造化データで扱いました。この記事は「よくある質問」に絞り、Googleの変更で何が変わり何が変わっていないか、どんな質問をどう書けばAIの回答に使われやすいか、WordPressでどう載せて確かめるかを書きます。

AIの回答は日・聞き方・使うサービスによって変わります。この記事の手順は、AIが答えを見つけやすいFAQを作り、正しく確かめるためのもので、回答に出ることを保証するものではありません。

AIに使われやすい質問の選び方

FAQに入れるべき質問は、作り手が答えたい質問ではなく、お客さまが実際に聞いてくる質問です。AIに聞かれる質問も、同じ人が同じ迷いを入れて聞くので、ほぼ重なります。次の場所から集めると、外れが少なくなります。

  1. 電話・メール・問い合わせフォーム・LINEで、この3か月に2回以上来た質問
  2. 予約や購入の直前に聞かれること（料金に含まれるもの、キャンセル、支払い方法、駐車場、所要時間）
  3. Search Console の「検索結果のパフォーマンス」で、自社サイトが表示されている「〜できる」「〜いくら」「〜違い」などの検索語句
  4. スタッフが口頭で毎回説明していること（初回の流れ、持ち物、対象外のケース）
  5. 口コミや比較サイトで誤解されていること（実際はやっていないサービス、古い料金）

反対に、「当社の強みは何ですか？」のような、誰も聞かない宣伝の質問は入れません。FAQPage を広告や宣伝の目的で使うべきではない、という点はGoogleも示しています（Search Engine Landによる整理）。

答えの書き方：1文目で答え、条件と数字を添える

AIは質問に合う部分をページから抜き出して答えを組み立てます。前置きが長いと、答えの部分が見つかりにくくなります。決まりは3つです。1文目で「はい／いいえ」や金額・時間を言い切る。2文目以降に条件や例外を書く。詳しい説明は別のページに任せてリンクする。

質問AIに使われにくい答えAIに使われやすい答え
土曜日も営業していますか？当店ではお客さまのご都合に合わせられるよう、柔軟な営業を心がけております。はい。土曜日は9時〜13時に営業しています。日曜・祝日は休みです。
料金はいくらですか？内容によって異なりますので、お気軽にお問い合わせください。基本プランは税込11,000円です。出張が必要な場合は、市外で税込2,200円を追加します。
キャンセル料はかかりますか？キャンセルポリシーをご確認ください。前日までのキャンセルは無料です。当日のキャンセルは料金の50%をいただきます。
◯◯には対応していますか？幅広いご要望にお応えしています。いいえ、◯◯は扱っていません。近い内容として△△を行っています。

表の金額や条件は書き方の例です。自社の実際の値を書いてください。「やっていないこと」をはっきり書くのも大切です。書いていないと、AIが他社の情報や古い情報で補ってしまうことがあります。

答えを変えたら、同じ事実が載っている他のページ（料金表、会社概要、予約ページ）も同じ日に直します。ページどうしで値が違うと、AIがどちらを使うかは分かりません。

FAQPage を付けるときの決まり

付けるなら、守ることは多くありません。いちばん大事なのは、マークアップの質問と答えが、ページに表示されている文と同じであることです。表示していない質問をマークアップだけに書くのは、Googleの決まりに反します。GoogleはAI機能についても、構造化データは表示されている本文と一致させるよう求めています（AI機能とウェブサイト）。

<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "FAQPage",
  "mainEntity": [
    {
      "@type": "Question",
      "name": "土曜日も診療していますか？",
      "acceptedAnswer": {
        "@type": "Answer",
        "text": "はい。土曜日は9時〜13時に診療しています（受付は12時30分まで）。日曜・祝日は休診です。"
      }
    },
    {
      "@type": "Question",
      "name": "駐車場はありますか？",
      "acceptedAnswer": {
        "@type": "Answer",
        "text": "建物の裏に3台分あります（無料）。満車のときは向かいのコインパーキングをご利用ください。"
      }
    }
  ]
}
</script>
<!-- 質問と答えは、ページの本文に表示されているものと同じ文にする -->

1つのページに FAQPage が2つ出ると、どちらが正しいか分かりにくくなります。SEOプラグインのFAQブロック、テーマの機能、手で貼ったコードなど、FAQを出すものを1つに決めてください。

今あるFAQのマークアップは消すべきか

消す必要はありません。リッチリザルトが出なくなっただけで、FAQPage の型は廃止されておらず、残しても Search Console のエラーにはならないと報じられています（TechWyse）。ただし、この機会に次の3つは直してください。

  1. 表示していない質問がマークアップに入っている（以前、リッチリザルトのためだけに足したもの）→ 本文に出すか、マークアップから外す
  2. 同じページに FAQPage が2つ以上ある → 出すものを1つにする
  3. 答えが古い（料金・営業時間・担当者が変わった）→ 本文とマークアップを同時に直す

逆に、リッチリザルトが出なくなったからといって、FAQの本文そのものを消すのは損です。お客さまとAIが読むのは本文です。

WordPressでの手順（Nurevo AIO を使う場合）

Nurevo AIO（無料、旧表示名 Nurevo AEO）では、FAQを「表示しているページにだけ」FAQPage として出します。表示していない質問は出しません。

  1. 「Nurevo AIO」の「設定」で、サイト全体の質問と答えを入れる
  2. FAQを見せたい固定ページに「Nurevo AIO FAQ」ブロック（またはショートコード [nurevo_faq]）を置く。質問は開閉式で表示され、そのページにだけ FAQPage が出る
  3. ページだけの質問は、編集画面の右側の「Nurevo AIO」パネルで入れ、ブロックを「このページ専用の質問」に設定する（ショートコードは [nurevo_faq source="post"]）
  4. Yoast SEO・Rank Math・All in One SEO・Slim SEO を使っている場合、Nurevoの質問はSEOプラグインの構造化データに足され、すでにある質問は重ねない。SEO SIMPLE PACK は構造化データを出さないので、Nurevo が FAQPage を出す
  5. 公開後、ページのソースで application/ld+json を探し、FAQPage が1つだけで、質問と答えが表示と同じかを確かめる。構造の確認には Schema Markup Validator も使える

Nurevo が出す FAQPage は、質問（Question の name）と答え（acceptedAnswer の Answer の text）だけのシンプルな形で、入れた文をそのまま使います。文を作り足したり、要約したりはしません。

効果の測り方：FAQを足す前と後で、同じ質問を聞く

FAQのリッチリザルトがなくなったので、Search Console の表示回数でFAQの効果を見ることはできなくなりました。AI検索での効果は、FAQに入れた質問を社名なしでAIに聞き、出典に自社のURLが出るかを、足す前と後で同じ条件で記録します。

記録すること理由
FAQに入れた質問を、社名なし・地域ありの形で5〜10個（例：「◯◯市で土曜に開いている歯医者は？」）社名を入れると、出て当たり前になる
日付・使ったAI・ログインの有無条件が変わると答えも変わる
名前が出たか、出典に自社のURLがあったか、FAQページか別のページかどのページが使われたかで、直す場所が分かる
同じ質問を2〜3回1回の結果は偶然のことがある
FAQを公開・更新した日前後を比べるため

Nurevoの無料プランとStandardでは、月に1回、業種と地域から作った社名なしの質問3つをNurevoのサービスがPerplexityに聞き、名前が出たか・サイトが引用されたかを表示します。Pro（月14,800円〜、ベータ）は最大20問をPerplexityで計測します（ChatGPTは設定され次第）。Googleは計測しないので、手で記録してください。詳しくはAIでの登場率の測り方へ。

なお、Nurevoが2026年10月に62事業者で調べたところ、構造化データなどサイト側の対応の点数と、Perplexityの回答に出る率との間に、はっきりした関係は見られませんでした（順位相関 0.03、調査の詳細）。マークアップだけで結果が変わると期待せず、質問の選び方と答えの中身で比べてください。

チェックリスト

  1. FAQの質問は、実際に問い合わせで来た質問から選んだ
  2. どの答えも1文目で言い切っている（はい／いいえ・金額・時間）
  3. やっていないこと・対象外のことも書いた
  4. 金額は税込か税抜かを書いた
  5. 同じ質問の答えが、ページどうしで一字一句そろっている
  6. マークアップの質問と答えが、表示されている文と同じ
  7. 1つのページに FAQPage は1つだけ
  8. 表示していない質問をマークアップから外した
  9. FAQを足す前に、社名なしの質問でAIの回答を記録した
  10. 料金・営業時間が変わったら、FAQも同じ日に直す決まりにした

よくある質問

GoogleのFAQリッチリザルトはいつ終わりましたか？

2026年5月7日から表示されなくなったと報じられています。2023年8月からは、よく知られた政府・保健医療のサイトに限られていました。Search Console のFAQレポートとリッチリザルトテストは2026年6月に、Search Console API は8月に終了するとGoogleのドキュメントで予告されていました。

FAQの構造化データは消したほうがいいですか？

消す必要はありません。FAQPage は schema.org の型として有効で、残しても問題は起きないと報じられています。表示していない質問が入っている場合と、同じページに2つ出ている場合だけ直してください。

FAQPage を付けるとChatGPTやPerplexityに引用されやすくなりますか？

そう明記した公式の資料は、この記事のために調べた範囲では見つかりませんでした。AIが読むのはページの本文なので、まず本文の質問と答えを良くし、マークアップは本文と同じ内容で付ける補助と考えてください。

GoogleのAIによる概要に出るためにFAQのマークアップは必要ですか？

Googleは、AI機能のために特別な構造化データは必要ないと説明しています。構造化データを使う場合は、表示されている本文と一致させることを求めています。

FAQは何問くらい書けばいいですか？

決まった数はありません。実際に問い合わせで繰り返し来る質問をすべて入れ、誰も聞かない宣伝の質問は入れない、が基準です。多くなったらテーマごとに見出しで分けてください。

FAQ専用ページと各サービスのページ、どちらに書くべきですか？

サイト全体に関わる質問は専用ページ、そのサービスだけの質問はサービスのページに置きます。両方に置くなら、答えの文をそろえてください。値が違うと、AIがどちらを使うか分かりません。

FAQを直したら、すぐAIの答えに反映されますか？

反映までの時間は、どのAIも公開していません。直した日を記録し、数日から数週間あけて同じ質問・同じ条件で確かめてください。出典に選ばれるかはAIが決めるもので、保証はできません。

AIがサイトを読める状態かを確かめる

無料チェックは登録不要です。URLを入れると、AIクローラーの許可、構造化データ、llms.txtの状態が分かります。WordPressなら無料のプラグインで、表示しているFAQだけを FAQPage として出し、SEOプラグインと重ならないように整えられます。
