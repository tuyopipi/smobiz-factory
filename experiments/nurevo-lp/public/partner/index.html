手順（WP-CLI）

プラグインに入っているWP-CLIコマンド（wp nurevo status・diagnose・export・import）を使います。

  1. 基準にするサイトに導入し、wp-adminの「Nurevo AEO」で設定します。WP-CLIで有効化したときは初期設定ウィザードが自動では開かないので、「Nurevo AEO › 初期設定」から開きます。
    wp plugin install nurevo-webmcp --activate
  2. 設定をJSONファイルに書き出します（wp nurevo export > nurevo.json でも書き出せますが、--file にすると他のプラグインの警告などがファイルに混ざりません）。キー・トークン・プラン・接続情報は含まれません。
    wp nurevo export --file=nurevo.json
  3. ファイルを確認します。settings の business_ で始まる項目（店名・説明・住所・電話・営業時間・業種・URL・メール）、faq_page_id、site_type、各ページのURL（return_policy_url など）と、faq・services は基準サイトの内容です。サイトごとに違う項目は削除してください。ファイルにない項目は、読み込み先サイトの今の値がそのまま残ります。
  4. "enabled" はAI向け出力のオン・オフです。"1" のまま読み込むと、その時点で出力が有効になります。お知らせの期間が終わってから有効にするなら "0" にします。共通の設定だけを残したファイルは次のとおりです。
    {
  "plugin": "nurevo-aeo",
  "format": 1,
  "settings": {
    "enabled": "0",
    "allow_ai_crawlers": "1",
    "ai_training": "default",
    "serve_llms_txt": "1",
    "serve_schema": "1",
    "avoid_schema_duplicates": "1"
  }
}
  5. ほかの各サイトで、プラグインを導入して設定を読み込みます。ファイルはそのサイトのサーバーに置くか、標準入力から渡します（wp nurevo import -）。キーや、このバージョンが知らない設定を含むファイルは読み込まれません。
    wp plugin install nurevo-webmcp --activate
wp nurevo import nurevo.json
  6. 結果を確認します。enabled と outputs（schema・llms_txt・ai_crawler_rules）で、そのサイトが何を公開しているかがわかります。そのあと、店名・住所・営業時間などは、サイトごとに「Nurevo AEO › 初期設定」で入力します。
    wp nurevo status
  7. 無料のAI診断は任意です。サイトのURLをNurevoのサービスに送るため、初回は --consent が必要です（wp-adminの同意のチェックと同じです）。お知らせを済ませたサイトでだけ実行してください。
    wp nurevo diagnose --consent

サイトを御社のダッシュボードにつなぐ（月次レポートなど）には、ダッシュボードでサイトごとに発行するペアリングコードを、各サイトの「Nurevo AEO › 設定」に入力します。ペアリングコードは設定ファイルでは引き継がれません。ペアリングすると、そのサイトの出力は有効になります。

MainWP・ManageWP・InfiniteWPのような複数サイトの管理ツールでも、プラグインの一括インストール機能でWordPress.orgの「Nurevo AEO」（nurevo-webmcp）を選んで導入できます。設定の読み込みは、WP-CLIか、各サイトの「Nurevo AEO › 設定 › ツール」で行います。Nurevoには、これらのツールとの専用の連携機能はありません。
