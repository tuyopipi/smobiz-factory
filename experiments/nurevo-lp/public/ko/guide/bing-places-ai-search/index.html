Copilot과 Bing을 위한 Bing Places for Business 설정: Google에서 가져오기, 동기화 덮어쓰기 방향, 중복 정리

Bing Places for Business는 Bing과 Bing Maps에 표시되는 비즈니스 정보를 관리하는 Microsoft의 무료 서비스입니다. 이미 Google Business Profile(GBP)이 있다면 가져오기가 가장 빠르며, 동기화를 켜면 GBP가 Bing을 덮어쓰므로 수정할 곳은 GBP와 웹사이트 두 곳뿐입니다. Microsoft는 Copilot과의 통합을 강화하고 있다고 밝혔지만, 현재 Copilot 답변이 Bing Places를 어떻게 쓰는지는 공개하지 않았습니다. 그래서 가장 확실한 준비는 Bing Places, GBP, 사이트의 상호, 주소, 전화번호, 영업시간을 똑같이 맞추는 것입니다.

2026년 11월 24일(일본 시간)에 작성했습니다. Bing Places의 동작은 같은 날 Microsoft 공식 블로그와 Microsoft Q&A에 올라온 Microsoft 직원의 답변으로 확인했습니다. 그날은 Bing Places 자체의 화면과 도움말 페이지를 읽을 수 없었기 때문에 화면 이름과 절차가 바뀌었을 수 있습니다. 등록할 때는 화면에 표시되는 내용을 따르세요.

어떤 비즈니스 정보도 Copilot이나 다른 AI가 여러분의 비즈니스를 보여 주거나 더 높은 순위에 올린다고 보장할 수 없습니다. AI 답변은 날마다 바뀝니다. 이 가이드는 AI가 여러분의 비즈니스를 정확하게 설명할 수 있도록 정보를 정리하는 방법을 다룹니다.

Bing Places란 무엇이며 2025년 10월 개편으로 무엇이 달라졌나

2025년 10월 3일, Microsoft는 새로 개편한 Bing Places for Business를 발표했습니다(Bing Search Blog). Bing 검색 결과와 Bing Maps에 표시되는 비즈니스 정보를 만들고 관리하는 무료 서비스입니다.

Copilot은 Bing Places를 사용할까? 알려진 것과 알려지지 않은 것

많은 글이 Copilot이 Bing Places 데이터로 지역 관련 질문에 답한다고 말합니다. 그러나 저희가 읽은 Microsoft 자료 중 그런 구조를 설명한 것은 없었습니다. 알려진 것과 알려지지 않은 것을 나누어 정리합니다.

항목상태출처
Bing Places 데이터는 Bing 검색 결과와 Bing Maps에 표시됨Microsoft가 설명함Bing Search Blog
Copilot과의 통합 강화계획으로 발표됨Bing Search Blog

현재 Copilot 답변이 Bing Places의 어떤 항목을 쓰는지공개되지 않음—
Bing Places가 Windows 검색이나 Edge에도 표시됨일부 대행사 글의 주장. Microsoft 자료에서는 찾지 못함—

구조가 공개되지 않은 이상 특정 항목에 기대기보다 기본 정보를 어디에서나 똑같이 유지하는 편이 합리적입니다. Copilot은 웹 페이지도 답변의 출처로 쓰므로 웹사이트도 똑같이 중요합니다.

설정: 기존 정보 찾기, 가져오기, 인증

  1. Microsoft 계정으로 bing.com/forbusiness에 로그인합니다.
  2. 먼저 내 비즈니스를 검색합니다. Bing은 공개 데이터로 정보를 자동 생성할 수 있어서, 그 위에 새로 만들면 중복이 생깁니다.
  3. GBP를 쓴다면 "Import from Google"(Google에서 가져오기)을 선택하고 GBP 계정으로 로그인한 뒤 지점을 고릅니다. 포럼에서 Microsoft 직원은 가져오기가 "could take up to two days"(최대 이틀 걸릴 수 있다)고 답했습니다(Microsoft Q&A, 2025년 11월).
  4. 가져온 뒤 카테고리를 확인합니다. 2023년의 지원 답변에서는 카테고리는 가져와지지 않으므로 직접 설정해야 한다고 했습니다(Microsoft Q&A). 2025년 개편으로 달라졌을 수 있으니 화면에서 확인하세요.
  5. GBP가 없다면 상호, 주소, 전화번호, 카테고리, 영업시간, 웹사이트를 직접 입력하고 제시되는 방법으로 소유권을 인증합니다. 어떤 방법(전화, 이메일, 우편 엽서 등)이 나오는지는 국가와 비즈니스 정보에 따라 다릅니다.
  6. Recommendation Tool의 제안(사진, 영업시간, 소셜 링크)을 하나씩 처리하고, 마지막으로 모든 내용이 사이트와 일치하는지 확인합니다.

저희가 읽을 수 있었던 자료에는 모든 국가의 주소를 지원하는지, 어느 곳에서 어떤 인증 방법이 제공되는지가 나와 있지 않았습니다. 프랑스의 한 사업자는 선택지가 우편 엽서뿐이었는데 엽서가 끝내 도착하지 않았다고 했고, Microsoft 직원은 Google 가져오기를 시도해 보고 안 되면 지원팀에 문의하라고 안내했습니다. 정보를 수동으로 게시할 수 있는 곳은 지원팀뿐입니다(Microsoft Q&A, 지원팀 문의).

사진 최대 100장, 카테고리 최대 10개 같은 제한은 Bing 도움말 페이지를 바탕으로 한 Whitespark의 가이드(2025-10-30 업데이트)에 나와 있습니다(Whitespark, 2차 자료).

GBP와 동기화: 어느 쪽이 덮어쓰는지 정하기

2023년 Bing Places 지원 전문가의 답변이 동기화 방향을 분명히 설명합니다(Microsoft Q&A). 개편 이전의 설명이라 세부 사항은 바뀌었을 수 있지만 원칙은 여전히 유용합니다.

항목2023년 지원팀 설명대응 방법
동기화 방식수동 또는 자동(매주, 격주, 매월)계절이나 휴일에 따라 영업시간이 바뀐다면 자동을 사용
덮어쓰기 방향GBP 데이터가 Bing 정보를 덮어씀. GBP와 충돌하는 Bing 쪽 수정은 어느 쪽이 더 최신이든 GBP 값이 됨동기화 중에는 Bing이 아니라 GBP를 수정
Bing에서 Google로Bing 대시보드에서는 GBP를 업데이트할 수 없음GBP와 사이트를 두 개의 기준 정보로 삼기
게시까지 걸리는 시간표준 게시 주기는 보통 약 10일이며, 인증이나 수정을 할 때마다 다시 시작됨급한 변경은 반복해서 고치지 말고 한 번에 모아서 처리
주소Bing은 주소가 필수이며, 주소가 없는 GBP 정보(방문 서비스형 비즈니스)는 표시(플래그)됨방문 서비스형 비즈니스는 주소 처리 방식을 확인

동기화하는 비즈니스에게 Bing Places는 GBP의 사본입니다. 오류를 발견하면 GBP와 사이트를 먼저 고치고 동기화로 Bing에 반영되게 하세요. 동기화하지 않으면 GBP, Bing, 사이트를 각각 고쳐야 하므로 정보가 어긋나기 훨씬 쉽습니다.

중복 정보나 직접 만들지 않은 정보를 발견했을 때

  1. Bing Maps에서 상호, 전화번호, 주소로 검색해 내 비즈니스 정보가 몇 개 있는지 세어 봅니다. 이전 전 주소와 예전 상호도 찾아보세요.
  2. Microsoft 직원은 중복 정보가 "likely created automatically from a different data source"(다른 데이터 소스에서 자동으로 생성되었을 가능성이 높다)라고 말합니다(Microsoft Q&A, 2026년 6월).
  3. 중복 정보는 인증하지 마세요. 둘 다 소유하면 어느 쪽이 맞는지 구분하기가 더 어려워집니다.
  4. 지원팀에 두 정보의 세부 내용(남길 것, 예를 들어 Google과 동기화된 것, 그리고 삭제할 것), 소유 증명, GBP 링크, 스크린샷을 보내고 병합이나 삭제를 요청합니다. 직원에 따르면 지역과 언어를 선택한 뒤 지원팀과 채팅할 수 있습니다.
  5. Bing Maps 정보의 "Suggest an edit"(수정 제안)이나 "Feedback"(피드백)으로도 중복을 신고합니다. 직원은 이 방법이 "sometimes works"(가끔 효과가 있다)라고 설명하므로 보장되지는 않습니다.

WordPress 절차: 사이트의 정보 맞추기

  1. 회사 소개나 오시는 길 페이지에 상호, 주소, 전화번호, 영업시간을 이미지가 아닌 텍스트로, Bing Places와 GBP에 입력한 것과 똑같은 표기로 적습니다.
  2. SEO 플러그인이나 테마가 구조화 데이터에 넣는 상호, 주소, 전화번호를 확인합니다. 무료 버전은 주소와 영업시간이 빠져 있는 경우가 많습니다. SEO 플러그인과 지역 비즈니스 구조화 데이터를 참고하세요.
  3. Nurevo AEO(무료 WordPress 플러그인)를 쓴다면 설정에서 상호, 주소, 전화번호, 영업시간을 입력합니다. 주소는 schema.org의 PostalAddress로 게시되며, 일본어 사이트에서는 일본 전화번호가 구조화 데이터에 국제 형식으로 게시됩니다(입력한 번호 자체는 바뀌지 않음). "Mon-Fri 9:00-18:00 / Sat 10:00-15:00" 같은 일반적인 영업시간 표기는 openingHoursSpecification으로 변환되고, 확실히 읽을 수 없는 영업시간은 추측하지 않고 입력한 그대로 게시됩니다. SEO 플러그인이 이미 설정한 값은 절대 덮어쓰지 않으며, 부족한 정보만 같은 @id 아래에 추가합니다. 0.9.1부터는 SEO SIMPLE PACK, VK All in One Expansion Unit과도 중복 없이 함께 동작합니다. WordPress.org에서 받기
  4. Bing이 사이트를 읽을 수 있는지 확인합니다. Settings > Reading(설정 > 읽기)에서 "Search engine visibility"(검색 엔진 가시성)의 체크가 해제되어 있어야 하고, /robots.txt가 Bingbot을 차단하지 않아야 합니다.
  5. 영업시간이 바뀌면 같은 날 사이트와 GBP(동기화하지 않는다면 Bing Places도)를 업데이트하고 날짜를 기록합니다.

설정 후 확인 방법

  1. Bing에서 상호를 검색해 Bing Maps 정보에 사이트와 같은 상호, 주소, 전화번호, 영업시간이 나오는지 확인합니다.
  2. Copilot에 "[지역]에서 [조건]인 [업종]", "[상호]의 영업시간은?" 같은 질문을 하고 답변과 출처를 기록합니다. 답변은 날마다 바뀌므로 매달 같은 날에 같은 질문을 합니다.
  3. Bing Webmaster Tools의 AI Performance에서 내 페이지가 Microsoft의 AI에서 얼마나 자주, 어떤 문구로 출처가 되었는지 확인합니다.
  4. 분석 도구에서 copilot.microsoft.com에서 유입된 방문을 확인합니다.
  5. ChatGPT와 Perplexity는 Bing과 별개로 동작합니다. AI 가시성 측정 방법처럼 고정된 질문 세트로 기록하세요. Nurevo AEO의 무료 AI 점검은 연결된 사이트에 대해 업종과 지역으로 만든 질문 세 개를 매달 한 번 Perplexity에 묻습니다. Pro 플랜(월 $99부터)은 지속적으로 측정하며, 현재는 Perplexity를 지원합니다(설정이 끝나면 ChatGPT도).

체크리스트

  1. bing.com/forbusiness에서 기존 정보를 검색했다
  2. GBP에서 가져왔거나, 직접 등록하고 인증을 마쳤다
  3. 카테고리가 설정되어 있는지 확인했다
  4. 동기화 여부를 정해 기록하고, GBP와 사이트를 기준 정보로 삼았다
  5. Bing Maps에서 중복, 예전 주소, 예전 상호를 검색했다
  6. 중복 정보는 인증하지 않고 지원팀에 병합이나 삭제를 요청했다
  7. 상호, 주소, 전화번호, 영업시간, 카테고리, URL이 Bing, GBP, 사이트에서 일치한다
  8. 구조화 데이터의 값이 사이트 본문과 일치한다
  9. robots.txt가 Bingbot을 차단하지 않는지 확인했다
  10. Copilot에 한 질문과 답변을 날짜와 함께 기록했다

고객 대신 등록하는 대행사와 지역 SEO 업체에게

먼저 어느 Microsoft 계정이 정보를 소유할지 정하세요. 비즈니스 자체 계정으로 만들고 대행사를 관리자로 추가하는 편이 안전합니다. 담당자가 바뀌어도 비즈니스가 접근 권한을 잃지 않습니다.

월간 유지 관리에 GBP, Bing Places, 사이트를 비교한 한 장짜리 표를 넣으면 AI 검색 대응을 보고서에 포함할 수 있습니다. 대행사가 AI 검색 대응을 월간 서비스로 만드는 방법과 파트너 페이지를 참고하세요.

자주 묻는 질문

Bing Places는 무료인가요?

네. Microsoft는 Bing Places for Business를 Bing과 Bing Maps의 비즈니스 정보를 만들고 관리하는 무료 서비스라고 설명합니다.

Google Business Profile이 있어도 Bing Places가 필요한가요?

GBP가 Bing Places에 자동으로 나타나지는 않습니다. Bing Places의 "Import from Google"(Google에서 가져오기)로 GBP를 바탕으로 정보를 만드세요. 동기화를 켜면 이후 GBP의 변경 사항도 Bing에 반영됩니다.

Bing Places에서 고친 내용이 원래대로 돌아갔습니다.

2023년 Bing 지원 전문가의 설명에 따르면, GBP 동기화가 켜져 있으면 충돌하는 항목은 GBP의 값으로 덮어써집니다. 동기화 중에는 GBP 쪽을 고치세요.

변경 사항이 표시되기까지 얼마나 걸리나요?

2023년 지원 답변에서는 게시 주기가 보통 약 10일이며 수정할 때마다 다시 시작된다고 했습니다. 2025년에는 직원이 Google 가져오기에 최대 이틀이 걸릴 수 있다고 했습니다. 현재 소요 시간은 화면에서 확인하세요.

Copilot은 Bing Places 데이터로 답하나요?

Microsoft는 Copilot과의 통합 강화를 발표했지만, 현재 답변이 Bing Places를 어떻게 쓰는지는 공개하지 않았습니다. Bing Places, GBP, 사이트의 정보를 똑같이 유지하는 것이 확실한 준비입니다.

모든 국가의 비즈니스가 등록할 수 있나요?

저희가 읽을 수 있었던 Microsoft 자료에는 지원 국가도, 국가별 인증 방법도 나와 있지 않습니다. 등록 화면에서 내 국가와 주소를 선택할 수 있는지, 어떤 인증 방법이 나오는지 확인하세요.

중복 정보를 직접 삭제할 수 있나요?

Microsoft 포럼 직원은 Bing Places 지원팀에 문의하라고 안내합니다. 남길 정보와 삭제할 정보의 세부 내용, 소유 증명을 보내고 병합이나 삭제를 요청하세요. 중복 정보는 인증하지 마세요.
