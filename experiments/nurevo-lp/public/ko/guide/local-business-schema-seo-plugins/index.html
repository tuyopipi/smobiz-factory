Yoast SEO·Rank Math·AIOSEO에 지역 비즈니스 스키마를 무료로 추가하는 방법

SEO 플러그인은 그대로 두세요. 무료 WordPress 플러그인 Nurevo AEO가 AI가 지역 비즈니스를 설명하는 데 필요한 정보(주소·전화번호·영업시간·업종·서비스·FAQ)를 Yoast SEO, Rank Math, All in One SEO가 이미 출력하는 구조화 데이터에 중복 없이 추가합니다.

최종 확인: 2026년 10월. SEO 플러그인의 요금제는 바뀔 수 있으니 최신 기능은 각 플러그인 공식 페이지에서 확인하세요.

Yoast SEO·Rank Math·AIOSEO 무료 버전이 출력하는 것

AI가 "근처에서 토요일에 진료하는 치과" 같은 질문에 답할 때는 추측 없이 읽을 수 있는 사실이 필요합니다. 어떤 업종인지, 어디에 있는지, 전화번호, 영업시간. WordPress에서는 이런 사실을 보통 SEO 플러그인의 JSON-LD에서 읽습니다.

무료 버전은 사이트를 이름·URL·로고가 있는 Organization으로 출력합니다. 지역 정보의 대부분은 유료 로컬 SEO 애드온이나 요금제에 포함되어 있습니다. 2026년 10월 기준:

이 플러그인들을 비판하려는 것이 아닙니다. 검색 순위는 SEO 플러그인의 역할이고, Nurevo AEO는 그 대신이 아니라 옆에서 함께 동작하도록 만들어졌습니다.

Nurevo AEO가 중복 없이 빠진 정보를 채우는 방식

Nurevo AEO는 SEO 플러그인의 구조화 데이터 옆에 두 번째 세트를 출력하지 않습니다. 각 플러그인이 JSON-LD 그래프를 만들 때 쓰는 필터(Yoast SEO의 wpseo_schema_graph, Rank Math의 rank_math/schema/validated_data, AIOSEO의 aioseo_schema_output)에 연결해 빠진 것만 추가합니다.

  1. 주소·전화번호·영업시간·설명·이메일을 기존 사업체 노드에 같은 @id로 추가합니다.
  2. SEO 플러그인이 이미 설정한 값은 덮어쓰지 않습니다. Rank Math의 Local SEO 설정을 입력했다면 그 값이 유지됩니다.
  3. 입력한 서비스를 추가하고 사업체에 연결합니다.
  4. 입력한 FAQ 질문은 Nurevo FAQ 블록이나 [nurevo_faq] 단축 코드를 둔 페이지에서만 해당 페이지의 FAQPage에 추가되며, 이미 답한 질문은 건너뜁니다.
  5. WebSite·WebPage·Article·브레드크럼은 SEO 플러그인이 출력한 그대로 둡니다.

결과적으로 페이지에는 하나의 사업체를 설명하는 하나의 그래프만 남고 중복이 없습니다. 그 밖의 구성(SEOPress, The SEO Framework, 테마 자체 스키마, SEO 플러그인 없음)에서는 Nurevo AEO가 자체 그래프를 출력하고 사업체 정보를 기존 사업체 @id 아래에 넣으므로, 역시 하나의 사업체로 읽힙니다.

5단계로 설정하기

  1. WordPress.org에서 Nurevo AEO를 설치하고 활성화합니다(플러그인 > 새로 추가에서 "Nurevo AEO" 검색). SEO 플러그인은 활성 상태로 둡니다.
  2. 설정 마법사가 한 번 열립니다. 사이트 유형(지역 비즈니스, 온라인 쇼핑몰, B2B)을 고르고 이름·주소·전화번호·영업시간·설명을 확인한 뒤, AI에 공개할 항목을 선택합니다.
  3. 기존 설정에서 자동으로 채워진 정보를 확인합니다. 빈 칸만 채우므로 직접 입력한 값은 바뀌지 않으며, 마법사가 영업시간을 실제로 게시될 형태로 다시 보여 줍니다.
  4. Nurevo AEO > Settings에서 서비스와 질문을 입력하고, FAQ를 보여 줄 페이지에 Nurevo FAQ 블록(또는 [nurevo_faq])을 배치합니다.
  5. Nurevo AEO > AEO Score를 열어 진단이 보내는 내용을 읽고, 동의에 체크한 뒤 Run diagnosis를 누릅니다. 그다음 체크리스트의 원클릭 수정을 적용합니다.

외부에서 AI가 무엇을 읽는지 보려면 홈페이지 URL로 무료 AI 가독성 점검을 실행해 보세요.

무료로 쓸 수 있는 기능

이 페이지의 내용은 모두 무료 요금제에서 동작합니다. 라이선스 키도, 체험 기간도 없습니다.

  1. AEO 점수: 0~100점, 신호등 색 알림과 수정할 항목 체크리스트.
  2. 기본 구조화 데이터, llms.txt, AI 크롤러 접근의 원클릭 수정.
  3. 서버에서 출력하는 schema.org JSON-LD. JavaScript를 실행하지 않는 크롤러도 읽을 수 있습니다.
  4. /llms.txt: WordPress 콘텐츠로 플러그인 안에서 생성.
  5. AI 검색이 페이지를 읽고 인용할 때 쓰는 크롤러를 robots.txt에서 허용하는 규칙.
  6. 지역 비즈니스, 온라인 쇼핑몰, B2B 기업용 사이트 유형.

유료 요금제가 추가하는 것은 항상 최신인 규칙 세트(Standard)와 AI 노출 측정(Pro, 베타)뿐이며, 이 페이지의 내용에는 필요하지 않습니다.

구조화 데이터로 할 수 있는 것과 없는 것

구조화 데이터는 AI가 정보를 정확히 읽도록 돕습니다. 정확한 영업시간, 정확한 전화번호, 정확한 업종. 하지만 AI가 무엇을 말할지는 결정하지 않습니다. AI가 반드시 당신을 언급하도록 보장할 수 있는 도구는 없으며, Nurevo도 그것을 약속하지 않습니다.

자주 묻는 질문

Nurevo AEO가 SEO 플러그인의 스키마와 중복되나요?

아니요. Yoast SEO, Rank Math, All in One SEO를 쓰는 경우 SEO 플러그인이 이미 출력하는 그래프에 빠진 정보만 같은 사업체 @id로 추가하며, 플러그인이 설정한 값은 덮어쓰지 않습니다. 페이지에는 하나의 사업체를 설명하는 하나의 그래프가 유지됩니다.

Yoast SEO, Rank Math, AIOSEO를 삭제해야 하나요?

아니요. 검색 순위를 위해 SEO 플러그인은 계속 사용하세요. Nurevo AEO는 그 위에 AI에 필요한 정보를 더합니다.

Nurevo AEO는 무료인가요?

네. 사업체 정보, 서비스, FAQ, AEO 점수, 원클릭 수정, JSON-LD, llms.txt, AI 크롤러 규칙 모두 무료 요금제에 포함됩니다. 유료 요금제는 항상 최신인 규칙 세트와 AI 노출 측정(베타)만 추가합니다.
