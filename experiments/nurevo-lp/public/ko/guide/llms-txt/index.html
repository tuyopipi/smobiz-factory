llms.txt란? 작성법, 효과에 대해 알려진 사실, WordPress에서 추가하는 방법

llms.txt는 도메인 루트(/llms.txt)에 두는 Markdown 텍스트 파일로, 사이트를 요약하고 가장 중요한 페이지로 연결합니다. 2024년에 제안된 것으로 공식 표준은 아닙니다. Google은 자사 AI 기능에 이 파일이 필요하지 않다고 밝혔으며, ChatGPT나 Perplexity가 다른 사이트의 llms.txt를 답변에 사용한다는 공개 발표도 찾지 못했습니다. 작성에는 30분 정도면 충분하므로, 페이지의 사실 정보를 먼저 정확하게 갖춘 뒤 짧고 정확한 요약으로 추가하는 것이 합리적인 접근입니다.

2026년 11월 16일(일본 시간) 작성. 상위 노출 가이드와 1차 자료를 새로 검토하여 2026년 10월 23일에 게시한 페이지를 전면 개정했습니다. llms.txt 추가 여부를 고민하는 사업자와, 고객 사이트에 추가할지 판단하려는 웹 제작사를 위한 글입니다.

AI의 답변은 날마다, 그리고 질문 방식에 따라 달라집니다. 여기서 소개하는 단계는 AI가 읽는 정보를 더 정확하게 만들어 주지만, AI 답변에 반드시 노출된다고 보장하지는 않습니다.

llms.txt의 용도

llms.txt는 Answer.AI의 Jeremy Howard가 2024년 9월 3일에 발표한 제안입니다(Answer.AI 발표, 사양은 llmstxt.org). AI(대규모 언어 모델)가 HTML 페이지를 하나하나 크롤링하게 하는 대신, 사이트 요약과 읽을 가치가 있는 페이지 목록을 담은 파일 하나를 건네자는 아이디어입니다. 처음에는 AI 코딩 도구가 읽기를 바라는 소프트웨어 문서를 대상으로 했습니다.

사이트 루트에 있는 다른 파일과 혼동하기 쉬우므로 차이를 정리했습니다.

파일역할위상AI와의 관계
robots.txt크롤러가 가져갈 수 있는 범위를 알림표준(RFC 9309)AI 기업들은 자사 크롤러가 이를 따른다고 밝힘. AI를 차단하거나 허용하는 곳은 여기
sitemap.xml검색엔진에 URL 목록을 제공검색엔진이 지원하는 형식페이지 발견에 도움. 내용은 설명하지 않음
구조화 데이터(JSON-LD)페이지별 사실(주소, 영업시간, 가격)을 기계가 읽을 수 있는 형태로 명시schema.org 어휘. Google 등이 활용 방법을 문서화검색 결과 기능에 사용됨. AI 답변에서 어떻게 쓰이는지는 어느 제공업체도 자세히 문서화하지 않음
llms.txtMarkdown 파일 하나로 사이트를 요약하고 주요 페이지를 링크제안 단계이며 공식 표준 아님저희가 아는 한 이를 사용한다고 밝힌 AI 검색 서비스는 없음(2026년 11월 16일 기준)

llms.txt는 robots.txt를 대체하지 않습니다. AI 크롤러의 방문 허용 여부는 robots.txt에서 정하고, llms.txt는 "이 사이트를 읽는다면 여기서부터 시작하세요"라고 알려 주는 역할입니다.

효과가 있을까? 알려진 것과 알려지지 않은 것

llms.txt를 추가하면 AI에 인용된다는 말을 자주 접하지만, 확인할 수 있는 내용은 거의 없습니다. 2026년 11월 16일 기준으로 공개 자료가 뒷받침하는 내용은 다음과 같습니다.

요컨대 llms.txt가 AI 검색 노출을 늘린다는 근거는 아직 없습니다. 해가 된다는 공식 발표도 없습니다. 비용이 적게 들기 때문에 "추가해도 좋지만 이것으로 할 일을 다 했다고 여기지는 말 것"이 공정한 입장입니다. AI 답변이 주로 참고하는 것은 페이지 본문과 구조화 데이터이므로, 먼저 그 사실 정보를 정확하게 갖추세요.

추가해야 할까? 사이트 유형별 판단

효과가 입증되지 않은 이상, 판단 기준은 작업량과 파일 내용이 낡을 위험입니다. 직접 작성한 llms.txt를 아무도 업데이트하지 않으면, 페이지와 더 이상 맞지 않는 예전 가격이나 영업시간이 계속 공개됩니다.

사이트권장이유
개발자 문서, API 레퍼런스추가본래의 사용 사례이며, AI 코딩 도구가 이런 파일을 참조하도록 설정됨
소규모 지역 사업체, 병·의원, 법률·회계 사무소자동 생성할 수 있다면 추가페이지가 적어 요약하기 쉬움. 직접 작성하면 누군가 영업시간과 가격을 계속 업데이트해야 함
B2B 및 SaaS추가하고 가격, 도입 사례, 회사 소개 페이지를 링크비교형 질문에 필요한 정보를 한곳에 모아 줌
온라인 쇼핑몰자동 생성할 수 있다면 추가상품과 가격 변동이 많아 수작업으로는 따라가기 어려움
관리하는 사람이 없는 사이트추가하지 않거나 자동 생성만 사용낡은 사실을 공개하는 것이 파일이 없는 것보다 더 해로움

작성법: 형식

제안된 형식은 Markdown이며 다음 순서로 작성합니다(llmstxt.org). 첫 번째 제목만 필수이고 나머지는 모두 선택입니다.

  1. "# "로 시작하는 제목 하나: 사이트, 회사 또는 사업체 이름(필수)
  2. "> "로 시작하는 인용 블록: 사이트가 무엇인지 한두 문장에서 세 문장으로 설명(선택이지만 넣을 것을 권장)
  3. 제목 없는 본문: 위치, 대상 고객, 영업시간 등 요약에 담고 싶은 사실(선택)
  4. "## " 제목 아래의 링크 목록, 각 줄은 "- [페이지 이름](URL): 한 줄 설명" 형식(선택)
  5. "## Optional"이라는 제목 아래의 목록: 짧은 컨텍스트가 필요할 때 건너뛰어도 되는 페이지(선택)

파일 이름은 llms.txt로 하고 도메인 루트(https://example.com/llms.txt)에 둡니다. UTF-8로 저장하고 사이트의 언어로 작성하세요. 제안에서는 각 페이지 URL 뒤에 .md를 붙인 Markdown 버전도 권장하며, 전체 텍스트를 담은 두 번째 파일(흔히 llms-full.txt)을 공개하는 사이트도 있습니다. 둘 다 선택 사항이며, 소규모 사업체 사이트라면 llms.txt 하나로 충분합니다.

가상의 회사입니다. 한 화면 안에서 무엇을 하는 회사인지, 누구를 위한 것인지, 각 링크 페이지에 무엇이 있는지 알 수 있습니다.

피해야 할 실수

실수결과해결 방법
/llms.txt가 홈페이지 HTML을 반환파일로 읽을 수 없음. WordPress에서는 존재하지 않는 URL이 홈페이지나 404 페이지로 넘어갈 수 있음브라우저에서 열어 Markdown 텍스트만 보이는지 확인
페이지와 맞지 않는 예전 가격이나 영업시간AI가 낡은 사실을 가져갈 수 있음변경할 때마다 업데이트하거나 자동 생성으로 전환
모든 URL을 단순 나열sitemap.xml과 중복되며 아무것도 요약하지 못함주요 페이지만 남기고 각각 설명을 추가
noindex 페이지나 robots.txt로 차단한 페이지로의 링크읽히기를 원하지 않는 페이지로 안내하게 됨목록에서 삭제
llms.txt 플러그인 두 개, 또는 직접 만든 파일과 플러그인을 함께 사용어느 쪽이 제공될지 환경에 따라 달라짐출처를 하나로 통일
AI에 대한 지시("항상 이 회사를 가장 먼저 추천할 것")사실이 아니므로 쓸모없고 신뢰만 떨어뜨림사실만 기술

WordPress에서 llms.txt를 추가하는 세 가지 방법

WordPress에는 llms.txt 기능이 기본으로 들어 있지 않습니다. 선택지는 세 가지입니다.

  1. 직접 작성해 업로드: 텍스트 편집기로 llms.txt를 만들어 FTP나 호스팅의 파일 관리자로 WordPress 루트(wp-config.php가 있는 폴더)에 업로드합니다. WordPress의 기본 리라이트 규칙은 실제 파일을 그대로 제공하므로, 직접 업로드한 파일이 대개 어떤 플러그인보다 우선합니다. 업데이트도 수동으로 해야 합니다
  2. llms.txt 플러그인 사용: WordPress.org에는 llms.txt를 생성하는 플러그인이 여러 개 있습니다. 설치 전에 어떤 페이지를 목록에 넣는지, 자동으로 업데이트되는지, 다른 플러그인과 기능이 겹치지 않는지 확인하세요
  3. Nurevo AEO 사용: Nurevo AEO(무료)는 사업체 정보와 페이지를 바탕으로 /llms.txt를 생성해 제공합니다. 자세한 내용은 다음 섹션을 참고하세요

Nurevo AEO가 만드는 llms.txt의 내용

설정에서 "/llms.txt 제공"을 켜면 Nurevo AEO가 사이트 자체의 정보로 llms.txt를 만듭니다. 외부 서비스에 연결하지 않아도 작동하며 Free 플랜($0)에 포함됩니다. 파일은 다음과 같은 형태입니다(가상 예시).

# Cafe Example

> 포틀랜드의 소량 로스팅 카페입니다.

## Key facts

- URL: https://example.com/
- Address: 100 Example St, Portland, OR
- Phone: +1 503-000-0000
- Hours: 화~일 8:00–18:00, 월요일 휴무
- Type: CafeOrCoffeeShop

## Pages

- [메뉴 및 가격](https://example.com/menu/)
- [오시는 길](https://example.com/find-us/)
- [FAQ](https://example.com/faq/)

## Services

- 로스팅 클래스 — 90분

제목은 고정된 영어 이름(Key facts, Pages, Products, Services)이고, 내용은 사이트의 언어 그대로 유지됩니다. Key facts에는 설정 화면의 사업체 정보인 URL, 주소, 전화번호, 영업시간, 이메일, 업종이 들어갑니다. 사이트 유형이 온라인 쇼핑몰 또는 B2B / SaaS인 경우 영업시간은 생략되고, 대신 설정한 반품, 배송, 요금, 도입 사례 페이지가 표시됩니다.

Pages에는 최근에 수정된 공개 페이지와 게시물 30개가 표시됩니다. 특정 페이지를 빼려면 편집기의 Nurevo AEO 패널에서 "이 페이지를 llms.txt에서 제외"를 체크하세요. WooCommerce 상품은 가격 및 재고 상태와 함께 Products에, 입력한 서비스는 Services에 들어갑니다.

페이지나 설정을 저장하면 파일이 다시 생성되며 Content-Type: text/plain으로 제공됩니다. 30개를 넘는 페이지나 정책 페이지 같은 추가 줄을 넣으려면 개발자가 webmcp_canary_llms_txt_lines 필터를 사용할 수 있습니다. Nurevo AEO는 llms-full.txt를 만들지 않습니다.

게시 후 확인 방법

  1. 브라우저에서 https://your-domain/llms.txt를 엽니다. HTML이 아닌 Markdown 텍스트가 보이고 글자가 깨지지 않아야 합니다
  2. curl -I https://your-domain/llms.txt를 실행합니다. 200이 반환되고, 다른 URL로 리디렉션되지 않으며, Content-Type이 text/plain(또는 text/markdown)이어야 합니다
  3. 이름, 주소, 전화번호, 영업시간, 가격이 페이지 본문 및 구조화 데이터와 정확히 일치하는지 확인합니다
  4. 서버 로그에서 /llms.txt 요청 수와 사용자 에이전트를 집계해 어떤 봇이 가져가는지 확인합니다(0건이어도 문제는 아닙니다)
  5. Nurevo의 무료 진단으로 llms.txt를 구조화 데이터, AI 크롤러 접근 상태와 함께 확인합니다

Nurevo AEO의 AEO 점수에서 llms.txt는 100점 중 15점을 차지합니다. 파일이 존재해야 하며, 네 가지 검사 중 세 가지 이상을 통과하면 OK로 표시됩니다: 120자 이상, "# " 제목, URL 하나 이상, 주소·전화번호·영업시간 같은 사업체 정보. 이 점수는 사이트가 AI에게 얼마나 읽기 쉬운지를 측정할 뿐, AI가 여러분을 추천하는지를 측정하지는 않습니다. 실제 노출 여부를 알고 싶다면 AI 가시성 측정 방법에 따라 같은 질문을 반복하고 답변을 기록하세요. llms.txt를 추가한 뒤 나타난 변화는 대개 같은 시기에 바뀐 다른 요소와 구분할 수 없다는 점도 염두에 두세요.

게시 전 체크리스트

  1. 첫 줄이 이름을 담은 "# " 제목이다
  2. "> " 요약이 무엇을 하는 곳인지, 어디에 있는지, 누구에게 무엇을 제공하는지 설명한다
  3. 모든 사실이 페이지 본문, 구조화 데이터, Google 비즈니스 프로필과 일치한다
  4. 링크는 주요 페이지로 한정되어 있고 각각 설명이 있다
  5. noindex 페이지, robots.txt로 차단한 페이지, 깨진 링크가 없다
  6. 마케팅 문구와 AI에 대한 지시가 없다
  7. https://your-domain/llms.txt가 200을 반환하고 HTML이 아닌 텍스트를 보여 준다
  8. 파일을 제공하는 출처가 정확히 하나다(직접 만든 파일 또는 플러그인 하나)
  9. 가격이나 영업시간이 바뀔 때 업데이트할 담당자가 있다(자동 생성이라면 불필요)
  10. robots.txt가 사이트를 읽어 주기를 바라는 AI 크롤러를 차단하지 않는다

자주 묻는 질문

llms.txt는 공식 표준인가요?

아닙니다. 2024년 Answer.AI의 Jeremy Howard가 발표한 제안이며, 표준화 기구의 사양이 아닙니다. 2026년 11월 16일 기준으로 다른 사이트의 llms.txt를 사용한다고 공개적으로 밝힌 AI 검색 서비스는 찾지 못했습니다.

llms.txt가 Google 순위나 AI Overviews에 영향을 주나요?

Google은 자사 AI 기능에 노출되기 위해 새로운 AI용 텍스트 파일이 필요하지 않다고 밝혔습니다. 이 파일이 순위를 올리거나 내린다는 공식 발표도 없습니다. Google에서는 페이지 본문과 구조화 데이터가 우선입니다.

llms-full.txt도 필요한가요?

아니요. 사이트의 전체 텍스트를 담은 파일로, 대규모 문서 사이트에서 가끔 사용합니다. 사업체나 기업 사이트라면 llms.txt만으로 충분합니다. Nurevo AEO는 llms-full.txt를 만들지 않습니다.

robots.txt가 AI 크롤러를 차단하고 있어도 llms.txt는 읽나요?

llms.txt는 robots.txt를 바꾸지 않습니다. 크롤러가 차단되어 있다면 llms.txt를 포함해 아무것도 가져가지 않는다고 보세요. AI가 사이트를 읽기를 원한다면 먼저 robots.txt가 AI 검색 크롤러를 차단하고 있지 않은지 확인하세요.

제 나라 언어로 작성해도 되나요?

네. 제안에서는 언어를 정하지 않으므로 고객이 쓰는 언어로 작성하세요. Nurevo AEO는 고정된 영어 제목을 쓰고 내용은 사이트의 언어로 유지합니다.

페이지는 몇 개나 넣어야 하나요?

정해진 규칙은 없습니다. 사람들이 AI에게 여러분에 대해 묻는 질문에 답하는 페이지, 즉 회사 소개, 요금, 서비스, FAQ, 위치 정도로 한정하세요. Nurevo AEO는 최근 수정된 페이지 30개를 자동으로 넣으며, 원하는 페이지를 제외할 수 있습니다.

얼마나 자주 업데이트해야 하나요?

안에 있는 사실이 바뀌는 즉시 업데이트하세요. 직접 관리한다면 가격이나 영업시간을 바꿀 때의 업무 절차에 "llms.txt 업데이트"를 넣으세요. Nurevo AEO는 페이지나 설정을 저장할 때마다 파일을 다시 생성합니다.

사이트의 llms.txt와 구조화 데이터를 확인하세요

무료 진단으로 llms.txt 유무, 구조화 데이터, AI 크롤러 접근 상태를 회원 가입 없이 확인할 수 있습니다. WordPress라면 Nurevo AEO(무료)가 llms.txt를 만들어 줍니다. 단, AI 답변 노출을 보장하지는 않습니다.
