WordPress SEO 플러그인과 AI 검색 대응: 웹 제작사 웹사이트 12,376곳 (2026년 11월)

일본 및 기타 국가의 웹 제작사 WordPress 웹사이트 12,376곳의 홈페이지를 조사했습니다. 일본에서 가장 많이 쓰인 SEO 플러그인은 All in One SEO(35.2%), 일본 외 지역에서는 Yoast SEO(53.1%)였습니다. 일본에서 SEO 플러그인이 감지된 사이트의 19.3–22.5%가 llms.txt를 갖추고 있었던 반면, 감지되지 않은 사이트는 7.7%에 그쳤습니다.

2026-11-14 게시. 데이터 집계일 2026-11-12. 조사: Nurevo AEO(Bestie.合同会社). Nurevo는 AI 검색 최적화(AEO) 도구와 WordPress 플러그인을 판매하고 있어 이 주제에 이해관계가 있습니다.

주요 결과

  1. 일본 웹 제작사의 WordPress 사이트 2,295곳 중 All in One SEO가 35.2%(807곳), Yoast SEO가 14.4%(331곳), Rank Math가 1.7%(40곳)에서 감지되었고, 48.6%(1,115곳)에서는 어떤 플러그인도 감지되지 않았습니다. 일본 외 제작사 WordPress 사이트 10,081곳에서는 Yoast SEO 53.1%, Rank Math 22.2%, All in One SEO 6.1%였습니다.
  2. 일본의 llms.txt 도입률은 플러그인이 감지된 세 그룹에서 19.3–22.5%, 플러그인이 감지되지 않은 경우 7.7%였습니다. 일본 외: All in One SEO 51.1%, Rank Math 40.8%, Yoast SEO 30.8%, 미감지 24.2%.
  3. 어느 플러그인 그룹에서도 robots.txt로 홈페이지에 대한 AI 봇 접근을 차단한 사이트는 적었습니다(일본 0.0–1.1%, 일본 외 3.8–9.2%). 일본 외에서는 WordPress가 아닌 사이트의 차단 비율이 더 높았습니다(15.9%).

조사 방법

  1. 대상: 웹 제작사 자사 웹사이트 — 일본 3,352곳(제작사로 확인됨), 기타 국가 20,335곳, 총 23,687곳. 일반 기업이 아닙니다.
  2. 접근 가능: 15,838곳의 홈페이지를 가져올 수 있었습니다(일본 2,486곳, 일본 외 13,352곳). 이 보고서는 그중 WordPress로 판별된 12,376곳(일본 2,295곳, 일본 외 10,081곳)을 다룹니다.
  3. 수집: 각 사이트의 홈페이지, /robots.txt, /llms.txt, /llms-full.txt를 각 1회 수집(User-Agent: NurevoSurvey/1.0), 기간은 2026년 11월 초부터 11월 12일까지이며 2026-11-12에 집계했습니다.
  4. 분류 기준: WordPress = 홈페이지 HTML에 wp-content/ 또는 wp-includes/, 또는 WordPress generator 태그가 포함됨. SEO 플러그인 = yoast, rank-math(rankmath), all in one seo(aioseo), seopress, slim seo 순으로 확인해 해당 HTML에서 처음 발견된 문자열. llms.txt = HTTP 200, HTML 아님, 20자 초과. AI 봇 차단 = GPTBot, ClaudeBot, PerplexityBot, Google-Extended, CCBot, OAI-SearchBot 중 하나에 적용되는 robots.txt 규칙이 홈페이지(/)를 disallow함(최장 일치). 모수는 robots.txt가 있는 사이트입니다.
  5. 국가는 자체 수집 목록상의 국가입니다. 30곳 미만 그룹은 표시하지 않습니다(국가별 점유율은 WordPress 사이트가 100곳 이상인 국가만 표시).

플러그인별 홈페이지 항목

SEO 플러그인이 감지된 사이트에서는 JSON-LD, Open Graph, canonical 링크가 90% 이상의 사이트에 있었습니다. 차이는 llms.txt와 BreadcrumbList에서 나타났는데, Rank Math와 SEOPress 그룹에서는 BreadcrumbList가 홈페이지에 거의 나타나지 않았습니다. 각 플러그인이 기본적으로 프런트 페이지에 출력하는 내용의 차이일 가능성이 큽니다. 하위 페이지는 조사하지 않았습니다.

6개 항목은 다음과 같습니다: (1) llms.txt가 있음, (2) JSON-LD가 있음, (3) Organization 또는 LocalBusiness 타입이 있음, (4) GPTBot, ClaudeBot, PerplexityBot, OAI-SearchBot 중 어느 것도 차단하지 않는 robots.txt가 있음, (5) meta description이 있음, (6) canonical 링크가 있음. 이 조사를 위해 만든 단순 집계이며 Nurevo 제품의 0–100점 점수가 아닙니다.

이 조사 인용하기

"Nurevo AEO survey (nurevo.jp)"를 출처로 밝히고 이 페이지로 링크하면 수치와 표를 자유롭게 인용·재게재할 수 있습니다. 바로 인용할 수 있는 문장:

  1. 일본 웹 제작사의 WordPress 사이트에서 가장 많이 쓰인 SEO 플러그인은 All in One SEO(35.2%, 2,295곳 중 807곳)로, 14.4%의 Yoast SEO를 앞섰다(Nurevo AEO 조사, 2026년 11월).
  2. 일본 외 웹 제작사 WordPress 사이트의 53.1%가 Yoast SEO, 22.2%가 Rank Math, 6.1%가 All in One SEO를 사용했다(Nurevo AEO 조사, 2026년 11월).
  3. 조사 대상 중 제작사 WordPress 사이트가 100곳 이상인 13개국 모두에서 Yoast SEO가 가장 많이 쓰인 SEO 플러그인이었다(42.7–58.1%)(Nurevo AEO 조사, 2026년 11월).
  4. All in One SEO를 사용하는 일본 외 웹 제작사 WordPress 사이트의 51.1%가 llms.txt를 갖추고 있었던 반면, Yoast SEO 사용 사이트는 30.8%였다(Nurevo AEO 조사, 2026년 11월).

한계

  1. 플러그인은 홈페이지 HTML에 남은 문자열로 판별했습니다. 플러그인 이름을 숨기는 설정이나 이를 제거하는 캐싱·압축(minification)은 "미감지"로 이어지며, 여러 플러그인의 흔적이 있는 사이트는 먼저 확인한 것으로 집계했습니다(Yoast SEO, Rank Math, All in One SEO, SEOPress, Slim SEO).
  2. 확인한 플러그인은 다섯 개뿐입니다. 그 외 플러그인(일본에서 쓰이는 SEO SIMPLE PACK 등)과 테마에 내장된 SEO 기능은 "미감지"로 집계되며, 이것이 일본의 높은 수치를 일부 설명할 가능성이 큽니다.
  3. 홈페이지만 조사했습니다. robots.txt는 /에 대해서만 판정했으며, 부분 차단이나 방화벽·CDN에 의한 차단은 집계하지 않았습니다.
  4. 모집단은 일반 기업이 아니라 웹 제작사 자사 웹사이트입니다. 플러그인과 항목 간의 관계는 동시 발생일 뿐 플러그인이 원인이라는 증거가 아닙니다(SEO에 더 투자하는 제작사가 플러그인 설치와 다른 작업을 함께 할 수 있음).
  5. 사이트당 1회 수집했으며 접근할 수 없는 사이트는 제외했습니다. llms.txt는 존재 여부만 확인했고 품질은 확인하지 않았습니다.

우리의 해석(의견)

아래는 조사 결과가 아닌 우리의 의견입니다. 모든 SEO 플러그인 그룹에서 구조화 데이터, canonical 링크, Open Graph 같은 기본 항목은 대체로 갖춰져 있었습니다. 플러그인 간 차이는 llms.txt 같은 새로운 항목과 홈페이지에 어떤 구조화 데이터를 출력하는지에서 나타납니다. SEO 플러그인이 감지되지 않은 WordPress 사이트와 WordPress가 아닌 사이트는 기본 항목이 빠진 경우가 더 많으므로, 먼저 이 부분을 점검해야 한다고 생각합니다. 이 중 어느 것도 AI 답변 노출을 보장하지 않습니다(다른 조사에서는 사이트 내 신호와 노출 사이에 관계가 나타나지 않았습니다).

내 사이트나 고객 사이트 점검하기

무료 점검은 약 1분 만에 llms.txt, 구조화 데이터, AI 크롤러 접근 상태를 보여 줍니다. WordPress에서는 Nurevo WebMCP 플러그인이 llms.txt를 게시하고, Yoast SEO, Rank Math 또는 All in One SEO가 이미 출력하는 구조화 데이터에 누락된 사업 정보를 중복 없이 추가합니다. 고객 사이트 전반에 도입하려는 제작사는 파트너 프로그램을 확인하세요.

자주 묻는 질문

일본 웹 제작사가 가장 많이 쓰는 SEO 플러그인은?

이번 조사에서는 All in One SEO입니다. 일본 웹 제작사 WordPress 사이트 2,295곳 중 807곳(35.2%)이었습니다. Yoast SEO는 331곳(14.4%), Rank Math는 40곳(1.7%)이었습니다(2026년 11월).

다른 나라는 어떤가요?

일본 외 제작사 WordPress 사이트 10,081곳에서 Yoast SEO 53.1%, Rank Math 22.2%, All in One SEO 6.1%, SEOPress 0.8%였습니다. WordPress 사이트가 100곳 이상인 13개국 모두에서 Yoast SEO가 1위입니다.

SEO 플러그인을 쓰면 llms.txt나 AI 대응이 좋아지나요?

이 조사는 인과가 아닌 동시 발생을 보여 줍니다. 일본에서 llms.txt는 플러그인이 감지된 사이트의 19.3–22.5%, 감지되지 않은 사이트의 7.7%에 있었으며, 이 중 어느 것도 AI 답변 노출을 보장하지 않습니다.
