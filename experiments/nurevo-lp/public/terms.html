サービス名: Nurevo（AI検索対策(AEO)・WebMCPサービス）

本利用規約（以下「本規約」）は、Bestie.合同会社（以下「当社」）が提供するAI検索対策(AEO)・WebMCPサービス「Nurevo」（以下「本サービス」）の利用条件を定めるものです。利用者（以下「ユーザー」）は、本規約に同意のうえ本サービスを利用するものとします。

第1条（定義）

  1. 「店舗情報」とは、店舗名・住所・電話番号・営業時間・業種・位置情報・価格帯等、本サービスで取り扱う情報をいいます。
  2. 「タグ」とは、本サービスが提供する、ユーザーのウェブサイトに設置するスクリプトをいいます。
  3. 「ホストページ」とは、当社が nurevo.jp 配下で生成・提供する店舗情報ページをいいます。
  4. 「紹介パートナー」とは、当社の定める条件のもとで本サービスを紹介し、紹介報酬を受け取る者をいいます。

第2条（登録）

  1. ユーザーは、当社所定の方法により登録を行うものとします。
  2. 当社は、登録内容に虚偽がある場合等、当社が不適当と判断した場合、登録を拒否または取り消すことができます。

第3条（本サービスの内容）

  1. 本サービスは、店舗情報を構造化データ（schema.org）等の形式で出力し、AI検索エンジン等に読み取り可能な状態にすることを支援します。
  2. 店舗情報の取得には、Google の Places API 等の外部サービスを利用する場合があります。
  3. 当社は、特定のAIサービスでの表示・掲載・上位化その他の成果を保証しません。

第4条（料金および支払い）

  1. 本サービスの月額料金は 3,000円（税込）とします。無料お試し期間はありません。
  2. 料金は月額前払いとし、決済事業者（Stripe）を通じて支払うものとします。
  3. 当社は、料金を変更する場合、事前に通知します。
  4. 既に支払われた料金は、当社に重大な帰責事由がある場合を除き、返金しません（日割り返金を含みません）。

第5条（解約）

  1. ユーザーは、当社所定の方法により、いつでも解約できます。
  2. 解約は当該請求期間の末日をもって効力を生じ、当該期間分の料金は返金されません。

第6条（禁止事項）

ユーザーは、次の行為をしてはなりません。

  1. 虚偽の店舗情報を登録する行為
  2. 第三者の権利を侵害する行為
  3. 本サービスを不正に利用する行為、法令に違反する行為
  4. AI検索エンジン等に対し、実体と異なる情報を意図的に読み取らせる行為（クローキング等）

第7条（提供の停止・中断）

当社は、保守、障害、外部サービスの停止その他やむを得ない事由がある場合、事前の通知なく本サービスの全部または一部を停止・中断できます。

第8条（免責）

  1. 当社は、本サービスにつき、特定目的への適合性、成果、正確性、完全性を保証しません。
  2. 当社は、本サービスの利用または利用不能により生じた損害について、当社の故意または重過失による場合を除き、責任を負いません。
  3. 当社が責任を負う場合でも、賠償額は、当該事由が生じた月にユーザーが当社に支払った料金額を上限とします。

第9条（知的財産権）

本サービスおよびホストページに関する知的財産権は当社または正当な権利者に帰属します。店舗情報に関する権利はユーザーまたは当該店舗に帰属します。

第10条（個人情報）

当社は、別途定めるプライバシーポリシーに従い、個人情報を取り扱います。

第11条（規約の変更）

当社は、必要に応じて本規約を変更できます。変更後の規約は、当社が定める方法で通知または本サイトに掲示した時点から効力を生じます。

第12条（準拠法・管轄）

本規約は日本法に準拠し、本サービスに関する紛争は、東京地方裁判所を第一審の専属的合意管轄裁判所とします。
