Install

導入方法

01

WordPress管理画面からNurevoプラグインをインストールします。

02

設定画面で「無料サイトキーを発行」を押します。キーは自動で発行・保存されます。

03

設定画面でNurevoタグを有効化します。

04

WordPress管理画面で統計と改善提案を確認できます。

WordPress公式ディレクトリ（準備中） 
<script src="https://nurevo.jp/tag.js" async data-webmcp-site-key="YOUR_SITE_KEY"></script>
  1. サイトURLとメールアドレスを入力してキーを発行します。
  2. 表示されたスニペットを </head> の直前に貼ります。
  3. Nurevoダッシュボードで、キー発行に使ったメールアドレスを入力します。
  4. 届いたリンクからログインし、統計と改善提案を確認します。

HTMLを直接編集できる場合は、この方法が最も速く確実です。

<script src="https://nurevo.jp/tag.js" async data-webmcp-site-key="YOUR_SITE_KEY"></script>
  1. サイトURLとメールアドレスを入力してキーを発行します。
  2. GTMでカスタムHTMLタグを作成し、スニペットを貼ります。
  3. トリガーに All Pages を選びます。
  4. 保存後、必ず「送信」から「公開」まで行います。
  5. Nurevoダッシュボードにログインし、統計を確認します。
